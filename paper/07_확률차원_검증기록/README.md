## 38장의 내용별 입구

38장 번호와 절 번호는 기존 인용을 위해 유지했다. 아래 절 번호로 본문에서 찾는다.

| 절 | 내용 | 현재 용도 |
|---|---|---|
| §1–10 | 차원 측도·UV 경계·유한 probe | 정의와 반례, 조건부 연결 |
| §11–20 | 물질 결합·중력·BAO·원자·screening | 특정 결합 가정의 실패 경계 |
| §21–23 | 공정한 비교·네 그룹·PMNS | 관측 평가 설계와 기존 가지 판정 |
| §24–26 | flavor 응답·Majorana·중성미자 응력 | 입력된 행렬의 응답과 보존 검산 |
| §27 | 준비도·공개 자료 감사 | 자료의 실제 범위와 미완성 항목 |

실행 코드는 저장소의 `verify/dimension_*.py`, 검증은 `tests/test_dimension_*.py`에 유지한다. 이 목록은 구현 재사용을 위한 것이며 모형 채택 선언이 아니다.
