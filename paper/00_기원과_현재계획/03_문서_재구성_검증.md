# 문서 재구성 검증 기록

2026-09-09. 이 기록은 문서 이동과 새 식의 기초 대수 검산에 관한 것이며 물리적 관측 검증이 아니다.

- 01–36장과 38장, 총 37개 장을 중복 없이 보존했다. 삭제 상태였던 37장은 복원하지 않았다.
- 8개 주제 폴더와 각 폴더의 읽기 안내를 만들었다. 루트에는 최신 읽기 지도와 용어사전을 유지했다.
- 이전 읽기 지도와 누적 현황을 검증기록 폴더로 옮겼다. 현재 원장 §2에는 새 연구 표적을 적었다.
- 이동 전후 경로를 대조한 결과, 옛 평면 장 경로를 가리키는 Markdown 링크와 새 입구 문서의 깨진 링크는 각각 0개다. 이동으로 새로 깨진 링크는 없다.
- 저장소 Markdown 대상 감사에서 누락 링크는 작업 전 119건, 최종 점검 106건이었다. 기존에 삭제된 원장·코드 등을 가리키는 링크가 남아 있다. 이를 문서 복원으로 임의 해결하지 않았다.
- `tests/test_canonical_document_policy.py`는 작업 전후 모두 7개 통과, 2개 실패였다. 실패 항목은 기존 수식 구분자와 누락 링크 검사다. 전체 문서 검사가 통과했다고 보고하지 않는다.
- 세 채널 행렬의 고유값, 첫 두 모멘트, 행렬식 항등식을 고정 난수 시드의 30개 안정 영역 대조점에서 확인했다. 최대 척도 정규화 오차는 약 $1.94\times10^{-15}$다. 이 검산은 공급한 행렬의 대수 관계만 확인한다.
