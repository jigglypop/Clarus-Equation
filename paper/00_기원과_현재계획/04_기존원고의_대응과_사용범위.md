# 기존 원고의 대응과 사용 범위

기존 `1_강의`부터 `5_유도`까지는 여러 차례 수정된 원본이다. 이 문서는 그 내용을 현재 논문의 근거로 어디까지 사용할지 정한다. 원문 52개는 현재 작업본을 그대로 참조 폴더에 보존하고, 경로 변경에 필요한 링크만 수정했다. 과거 Git 판본으로 되돌리거나 조건부 정리를 삭제하지 않았다.

## 1. 현재 장과 원본의 관계

현재 본문은 관계 상태·사영·공통 스펙트럼·계량 응답을 연결한다. 기존 강의의 Hodge 대응·Poisson 고정점, 상수 문서의 경험식, 실수 singlet-portal EFT는 각각 별도의 가정에서 성립한다. 이들을 차례로 나열해 새 공통 스펙트럼의 유도가 완성됐다고 쓰지 않는다.

## 2. 지금도 사용할 수 있는 수학

연속 곱함수의 지수형, 명시한 분지과정의 최소 소멸 고정점, 3차원 Hodge 대응은 적힌 전제에서 읽는다. 이 결과를 물리 공간의 유일한 발생이나 관측 밀도의 결정으로 확대하지 않는다. 현재의 스펙트럼 차원과 과거의 형식 성분 수 역시 다른 정의다.

[Master action 유도](../참조/5_유도/06_Master_Action_Universal_Derivation.md)는 field content·대칭·경계조건을 고정한 변분과 일관된 축약을 제공한다. 이 원칙은 현재 공통 작용에도 적용한다. 그러나 기존 scalar–tensor 작용과 현재 세 복소 스칼라의 질량행렬은 같은 모형이 아니므로, 계수와 진공 조건을 자동으로 가져오지 않는다.

[암흑에너지 유도](../참조/5_유도/04_Dark_Energy_Derivation.md)의 FLRW 보존식과 canonical scalar의 범위는 표준 기준선이다. 일반 계량 변분을 생략하고 상대 루프 퍼텐셜의 값을 곧바로 절대 진공밀도로 넣는 근거가 아니다. [블랙홀 분기](../참조/5_유도/07_Black_Hole_Derivation.md)도 상수장 분기의 존재 조건 아래에서만 사용한다.

## 3. 현재 서술로 바꾸어 읽어야 하는 부분

[선택과 접힘](../참조/5_유도/00_선택과_접힘.md)은 추상 기록, 방출 에너지 장부, 공급한 위상공간 표지를 구분한다. 이 구분은 현재 비동기 관계 틱에서도 유지한다. 기록이나 상태의 보완 성분이 선택된 가지에 별도의 중력원으로 자동 가산된다는 결론은 없다.

[극장 에너지 장부](../참조/5_유도/08_극장과_좌석_에너지장부.md)와 [양자 개장](../참조/5_유도/09_양자_극장_개장/00_읽기_순서.md)은 초기 자료·질량 변화·입자 생성의 조건부 비교로 읽는다. 점유수의 보존, 입자 생성이 없는 단열 근사, 실제 에너지 공급원의 포함 여부를 구분해야 현재 공통 스펙트럼의 점유 방정식과 연결할 수 있다.

기존 상수 문서에서 입력한 결합·질량·허블 값은 새 이론의 산출값으로 다시 세지 않는다. 특히 [H0 재현성 원고](../참조/3_상수/12_H0_source_role_readout_paper_draft.md)는 실행 패키지 부재와 선형 모형의 식별 조건을 명시한 미완성 문서다. 폴더 정리로 그 자료가 생기거나 관측 문제가 해결되는 것은 아니다.

공학·단백질·뇌·LLM의 functional은 목적과 상태공간이 다른 응용이다. 계산 안정성이나 모델 성능을 개선했더라도 QFT–GR 연결, 암흑부문의 정체, 힘의 통합에 대한 증거로 옮기지 않는다.

## 4. 앞으로 원고를 수정하는 위치

현재 주장과 설명은 [통합 논문](../CE_통합_논문.md) 및 `paper/00_`~`07_`의 해당 장에서 수정한다. 참조의 원문은 상세 증명·이전 가정·조건부 응용을 추적하는 자료다. 새로운 계산을 과거 원본에 누적해 현재 본문을 둘로 나누지 않는다.

원문의 오류를 고칠 때에는 수정할 수식과 전제를 명시한다. 단지 오래된 모형이라는 이유로 반증됐다고 표시하지 않으며, 내용·수치의 변경과 경로 정리를 구분한다. 이 정리는 새 관측 적합이나 물리적 지위의 승격을 수행하지 않는다.

## 5. 이번 정리의 검증

이동 전 작업본을 기준으로 원문 52개를 대조했다. 상대 링크와 저장소 경로를 새 위치로 바꾼 결과가 현재 파일과 일치한다. 신규 안내 문서는 별도로 작성했으며, 기존의 수식·수치·조건부 판정은 변경하지 않았다.

문서 검사 도구 다섯 개의 Python 구문과 저장소 루트·원장 경로를 확인했다. 문서 정책 검사 9개 중 7개가 통과했다. 전체 수식 표기와 전체 상대 링크 검사는 기존 다른 원고의 표기 및 미확보·삭제된 대상 문제로 통과하지 않았지만, 이동 전후 비교에서 이번 재배치로 추가된 끊어진 링크는 없었다. 이 검증은 원문 보존과 경로 변경에 관한 것이며 물리 계산이나 관측 적합의 재실행은 아니다.
