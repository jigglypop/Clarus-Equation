# 원본 묶음 재현과 전체 거리 오차

## 1. 원본 검증과 실행 범위

압축파일 SHA-256은 `5de467e4b9964ff227b9ec9c8bb82c64a17183a4c754e6ee5f142d758f75ce91`이다. 내부 manifest의 29개 파일을 크기와 SHA-256으로 대조했고, manifest 외의 누락·추가 파일이 없음을 확인했다. 실행은 별도 `_workspace/ce_obs32_reproduction/CE-OBS32`에서 수행했다. 원본 ZIP은 변경하지 않았다.

```powershell
$env:OPENBLAS_NUM_THREADS='1'
.venv/Scripts/python.exe -W error _workspace/ce_obs32_reproduction/CE-OBS32/observable_bridge.py
.venv/Scripts/python.exe -W error _workspace/ce_obs32_reproduction/CE-OBS32/postcomparison_diagnostics.py
```

두 명령 모두 종료 코드 0이다. 실행 환경은 Python 3.14.4, NumPy 2.3.5, SciPy 1.18.0이다. 실행 후 코드·계약·자료·출처 문서 15개의 해시도 원본과 일치했다. 실행 폴더의 기존 manifest는 첨부 당시의 결과를 기록하므로, 재생성된 결과의 차이는 [로컬 재현 기록](../../verify/ce_obs32_reproduction.json)으로 구분한다.

이 묶음에는 관측 코드와 실시간 연구 보고서·R01–R12 원장 사본도 들어 있다. 실시간 양자 생성 코드 전체가 포함된 것으로 확대하지 않는다.

## 2. 무엇을 같은 입력으로 계산했는가

원본 계약의 세 복소 보손·등점유·차가운 수보존 물질·평탄 후기 배경을 유지했다. r=0.15, 0.35와 초기 θ=0.1, 0.3, 0.5의 여섯 점, 정칙 선형 가지의 초기 속도, $f/M_P=1$, 물질 계수 $3/7$, 결합 물질 비중 0.84를 바꾸지 않았다. 관측값을 배경 solver에 넣거나 CE 매개변수를 새로 적합하지 않았다.

기준은 동일한 밀도 계수의 θ=0 해이며 Ωm=0.3 평탄 ΛCDM 거리와 일치한다. 기준과 모든 후보에서 공통 눈금 $A=c/(H_0r_d)$ **한 개씩**만 전체 거리 자료에 적합한다. 이 A는 관측 보정값이며 절대 H0나 음향눈금의 예측이 아니다.

## 3. 원본과 독립 검산의 일치

환경 및 검산 오차 자체를 제외하고 대조한 주요 수치 필드 236개의 최대 절대차는 $4.64\times10^{-13}$ 미만이었다. 여섯 시간 이력도 각각 2001×9 전체 배열을 대조했다. 비교 허용치는 상대 10⁻⁸, 절대 10⁻⁹이며 원본과 일치했다. 수치 필드 수를 독립적인 물리 성과의 개수로 세지 않는다.

원본 검산은 양의 운동량 적분 대 로그합, 퍼텐셜 미분, 총 에너지 연속식, H 미분, DOP853 대 Radau, 우주시간으로 별도 적분한 배경을 포함한다. 이번 실행의 DOP853–Radau 거리비 최대차는 $6.07\times10^{-14}$ 미만, 독립 우주시간 계산의 최종 θ·속도·H 상대차는 $5.28\times10^{-8}$ 미만이다.

추가로 저장된 13개 예측값과 원자료에서 Cholesky 방식으로 A를 다시 적합하고 χ²를 다시 계산했다. 원본의 역공분산 계산과 10⁻⁹ 이내로 일치했다. 이 검산은 배경·통계 구현을 확인하며 해당 모형의 관측 성공을 증명하지 않는다.

## 4. 전체 13거리에서 오차는 감소하지 않았다

표준화 RMSE는 $R=\sqrt{\chi^2/13}$이다. 이는 자유도 보정된 reduced χ²가 아니다.

따라서 이 여섯 고정 시험점은 전체 거리에서 개선을 보이지 않는다. 후보 전체에 대한 전역 기각은 아니다. 원본 사후 진단에서 θ² 방향의 작은 변위가 전체 χ²에 주는 기울기도 두 r 모두 양수였으나, 이는 θ=0.1에서 추정한 국소 방향이며 모든 초기 상태를 검사한 결과가 아니다.

여섯 거리비만 사용하는 보조 진단에서는 구분이 필요하다. 1차 오차 전파 점수는 여섯 점 모두 증가하지만, 각 적색편이의 진폭 여섯 개를 제거한 별도 profile 점수는 θ=0.1에서 조금 감소한다. 후자는 전체 13거리에서 A 한 개를 적합하는 평가와 다르다. 이 작은 감소를 선택해 전체 관측 개선으로 보고하지 않는다.

## 5. 다음 계산에서 유지할 경계

원본은 특정 후기 초기상태에서의 관측 진단이다. 생성에서 후기까지의 상태 선택, 절대 진공항과 암흑물질량, 재결합·CMB·성장, 물질·힘의 완전한 matching 및 독립 검증은 여전히 남아 있다. 상호작용하는 암흑부문에 표준 압축 BAO template을 적용하는 타당성도 별도 검사다.

앞선 하전 짝·홀로모픽 블록 계산은 이 중성 배경에 이미 포함된 수정이 아니다. 두 결과를 연결하려면 같은 작용에서 추가 진공항·운동항·물질 응답을 다시 유도해야 하므로, 이번 거시 점수와 앞선 뮤온 점수를 합산하지 않았다.

이제 최신 원본의 전체 거리 재현은 가능하며 파일 업로드를 다시 요청할 이유는 없다. 현재의 정확한 판정은 **원본 재현 완료, 여섯 고정 후보의 거리 오차 증가, 전체 공동 RMSE 개선 미완성**이다.
