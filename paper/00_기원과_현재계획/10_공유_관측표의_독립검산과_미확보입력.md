# 공유 관측표의 독립 검산과 미확보 입력

**후속 상태:** 사용자가 원본 ZIP을 제공했고 [전체 배경·13거리 재현](11_원본묶음_재현과_전체거리_오차.md)을 완료했다. 아래 미확보 서술은 첨부 전 감사 이력이며 현재의 파일 대기 조건이 아니다.

2026-09-09. **[관측 비교·미완성]** 원래 공유 대화에 표시된 CE 거리비 여섯 개를 공개 DESI DR2 평균·공분산으로 독립 검산했다. 이 표시 시험점의 표준화 RMSE는 1.06950으로, 고정 Ωm=0.3 평탄 ΛCDM의 0.98874보다 크다. 원래 CE 배경 코드를 재실행한 것은 아니며, 전체 공동 RMSE 감소는 확인되지 않았다.

## 1. 다시 확인한 목표와 출처

[첫 공유 대화](https://chatgpt.com/share/6aa0e93e-2dec-83ee-b20a-d1ee57fa611d)는 8개 성공 조건 아래 R01–R12의 미완성 작업을 구분한다. 응답자는 이를 서로 독립적인 20개 완료 조건으로 더하지 않는다고 명시한다. 현재 과제에서 확인해야 하는 전체 범위는 다음과 같다.

| 범위 | 완료를 보일 증거 | 현재 확인 |
|---|---|---|
| R01–R03: 관계·접힘, 에너지 원천, 계량과 표준 극한 | 같은 미시 법칙에서 장·상태·계량까지 이어지는 유도 | 공급한 스펙트럼과 계량 아래의 조건부 결과만 존재 |
| R04: 네 힘과 물질 | 군·표현·질량·혼합·결합의 공통 유도와 관측 | 보정 관계만 있으며 공통 위상 문턱은 세 역결합 차이를 줄이지 않음 |
| R05–R07: 계수·절대 진공·상태 | 외부 정규화와 상태 입력을 예측으로 대체한 계산 | s, ε, f, 진공 기준, 상태 및 새 F항이 아직 입력 |
| R08: 정칙성·안정성·인과성 | 실제 사용 영역의 재규격화·근사·상호작용 검사 | 개별 적분·대수 검산을 통과했으나 전체 작용 검사는 미완성 |
| R09–R11: 암흑물질·가속·섭동·재결합·CMB·허블 | 같은 초기 상태에서 모든 관측으로 이어지는 전방 계산 | 서로 다른 부분 계산이 있으며 원래 최신 실행 묶음은 미확보 |
| R12: 독립 관측과 복잡도 | 동결된 공통 후보의 독립 자료에서 전체·각 부문 오차 감소 | 뮤온 구성항의 작은 산술 감소만 있으며 이번 거리비는 증가 |

최근의 진공항·짝·질량 블록 검사는 후보를 제한하는 계산이다. 이를 원래 관측 목표의 달성률이나 원리의 유도로 세지 않는다. 더 많은 임의 장·대칭을 추가하는 것만으로 목표가 가까워진다고 가정하지 않는다.

## 2. 실제 자료를 다시 확보했다

별도 로컬 `ce-cosmo` 작업본에서 DESI DR2 자료를 찾았다. 이후 [배포 평균](https://raw.githubusercontent.com/CobayaSampler/bao_data/v2.6/desi_bao_dr2/desi_gaussian_bao_ALL_GCcomb_mean.txt)과 [배포 공분산](https://raw.githubusercontent.com/CobayaSampler/bao_data/v2.6/desi_bao_dr2/desi_gaussian_bao_ALL_GCcomb_cov.txt)을 원격에서 다시 받아, 기존 로컬 파일 및 SHA-256과 바이트 단위로 일치함을 확인했다. 현재 저장소의 [자료 manifest](../../benchmarks/cosmology/desi_dr2/manifest.json)에 출처와 해시를 남겼다.

13개 원래 관측값의 순서는 보존했다. 특히 z=2.33은 DH 다음 DM 순서이므로 위치를 고정해 추정하지 않고 관측량 이름으로 짝지었다. 원래 13×13 공분산의 유한성·대칭·양의 정부호도 확인했다.

이번 진단은 각 짝의 $F_{AP}=D_M/D_H$ 여섯 개다. BGS의 DV 한 점은 비율 짝이 없어 이 진단에서 채점하지 않았으며, 원자료에는 보존했다. 따라서 여섯 비율 결과를 전체 13거리 likelihood라고 부르지 않는다.

$$
J_{i,M}=1/D_{H,i},\qquad J_{i,H}=-D_{M,i}/D_{H,i}^2,
\qquad C_{AP}=JC_{13}J^T.
$$

비율 공분산은 1차 오차 전파이며 정확한 비율 확률분포가 아니다. 공유 대화에 표시된 관측 비율·오차가 이 계산과 표시 자리에서 일치했다.

## 3. 실제 계산한 오차

CE 예측값은 공유 대화의 r=0.35, 초기 θ=0.5 표에 표시된 소수 다섯 자리 값이다. 원래 배경해의 모든 매개변수와 실행 패키지를 확보한 것이 아니므로 해당 숫자를 다시 생성했다고 하지 않는다.

| 비교 | χ² | 표준화 RMSE = √(χ²/6) |
|---|---:|---:|
| 공유 표의 CE 예측 | 6.86293222 | 1.06949616 |
| 평탄 ΛCDM, Ωm=0.3 고정 | 5.86561399 | 0.98873775 |
| 평탄 ΛCDM, Ωm 한 개를 같은 자료에 적합 | 5.85863460 | 0.98814933 |

마지막 적합값은 Ωm=0.29852535다. 적합과 고정 비교를 분리하며, 이 사후 비교로 독립 예측력을 입증하지 않는다. CE 표와 고정 기준의 RMSE 차이는 **+0.08075841**, 적합 기준과의 차이는 **+0.08134683**이다. 오차가 감소하지 않았다.

각 CE 표 숫자의 반올림 폭을 ±5×10⁻⁶로 두면 RMSE 변화의 보수적 상한은 $5\times10^{-6}/\sqrt{\lambda_{min}(C_{AP})}=0.00029225$ 미만이다. 따라서 표시 정밀도만으로 위 비교의 부호가 바뀌지는 않는다. 전체 이론 불확도나 후보 자유도의 비용을 계산한 결과는 아니다.

같은 잔차의 Cholesky 계산과 공분산 선형계 풀이를 대조했다. [코드](../../verify/shared_desi_ap_audit.py), [전체 결과](../../verify/shared_desi_ap_audit.json)는 다음 명령으로 재현한다.

```powershell
.venv/Scripts/python.exe -W error verify/shared_desi_ap_audit.py
```

## 4. 원래 계산을 이어가기 위해 빠진 파일

공유 대화는 다음 파일을 sandbox 첨부로 제공했다고 표시하지만, 현재 작업본·주변 CE 저장소·Downloads에서 해당 이름의 파일을 찾지 못했다. 공개 HTML에는 sandbox 링크가 있으며 실제 묶음의 바이트는 포함되지 않았다.

- `CE_observation_prediction_bundle_2026-09-09.zip`: 전체 코드·관측자료·공분산·여섯 시험점·검증 결과
- `CE_realtime_quantum_gr_2026-09-09.zip`: 실시간 양자상태·계량 실행과 시간 이력
- `CE_remaining_conditions_register_2026-09-09.json`: R01–R12의 출처와 종료 기준 원장

첫 묶음이 우선 필요하다. 이것이 확보되면 실제 배경 생성부터 전체 13거리 비교를 재실행하고, 이전 공유 결과와의 차이 및 누락된 물질·상태 입력을 확인할 수 있다. 위 원문이 밝히듯 최신 첨부 계산은 원격 30장 커밋에 게시되지 않았으므로 과거 커밋의 코드를 같은 실행물로 대체하지 않는다.

**목표는 계속 미완성이다.** 이번 검산으로 원래 표시된 거시 시험점에서 개선이 없다는 증거를 추가했다. 새 뮤온 후보의 점수와 이 CE 표를 합쳐 공동 RMSE로 만들지 않는다. 실제 공통 작용·상태와 전체 관측 연결은 별도로 완성해야 한다.
