# 공통 참고문헌과 외부 검증 기준

이 참고문헌은 본문에서 쓰는 외부 문헌을 정의·정리·외부입력·비교·배경의 source role로 구분해 연결한다. 인용은 표준 결과의 출처 또는 데이터 provenance를 제공하지만, CE의 채택 공리·새 bridge·물리 해석을 그 자체로 증명하지 않는다.

독자는 본문에서 처음 등장한 식·가정·외부 수치를 확인할 때 해당 절의 역할을 먼저 읽고 이 목록으로 돌아온다. 수학 문헌은 조건부 정리의 전제, 관측 문헌은 비교 입력, 배경 문헌은 맥락을 제공하며 서로의 지위를 대체하지 않는다.

이 목록은 01–14장에서 사용하는 표준 결과와 관측 비교의 최소 출처다. 수치에는
데이터 판본, 재규격화 scheme/scale 및 신뢰수준을 함께 적는다. 외부 수치를 입력한
계산은 독립 예측으로 세지 않는다.

## 사용 원칙

인용은 주장 유형에 맞게 source role과 연결 문장을 갖춰야 하며, 정의·정리·외부입력·비교·배경을 혼동하지 않는다. 인용된 관측값은 증명이 아니고, 인용된 표준 정리는 본문에 없는 가정을 보충해 주지 않는다.

- CODATA와 PDG의 오차보다 큰 잔차를 가진 식은 “정확한 예측”으로 표시하지 않는다.
- 서로 다른 scale 또는 scheme의 결합상수와 running mass를 직접 비교하지 않는다.
- 정본에서 제거한 부모 명제의 재도입 방지 증거는 코드 내부 immutable
  regression witness로만 보존하며, 후속 장의 메커니즘에 사용하지 않는다.
- 원 논문에 없는 loop factor, phase-space factor 또는 transport coefficient를 표준식처럼
  사용하지 않는다.
