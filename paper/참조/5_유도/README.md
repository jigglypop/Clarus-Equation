# 상세 유도 원본

선택과 접힘, 에너지 장부, 변분·축약과 조건부 우주론을 보존한다. 기록에서 에너지 원천으로 가는 추가 사상과 scalar–tensor의 선택을 구분하며, 이미 공급한 작용의 해를 시공간이나 절대 진공값의 기원으로 확대하지 않는다.

이 묶음의 현재 역할은 [기존 원고 대응표](../../00_기원과_현재계획/04_기존원고의_대응과_사용범위.md)에서 확인한다. 현재 서술은 [통합 논문](../../CE_통합_논문.md), 전체 참조는 [참조 안내](../README.md)를 따른다.
