# 참조 원고 안내

이곳에는 현재 논문의 상세 근거, 이전 구성의 원본, 독립 응용을 보존한다. 현재 연구의 입구는 [통합 논문](../CE_통합_논문.md)과 [장별 읽기 지도](../00_읽기_지도.md)다. 참조에 옮겼다는 사실은 해당 수학을 기각했다는 뜻이 아니다.

## 이전 구성의 원본

| 묶음 | 읽는 목적 |
|---|---|
| [1 강의](1_강의/README.md) | 연역·귀납·형식 기호의 구분 |
| [2 경로적분과 응용](2_경로적분과_응용/README.md) | 조건부 수학·EFT와 문제별 한계 |
| [3 상수](3_상수/README.md) | 외부 입력·경험식·모형별 산출의 구분 |
| [4 공학적 활용](4_공학적_활용/README.md) | 설계 가정과 독립 응용 |
| [5 유도](5_유도/README.md) | 기록·에너지·변분·우주론의 상세 계산 |
| [리만·등호이전](리만과_등호이전.md) | 수론 기반 계산과 후보공간·농축 수학 |

[기존 원고 대응표](../00_기원과_현재계획/04_기존원고의_대응과_사용범위.md)는 각 원본이 현재 본문의 어떤 논증을 보조하는지 설명한다. 원문의 국소 번호는 이전 구성의 식별자이며 현재 논문의 장 순서가 아니다.
