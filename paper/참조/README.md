# 참조 원고 안내

이곳에는 현재 논문의 상세 근거, 이전 구성의 원본, 독립 응용을 보존한다. 현재 연구의 입구는 [통합 논문](../CE_통합_논문.md)과 [장별 읽기 지도](../00_읽기_지도.md)다. 참조에 옮겼다는 사실은 해당 수학을 기각했다는 뜻이 아니다.

- 공통 스펙트럼 재현기록(`공통스펙트럼_재현기록.json`): 현재 체크아웃에서 미확보
- [이전 전체 안내](이전_연구목차/논문_이전_안내.md): 재구성 전 문서 지도와 조건부 모형 요약
- [형식적 수학 모델](형식적_수학_모델과_증명.md): 별도 형식 구조의 정의와 가정
