# 강의 원본

연역·귀납·형식 기호에 관한 이전 강의 세 편을 보존한다. 곱적 함수·Hodge 대응·Poisson 고정점의 수학과 관측량으로의 물리 사상을 구분해 읽는다. 현재 공통 스펙트럼 후보가 이 강의의 모든 연결을 유도했다는 뜻은 아니다.

이 묶음의 현재 역할은 [기존 원고 대응표](../../00_기원과_현재계획/04_기존원고의_대응과_사용범위.md)에서 확인한다. 현재 서술은 [통합 논문](../../CE_통합_논문.md), 전체 참조는 [참조 안내](../README.md)를 따른다.
