# 1장 서론

이 논문은 강한 결합 상수 $\alpha_s(M_Z)$ 하나를 연속 입력으로 두고, 입자물리의 결합·섞임·질량비와 우주론의 성분·팽창률·음향 눈금을 같은 규칙으로 계산하는 이론을 제시한다. 출발점은 렌더링 가설이다. 물리적 실재는 1차원, 2차원, 3차원의 순서로 확정되고, 각 단계에서 살아남는 성분이 관측값을 정한다는 가설이다. 양자·입자 17행과 우주론 22행(BAO 13성분 포함)을 함께 채점한 표준화 잔차의 공동 RMSE는 0.834이고, $3\sigma$를 넘는 행은 없다. 같은 행에서 표준모형과 ΛCDM을 합친 기준 모형은 1.442다. 그러나 규칙의 상당수는 채점 자료를 본 뒤 정해졌고, 이론은 연구 목표 계약의 두 검증 조건을 아직 충족하지 않는다. 이 장은 문제와 판정 기준, 가설의 윤곽, 결과와 그 한계, 논문의 구성을 차례로 제시한다.
