# 1.5 논문의 구성

## 1.5.1 장 구성

2장은 렌더링 공리와 코어 식을 세운다. 3장은 공리에서 게이지군과 한 세대의 물질 구조를 얻는다. 4장은 쿼크와 렙톤의 섞임과 CP 위상을, 5장은 전자약 결합·렙톤 질량비·전약 계층·중성미자 질량을 계산한다. 6장은 기록 계보의 가지치기와 경주에서 우주 성분과 Higgs 질량을 얻는다. 7장은 빛·중력·지평선, 8장은 시간축 기울기와 허블 판독·음향 눈금, 9장은 급팽창·암흑에너지·구조 성장을 다룬다. 10장은 기록과 비관측 상태의 수학이다. 11장은 공동 채점의 자료·규칙·결과, 12장은 기준 모형 비교와 계약 판정, 13장은 사전 등록 예측이다. 14장은 반례와 한계, 열린 문제를 논의한다. 부록 A는 재현 방법, 부록 B는 선택 이력, 부록 C는 이전 연구 기록의 절 번호 대응표, 부록 D는 기호표다.

## 1.5.2 지위 표지

모든 형식 명제에는 다음 표지 가운데 하나를 붙인다. 수치 일치나 검사 통과는 표지를 올리지 않는다.

| 표지 | 뜻 |
|---|---|
| [정의] | 기호·대상·정의역 |
| [공리] | 모형·상태·물리 사상의 선택. 증명 대상이 아니다 |
| [정리] | 적힌 전제에서 증명한 명제. 조건부면 전제를 밝힌다 |
| [산출] | 정의·공리·정리를 대입한 수치 결과 |
| [경험식] | 원리에서 유도되지 않은 식 |
| [가설] | 해석상의 선택. 비용을 bit로 적는다 |
| [읽기] | 새 선택이 든 해석. 증거로 세지 않는다 |
| [미완성] | 작용·상태·증명·자료 연결이 더 필요한 항목 |
| [예측] | 값과 기각 조건을 동결한 관측량. 사전 등록 번호(P01–P44)를 함께 적는다 |

## 1.5.3 번호와 분리 원칙

장은 폴더 하나이고, 절은 그 폴더 안의 파일 하나(N.M), 조는 파일 안의 번호 붙은 제목(N.M.K)이다. 부록은 `부록` 폴더에 A–D 파일로 둔다. 형식 명제는 들어 있는 조의 번호를 쓰고(예: 정리 2.2.2), 식 번호는 조 번호에 문자를 붙인다(예: 식 (2.5.1a)). 본문은 최종 체계만 적는다. 자료를 본 뒤에 고른 규칙은 본문에서 [가설]이나 [경험식]으로 표시하고 bit 비용을 함께 적으며, 몇 개의 후보 가운데 어떻게 골랐는지는 부록 B에만 적는다. 이 체계가 만들어진 과정의 전체 기록은 레거시로 옮긴 이전 연구 기록에 있고, 사전 등록 파일과 코드가 가리키는 그 기록의 절 번호는 부록 C에서 이 논문의 번호로 이어진다.
