# 10.7 두 목표의 충족 범위

## 10.7.1 OBJ-02에서 채운 것

연구 목표 계약의 OBJ-02는 다음을 요구한다. "아직 관측되지 않은 양자 성분이 소멸한다고 가정하지 않고, 비동기 틱에서 전역 상태 또는 기록 가능한 보완 성분으로 남다가 물리적 관측 기록에서 확정되는 사상을 구성한다."

이 장은 그 첫 단계를 채운다.

| 요구 | 이 장의 대응 | 지위 |
|---|---|---|
| 소멸을 가정하지 않음 | 전체 상태는 순수하고, 비관측 성분은 경계 밖 $\mathcal M'$에 남는다 | 공리 10.3.2 |
| 확정되는 사상 | 기록 대수 $\mathcal M(\tau)$로의 제한. 새로 확정된 것은 상대 교환자다 | 정의 10.4.1 |
| 확정의 한 방향성 | 상태 보존 되돌림은 옛 기록과 새 기록의 상관이 없을 때만 있다. 이를 비가역성으로 읽는다 | 정리 10.4.2, 읽기 10.4.3 |
| 확정의 조건 | 란다우어 기록과 빛원뿔 도착 | 미완성 10.4.5 |

이 충족은 정의상의 식별이다. 확정을 기록 대수로의 제한으로 정의하면, 비관측 성분이 소멸하지 않는다는 것과 확정이 하나의 사상이라는 것은 공리 10.3.2와 정의 10.4.1에서 바로 나온다. 비확정 성분이 어떤 동역학을 거쳐 한 결과로 확정되는지는 유도되지 않았다. 이 단계가 보이는 것은 목표의 요구를 표준 양자론과 모순 없이 담는 틀이 있다는 것이다.

## 10.7.2 OBJ-02에서 남은 것

**[미완성 10.7.2] OBJ-02의 남은 요구.** 다음은 채워지지 않았다.

1. 비동기 틱: 기록 대수는 한 세계선의 고유시간 $\tau$로 매개된다. 여러 관측자의 기록이 서로 다른 틱으로 쌓이는 비동기 구조는 구성되지 않았다.
2. 방향: 확정이 어느 쪽으로 쌓이는지는 1 bit의 가설로 남는다(가설 10.4.4).
3. 시점과 속도: 기록이 언제, 얼마나 빨리 생기는지에 보편 법칙이 없다. 란다우어 기록 조건은 정성 판정이다(미완성 10.4.5).
4. 검산 범위: 기록 대수의 검산은 유한 모형($d_A=d_C=3$)뿐이다.
5. 비확정 성분의 존속: 비확정 성분이 소멸하지 않고 남는다는 것은 급팽창 경계의 띠를 지나는 동안에 한해 동역학으로 읽힌다(정리 10.6.2). 일반적인 존속 법칙은 없다.

## 10.7.3 OBJ-03에서 채운 것

연구 목표 계약의 OBJ-03은 다음을 요구한다. "비관측 성분의 존재공간, 정규화, 시간 진화, 보존량과 관측 투영을 정의하고, 어느 명제가 정리이며 어느 부분이 물리적 가정인지 분리한다."

다섯 요구는 모듈러 틀에서 모두 정의되었다.

| 요구 | 이 장의 정의 | 근거 |
|---|---|---|
| 존재공간 | 경계 밖 관측량의 대수 $\mathcal M'$ | 정의 10.3.1, 10.3.3 |
| 정규화 | 제한 $\rho_B$, $\operatorname{spec}\rho_B=\operatorname{spec}\rho_A$ | 정의 10.3.3(슈미트 분해) |
| 시간 진화 | 모듈러 흐름 $\Delta^{is}$. $\mathcal M'$ 위에서는 거꾸로 흐른다 | 정리 10.3.7 |
| 보존량 | $\ln\Delta\,\psi=0$ | 정리 10.3.7 |
| 관측 투영 | 제한(부분 대각합). 렌더링 쪽 상태는 열적이다 | 정리 10.3.4 |

## 10.7.4 정리와 전제의 분리

이 장의 수학 정리는 표준 정리의 적용이다. Tomita–Takesaki 정리, Takesaki의 조건부 기댓값 정리, Connes–Rovelli의 틀, Gibbons–Hawking 온도, Bisognano–Wichmann 정리, 레–슐리더 정리, Borchers 정리를 쓴다. 유한 모형의 검산(정리 10.3.4–10.3.8, 정리 10.4.2)은 통과가 예상된 일관성 확인이며 위험한 예측이 아니다. 이론의 몫은 식별과 전제이며, 2.8.1조가 이 장으로 미룬 모듈러 틀의 추가 전제도 여기에 모은다.

| 전제 | 지위 | 위치 |
|---|---|---|
| 렌더링 대수는 사건 지평 안쪽의 관측량이다 | 식별(정의) | 정의 10.3.1 |
| 전체 상태는 순수하다 | 공리 | 공리 10.3.2 |
| 기록 위상은 모듈러 매개변수의 $2\pi$배다(Connes–Rovelli 식별) | 열적 시간 공리의 남은 전제 | 정리 10.3.6 |
| 렌더링 쪽 상태는 KMS 꼴이다(드 시터에서 정확, ΛCDM에서 점근) | 열적 시간 공리의 남은 전제 | 정리 10.3.6 |
| 열적 시간의 온도는 최종 지평의 것이다 | 자료가 정한 뒤의 설명 | 읽기 10.3.10 |
| 기록이 쌓이는 쪽이 미래다 | 가설(1 bit, 4.3절의 향과 같은 bit) | 가설 10.4.4 |
| 우주의 시작은 분별의 시작이다 | 공리 | 공리 10.5.1 |
| 확률 무게 원천은 비관측 성분의 정확한 법칙이다 | 조건 | 정리 10.5.9 |
| 가지치기 동안 공간은 기록으로 이루어진다 | 가설(장부 비용 없음) | 가설 10.5.4 |
| 분별의 시작은 양자 확산의 끝이며, 급팽창은 정확한 스타로빈스키 퍼텐셜이다 | 가설과 모형 가정 | 가설 10.5.7 |
| 평형 바다의 예산과 늦은 우주의 열역학 전제 | 가설 | 정의 10.6.1, 가설 10.6.5 |
| 기록은 란다우어 상한 그대로 일어난다 | 가설 | 가설 10.6.4 |

## 10.7.5 OBJ-03에서 남은 것

**[미완성 10.7.5] OBJ-03의 남은 요구.** 다섯 요구는 정의되었지만 다음이 남는다.

1. 검산은 두 인자가 5차원인 유한 모형뿐이다. 지평의 대수는 III₁형이라 밀도행렬이 없으며, 그 경우에도 Tomita–Takesaki 정리가 성립한다는 것은 인용이다.
2. 보존량으로 제시된 것은 $\ln\Delta\,\psi=0$ 하나다.
3. 열적 시간과의 대응은 점근 KMS에 기댄다. 주 배경(진공 기울기 판독)에는 점근 드 시터 상태가 없다(읽기 10.3.10).
4. 최종 지평의 선택은 설명이며 유도가 아니다.

이 장의 어떤 결과도 예측값과 공동 점수를 바꾸지 않는다. 기울기를 열적 시간에서 유도한 주 판본의 39행 공동 RMSE는 0.8407($\chi^2=27.56$) 그대로다. 이 장이 등록한 예측은 P44 하나이며, 10.5절과 10.6절의 계산이 관측과 닿는 곳은 공간 곡률 하나다. 계약 VAL-01과 VAL-02의 판정은 12장에 있다.
