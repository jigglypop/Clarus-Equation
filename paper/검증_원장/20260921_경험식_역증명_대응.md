일반 증명은 각 장의 전제와 대수 전개, 실행 증거는 결과 JSON의 Claim ID별 항목에

   연결했다. 시간 의존 총응력과 실제 초기상태를 대신하는 결과는 아니다.
   25장은 §6.4–7.6의 Gaussian 상태 영역과 에너지 교환, 상관 인계 오차,
   광자 생성 상한·간섭·같은 공통 함수형의 유한 자율 되먹임을 직접 연결했다.
   유한계의 총에너지 보존을 전체 continuum in-in 재규격화의 완료로 세지 않는다.
   26장은 40–41장의 실제 cold/열적 상태와 고정 커밋의 28–29장 주기 경계
   전제를 대조했다. 단일 모드의 순수 elliptic 유일성은 유지하고, 공간·열적·
   다중 모드·끌개·가변 경계로 확대하는 연결을 직접 판정했다.
   27장은 §8 및 38장의 실제 차원 가중·rank-one probe·국소 나머지를 대조했다.
   정적 내부 Gaussian 모형의 무한 Fock 구현은 조건부로 증명하지만,
   전체 시공간·상호작용·중력의 UV 완성으로 승격하지 않는다.
   28장은 §3.11–3.16 및 50·52장의 호환 연결·실제 표현·질량·gauge 보정을
   직접 대조하고 전체 해·오차·최소 닫힘과 사차 원천을 보충했다.
   구체 표현의 기원, 공간 프레임의 전역 물리 구현과 전체 비가환 작용은 별도다.
   29장은 보존된 05–06장의 실제 양의 격자·조건부 기록·연속 공간 준비를
   폐경로 오차·곡률·정규화 전이·혼합 상태·순간/BV 준비·부피 극한까지 대조했다.
   30장은 보존된 07–10장의 실제 기록·역산·순수 scalar 흐름·곡률 포털에
   비용·오차·중채널 상쇄·허용 파형의 KK 반례를 추가했다.
   01–04장의 다른 작용과 빛/공동 상태 후보는 아직 개별 감사 대상이다.
2. 후보 가지들의 연결: 세 Gaussian 스칼라, 추가 Majorana/스칼라, 기록장치의
   서로 다른 작용과 준비를 하나로 합칠 수 있다는 구체 명제는 각 장의 field content와
   matching 조건을 고정해 검사해야 한다. R35–R36은 실제 보완분배와 수송 차이를
   계산했다. 나머지 후보를 R09의 일반 표현 반례만으로 모두 기각하지 않는다.
3. 고정한 실제 QCD의 행렬원소·전체 gauge/muon 도표·공간 전달함수·양자중력
   연속극한은 숫자가 없는 일반식으로 산출 완료를 주장하지 않는다. 구체 후보를
   고정한 추가 계산 또는 해당 주장 자체의 반례가 필요하다.
4. 삭제된 과거 관측 원본과 새 독립 검증 자료는 부재 상태다. 자료가 없는 것은

이 원장은 다음 실행의 작업 경계이며, 불가능한 모든 이론을 일괄 부정하는 문서가 아니다.

## 7. CE-JS3 — 질량 입력을 푼 뒤의 최소 차수와 선택 실패

|---|---|---|
| 내부 대칭 → 허용 작용 | 단일 traceless Hermitian 행렬의 다항식 불변량은 두 trace로 생성; 고정 이차 trace의 첫 비상수는 삼차 trace | 미분항·다른 장의 전체 작용 분류는 아님 |
| 유한 정합 계수 → 진공 순서 | 엄격한 오목성으로 끝점 선택·정확한 전환 계수·전체 분할 구간의 두 작용 반례 | 원래 유한항 금지 조건은 별도 전제로 유지 가능 |
| 선택된 끝점 → 안정성 | 세 정상 방향의 양의 Hessian; 내부 궤도의 네 영 방향 | 고정 두 모멘트의 형상 안정성; 반경·절대척도 안정화는 아님 |
| 경험 반응 → 미정 계수 | 정적 형상 곡률 및 비기준 상태의 공통 반응 잔차에서 유일 역산 | 실제 독립 반응·정규화가 필요; 기준 상태만으로는 식별 불가 |

[실행과 해시](../../experiments/ce_invariant_selection_20260921/results.json)는
기존 103개 주장 그룹·1104개 검사의 합계에 넣지 않는다.
이번 결과는 그 수를 늘리는 대신, 유한항을 금지하는 전제가 다른 조건들에서
따라오는지에 답한다. 답은 부정이며, 그 자유도를 없앨 추가 반응 조건도 식으로 명시했다.

## 10. CE-CC1 — 제약 대수에서 중력 작용과 공통 물질 원뿔까지

[35장](../후속연구_기록과_상태선택/35_제약대수에서_Einstein_작용과_공통_전파원뿔까지.md)은
