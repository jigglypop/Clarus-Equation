# 수학 도구 확정 원장

## 1. 현재 작업 계약

2026-09-11 사용자는 토글·판정 경계·관측 밖 상태의 수학적 판정을 먼저
완성하고, 등호이전과 리만 부분의 증명을 논문에 기록하도록 요청했다.
이 원장은 그 요청의 전체 범위를 유지한다. 78장의 공간 방사 계산은
사전등록 상태로 보존하고, 이번 작업은 그 계산에 앞서는 수학을 검토한다.

목표는 가정이 명시된 증명, 그 가정을 뺄 때의 반례, 재사용 가능한
정확한 식을 확정하는 것이다. 수치 일치나 문서 존재만으로 증명이 완전하다고
판정하지 않는다. 기존 파일의 이름이 ‘증명’이어도 본문을 확인한다.
리만은 저장소의 제타·Mellin·위치 부호화와 이번 판정 경계의 리만기하를
구별해 다룬다. 리만 가설의 증명이나 암흑부문 동정을 전제하지 않는다.

‘판정 완료’는 위에 명시한 기초 도구의 일반 증명·반례·전제 검토와
원고 반영을 뜻한다. 모든 물리 가정의 참, 저장소의 모든 역사적 주장,
리만가설 해결 또는 proof-assistant 형식 검증을 뜻하지 않는다.
수학적 충분조건이 존재한다는 것과 실제 CE 작용이 그것을 만족한다는
것을 구별한다.

## 3. 계산 전 고정한 검산 범위

첫 묶음 CE-MATH-B1은 유한차원 양자 상태공간에서 시작한다. Hermitian
판정 연산자, unitary 토글, 관측 사상과 Gibbs 비용을 먼저 정의한다.
행렬 항등식은 SymPy의 정확 연산으로, 비선형 함수의 예는 독립 수치 계산으로
대조한다. 유한 예는 일반 정리의 증명을 대체하지 않는다. 보편 명제는
본문에서 일반 증명 또는 명시적인 반례로 판정한다.

리만 사양은 실제 식의 translation/scale 변환, sheet floor,
서로 다른 query/key와 복소 가중치의 Hermitian 조건을 검사한다.
수론·기하·확률·물리 존재론 사이의 추가 연결은 자동 승계하지 않는다.

이 단계에는 새 관측 입력이나 피팅이 없다. 수학 도구의 검증과 전체 물리
성공은 별개이며 scientific_success=false, full_joint_rmse=null을 유지한다.

Born B0–B5의 기존 일반 증명은 조건부로 유지한다. B4를 뺀
제곱진폭 이외의 확률 assignment를 명시해 전제의 실제 역할을 확인했다.
Gibbs 확률을 성공 조건부 law로 만드는 CP instrument는 구성했지만,
Born 규칙과 PVM을 입력으로 쓴 사실을 숨기지 않는다.

## 5. 검산 영수증

재현 명령:

    python -X utf8 -B verify/ce_mathematical_boundary_audit.py

[계산 코드](../../verify/ce_mathematical_boundary_audit.py)와
[JSON 결과](../../verify/ce_mathematical_boundary_audit.json)에 정확 항등식
69개, 반례 기록 30항목, 최대 부동소수 절대오차
$2.5121479338940403\times10^{-15}$를 기록했다. 허용치는 $10^{-10}$이다.
Source hash, 실행 환경, 세 사전등록 hash를 함께 보존한다.

일반 증명과 다른 행렬 계산·적분·Christoffel 계산 경로로 유한 예를
대조했다. 별도 사람이나 별도 에이전트의 심사라고 주장하지 않는다.
코드 통과는 일반 정리나 물리 가정의 참을 판정하는 증명기가 아니다.
네 새 Markdown의 수식 정규화, 문서 링크, Python 구문, JSON/source
일치와 변경분 공백 검사를 수행했다. 기존 대규모 물리 회귀나 MRA 학습
실험은 이번 기초 수학 패치의 검사 범위가 아니다.

## 6. 다음 연구가 사용할 입력과 미해결 연결

재사용할 수 있는 것은 유한 양자 판정 경계와 토글 조건, 정규화된 CP
관측 사상, 보완 block의 양성 조건, 비용·prior에 조건부인 농축 정리,
명시적 Sobolev/Gaussian 경로 패키지, 커널·조건화·Born refinement 정리,
실수 주파수 회전·Mellin·Gram·정의역 있는 자기수반 연산자다.

다음 물리 분기는 공통 작용에서 실제 판정 연산자·계량·prior·기록
장치를 지정해야 한다. 경계 비용이 단일 결과를 선택한다거나 같은
경계가 Einstein 작용을 유일하게 정한다는 판본은 반례로 기각했다.
ASM-01의 무한/유한/무차원 존재론, ASM-02의 비동기 비관측 성분,
ASM-03의 경계로부터 최소작용은 아직 검증 대상 가정이다.
이 수학 감사로 OBJ-01–04 또는 VAL-01–02 달성을 선언하지 않는다.
