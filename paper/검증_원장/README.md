이 폴더는 목표 계약, 조건부 산출, 정리의 적용범위와 반례·관측 판정을 보존한다.
파일명이 ‘원장’ 또는 ‘증명’이어도 자연에 대한 물리적 참을 자동으로 뜻하지 않는다.
각 문서의 `[정의]·[정리]·[공리]·[산출]·[경험식]·[미완성]·[예측]` 표지를 따른다.

## 관리 경계

특화 감사는 `특화_감사/`, 정리 전의 상세 진전 기록은
[이력 보존본](이력/진전_원장_2026-09-10.md)에 둔다. 폴더 분류는 주장 지위의 변경이 아니다.
보존 정리의 본문·전제·반례와 검산 산출물은 유지한다.

새 원장은 독립적인 판정 책임이 있을 때만 만든다. 같은 후보의 후속 계산은 번호 장에,
같은 판정의 갱신은 기존 원장에 기록한다. 색인은 경로와 역할만 안내한다.
