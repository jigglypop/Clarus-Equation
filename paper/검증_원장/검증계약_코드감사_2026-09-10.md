**[산출] 공동 산술:** 고정된 4행 합성 공분산에서 Cholesky와 고유분해 RMSE의

악화하는 합성 대조군은 거부됐다. 중력 행이 그대로인 대조군도 기존 엄격 감소 규칙상

전체 후보 공간의 기각은 아니다. 공급한 질량·초기 상태·축척은 유도된 예측으로

독립 검산은 잔차 산술 및 기존 두 적분 표현의 비교에 한정된다. 전방 모형 전체를
별도 구현한 검산이나 독립 관측 검증은 아니다.

## holdout 실패와 집중 실행 영수증

실행 환경: Python 3.11.9, NumPy 2.4.6, SciPy 1.17.1. 감사 JSON에 진입 코드 해시를
기록했다. 이것은 모든 의존 코드·자료의 전이적 동결 manifest가 아니다.

- 공동 잔차·holdout·전방 모형 집중 검사: **95 passed**.
- contextual obstruction·finite CTP·pointer QCA·Plebanski·Regge 집중 검사: **128 passed**.
- 합계 **223 passed**는 해당 8개 파일의 구현 증거다. 전체 회귀를 실행한 수가 아니다.
- `python -B verify/contract_code_audit.py`: 정상 완료. 역사적 후보 JSON은 보존했다.
- `python -B experiments/preregistration/validate_holdout_manifest.py`: 종료 코드 1.
  양자·우주론 v2 모두 holdout `unassigned`, evaluation `NOT_READY`.
- 문서 정책 검사: **2 failed, 7 passed**. 기존 원고의 수식 구분자와 누락 상대 링크가
  실패 원인이다. 전체 문서 정책 통과를 주장하지 않는다.

실제 검증에서 누락된 동결 참조는 다음 네 개다.

```text
reality_stone/python/reality_stone/clarus/quantum.py

```

`test_holdout_preregistration.py`의 문법 검사 일부는 명시적으로
`verify_artifacts=False`를 사용한다. 따라서 95개 통과와 실제 manifest 실패는 모순이 아니다.
현재 전방 모형의 import 위치는 `examples.physics.darksector.ce_residual_forward_model`이다.
경로가 바뀌었더라도 동결 원본과의 바이트 동일성 확인 없이 참조를 바꿀 수는 없다.

## 다음 분기의 구체적 입구

1. 각 생존 후보의 작용·상태·매개변수·차원·기록 사상·반증 조건을 같은 판본으로 묶는다.
   ASM-01의 표현 비교와 ASM-03의 경계→작용 연결은 별도 미해결 항목으로 유지한다.
2. 누락된 동결 원본은 기존 해시와 일치하는 자료를 복구하거나, 현재 코드의 변경 내역을
   설명하는 상위 판본을 작성한다. 기존 v1/v2를 수정하거나 성공으로 바꾸지 않는다.
3. 최신 후보를 대상으로 모든 필수 블록의 자료·기준·공분산·교차상관 가정·허용치·
   훈련 매개변수 비용을 동결한다. 알려지지 않은 허용치와 자료는 이 감사에서 만들어 넣지 않는다.
4. 독립 holdout을 접근 전에 배정한 뒤 동일 전방 모형으로 평가한다.
   이번에 실패한 여섯 점을 관측별 재피팅으로 구제하지 않는다.
