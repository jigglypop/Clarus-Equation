# 최신 연구 읽기 지도

논문 장 폴더는 `paper/` 바로 아래에 둔다. [통합 논문](CE_통합_논문.md)은 전체 서술을, 아래 장들은 상세 근거를 제공한다. 기존 `1_`~`5_` 원본과 리만·등호이전은 [참조](참조/README.md)에 두며, [원고 대응표](00_기원과_현재계획/04_기존원고의_대응과_사용범위.md)에서 현재 사용 범위를 확인한다.

2026-09-19 갱신. 연구 방향은 **국소 비동기 틱 → 공통 스펙트럼과 작용 → 양자 반응과 중력원 → 공동 관측 검증**이다. 전체 연결이 이미 성립했다는 뜻은 아니다. 이번에는 공통 스펙트럼 가지의 실제 유도 결과를 81–85장의 상세 본문으로 분리했다. 중간 탐색 이력을 추가하지 않고, 각 결과가 성립하는 전제와 계산을 해당 분야에서 읽도록 배치했다.

## 현재 상세 본문 읽기 순서

| 순서 | 장 | 이어지는 논리 |
|---|---|---|
| 1 | [81. 상대작용의 유한성과 최소 스펙트럼](06_QFT_재설계/81_상대작용의_유한성과_최소_스펙트럼.md) | 유한성 → 두 모멘트 보존 → 최소 세 채널 → 코사인식 → 1+2 진공과 CP² |
| 2 | [82. 공통 스펙트럼의 중력·게이지·뮤온 반응](06_QFT_재설계/82_공통_스펙트럼의_중력_게이지_뮤온_반응.md) | 같은 상대 퍼텐셜의 질량미분 → 표현별 반응 → 프레임·보존적 교환 |
| 3 | [83. 유도 중력계수와 위상 운동항의 공동 정합](06_QFT_재설계/83_유도_중력계수와_위상_운동항의_공동_정합.md) | 명시한 추가 장내용 → 합규칙 → 기준 F와 K → 공통 척도비 |

순서는 설명의 순서이며 모든 가정이 앞 장에서 자동으로 유도된다는 뜻은 아니다. 81장의 최소 스펙트럼은 83장의 반각 수송·추가 장내용을 선택하지 않는다. 83장의 블록별 보완질량과 84–85장의 균등분배 경로도 각 장에 구분했다. 84장의 혼합상태와 85장의 차가운 입자 초기조건은 서로 다른 준비부문이다.

81–85장은 통합 논문의 관계·스펙트럼·공통 반응·중력 문제로 되돌아가는 링크와 출처·검사 대응을 포함한다. 종합 본문을 다른 독립 논문으로 교체하지 않았다. 이전에 한 파일로 묶었던 [선별 전진 원장](검증_원장/20260919_선별_전진_증명.md)은 이제 위치 안내만 제공한다.

## 역구조와 상태 되먹임 — 86–87장

2026-09-19 후속 연구. [86. 공통반응의 역구조와 관계수송](06_QFT_재설계/86_공통반응의_역구조와_관계수송.md)은 정확한 질량반응에서 분할·위상을 역복원하고, 최소 관계실현·사영잔여·같은 리만 계량과 진공 궤도 수송을 연결한다. [87. 보존전하의 스펙트럼 되먹임과 역상태](06_QFT_재설계/87_보존전하의_스펙트럼_되먹임과_역상태.md)는 그 진공 고정 제약을 풀고, 같은 운동계수에서 질량배열의 힘·내부 최소점·정상상태의 역복원·변하는 중력계수의 두 좌표 진화를 계산한다.

86–87장은 원래 세 복소스칼라 상대 Gaussian 가지를 사용한다. 83장의 추가 스칼라·Majorana 장내용과 합쳐 단일 무가정 이론으로 읽지 않는다. 원본 14개 검증 그룹을 재실행했고 신규 7개 그룹을 실행했다. 비영 전하에서 위상이 움직이는 진단해를 얻었지만 그 해는 가속하지 않으며, 새로운 공동 관측 성공을 주장하지 않는다. [입력 해시·검사·재현 명령](검증_원장/20260919_역구조_전하_게시.json)에 출처를 남긴다.

## 힉스 연결과 비전개 질량극 — 88–89장

2026-09-19. [88. 힉스 포털의 역선택과 클라루스 질량극](06_QFT_재설계/88_힉스_포털의_역선택과_클라루스_질량극.md)은 모든 진공 방향의 상대 유한성으로 채널 포털을 단위행렬로 제한하고, 같은 Gaussian 작용의 완전한 이차 운동량 커널에서 유일한 양의 잔차 질량극과 역스펙트럼을 구한다. [89. 힉스장과 클라루스장의 차이](06_QFT_재설계/89_힉스장과_클라루스장의_차이.md)는 표준 Higgs doublet, 과거 singlet EFT, 최신 관계행렬을 구분하고 두 부문의 공통 반응과 상태조건을 설명한다.

기존 IRS1 14개·IRS2 7개 그룹 및 신규 11개 그룹을 실제 실행했다. 정확성의 새 범위는 일정 평탄 배경의 Gaussian 물질 이차 커널이며 전체 loop·자연적 초기조건·관측 성공이 아니다. [출처·해시·재현 원장](검증_원장/20260919_힉스_클라루스_검증.json)을 함께 읽는다.

## 현재 증명과 검증의 경계

명시한 상대 유한성·최소성 조건에서 세 채널 표준형과 진공 분할을 유도했고, 지정한 장내용과 상태에서는 공통 반응·계층 최소점·힘 관계를 계산했다. 각 장은 기호, 고정 입력, 직접 유도, 수치 대조와 미완성인 물리 사상을 구별한다.

절대척도, 자연적인 상태 준비, 실제 입자·시공간의 기원과 전체 공동 관측 성공은 이 조건부 결과들의 수만으로 완료되지 않는다. 16개 집중 검사는 원문의 선택된 식에 대한 구현 대조다. 전체 우주론 전달행렬의 재생성과 새 관측 likelihood는 이 편집 작업에 포함되지 않는다.
