# 후속 연구 — 기록·상태·값의 선택

2026-09-20 누적 게시판. 기존 01–11장 원문과 미게시 실험 코드는 제공된 누적 패치의 바이트를 유지한다. 각 장의 “이번 실행”·Git 상태·검사 수는 작성 당시 이력이다. 이번 게시가 모든 오래된 검사의 재실행이나 관측 성공을 뜻하지 않는다.

01–06장은 원 보고서를 보존한 이력이다. 기존 main의 CE-RS1·CE-CR1 코드와 앞선 원본 ZIP의 코드 범위를 혼동하지 않는다. 전체 원본 ZIP들은 사용자가 받은 누적 다운로드 묶음의 source_archives에 보존돼 있으며, 이번 Git 게시에는 제공된 추가 전용 패치의 paper/·experiments/ 파일을 포함한다.

이번 실행에서는 GP1 32개, HS1 36개를 재실행했고 원 수치 필드가 일치했다. JS1 신규 39개에는 음성대조와 국소 시간 근사의 적용 한계 검사도 포함된다. 다른 장의 과거 검사 수를 이번 검사 수로 합산하지 않는다.

각 후보의 입력·가정·정리·계산·적용범위를 유지한다. 후속 확장 모형을 검증 전 본 CE의 무가정 기본식으로 대체하지 않는다. 최상위 목표는 [기존 연구 목표 계약](../검증_원장/연구_목표_계약.md)을 따른다.
