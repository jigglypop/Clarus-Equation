# 후속 연구 — 기록·상태·값의 선택

2026-09-22 현재 작업은 [38장 고정밀 경험식의 복원과 교차 역예측](38_고정밀_경험식의_복원과_교차_역예측.md)이다.
암흑부문·뮤온·허블의 성공 숫자를 원본 식과 함께 보존하고, 역산의 정리와
다른 부문의 예측 및 이를 구현하는 조건부 저에너지 구성을 추가한다.

2026-09-20 누적 게시판. 기존 01–11장 원문과 미게시 실험 코드는 제공된 누적 패치의 바이트를 유지한다. 각 장의 “이번 실행”·Git 상태·검사 수는 작성 당시 이력이다. 이번 게시가 모든 오래된 검사의 재실행이나 관측 성공을 뜻하지 않는다.

기존 역검증 기록은 **17–30장 CE-RB1–RB12(2026-09-21)**이다. 경험식에서 필요한 전제를 역추적하고 R01–R103에 조건부 증명 또는 반례를 연결한다. 17–19장은 경험식·유한 기록·공변 작용, 20장은 83·85–88장의 정확한 커널과 가지 정합, 21장은 84장 및 후속 11–16장의 상태·역산 조건, 22장은 82장의 지정된 뮤온 구성항, 23장은 사건·관계시계·공통 기하와 Maxwell 후보, 24장은 S4 무한합과 곡률 응답, 25장은 실시간 상관·광자 생성과 유한 자율 되먹임, 26장은 공간·열적 안정성과 주기 경계의 상태 선택, 27장은 확률측도·UV 수렴과 내부 rank-one Fock 구현, 28장은 공변 수송·표현 질량과 지정 gauge 보정의 닫힘, 29장은 보존된 05–06장의 기록·선택·준비와 부피 극한, 30장은 07–10장의 역산 오차·기록 비용·scalar 흐름과 실제 곡률 포털을 다룬다. 원문이 금지하는 변형은 해당 명제의 반례로 쓰지 않는다. 현재 103개 주장 그룹·1104개 검사가 통과했다. 실제 자연값 전체의 선택과 공동 관측 성공은 미완성이다.

## 순서

새 핵심 구성은 **31장 CE-JS2**에서 시작한다. 기존 공동 선택의 반경 불안정을 넘는
새 작용을 명시하고, 유한 반경 전역 최소점·비영 분할·다섯 변수의 엄격한
국소 안정성을 증명했다. 새 중성장의 기원과 질량 선택은 아직 입력이다.
위 CE-RB의 검사 합계는 이 새 증명의 진척률을 나타내지 않는다.
이어 **32장 CE-JS3**는 외부 질량을 풀었을 때의 실패와 최소 bulk 안정화 차수를
유도한다. 새 스칼라의 같은 차수 자기 loop를 생략한 근사에서 여섯 변수
국소 안정성을 인증했다. 질량 순서와 독립 계수 선택은 원래 목표에 맞게
닫히지 않았으며, 자기 loop를 포함한 함수의 국소 해도 별도로 남는다.

## 재현

38장 CE-EI1은 [경험식 복원·역예측 계산](../../experiments/ce_empirical_inverse_20260922/README.md)으로
원본 9개·정확한 3계층 분할·뮤온 두 역사 분기·허블 두 분기·DE 상태방정식을
보존하고 역함수, 공분산, 유한핵 정규화, flow 수렴, 재구성 KG 방정식을 검산한다.

37장 CE-JG1은 [공동 사상과 혼합 괄호 계산](../../experiments/ce_joint_geometry_20260922/README.md)으로
세 채널의 33개 독립 기하 변분과 전체 Grassmannian 혼합 반례를 검산한다.

36장 CE-SC1은 [상태 사상과 전체 괄호 계산](../../experiments/ce_state_canonical_20260921/README.md)으로
정규화 상태·여섯 계량 변분·비가환 계량 괄호·같은 계량과 다른 곡률을 검산한다.

35장 CE-CC1은 [정확한 기호 계산](../../experiments/ce_constraint_closure_20260921/README.md)으로
제약 괄호·계수 역유도·Legendre 변환·제약면 반례와 공통 물질 원뿔을 대조한다.
고전 최소 작용류의 조건부 정리이며 전체 목표 완료율로 환산하지 않는다.

31장 CE-JS2는 별도 폴더
[ce_joint_stabilization_20260921](../../experiments/ce_joint_stabilization_20260921/README.md)의
구성·역검사와 구간 인증 코드로 재현한다. 성공 사례와 실패한 질량 가지를 함께 저장한다.
32장 CE-JS3는
[ce_dynamical_mass_20260921](../../experiments/ce_dynamical_mass_20260921/README.md)의
동적 질량 선택 코드와 여섯 변수 구간 인증으로 재현한다.
33장 CE-IS1은
[ce_invariant_selection_20260921](../../experiments/ce_invariant_selection_20260921/README.md)의
불변량 대수·독립 resolvent 적분·최소점 전환·반응 역산으로 검산한다.
34장 CE-IR1은
[ce_interacting_response_20260921](../../experiments/ce_interacting_response_20260921/README.md)의
같은 두 루프 작용·유한 자기장 적분·곡률 및 게이지 반응·두 계수 역산으로 검산한다.

17–18장 CE-RB1: `experiments/ce_reverse_bridge_20260921/verify_reverse.py`.
2026-09-21에 21개 주장 그룹의 86개 기호·수치 검사를 실행했다.
결과와 코드 해시는 같은 폴더의 `results.json`에 있다. 합성 모형의 반례와
조건부 항등식 검산이며 관측자료 재현·전체 CE 증명으로 합산하지 않는다.

19장: 같은 폴더의 `verify_empirical.py`, `results_empirical.json`.
R22–R32의 52개 검사가 통과했다.

20장: 같은 폴더의 `verify_branches.py`, `results_branches.json`.
R33–R40의 71개 검사가 통과했다.

21장: `verify_states.py`, `results_states.json`, R41–R48의 56개 검사.
22장: `verify_muon.py`, `results_muon.json`, R49–R50의 43개 검사.
23장: `verify_geometry.py`, `results_geometry.json`, R51–R58의 56개 검사.
24장: `verify_curvature.py`, `results_curvature.json`, R59–R64의 64개 검사.
25장: `verify_realtime.py`, `results_realtime.json`, R65–R70의 81개 검사.
26장: `verify_stability.py`, `results_stability.json`, R71–R76의 95개 검사.
27장: `verify_uv.py`, `results_uv.json`, R77–R82의 101개 검사.
28장: `verify_transport.py`, `results_transport.json`, R83–R89의 119개 검사.
29장: `verify_records.py`, `results_records.json`, R90–R96의 133개 검사.
30장: `verify_identifiability.py`, `results_identifiability.json`, R97–R103의 147개 검사.
합계는 103개 주장 그룹·1104개 검사이며 열세 결과 파일은 서로 다른 검사 집합을
기록한다. `audit_artifacts.py`는 현재 소스·결과 해시, Claim ID, 로컬 링크와
목차의 현재 합계를 검사한다.

07장 CE-RV1: `experiments/ce_record_values_20260919/`.
08–09장 CE-RI1: `experiments/ce_record_identification_20260920/`.
10장 CE-GP1: `experiments/ce_geometric_portal_20260920/`.
11장 CE-HS1: `experiments/ce_holonomy_selection_20260920/`.
12장 CE-JS1: `experiments/ce_joint_selection_20260920/`.

01–06장은 원 보고서를 보존한 이력이다. 기존 main의 CE-RS1·CE-CR1 코드와 앞선 원본 ZIP의 코드 범위를 혼동하지 않는다. 전체 원본 ZIP들은 사용자가 받은 누적 다운로드 묶음의 source_archives에 보존돼 있으며, 이번 Git 게시에는 제공된 추가 전용 패치의 paper/·experiments/ 파일을 포함한다.

이번 실행에서는 GP1 32개, HS1 36개를 재실행했고 원 수치 필드가 일치했다. JS1 신규 39개에는 음성대조와 국소 시간 근사의 적용 한계 검사도 포함된다. 다른 장의 과거 검사 수를 이번 검사 수로 합산하지 않는다.

각 후보의 입력·가정·정리·계산·적용범위를 유지한다. 후속 확장 모형을 검증 전 본 CE의 무가정 기본식으로 대체하지 않는다. 최상위 목표는 [기존 연구 목표 계약](../검증_원장/연구_목표_계약.md)을 따른다.
