# 14장 논의

이 장은 이론이 어디서 실패했고 무엇이 아직 증거가 아닌지를 정리한다. 먼저 자료로 기각된 경로를 부문별로 모은다. 이어서 결과의 한계를 적는다. 연속 입력은 다섯이고, 규칙의 상당수는 자료를 본 뒤 정해졌다. 단일 작용과 중력 블록이 없으며, 동결 뒤 자료로 판정된 예측은 아직 없다. 그다음 남은 문제를 판정 수단과 함께 적고, 마지막으로 이 논문이 무엇을 보였고 무엇을 보이지 못했는지를 요약한다.
