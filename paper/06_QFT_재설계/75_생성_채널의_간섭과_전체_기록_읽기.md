# 75. 생성 채널의 간섭과 전체 기록 읽기

## 75.1 계산 전 등록: CE-UR4-P2

**[후보: 같은 작용의 전체 두 입자 준비·단일 읽기]** 74장의 CE-UR4-P1
준비에 같은 source의 모든 light-record 두 입자 최종 진폭을 붙인다.
동반 입자를 부분추적하기 전에 생성 채널을 고전 확률로 바꾸지 않는다.
작용과 물리적 확정 공리를 새로 바꾸지 않으며, 실제 source·pointer
준비와 전체 비사건 사상은 열린 조건으로 유지한다.

1. 원래 cubic tensor와 성분 potential에서 scalar 접촉항, heavy scalar,
   heavy Majorana 교환을 다시 추출한다. $S,\bar S,\psi_S$를 모두 초기
   기록으로 두고 Higgs probe의 허용된 두 입자 출력들을 센다.
   접촉·교환의 상대 부호, $t/M^2$ 항과 Majorana spin 합을 검사한다.
2. 고정 에너지·반대 방향 두 mode의 scalar 생성 진폭 행렬을
   $C_s=\begin{pmatrix}1&-m/M\\-m/M&0\end{pmatrix}$ 후보로 두고,
   fermion 쌍의 Dirac spinor 진폭 행렬과 함께 동반 입자를 추적한다.
   전체 trace가 74장의 생성 단면적 합과 일치하는지, 남는 scalar
   coherence와 fermion polarization이 무엇인지 독립 검사한다.
3. 같은 최종 상태로 가는 모든 진폭을 먼저 더해 양의 읽기 효과를 만든다.
   scalar와 fermion 출력에 같은 각·에너지 응답을 주는 등록된
   inclusive detector에서 coherence 기여가 상쇄되는지 검사한다.
   각 성분을 구분하는 detector에서는 동일 결론을 자동 승계하지 않는다.
4. 74장의 모든 질량·coupling·에너지·cone·column-density·검출 해상도와
   중심 8 표준편차 조건부 luminosity 분포를 그대로 유지한다.
   생성 채널 전체의 밀도행렬을 사용해 $+z,+y$ 전달 계수와 같은 분류
   문턱의 조건부 오차를 계산한다. scalar 쌍만의 수치, incoherent
   채널 합, source fermion을 임의로 무편극으로 놓은 대조도 보존한다.
   detector를 유리하게 바꾸거나 새 관측값에 맞춰 재피팅하지 않는다.
5. 방향별 외부 Dirac spinor와 불변 trace/4-vector 식을 독립 비교한다.
   질량 shell·보존·양의 효과·단위·추가 기록 쌍의 문턱을 검사한다.
   74장 scalar-particle 읽기를 독립 부분 채널로 다시 얻지 못하면
   해당 유도·수치의 적용 범위를 바로잡고 원래 사전 등록은 보존한다.
6. 기본 허용치는 정규화된 $10^{-8}$, 적분은 독립 차수의 자연 전달
   척도로 나눈 차이 $10^{-6}$다. 작은 보정은 leading 결과와의 차이
   자체도 두 차수로 비교하고 절단 근사와 반올림 오차를 구분한다.
   사전 등록 해시를 고정한 후 수치 검산한다.

최저차 두 기록 생성과 tree 단일 읽기를 닫아도 full S, 추가 방사,
유한 packet 전파·장치 준비·반복 기록·비동기 확정이나 공통 중력의
증명으로 판정하지 않는다. scientific_success=false, full_joint_rmse=null,
새 관측 입력·피팅 없음의 경계를 유지한다.
