# QFT 재설계

기존 QFT 재설계 계획을 보존한다. 현재의 우선순위는 기원 폴더의 공통 작용 계획이다. 37장은 현재 삭제 상태이며 복원하지 않았다.

공통 전자기 운동항에서 광자 모드·생성·위상 소스가 나오는 유도와 CE-PD33 재계산은 [통합 논문 §7.4–7.6](../CE_통합_논문.md#74-같은-게이지-운동항에서-광자-파동과-생성식을-유도하기)에 통합했다. 같은 차원 있는 분할을 유지한 기존 우주 이력의 생성량까지 계산한다.
