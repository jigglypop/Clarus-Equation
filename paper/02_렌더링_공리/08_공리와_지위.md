# 2.8 공리와 지위

## 2.8.1 공리 목록

이 논문이 쓰는 공리는 다음과 같다. 각 공리는 자연에서 증명된 사실이 아니라 모형의 선택이며, 그 선택의 값은 관측과 사전 등록 예측이 판정한다.

| 공리 | 내용 | 위치 |
|---|---|---|
| 실현 공간 | $V=V_3\oplus V_2=\mathbb C^5$, 통로 = $\Lambda(V)$의 기저 | 공리 2.1.1 |
| 균일 동전 | $R=aI_5$ | 공리 2.1.2 |
| 입력 공리 | $\det(R\vert_{V_3})=\alpha_s(M_Z)$ | 공리 2.1.3 |
| 렌더링 진폭 | $A_m(W)=\operatorname{tr}P_W\det(P_WRP_W\vert_W)$ | 공리 2.2.1 |
| 기록 공리 | 렌더링 = 참·거짓 한 비트의 기록 | 공리 2.3.1 |
| 무차별 공리 | 기록 전의 명제는 공평한 동전 | 공리 2.3.2 |
| 기록 갱신 규칙 | 확정은 빛원뿔 안에서만 원천을 바꾸고, 먼저 온 기록이 정한다 | 공리 2.3.3 |
| 세대 순환 공리 | 세대 공간은 3-순환, 선도 질량 행렬은 순환 행렬 | 3.3절 |
| 세대 가중치 공리 | 2세대에만 경계 인자 $1+\delta/2\pi$ | 4.1절 |
| 나/바깥 경계 공리, 부호 공리 | 렙톤 섞임의 분별과 옥탄트 부호 | 4.4절 |
| 거울 공리 | 렙톤과 쿼크의 CP 방향은 반대 | 4.5절 |
| 독립 후손 공리 | 기록의 인과적 후손은 평균 $D$의 포아송 | 6.1절 |
| 끊긴 계보 공리 | 끊긴 계보가 보이는 바리온 | 6.2절 |
| 복소 빠르기 판독 공리, 기록 에너지 공리 | 판독 틀과 기록 에너지의 양수 조건 | 7.1절 |
| 지평선 화소 공리 | 화소마다 1 nat, 화소 넓이 $4\ell_P^2$ | 7.4절 |
| 복소 척도인자 공리, 유클리드 회전 공리 | $A=ae^{i\varphi}$, 계량은 $\vert A\vert$만 본다 | 8.1절 |
| 열적 시간 공리, 진폭 절반 공리 | 기록 위상은 최종 지평선의 온도로 쌓이고, 기울기는 그 절반 | 8.3절 |
| 관측 사상 | 틀 사이 비는 1차 투영을 받는다(고유시간 판본) | 8.4절 |
| 전체 상태의 순수성 | 관측자 영역과 그 바깥을 합친 전체 상태는 순수하다 | 10.3절 |
| 시작 공리 | 우주의 시작은 분별의 시작이다 | 10.5절 |

10장의 모듈러 틀이 쓰는 나머지 전제는 10.7절의 전제 표에 모았다.

## 2.8.2 읽기와 가설

[읽기]는 새 선택이 든 해석이며 증거로 세지 않는다. 이 장의 읽기는 사건 사전(2.3.6), 결합–섞임 사전(2.4.1), 가둠 규칙(2.4.2), 곱과 합(2.4.7), 극에서의 기록(2.6.4), 균형 원리(2.6.6), 눈금 없음(2.6.7), 기운 동전(2.7.4)이다. 다른 장의 읽기는 각 장에서 표시한다.

[가설]은 자료를 보고 고른 해석상의 선택이며, 선택 비용을 bit로 적는다. 이 장의 가설은 자기일관 고정점(2.7.1) 하나다. 다른 장의 가설과 모든 선택 비용의 합계(가설 장부)는 12.1절에 있다. 각 선택이 몇 개의 후보 가운데 무엇을 보고 이루어졌는지는 부록 B에 있다.

## 2.8.3 유도되지 않은 네 식

**[경험식 2.8.3] 유도되지 않은 네 식.** 다음 네 식은 이 장의 공리에서 유도되지 않는다.

| 식 | 내용 | 위치 |
|---|---|---|
| 합규칙 | $\alpha_s+\alpha_2+\alpha_{\rm em}=\frac1{2\pi}\big(1+\frac{\alpha_s}{16\pi}\big)$ | 5.1절 |
| 계층 식 | $v/M_{\rm Pl}=e^{-12D}(1+\alpha_s/4\pi)/F$ | 5.3절 |
| 원시 요동 진폭 | $A_s=2.1035\times10^{-9}$을 주는 식 | 9.2절 |
| 지평선 식 | $H_0t_{\rm Pl}=\sqrt\pi\,e^{-S/2}(1+\alpha_s/4\pi)$ | 7.7절 |

네 식은 수치 추측으로서 시험한다. 채점에서 연속으로 맞추는 양은 $\alpha_s$ 하나이지만, 설명 길이로 복잡도를 셀 때는 이 네 식을 적합 매개변수로 센다. 식을 기호로 적는 비용이 해당 매개변수를 측정 정밀도까지 적는 비용보다 크기 때문이다. 그 회계에서 연속 입력은 $\alpha_s$, $\alpha_{\rm em}$, $v/M_{\rm Pl}$, $A_s$, $h$의 다섯이다(12.4절).
