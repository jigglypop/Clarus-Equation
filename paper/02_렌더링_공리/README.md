# 2장 렌더링 공리

이 장은 이론의 공리와 코어 식을 세운다. 렌더링된 공간은 색 공간과 약력 공간의 직합 $\mathbb C^5$이고, 렌더링 연산은 모든 게이지 축에 같은 수 하나(렌더링 동전)를 곱한다. 연속 입력은 이 동전의 세제곱인 강한 결합 상수 $\alpha_s$ 하나다. 렌더링은 참과 거짓 가운데 하나를 남기는 기록이며, 기록 전의 명제는 공평한 동전이다. 결합과 섞임을 렌더링 진폭에서 읽는 사전을 두면 약혼합각 관계 $\hat s_Z^2=4\alpha_s^{4/3}$가 조건부 정리로 나온다. 그 사전은 관계를 본 뒤에 세운 읽기이므로, 관계의 증거는 계수 사전이 주는 5.1 bit를 넘지 않는다. 관계가 성립하는 척도는 Z 극 하나다. 입력을 스스로 정하려는 고정점 가설은 계산은 닫히지만 다른 자와 내부 긴장을 가진다. 장 끝에는 이 논문이 쓰는 공리·읽기·가설과, 공리에서 유도되지 않는 네 식을 모아 둔다.
