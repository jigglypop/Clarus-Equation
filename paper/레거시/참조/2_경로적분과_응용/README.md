# 경로적분과 응용 원본

차원 정의, 고정점, 인플레이션, 입자 질량과 경로적분의 조건부 계산을 보존한다. 파일명에 남은 ‘유일성’이나 ‘해결한 난제’는 이전 식별자이며 실제 주장의 범위는 각 본문의 전제와 미완성 항목을 따른다.

이 묶음의 현재 역할은 [기존 원고 대응표](../../00_기원과_현재계획/04_기존원고의_대응과_사용범위.md)에서 확인한다. 현재 서술은 [통합 논문](../../CE_통합_논문.md), 전체 참조는 [참조 안내](../README.md)를 따른다.

## 함께 보존한 도구

문서 검사·수식 정규화 도구 다섯 개는 원문과 함께 둔다. 저장소 루트와 검증 원장 경로는 새 위치에 맞춰 수정했다. 이 도구의 실행 성공은 문서·구현 검사이며 현재 이론이나 관측의 성공 판정이 아니다.
