# 상수·경험식 원본

외부 관측 입력, 경험식, 조건부 산출과 재현성 노트를 보존한다. 기존 입력값과 우주론 대응을 현재 공통 스펙트럼의 예측으로 재사용하지 않는다. 자료 판본과 모형이 다른 수치도 한 식의 성과로 합치지 않는다.

이 묶음의 현재 역할은 [기존 원고 대응표](../../00_기원과_현재계획/04_기존원고의_대응과_사용범위.md)에서 확인한다. 현재 서술은 [통합 논문](../../CE_통합_논문.md), 전체 참조는 [참조 안내](../README.md)를 따른다.
