# 레거시: 첫째 이론 원고와 이전 연구 기록

이 폴더는 첫째 이론의 원고와 과거 원문을 보존한다. 첫째 이론은 국소 비동기 틱의 관계망에서 공통 스펙트럼과 공통 작용을 세우고, 양자 반응과 중력원을 거쳐 공동 관측 검증으로 가는 경로였다. 공동 관측오차를 줄이지 못해 폐기했다. 여기 있는 정리와 반례는 적힌 전제 안에서만 참이며 현재 판정의 근거로 쓰지 않는다. 링크 유지 외에는 고치지 않는다.

현재 이론은 [렌더링 생존식 논문](../README.md)이다. 이 폴더에는 그 논문의 이전 연구 기록인 [옛 43장](07_확률차원_검증기록/43_렌더링_생존식과_양자_거시_공동_RMSE.md)도 있다. 사전 등록 파일과 해시로 잠긴 코드는 그 기록의 절 번호를 가리키며, 논문의 조와의 대응은 논문의 [부록 C](../부록/C_이전_기록_번호_대응표.md)에 있다.

## 읽는 순서

첫째 이론의 논문은 **관계 차원의 공간적 발현 → 같은 관계의 거리·힘·곡률 → 잔여 상태의 공통 작용 → 스펙트럼 구현 → 양자·거시 관측**의 순서로 읽는다. 공통식의 출발 가설과 유도는 [통합 논문](CE_통합_논문.md)의 §2.4·3.3–3.16에 있다. 특히 §3.8–3.10은 같은 관계 상태에서 운동식·코사인 질량식·비가환 곡률을 함께 계산한다. 장 폴더는 이 문서와 같은 폴더에 있다. 이전 `1_`~`5_` 원본과 리만·등호이전은 [참조](참조/README.md)에 있다.

추가된 CE-PD33 광자 연구는 같은 본문의 §2.5와 §7.4–7.6에서 읽는다. 파동·검출 기록, 공통 게이지 운동항의 광자 생성식, 위상에 대한 되먹임과 기존 우주 이력의 생성량을 이유와 함께 유도한다. [공유 원문](참조/CE_PD33_공유원문_2026-09-10.txt)은 보존하고, 원문에 첨부되지 않은 코드 대신 독립 재계산 (과거 기록: `verify/ce_photon_common_action.py`)을 연결했다.

§3.14–3.15는 잔여 성분을 제거한 뒤에도 같은 분할을 보존하는 조건과, 게이지 생성자의 이차형식으로 표현별 질량비를 묶는 후보를 다룬다. 기존 평균 질량척도와 우주 배경을 유지한 부분 오차 비교는 §9.7에 있다. 절대척도·초기상태·전체 공동 검증은 이 조건부 비교에서 새로 결정되지 않는다.

§3.16은 이 질량 관계가 게이지 양자 보정 아래에서 어떤 추가 항을 요구하는지 유도한다. §9.8은 질량의 척도 의존성만 넣어서 생긴 점수 변화를 정합 로그와 함께 검사하며, 그 변화를 추가 관측 개선으로 세지 않는다.

1. [통합 논문](CE_통합_논문.md): 첫째 이론의 설명과 조건부 결과를 10개 장으로 연결한다. §9.9는 렌더링 체계의 요약이며 레거시로 옮긴 뒤로는 갱신하지 않는다. 현재 판정은 43장 §43.1이 정본이다.
2. [이전 읽기 지도](07_확률차원_검증기록/이전_읽기_지도.md): 장별 상세 원고의 목차다. 그 문서의 ‘현재’와 ‘다음’은 전환 이전 표현이다.
3. [기존 원고 대응표](00_기원과_현재계획/04_기존원고의_대응과_사용범위.md): 이전 원본에서 무엇을 이어받고 구분하는지 확인한다.
4. [첫째 이론의 전체 예측 판정](07_확률차원_검증기록/42_공통식_전체_예측_판정.md): 공통 스펙트럼 후보의 부분 점수와 미완성 범위를 확인한다.
5. [용어사전](용어사전.md), [코어 독자 가이드](코어_독자_가이드.md): 첫째 이론의 용어와 코어 설명이다.

## 첫째 이론과 이전 원본의 구분

첫째 이론의 공통 스펙트럼 후보는 장내용·질량행렬·상태를 명시한 뒤 상대 양자작용과 그 반응을 계산한다. 기존 Poisson 고정점·Hodge 대응·singlet-portal EFT는 다른 전제에서 얻은 조건부 수학이다. 이 수학을 보존하는 것과 새 스펙트럼이 그 모두를 유도했다는 주장은 다르다.

[공리·모형 사전](00_기원과_현재계획/15_CE_공리계와_모형_사전.md), [조건부 장론·확률 코어](06_QFT_재설계/36A_조건부_장론과_확률_코어.md), [상수 조건부 산출 원장](../검증_원장/상수_조건부_산출_원장.md), [코어 독자 가이드](코어_독자_가이드.md)는 기존 모형의 정의·유도·입력을 추적한다. 그 안의 모형 선택과 수치를 현재 후보의 입력이나 예측으로 자동 승계하지 않는다. 첫째 이론의 서술과 원본의 대응은 통합 논문과 대응표를 기준으로 읽는다.

## 분석과 재현

2026-09-10 최소 테스트 정리 이전의 세부 테스트 파일명과 통과 수는 역사적 검산 영수증이다.
현재 실행 가능한 계약은 [최소 필수 테스트](../../tests/README.md)만 사용하며, 삭제된 세부
회귀는 Git 이력에서만 복구한다.

현재 계산은 `examples/physics/`, 검사는 `tests/` 한 곳에서 관리한다.
과거 `verify/`, `ledger/`, `derivations/`와 일회성 작업물은 정리했다. 문서의
‘과거 기록’·‘과거 검산’ 경로와 당시 통과 수는 역사적 기록이며 현재 재실행을 보장하지 않는다.
Git에 기록된 파일은 이력에서 복구할 수 있다. 미커밋 검산도 정리 대상에 포함되었으므로
모든 과거 실행물을 Git에서 복구할 수 있다고 가정하지 않는다.

- [두 공유 대화의 요구와 검증 범위](00_기원과_현재계획/05_두_공유대화의_요구와_검증범위.md): 원래 두 링크의 직접 확인과 목표 유지
- [공통 스펙트럼의 뮤온 부호와 관측오차](00_기원과_현재계획/06_공통스펙트럼_뮤온_부호와_관측오차.md): 독립 적분 검산과 고정 관측 요약 비교

- [최신 연구 분석과 논문 구성](00_기원과_현재계획/13_최신연구_분석과_논문구성.md): 공유 대화와 로컬 원고의 판본·가정 비교
- 공통 스펙트럼 재현기록(`참조/공통스펙트럼_재현기록.json`): 현재 체크아웃에서 미확보; 고정 커밋의 재실행 주장은 원기록을 복구하기 전까지 검증 근거로 사용하지 않음
- [문서 재구성 기록](00_기원과_현재계획/03_문서_재구성_검증.md): 이전 정리 작업의 검사 범위

문서 정책 검사의 현재 경로는 다음과 같다.

```powershell
python -B -m pytest -p no:cacheprovider tests/test_canonical_document_policy.py -q
```

미확보·삭제된 실행물은 클릭 가능한 파일 링크 대신 경로와 상태로 표시한다. 문서 정리로 연구 주장의 지위나 미완성 판정을 바꾸지 않는다.
