# 6장 계보와 경주

이 장은 기록이 후손을 낳아 가지를 치는 과정에서 우주의 성분과 Higgs 질량을 함께 얻는다. 기록마다 후손 수를 평균이 유효 차원 $D=3+\delta$인 포아송 분포로 두면(독립 후손 공리), 한 기록에서 시작한 계보가 끊길 확률은 $q=e^{-D(1-q)}$의 가장 작은 근 $0.048645$다(계보 소멸 정리). 끊긴 계보를 보이는 바리온으로 두면(끊긴 계보 공리) $\Omega_b=q$다. 살아남은 계보에서 자기 사건과 붙잡힘 사건이 경주하고 먼저 온 기록이 운명을 정한다고 두면 $\Omega_{\rm DM}/\Omega_\Lambda=\alpha_sD$와 $\Omega_m=0.30796$을 얻는다(경주 정리, 조건부). 같은 경주를 질량 = 빠르기로 읽으면 Higgs와 Z의 질량비 $F=1+\alpha_sD$가 읽히고, 경주를 한 칸 더 이으면 top 극 질량 $m_t=M_ZF^2=172.33$ GeV라는 가설이 나온다. 그러나 $F$는 경험식이고 두 읽기는 증거가 아니다. $q$ 방정식은 $\Omega_b$에, 경주의 선형 꼴은 $\Omega_m$과 $M_H$에 맞춰 고른 식이므로 이 장의 수치 일치는 새 증거가 아니며, 새로 생긴 것은 기제다. $M_H/M_Z-1=\Omega_{\rm DM}/\Omega_\Lambda$는 두 식이 같은 인자 $\alpha_sD$를 공유해 생긴 구성상 항등이다. 이 장의 등록 예측은 P12, P13, P28, P35, P39이며 P35는 파생 예측이다. 동결 뒤 공개된 자료로 판정된 예측은 없고, 이 장의 결과는 계약 VAL-01·VAL-02의 충족을 뜻하지 않는다.
