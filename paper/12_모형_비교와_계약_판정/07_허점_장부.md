# 12.7 허점 장부

## 12.7.1 허점과 현재 상태

이 이론의 주장이 기대는 허점과 각 허점의 현재 상태는 다음과 같다. "막음"은 허점을 닫는 논증이나 절차가 있다는 뜻이고, 그 논증의 전제는 오른쪽 칸에 남는다.

| 허점 | 현재 상태 | 남는 것 |
|---|---|---|
| 약혼합각 정리의 순환과 정의역 | 막음. 실현 공간, 균일 동전, 결합–섞임 사전, 가둠 규칙의 조건부 정리다(정리 2.4.3). | 사전과 가둠 규칙은 결과를 본 뒤 세운 읽기다(읽기 2.4.1, 2.4.2). 증거는 지수 사전의 5.1 bit 그대로다. 판정은 FCC-ee가 한다. |
| 시간축 기울기 $\pi/8$의 출처 | 막음. 열적 시간 공리, 진폭 절반 공리, $\Omega_m$에서 $\theta_0=0.398$이 나온다(8.3절). | 두 공리는 공리로 남는다. "왜 지금 절반인가"는 1.4% 일치의 우연이다. |
| 관측 사상의 시간 의미 | 막음. 고유시간 판본으로 정했고, 단위 판본은 가장 오래된 별의 나이로 기각된다(8.4절). | 판별 예측 P43(우주 시계 67.77) |
| 설명 길이의 식 구조 비용 | 부분적으로 막음. 부담의 54–74%가 코어 네 식에 있고, 넷은 유도되지 않아 매개변수로 내렸다. 손익분기는 기호당 2.5–3.5 bit다(산출 12.4.6). | 가장 좁은 사전의 양자 블록과 개방 탐색 부호에서는 우위가 없다. 연속 입력은 다섯이다. 지평선 식의 정보는 선도 계수가 아니라 O(1) 상수에 있다(7.7절). |
| P17의 등록 절차 | 막음. 등록 전 문헌 점검을 한다(13.1절). | — |
| 그라데이션의 무게 시점 | 1 bit의 선택으로 남는다(8.7절). | 자료가 가를 때까지 선택이다. |
| 게이지군, 고전 중력, 강한 장 | 가정을 고른 결과다. 논리의 허점이 아니라 설명의 깊이 문제다. | 실현 공간, "계량은 $\lvert A\rvert$만 본다", 지평선 화소를 공리로 명시한다. |
| 동결 뒤 자료 판정 0건 | 열림(산출 12.5.2) | 시간만이 막는다. JUNO, DUNE·Hyper-K, DESI 최종 자료, FCC-ee, 우주 시계가 판정한다. |
| 지평선 선도항의 원리 | 읽기 수준에서 막음. 원 없는 임계 잠김(포물형)과 Fatou 좌표에서 $3\zeta(2)N_e$가 정규화까지 나온다(7.7절). | 로그 화소 수가 Fatou 거리 제곱의 합이라는 새 전제가 든다. O(1) 상수는 단순 상수로 식별할 수 없다(우연 기대 23). |
| $N_e=18D$의 재가열 정합 | 열림. 순간 재가열의 $N_*=55.58$보다 1.6 많다(9.3절). | 급팽창 뒤 $w>1/3$인 시기를 요구한다. 재가열 모형이 없다. |
| 계약 VAL-01·VAL-02 | 미충족. 공동 RMSE 감소만 충족한다(12.6.1조, 12.6.2조). | 단일 작용, 중력 블록, 필수 블록과 허용치의 사전 지정, 훈련·시험 분할 |

## 12.7.2 감사가 더한 항목

지위를 실제보다 높게 적기 쉬운 항목과 그 현재 지위는 다음과 같다. 각 항목의 논증은 오른쪽 절에 있다.

| 항목 | 현재 지위 | 절 |
|---|---|---|
| 약혼합각 | 조건부 정리다. 전제인 결합–섞임 사전과 가둠 규칙은 결과를 본 뒤 세운 읽기이고, 증거는 지수 사전의 5.1 bit(눈금 폭을 인정하면 3.1 bit)다. | 2.4절(정리 2.4.3) |
| 분별 통로 계단의 크기(1/8, 2/8, 4/8) | 기록 공리와 무차별 공리에서 유도되지 않는다. 높이를 섞임각 편차로 옮기는 규칙은 [경험식]이고, 사건 사전은 [읽기]다. 규칙 선택 비용은 후보 다섯이면 2.3 bit다. | 4.4절 |
| 렙톤 규칙의 정밀도 | 극 질량비와 공통 척도 $\overline{\rm MS}$ 질량비는 약 $-0.98\%$ 다르다. 이론 불확도를 넣으면 정밀도 주장과 자기일관 고정점과의 $-3.75\sigma$ 긴장은 렙톤 규칙의 좁은 불확도 아래에서만 성립한다. | 5.2절 |
| 플랑크 판독 인자 | 세 후보 가운데 음향 각도로 고른 [가설]이다. 장부는 0 bit로 세지만 선택 이력이 있다(산출 12.1.5). | 5.3절 |
| $M_H/M_Z-1=\Omega_{\rm DM}/\Omega_\Lambda$ | 두 식이 같은 인자 $\alpha_sD$를 공유해 생긴 구성상의 항등이다. P35는 파생 예측이다. Planck와의 비교는 $-1.12\sigma$이고, DESI와의 일치는 DESI로 고른 그라데이션 선택의 일관성이다. 사후 탐색에서는 672회 시행 가운데 같은 허용치 안의 적중이 8개였다. | 6.5절 |
| $(m_\mu/m_\tau)/\sin^2\theta_W$ | 약혼합각 정리와 렙톤 규칙을 합친 일관성 확인이다. P36은 파생 예측이다. | 5.2절 |
| 지평선 화소 | 인자 4는 나이퀴스트 표본화로 정당화되지 않는다. 화소 크기 $4\ell_P^2$는 중력 상수(곧 1/4)를 재현하도록 고른 선택이다. "화소 하나에 1 nat"은 미분 엔트로피의 단위 선택에 달려 있다. 지평선 화소는 공리로 적는다. | 7.4절 |
| 나이테 판독 인자 $1-\Omega_m(1-\cos\theta)$ | 확률 무게 정리의 따름정리가 아니다. 에너지 몫 가중, 오늘의 무게, 1차 투영, 길이 판독에의 곱셈이라는 추가 전제를 가진 조건부 읽기다. 비용은 적합 선택과 변형 선택을 합쳐 센다. | 8.7절 |
| 지평선 열적 주기의 시각표 | $2\pi/H_\Lambda$는 허수 시간의 주기다. 이것을 실시간의 흐려짐–재생–재시작 순환으로 옮긴 시각표는 [읽기]이자 [미완성]이다. 과거 자료는 "지금 잠김"과 "계속 돎"을 가르지 못한다. | 8.8절, 10.1절 |
| 기록의 비가역성 | 수학 정리(모듈러 불변 조건부 기댓값)의 적용인 상관 판정과, 그것을 비가역성으로 읽는 해석으로 나뉜다. OBJ-02의 첫 단계 충족은 정의상의 식별이다. | 10.4절 |
| 가설 장부의 감축 | 다섯 감축은 결과를 안 뒤 세운 전제에 기댄다. 감축 전 값과 되돌린 효과는 산출 12.1.5에 있다. | 12.1.5조 |
| 사전 등록의 독립 수 | 등록 파일은 독립 예측을 40개로 세지만, P35와 P36을 빼면 그보다 적다. | 13.1절 |
