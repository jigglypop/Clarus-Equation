# 측정과 접힘

기록·측정·환경장과 암흑부문 EFT의 기존 가정과 경계를 보존한다. 과거의 현재 상태는 새 공통 작용의 완료 판정이 아니다.

CE-PD33의 광자 간섭·검출 기록·인과적 접힘은 [통합 논문 §2.5](../CE_통합_논문.md#25-빛의-진폭과-검출-기록을-같은-상태에서-얻기)에서 유도한다. 미검출 결과를 포함한 확률 정규화와 관계 차원이 공간으로 나타나기 위한 조건을 함께 설명한다.
