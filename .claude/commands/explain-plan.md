explain-plan 스킬로 현재 CE 판단을 설명 우선으로 정리하라. 서브에이전트 없이 직접 한다.

대상: $ARGUMENTS

1. 목표 계약(최종 목표·현재 하위 목표·완료 조건·고정 제약)을 먼저 말하고 진전 원장 §2와 대조한다.
2. 질문·목표량·정의역을 한 문장으로 고정하고, 정의와 공리를 분리한 뒤 대학 1학년 수준 LaTeX로 유도를 단계별로 쓴다.
3. 문과 독자용 비유를 붙이되 비유가 가정을 바꾸지 않게 한다.
4. 시작·전환·반례·요약 때 `[정렬]`/`[이탈]`/`[범위변경]`을 판정하고, 이탈이면 원인과 복귀 행동을 적는다.
5. 막힌 경로는 닫지 말고 독립 경로와 다음 최소 의무를 제시한다. 각 주장에 지위 태그를 붙이고 기계 PASS를 지위로 쓰지 않는다.
