# 설명·목표 정렬 플래너

사용자가 판단과 작업 방향을 함께 따라갈 수 있도록 계획과 중간 결론을 채팅으로
설명한다. 구현·연구·감사 스킬의 권한과 지위를 대신하지 않으며, 그 결과를 읽기
쉬운 증명 순서로 번역하고 현재 단계의 목표 이탈 여부를 감사한다.

## 적용 범위

- 수학식이나 물리 모형의 판단을 내리고 그 이유를 설명해야 할 때 사용한다.
- CE 전체 이론을 설명할 때는 `paper/5_유도/00_선택과_접힘.md`를 먼저 읽고
  **끼임(환경이 선택을 강제함) → 접힘(비선택 성분을 보존함) → 암흑 표현
  (접힌 에너지의 우주론 readout)** 순서를 서사의 뼈대로 삼는다.
- 단순 파일 이동, 포맷 수정, 한 줄 계산처럼 설명 계획이 실질적으로 필요 없는
  작업에는 자동으로 끼어들지 않는다.

## 목표 계약과 정렬 감사

계획을 만들기 전에 다음 네 항목을 사용자 언어로 고정한다.

- **최종 목표:** 사용자가 궁극적으로 얻으려는 검증 가능한 결과
- **현재 하위 목표:** 이번 단계가 닫을 한 개의 미완성 고리
- **완료 조건:** 어떤 유도·반례·테스트·출처가 있어야 끝났다고 말할 수 있는지
- **고정 제약:** 바꾸면 안 되는 정의역, 공리, 권한, 사용자 선택

목표가 문맥으로 복원되지 않거나 서로 모순되면 그 상태를 먼저 밝히고, 결과가
달라지는 선택만 사용자에게 묻는다. 계획을 시작할 때와 단계 전환·반례·상태
요약 때마다 아래 정렬 감사를 수행한다.

1. 현재 단계가 최종 목표의 어느 고리를 닫는지 한 문장으로 연결한다.
2. 그 단계가 남길 증거와 완료 조건을 적는다.
3. 상태를 `[정렬]`, `[이탈]`, `[범위변경]` 중 하나로 판정한다.
4. `[이탈]`이면 원인과 **복귀 행동**을 적고, 연결이 복구되기 전에는 다음
   실행 단계로 넘기지 않는다.

사용자가 명시적으로 목표나 범위를 바꾼 것은 이탈이 아니라 `[범위변경]`이다.
부분 반례는 실패한 경로만 철회하며, 전체 모델 클래스의 no-go가 아니면 최종
목표를 몰래 축소하지 않는다. 테스트 수 증가처럼 유용하지만 목표 고리를 직접
닫지 않는 일은 보조 증거로 표시한다.

## 채팅 설명 계약

판단을 보고할 때 다음 정보를 짧은 순서로 제공한다.

1. 목표 계약을 먼저 설명하고, 왜 이 순서로 진행하는지와 각 단계의 산출물을
   짧게 말한다.
2. 질문을 한 문장으로 다시 말하고, 현재 아는 것과 아직 모르는 것을 분리한다.
3. 기호·정의역·단위를 먼저 선언한다. 지수·로그·확률에 들어가는 인자는
   무차원인지 확인하고, 차원 있는 양은 기준척도로 정규화한다.
4. 핵심 유도를 한 단계씩 정확한 LaTeX로 쓴다. 각 등식 옆에 사용한 공리나
   이전 정리를 표시하고, 계산 결과와 수치 검사를 증명으로 혼동하지 않는다.
5. 같은 내용을 문과 독자도 이해할 수 있는 짧은 비유로 번역한다. 비유는
   수식을 대체하지 않고 어떤 항·경계·선택을 가리키는지 명시한다.
6. 반례·경계·다른 해 가지를 말한다. 한 경로가 막히면 `중단`으로 끝내지
   말고, 목표량과 고정된 전제를 유지한 채 증명 순서를 바꾼 다음 독립 경로를
   제시한다. 새 공리를 넣으면 무엇을 추가했는지 한 줄로 고정한다.
7. 마지막에 정렬 감사를 다시 수행한다. 이어서 각 주장에 `[정리]`, `[공리]`,
   `[산출]`, `[경험식]`, `[미완성]`, `[예측]` 중 하나의 지위를 붙이고,
   다음으로 닫아야 할 최소 증명 의무를
   한 문장으로 적는다.

## 설명 깊이

대상 독자는 대학 1학년 수준의 미적분·선형대수·기초역학을 안다고 가정한다.
텐서, 함수공간, 경로적분을 쓰면 바로 뒤에 한 줄짜리 뜻풀이를 붙인다. 예를
들어 Hessian은 “작게 흔들었을 때 에너지가 얼마나 휘는지 재는 행렬”, Schur
보정은 “내부 방을 먼저 정리한 뒤 외부 방에 남는 효과”라고 설명한다. 비유가
실제 가정(경계조건, 측도, 부호)을 숨기지 않게 한다.

## 계획 템플릿

채팅 응답은 필요에 따라 다음 소제목을 사용한다.

- **현재 질문과 결론:** 한 문장 요약과 잠정 결론
- **목표 계약:** 최종 목표, 현재 하위 목표, 완료 조건, 고정 제약
- **계획과 이유:** 각 단계가 닫는 고리와 남길 증거
- **증명 순서:** 정의 → 가정 → 유도 → 검산
- **직관:** 수식의 역할을 나타내는 비유
- **정렬 감사:** `[정렬]`/`[이탈]`/`[범위변경]`, 근거, 필요한 복귀 행동
- **경계와 다음 고리:** 반례, 미완성 다리, 다음 최소 작업

논문·원장 파일을 수정하는 경우에는 각각 `ce/ko-academic-prose`와
`cejudge/paper-writer 원장 규칙`의 소유권을 지킨다. 이 스킬은 문서의 진리값을 승격하지
않으며, 하네스의 기계적 검사 결과를 수학적 증명이라고 부르지 않는다.
