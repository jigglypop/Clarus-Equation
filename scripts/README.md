# 스크립트 안내

현재 자동 연구 루프는 없다. Astra의 연구 판단은 루트 `AGENTS.md`와
`paper/검증_원장/연구_목표_계약.md`의 명시적 계약을 따른다.

`retired_claude/`에는 삭제된 `.claude` ledger와 Claude CLI를 요구하던 과거 드라이버를
보존한다. 현재 하네스로 실행하지 않는다.

## 코드 정리 로드맵

정리 단계는 물리 계산과 결과 JSON을 다시 생성하지 않는 작은 변경 묶음으로 진행한다.
각 단계는 집중 검사, 수집 검사, `git diff --check`를 통과한 뒤 다음 단계로 넘어간다.

| ID | 범위 | 완료 조건 | 상태 |
|---|---|---|---|
| CLEAN-01 | 테스트 공통 저장소 경로 | 활성 테스트의 `parents[1]` 직접 계산 0건, 공통 helper 계약 검사 통과 | 완료 |
| CLEAN-02 | 최소 필수 회귀 집합 | 활성 테스트 98개를 목표 직결 12개로 축소하고 allowlist로 고정 | 완료 |
| CLEAN-03 | `verify/` 절대경로 제거 | 질문·카드 디렉터리별로 입력 경로만 이식하고 저장 결과는 불변 | 부분 완료 |
| CLEAN-04 | 실행기와 결과 생성 분리 | import가 결과 파일을 쓰지 않고 명시적 `main()`에서만 산출 | 다음 |
| CLEAN-05 | 전체 수집 환경 복구 | 고정 requirements 환경에서 필수 12개 collect 오류 0건 | 환경 대기 |

`CLEAN-03`은 현재 `Q-0013/F-01`, `Q-0014/F-01`, `Q-0020/F-01`의 직접 실행 경로부터
처리한다. 다른 adversary 폴더는 깊이와 `ROOT`·`ADV`·외부 scratch 의미가 다르므로
저장소 전체 문자열 치환을 금지하고 질문 디렉터리별로 감사한다. 과거 JSON의 command와
수치는 provenance이므로 새 실행 없이 고치지 않는다.
