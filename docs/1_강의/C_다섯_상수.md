# 다섯 상수로 읽는 CE의 형식 구조

이 강의는 \(e,\pi,i,1,0\)을 물리량의 독립적 원인으로 취급하지 않는다.
이들은 지수, 위상, 복소구조, 항등원과 영원을 적는 생성 문법이다.

## 0. 형식 출처

| 표지 | 의미 |
|---|---|
| **[정의]** | 기호와 정의역 선언 |
| **[정리]** | 명시한 가정에서 증명된 명제 |
| **[공리]** | 선택·정규화·물리적 식별 입력 |
| **[산출]** | 위 항목들에 값을 넣은 계산 결과 |
| **[경험식]** | 자료를 참고해 고른 관계 |
| **[미완성]** | 필요한 증명·동역학·재현 자료가 남은 관계 |
| **[예측]** | 모델과 비교 규약을 사전에 고정한 관측 명제 |

관측값은 수학적 출처가 아니라 별도 비교 자료다.

## 1. \(e\): 곱적 감쇠

**[정리]** 연속이고 양수인 함수 \(S:[0,\infty)\to(0,\infty)\)가

\[
S(x+y)=S(x)S(y),\qquad S(0)=1
\]

을 만족하면 \(S(x)=e^{ax}\)인 상수 \(a\)가 존재한다. 비증가 조건을
더하면 \(a=-\lambda\), \(\lambda\geq0\)이다. 비자명 감쇠
\(S\not\equiv1\)을 더 요구하면 \(\lambda>0\)이다.

**[공리]** 이 비자명 가지에서 감쇠 깊이를 재척도해 \(\lambda=1\)로 둔다.

\[
S(x)=e^{-x}.
\]

[자족 증명](../참조/핵심_정리_증명.md#exp-theorem)

밑 \(e\)의 출현은 연속 곱법칙의 표현이다. 이 정리만으로 물리적 깊이
\(D\)나 특정 계수 \(e^{-1}\)가 선택되지는 않는다.

## 2. \(\pi\)와 \(i\): 위상

**[정리]** \(\theta\in\mathbb R\)일 때 복소 지수의 정의에서

\[
e^{i\theta}=\cos\theta+i\sin\theta,\qquad e^{i\pi}+1=0
\]

이다. 원의 주기는 \(2\pi\)다.

[자족 증명](../참조/핵심_정리_증명.md#euler-identity)

게이지 주기 하나를 특정 감쇠 깊이나 결합 합 규칙에 대응시키는 단계는
**[공리]**다. Euler 항등식 자체는 게이지군, 결합상수 또는 입자 스펙트럼을
결정하지 않는다.

## 3. \(0\)과 \(1\): 차원 방정식과 고정점

### 3.1 형식 차원

**[정리]** \(d\)차원 벡터공간에서

\[
\dim\Lambda^1=d,\qquad \dim\Lambda^2=\frac{d(d-1)}2.
\]

두 차원이 같다는 조건의 정수해는 \(d=0,3\)이다. 양의 정수로 제한하면
\(d=3\)만 남는다.

[자족 증명](../참조/핵심_정리_증명.md#exterior-dimension)

**[공리]** 이 비자명 분기를 실제 공간 차원으로 읽는다. \(N_c=d\),
\(N_w=d-1\), \(N_{\rm gen}=d\) 같은 내부 대칭의 식별은 각각 별도
물리 사상이며 위 대수 정리의 결론이 아니다.

### 3.2 최소 소멸 고정점

**[정리]** \(D>1\)이고

\[
F_D(q)=e^{-D(1-q)}
\]

라 하자. \(I_D=[0,1/D]\)에서 \(F_D\)는 자신으로 가는 축소사상이다.
따라서 \(I_D\) 안에 유일한 고정점 \(q_{\rm ext}\)가 있다. \(q=1\)도
전체 구간의 고정점이므로 구간을 명시하지 않은 광역 유일성·수렴 주장은
사용하지 않는다.

\[
q_{\rm ext}=-\frac1D W_0(-De^{-D}),\qquad
s_{\rm branch}=1-q_{\rm ext}.
\]

[축소사상·Lambert·Poisson 최소해 증명](../참조/핵심_정리_증명.md#poisson-fixed-point)

**[공리]** \(q_{\rm ext}\)나 \(s_{\rm branch}\)를 물리적 관측량에
대응시키려면 별도 readout 사상이 필요하다.

## 4. 조건부 Born 정리

**[정리: 외부 문헌]** \(\mathcal H\)를 실수 또는 복소수의 분리 가능한
Hilbert 공간,
\(\dim\mathcal H\geq3\)이라 하자. 닫힌 부분공간의 직교 projector \(P\)에
대한 함수 \(\mu(P)\in[0,1]\)가 \(\mu(I)=1\)이고 서로 직교하는 가산족
\(\{P_n\}\)에 대해

\[
\mu\!\left(\sum_nP_n\right)=\sum_n\mu(P_n)
\]

을 만족하면, 양의 trace-class operator \(\rho\geq0\),
\(\operatorname{Tr}\rho=1\)가 존재하여

\[
\mu(P)=\operatorname{Tr}(\rho P)
\]

이다.

[정확한 가정과 정식 문헌](../참조/핵심_정리_증명.md#gleason-theorem)

비맥락성과 가산성은 복소 위상 \(i\)만으로 도출되지 않는다. CE가 이 가정,
측정 instrument와 단일 시행 결과를 제공하는 단계는 **[미완성]**이다.

## 5. Koide 조건의 대수

**[정리]** 양의 \(x_i=\sqrt{m_i}\)에 대해

\[
\frac{\sum_i x_i^2}{(\sum_i x_i)^2}=\frac23
\]

인 조건은 \(x\)와 정규화된 민주축
\(u=(1,1,1)/\sqrt3\) 사이의 각이 \(45^\circ\)라는
조건과 동치다.

[자족 증명](../참조/핵심_정리_증명.md#koide-angle)

실제 렙톤 질량이 이 조건을 따르는 동역학과 절대 질량 스케일은
**[미완성]**이다.

## 6. 물리 입력과 계산

현재 수치 체인의 출처는 다음처럼 분리한다.

| 항목 | 출처 |
|---|---|
| \(\alpha_s(M_Z)\), \(v_{\rm EW}\), 입자 질량 | **[공리]** 외부 입력 |
| \(\sin^2\theta_W=4\alpha_s^{4/3}\) | **[경험식]** |
| \(\delta=\sin^2\theta_W\cos^2\theta_W\)를 차원 증분으로 읽기 | **[공리]** |
| \(D_{\rm eff}=d+\delta\) | **[공리]** 선형 결합 규칙 |
| 주어진 \(D_{\rm eff}\)의 \(q_{\rm ext}\) | **[산출]** |
| CKM·PMNS·Higgs·질량 관계 | **[경험식]** 또는 **[미완성]** |

CKM과 Higgs의 현재 경험식은
[입자물리 문서](../3_상수/4_입자물리.md), PMNS 경험식은
[PMNS 문서](../3_상수/5_PMNS.md)에 둔다.

## 7. 다섯 상수 밖에서 필요한 장론 자료

수학상수는 작용을 표기하지만 작용의 모든 계수를 고정하지 않는다.

**[공리]** 한 일관된 선택지는 \(Z_2\) singlet-portal EFT다.

\[
V(H,\phi)=V_H(H)+\frac12m_\phi^2\phi^2
+\frac{\lambda_\phi}{4}\phi^4
+\frac{\lambda_{H\phi}}2\phi^2H^\dagger H.
\]

**[정리]** \(\lambda_H,\lambda_\phi>0\)일 때 portal 사차항이 음이
아니기 위한 필요충분조건은

\[
\lambda_{H\phi}\geq-2\sqrt{\lambda_H\lambda_\phi}.
\]

[증명](../참조/핵심_정리_증명.md#portal-boundedness)

**[정리]** 부등식을 엄격하게 두고 scalar--Higgs bosonic truncation의
연속·유한 다항식 작용과 양의 격자 kinetic term을 사용하면 각 유한
Euclidean cutoff에서 partition function과 모든 다항식 모멘트가 유한하다.
[증명](../참조/핵심_정리_증명.md#finite-lattice-measure)

여기서 \(e\)는 가중치, \(\pi\)는 적분 정규화, \(i\)는 Lorentzian
진폭을 적는 데 나타난다. 그러나
\(m_\phi,\lambda_\phi,\lambda_{H\phi}\)의 값은 여전히 모형 입력이다.

## 8. 남은 이론 과제 **[미완성]**

- 부호와 경계항을 고정한 공변 작용
- 내부 게이지군과 물질 표현을 선택하는 동역학
- Yukawa·중성미자 질량행렬의 선택 동역학과 재위상 불변 CP 계산
- 고정점 확률을 우주론 관측량에 연결하는 likelihood
- Born 측도 가정을 산출하는 측정 동역학

이 자료가 없는 관계는 다섯 상수의 수학적 항등식만으로 유도된 것으로
세지 않는다.
