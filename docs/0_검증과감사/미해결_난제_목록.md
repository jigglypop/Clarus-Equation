# 미해결 난제 목록

이 문서는 Clarus Equation 작업에서 앞으로 검산하거나 명시적으로 `Open`으로 남겨야 할 인류 주요 미해결 문제를 정리한다. 목적은 "풀었다"는 선언이 아니라, 어떤 문제를 아직 못 닫았는지와 무엇을 만들면 검산 가능한지 분리하는 것이다.

상태 기준:

- `Open`: 학계에서도 미해결이고, repo에서도 아직 닫지 않음.
- `Bridge`: repo에 수식/해석/부분 코드가 있으나 정식 해결은 아님.
- `Tooling`: 계산 도구나 테스트는 있으나 문제 자체 해결은 아님.
- `Out of scope`: 현재 repo의 핵심 축과 직접 연결되지 않음.

## 8. 정리 원칙

앞으로 새 문서를 만들 때는 다음 기준을 적용한다.

1. 검산 코드, test, 또는 명확한 falsification target이 없으면 `Bridge` 이상으로 올리지 않는다.
2. 개인적 사고 로그나 임시 대화 덤프는 정식 문서로 승격하지 않고 삭제한다.
3. 같은 주제를 반복하는 `.md`는 하나의 canonical 문서로 합치고, 나머지는 제거한다.
4. "해결"이라는 단어는 Exact proof, independently reproduced numerical likelihood, 또는 accepted theorem 수준에서만 쓴다.
