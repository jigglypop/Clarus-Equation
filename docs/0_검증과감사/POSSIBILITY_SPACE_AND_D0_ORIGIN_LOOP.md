# 가능성 공간과 (d=0) 우주 기원 루프

## 1. 명제 분리

| 명제 | 판정 |
|---|---|
| 유한한 완전역사 집합 전체를 한 번에 평가할 수 있다 | `PROVED / FINITE` |
| 현재까지의 과거를 고정한 뒤 목표 미래의 조건부 확률을 높일 수 있다 | `PROVED / FINITE` |
| 유한한 양의 재가중으로 prior 확률 0인 역사를 만들 수 있다 | `REFUTED` |
| (d=0) 내부에 세계선·관찰자가 존재한다 | `REFUTED UNDER CE DEFINITIONS` |
| (d=0)이 (d=3)보다 시간적으로 먼저 존재했다 | `OPEN / NOT DERIVED` |
| CE가 물리적 (d=0\to d=3) 우주탄생 동역학을 갖는다 | `OPEN` |

## 2. 완전역사 관조의 유한 정리

후보 역사 (\gamma_i)의 시간표본 (O_{ij}), 역사 prior (p_i), 시간
가중치 (w_j)가 모두 유한하고 정규화되어 있다고 하자. 각 완전역사
readout과 ensemble readout은

\[
R_i=\sum_jw_jO_{ij},\qquad
\langle R\rangle=\sum_ip_iR_i
\]

로 유일하고 유한하게 정의된다. 이는 모든 시간표본과 모든 후보역사를
한 연산에서 평가한다. 시공간 내부 관찰자가 시간을 초월한다는 뜻은
아니며, 완전역사에 작용하는 함수형의 유한 근사다.

## 3. 목표 미래 재가중 정리

현재까지 같은 과거를 가진 후보만 조건화한 분포를 (p_i), 목표 집합을
(A)라 하자. 목표에 강도 (u\ge0)의 tilt를 주면

\[
p_i^{(u)}=
\frac{e^{u1_A(i)}p_i}{\sum_je^{u1_A(j)}p_j}.
\]

초기 목표질량을 (q=p(A))라 하면

\[
q(u)=\frac{e^uq}{1-q+e^uq},\qquad
q'(u)=\frac{e^uq(1-q)}{(1-q+e^uq)^2}.
\]

따라서 (0<q<1)이면 (u>0)에서 목표질량이 엄격히 증가한다.

## 4. zero-support 불변 정리

재가중이 유한한 양의 함수 (w_i>0)로 주어지면

\[
p_i'=\frac{w_ip_i}{\sum_jw_jp_j}.
\]

그러므로 (p_i=0\iff p_i'=0)이다. 이미 후보공간에 없거나 현재 기록과
양립하지 않아 조건부 질량이 0인 과거·CTC 역사는 재가중만으로 생성되지
않는다. 후보공간 자체 또는 역사 사이의 전이 kernel을 새로 정의해야 한다.

## 5. (d=0) 관찰자 조건부 불가능 정리

CE 문서의 (d=0) 정의를 채택하면 공간 경로, 게이지 상호작용, 내부 상태
변화가 없다. 관찰자를 세계선과 상호작용을 통해 기록을 갱신하는 물리계로
정의하면 (d=0) 내부 관찰자는 존재할 수 없다. 이는 CE 정의 아래의
조건부 정리이며, 의식 일반에 대한 형이상학적 정리가 아니다.

## 6. (d=0) 우주가 먼저였는가

먼저 **무차원량(dimensionless quantity)**과 **0차원 공간
(zero-dimensional space)**을 구분한다. 단위변환에 불변인 확률·결합상수·
비율을 사용한다는 사실은 배경 공간의 차원 (d)가 0임을 함의하지 않는다.
CE의 무차원 코어와 (d=0) 대수근은 서로 다른 명제다.

차원식

\[
d(d-3)=0
\]

에서 (d=0,3)이 나오는 것은 산술적 사실이다. 하지만 근 두 개의 존재는
시간 순서, 전이율, 초기조건 또는 우주탄생 진폭을 주지 않는다. 특히
(d=0)에 시간이 정의되지 않는다는 CE 해석을 채택하면 “(d=0)이 먼저”의
`먼저`도 내부적으로 정의되지 않는다.

물리적 기원 명제로 승격하려면 최소한

\[
\mathcal A_{0\to3}
=
\int_{d(\lambda):0\to3}\mathcal Dd\,\mathcal Dg\,
e^{iS[d,g]/\hbar}
\]

와 같은 차원·계량 동역학, 경계조건, 정규화 측도, (d=3) 선택확률 및
관측 가능한 흔적이 필요하다. 현재 CE에는 이 package가 없다.

## 7. 최종 판정

CE가 현재 닫은 것은 “(d=0)이 방정식의 자명근/경계 읽기다”까지다.
“우주 이전에는 오직 무차원 우주만 있었다”는 주장은 현재 공리적 해석
또는 존재론적 서사이며 증명된 물리 결론이 아니다.
