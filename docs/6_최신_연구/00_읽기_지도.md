# 최신 연구 조립 목차: 측정, 접힘과 암흑 표현

이 문서 묶음은 2026년 8월까지 `_workspace/ce/`에서 완료되거나 중간 판정을 받은 연구를 루트 문서 체계에 연결하는 독자용 입구다. 작업공간의 보고서를 그대로 복사하지 않고, 살아남은 좁은 명제·완전 반례·미완성 다리를 기존 정본과 연결한다.

핵심 기여는 열 가지다. 첫째, 외부 0차원 경계, 이산 측정 기록, 유한시간 측정 과정과 지속 carrier를 서로 다른 타입으로 분리한다. 둘째, 측정깊이와 비선택 기회비용에서 실제로 증명되는 무차원 구조를 보존한다. 셋째, 그 구조를 암흑부문으로 읽으려면 별도의 공변 작용·초기자료·미시 사상이 필요하다는 한계를 명시한다. 넷째, 0차원 composition에서 초기 abundance로 가는 사상의 rank 결손을 계산하고, 최신 SH0ES를 외부 목표로 한 $r_d$·$r_s$ 폐쇄와 아직 남는 $\omega_m$ 조건을 분리한다. 다섯째, 빛을 3차원 현실의 ‘렌더링 창’으로 보는 직관을 인과기하로 검산해, 빛원뿔이 정하는 등각구조와 빛만으로 정할 수 없는 부피·곡률·차원을 분리한다. 여섯째, 겹친 가능성이 국소 기록으로 남는 과정과 그 기록의 인과적 접근가능성을 분리하고, 중력을 branch 확률 자체가 아니라 조건부 유효작용의 기하 saddle로 정식화한다. 일곱째, 공간 개장을 서로 다른 무게의 선택 좌석 장부로 형식화해 물질·복사·진공의 조건부 희석식을 증명하고, 같은 장부가 서로 다른 압력과 current를 허용한다는 비식별성 반례를 고정한다. 여덟째, 좌석을 실제 다종 양자장으로 옮긴 조건부 개장 작용에서 매끈한 질량 변화의 점유수와 에너지 장부를 계산하고, 순간 개장의 UV 발산과 생성입자만으로 암흑에너지가 되지 않는 no-go를 분리한다. 아홉째, 플랑크 길이를 최소 존재길이가 아니라 최소 고전기하 렌더링 경계로 읽는 새 가설을 정리하고, 별도 렌더장·확률=에너지 직접대응·강제 tanh 경로를 폐기한 뒤 `0D 사건 → causal 2-complex → BF/Plebanski → stationary 3+1 Lorentzian GR` 브리지를 조건부 정리 프로그램으로 재구성한다. 열째, Poisson split을 독립 rendered continuation과 merge face로 marking한 최소 블록 RG를 계산해 $m_*=1-1/D$의 정확한 평균 임계 의미를 고정하고, full Poisson law의 고정점 주장을 폐기한 뒤 persistent Q-spine과 scale-free folded side tree를 실제 국소 고정구조로 분리한다.

## 독해 규칙

- 기계 검증 성공은 적힌 식의 구현 무결성만 뜻한다.
- 조건부 EFT의 안정성은 0차원 기원이나 암흑물질·암흑에너지 동일성을 증명하지 않는다.
- `COMPLETE`는 해당 연구 질문의 감사 종료를 뜻하며 강한 부모 주장의 참을 뜻하지 않는다.
- `INTERIM`과 `OPEN / NO_RESULT_YET`는 최신 정본에서 미완성으로 유지한다.
- 10장의 렌더링·0D→GR 구조는 아직 `CONJECTURAL BRIDGE`이며, 기존 GR/Plebanski 수학을 0D 규칙에서 유일하게 유도했다는 뜻이 아니다.
- 11장의 Q-spine 고정점은 split/merge **count law와 persistent-line quotient**의 결과이며 face topology, simplicity와 GR fixed point를 증명하지 않는다.
