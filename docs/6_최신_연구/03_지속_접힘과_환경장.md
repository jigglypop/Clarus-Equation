# 3. 지속 접힘과 환경장

이 장은 완료된 기록이 지속 carrier로 보존된다는 공리를 채택했을 때 얻는 최소 동역학을 설명한다. record에서 carrier로 가는 사상은 미완성이지만, 사상 이후의 finite network 수학은 조건부로 닫을 수 있다.

## 3.1 carrier measure와 coarse graining

비선택 history의 pushforward 후보를

$$
\mu_F(B)=\int_{\Gamma_{\rm ns}}w(\gamma)
\mathbf1_B(F(\gamma))\nu_{\rm ns}(d\gamma)
$$

로 쓴다. 유한 atomic 특수화는 $\mu_F=\sum_jw_j\delta_{X_j}$다. 이는 measure의 정의이지 표준 양자역학이 carrier를 생성한다는 정리가 아니다.

strict point stress는 일반적으로 UV 발산을 일으키므로 폭 $\ell>0$의 form factor로 coarse-grain해야 한다. Gaussian witness에서는 $\int g_\ell^2\propto\ell^{-3}$, $\int|\nabla g_\ell|^2\propto\ell^{-5}$이므로 $\ell\to0$을 물리적 local-stress 극한으로 취할 수 없다.

## 3.2 단일 환경장과 기억

유일한 동적 상태를 무차원 환경장 $\chi$로 두고 exponential memory kernel을 택하면 finite carrier 위에서

$$
\tau\dot{\boldsymbol\chi}
=-(\boldsymbol\chi-\mathbf b)+AW\sigma(\boldsymbol\chi),
\qquad \sigma(\chi)=\frac{\chi}{1+\chi}
$$

를 얻는다. 이 식은 해당 kernel 아래 Volterra 식의 정확한 ODE 환원이다.

비음 행렬 $W$가 constant row sum을 갖고 $\mathcal B=A\rho(W)>1$이면 uniform positive branch $\chi_*=\mathcal B-1$이 존재한다. 그러나 zero seed와 zero initial history에서는 $\chi\equiv0$도 해이므로 threshold는 spontaneous creation 법칙이 아니다.

## 3.3 물리적 범위

환경장은 carrier 사이의 재활성화를 매개할 수 있지만 energy reservoir와 같지 않다. retarded kernel의 인과성, finite-width UV 규약과 네트워크 안정성은 구현 가능한 조건부 결과다. $\nu_{\rm ns}\to\mu_F$의 실제 물리 사상, covariant stress와 암흑부문 동일성은 다음 장에서도 추가 입력으로 남는다.
