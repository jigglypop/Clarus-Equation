# 뇌의 프로그래밍 언어 역공학 루프

이 문서는 신경 기록에서 잠재 상태와 재사용 가능한 계산 단위를 추정하는 조건부 역공학 protocol이다. 독자는 population recording, 상태공간 모형, 인과 개입과 holdout의 뜻을 안다고 가정한다. 입력은 공통 timebase를 가진 신경·행동·자극 기록이고 출력은 후보 상태·operator·반증 gate이며, 성공은 개입과 cross-task holdout에서의 재현이고 계산 비유를 실제 생물학적 기제로 동일시하는 것은 실패다.

> **현재 판정: `TASK CODE SKELETON = YES /
> NEURAL LANGUAGE IDENTIFIED = NO`**
>
> - `YES`: 실험 과제는 `무엇을 읽을지`와 `어느 반응축으로 보낼지`라는
>   두 칸짜리 후보 명령으로 분해된다.
> - `YES`: 공식 processed 자료의 과제 간 색·반응 해독 결과는 재현된다.
> - `YES`: 표현 수준의 공유 감각 frontend·과제별 route·공유 운동
>   backend 인터페이스는 후보 골격으로 지지된다.
> - `YES`: 403개 열을 27개 실제 기록 세션으로 되돌릴 수 있어 제한된
>   세션별 operator 탐색은 가능하다.
> - `NO`: 고정 operator뿐 아니라 `K=2/3` 상태 전환, 잠재 공통 successor,
>   D1↔D3 frozen transfer와 상태 수준 부모+잔차 proxy도 고정된 대조군을
>   통과하지 못했다.
> - `NO`: 재사용 가능한 신경 operator, 실제 공통 callee, 과제 상속 트리,
>   고정 뉴런 opcode, 문법 또는 뇌 프로그래밍 언어가 식별된 것은 아니다.
> - `TEST_UNAVAILABLE`: 빠진 과제 조합의 실제 예측과 선택적 교란·rescue는
>   공개 자료에 없어서 아직 시험할 수 없다.
>
> 가장 유력한 첫 후보는 “뉴런 하나가 명령어다”가 아니라,
> **여러 뉴런의 드리프트 위에서 반복되는 저차원 집단 연산**이다.
> 그러나 집단 상태가 해독된다는 사실만으로 프로그래밍 언어가 되지는
> 않는다. 여기서 `NO`는 “현재 식별하지 못했다”는 뜻이며, 뇌에 그런
> 체계가 절대로 없다는 뜻은 아니다.

## 1. 바이트코드 비유를 한 단계 더 정확히 만들기

바이트코드 비유는 관측된 출력에서 숨은 계산 단위를 찾는 어려움을 설명할 뿐 뉴런이 디지털 명령을 실행한다는 주장 아니다. 실제 기제는 spike·calcium·synapse의 시간척도와 개입 자료로 따로 검증해야 한다.

뉴런의 spike train만 기록해서 뇌의 계산을 찾는 일은 디버그 심볼이 없는
바이트코드를 읽는 것보다도 어렵다. 실제로는 다음 정보까지 모르는
분산형 자기수정 장치의 전압 흔적을 보는 데 가깝다.

- 명령어 경계가 어디인지
- 어느 상태가 register이고 어느 상태가 입력인지
- 동일한 계산이 매번 같은 뉴런에서 실행되는지
- 지역별 clock이 같은지
- code와 data가 분리되어 있는지
- 학습 때문에 실행 중 배선이 바뀌는지

따라서 spike 하나를 bit, 뉴런 여덟 개를 byte처럼 고정 대응시키는
역공학은 실패하기 쉽다. 그렇다고 원리적으로 해독이 불가능한 것은 아니다.
개별 구현이 바뀌어도 보존되는 **입출력 관계, 저차원 상태 전이, 과제 간
재사용과 인과적 결손**을 찾으면 한 단계 위의 중간표현을 복원할 수 있다.

핵심 질문은 “어느 뉴런이 무슨 뜻인가”에서 다음으로 바뀐다.

> 어떤 집단 상태 전이가 여러 문맥에서 같은 연산으로 재사용되고,
> 그 출력이 다른 집단 연산의 입력으로 합성되는가?

## 2. 이름 충돌부터 제거한다

기존 Clarus cell과 신경 assembly는 정의역과 관측 단위가 다르므로 이름만으로 합치지 않는다. 이 절은 용어 충돌이 인과 대응 주장으로 번지는 것을 막는 경계다.

이 저장소의 기존 `Clarus cell`은 이미 생명 유지와 자기동일성 loop를 가진
실제 생물학적 세포를 뜻한다. AGI 문서의 `ClarusCell`은 국소 상태를 가진
런타임 단위다. 뉴런 집단까지 같은 이름으로 부르면 세 층이 섞인다.

| 이름 | 이 문서에서의 뜻 | 현재 지위 |
|---|---|---|
| **생물학적 Clarus cell** | 막·대사·수리·동일성을 유지하는 실제 세포 | 기존 생명 문서의 정의 |
| **neural Clarus assembly** | 여러 뉴런에 걸친 국소 재귀 집단의 후보 | 관측으로 찾아야 하는 `Open` 객체 |
| **Clarus instruction** | assembly 상태가 구현하는 재사용 가능한 상태 전이 | `Open` |
| **Clarus program** | instruction을 gating하여 순서대로 합성한 실행 경로 | `Open` |
| **Clarus IR** | 뉴런별 spike와 행동 사이의 잠재 중간표현 | working hypothesis |

따라서 이 문서에서 unqualified `cell`은 생물학적 세포에만 쓰고,
계산 단위 후보는 `assembly` 또는 `instruction`이라고 부른다.

## 3. 신경 코드와 프로그래밍 언어의 차이

decode 가능성은 기록이 행동 정보를 담는다는 뜻이지 문법·호출·instruction의 존재를 증명하지 않는다. 아래 구분은 관측 상관, 잠재 상태 추정, 조작 가능한 계산 가설을 순서대로 분리한다.

어떤 자극이나 행동을 neural activity에서 decode할 수 있다는 사실은
**신경 코드**의 증거다. 프로그래밍 언어에는 더 강한 구조가 필요하다.

| 단계 | 필요한 관측 | 허용되는 가장 강한 표현 |
|---:|---|---|
| `L0` | 자극·행동이 집단 활동에서 decode됨 | neural code |
| `L1` | 뉴런이 바뀌어도 잠재 상태나 동역학이 보존됨 | neural intermediate representation 후보 |
| `L2` | 압축 상태와 입력으로 다음 상태·출력을 예측 | stateful transducer 후보 |
| `L3` | 같은 전이가 다른 과제·문맥에서 재사용됨 | reusable instruction 후보 |
| `L4` | 처음 보는 조합을 기존 instruction의 합성으로 예측 | language-like compositional system |
| `L5` | 특정 instruction의 개입이 예측한 하위 기능만 깨고 rescue됨 | causal programmable substrate 후보 |

현재 CE 뇌 문서와 공개 신경과학이 지지하는 것은 주로 `L0`–`L2`, 일부
과제에서 `L3`–`L4` 후보까지다. 뇌 전체에 공통인 언어 또는 `L5`는
아직 열려 있다.

### 3.1 assembly 하나는 모나드가 아니다

assembly의 입력·상태·출력 표기는 계산 모형의 interface일 뿐 범주론적 객체나 생물학적 모듈의 직접 측정이 아니다. 동일한 transition을 가진 경쟁 latent model과의 holdout 비교가 필요하다.

neural Clarus assembly의 상태를 $s$, 입력을 $u$, 출력과 새 상태를
$(o,s')$라고 하면 최소 후보는 다음과 같은 확률적 상태 변환이다.

$$
\mathcal T_k:(s,u,c)\longmapsto \mathbb P(o,s'),
$$

여기서 $c$는 과제, 각성, 보상과 진동 위상 같은 문맥이다.
assembly 하나는 모나드 자체라기보다 확률적 state transducer, 범주론
용어로는 상태·확률 효과를 가진 Kleisli arrow 후보에 가깝다. 모나드는
이런 효과 있는 계산들을 일관되게 합성하는 **전체 문맥과 연산 체계**를
가리킨다. “내부 상태가 있다”는 이유만으로 단일 assembly를 모나드라고
부를 수 없다.

1. 아무 연산도 하지 않는 identity 경로가 있어야 한다.
2. 한 assembly의 출력 효과를 다음 assembly에 넘기는 합성이 안정해야 한다.
3. 괄호를 다르게 묶어도 관측 가능한 합성 결과가 허용 오차 안에서 같아야
   한다.
4. 숨은 상태 효과가 선언한 경계를 통해서만 다음 연산에 전달되어야 한다.

이 unit/bind/associativity의 경험적 근사를 여러 assembly의 합성 체계가
통과하기 전에는 각 단위를 `stateful transducer`라고만 부르고,
`monadic composition system`은 가설로 남긴다.

### 3.2 하나의 전역 언어인가, 영역별 local DSL인가

전역 언어와 영역별 DSL은 cross-area transfer와 latency를 달리 예측하는 경쟁 가설이다. 기록 영역·task·timebase가 다르면 같은 operator라는 판정은 보류한다.

지금까지 “뇌의 언어”를 단수로 쓴 것은 가설을 지나치게 좁혔다. 더
검증 가능한 후보는 다음 네 층이다.

| 층 | 후보 역할 | 현재 판정 |
|---|---|---|
| 공통 생물학적 runtime | 막전위, spike, 시냅스, 억제성 cell type | 존재 |
| 영역별 local DSL | 영역 고유 세포·배선·국소 동역학이 구현하는 특수 계산 | `PLAUSIBLE`, 미식별 |
| 영역 간 ABI | 전체 상태가 아니라 좁은 population subspace로 주고받는 interface | 일부 영역에서 관측 후보 |
| 과제 program | 감각·규칙·행동 primitive를 문맥에 맞게 재조합 | 일부 과제의 표현 후보 |

이 구분은 단순 소프트웨어 비유만은 아니다. 마우스 피질의 cell-type
atlas에서는 많은 억제성 유형이 영역 사이에 공유되지만 흥분성 유형에는
영역 특이성이 있었다
([Tasic et al., 2018](https://www.nature.com/articles/s41586-018-0654-5)).
동시 기록한 V1–V2에서는 V1 전체 활동이 아니라 작은 communication
subspace만 V2 변동과 연결되었다
([Semedo et al., 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6449210/)).
같은 시각 경로의 feedforward와 feedback도 서로 다른 population
pattern을 사용했다
([Semedo et al., 2022](https://www.nature.com/articles/s41467-022-28552-w)).

따라서 현재 가장 정직한 후보는 **공통 물리 runtime 위의 영역별 local
DSL + 좁은 interface**다. 그러나 이것은 아직 언어 식별이 아니다.
token 경계, 문법, 보지 않은 합성과 인과 semantics가 없기 때문이다.

### 3.3 누가 최적화하는가

분산된 가소성·neuromodulation은 중앙 optimizer 비유의 대안이다. 목적함수는 관측된 learning curve와 perturbation으로 식별해야 하며, 단일 loss를 실제 뇌가 명시적으로 계산한다고 단정하지 않는다.

현재 문헌은 모든 시냅스의 목적함수를 계산하는 중앙 optimizer 하나보다
분산된 여러 시간척도를 더 지지한다.

1. 현재 활동과 억제 경쟁이 지금 사용할 세포·수상돌기 가지를 고른다.
2. 국소 Hebbian/STDP와 eligibility trace가 함께 활성화된 연결에
   임시 흔적을 남긴다.
3. 도파민 같은 neuromodulator가 어떤 국소 흔적을 굳힐 가치가 있는지
   제한된 시간창에 표시한다.
4. 수면·replay가 경험을 다시 활성화해 장기 고정과 간섭 해소에
   기여한다.

서로 다른 운동 과제가 같은 뉴런에서도 서로 다른 수상돌기 가지에
가소성을 만들었고, SST 억제를 제거해 가지 구획이 겹치자 앞 과제의
가소성과 수행이 손상되었다
([Cichon & Gan, 2015](https://www.nature.com/articles/nature14251)).
도파민은 이미 활성화된 국소 spine 흔적을 좁은 시간창에서 구조적
가소성으로 바꿨다
([Yagishita et al., 2014](https://pmc.ncbi.nlm.nih.gov/articles/PMC4225776/)).
학습 때 활성화된 감각 뉴런을 이후 수면 중에만 억제해도 기억의
구체성이 손상되었다
([Clawson et al., 2021](https://www.nature.com/articles/s41467-021-21471-2)).

그러므로 역공학 질문은 “누가 최적화하나?”에서 **어느 시간척도의 어떤
기전이 어떤 자유도를 바꾸는가?**로 바꾼다. 현재 Tafazoli snapshot에는
초보→숙련 궤적, 시냅스, neuromodulator와 수면 기록이 없으므로
`optimizer mechanism identified = NO`다.

여기서 수면 단계와 생성 확산을 같은 것으로 놓지 않는다. 현재
`sleep.py`는 NREM에 라플라시안 평활화와 선택된 covariance update를,
REM에 비선택 residual의 저차원 remix와 잡음을 배정한다. 이것은
phase별 학습 규칙의 구현이지, NREM이 score-based diffusion의 forward
noising이고 REM이 그 reverse-time sampler라는 증명이 아니다. 실제
NREM과 REM이 서로의 확률적 역과정인지, 뇌가 시간조건부 score를
학습하는지는 검증되지 않았다. 따라서
`NREM = forward`, `REM = reverse`는 앞으로 비교할 **연구 비유**로만
두며, 이 대응으로 optimizer나 신경 언어 claim을 올리지 않는다.

### 3.4 영역 크기보다 latency와 throughput인가

영역 비교에서는 node 수보다 입력-출력 지연과 정보 throughput이 관측 가능한 변수다. sampling rate와 preprocessing이 다르면 latency 추정은 비교 불가능하다.

이 구분이 영역 수보다 직접적이다.

| 축 | 측정 질문 |
|---|---|
| latency | 입력 뒤 usable interface 또는 행동 출력이 나오기까지 얼마나 걸리는가 |
| throughput | 단위 시간에 서로 간섭 없이 몇 개의 독립 항목·bit를 처리하는가 |
| capacity | 충분한 시간 동안 구별 가능한 상태·정보가 얼마나 포화되는가 |
| persistence | 정보를 얼마 동안 안정적으로 유지하는가 |
| cost | 그 성능에 필요한 spike, ATP, 배선과 동기화 비용은 얼마인가 |

큰 영역이나 많은 뉴런은 병렬 capacity와 throughput을 늘릴 수 있지만,
장거리 왕복과 직렬 stage가 늘면 single-item latency는 커질 수 있다.
작은 국소 회로는 빠를 수 있지만 동시 처리 가능한 독립 축이 적을 수 있다.
또 오래 유지되는 association-cortex code는 단순히 “느린 열화판”이 아니라
빠르게 바뀌는 sensory code와 다른 기능이다. 실제 마우스 auditory
cortex와 posterior parietal cortex는 각각 수백 ms의 빠른 변동과 약
1초의 안정된 choice code라는 다른 population timescale을 보였다
([Runyan et al., 2017](https://www.nature.com/articles/nature23020)).

`영역 수가 늘면 성능이 단조롭게 떨어진다`는 보편 명제의 판정은
`NO`다. 영역 수와 실제 활성 뉴런 수, 영역 간 유효 통신 차원, 표현의
겹침, noise correlation과 에너지 비용은 서로 다른 변수다.

더 정확한 후보는 다음이다.

> 무차별적인 모집 자체보다, 필요 없는 통신폭·표현 충돌·공유 잡음과
> 장거리 비용이 이득을 넘을 때 성능이 떨어진다.

많은 영역이 참여해도 좁은 interface만 열리면 간섭을 제한할 수 있다.
반대로 위 수상돌기 실험처럼 한 영역 안에서도 두 과제가 같은 국소
자원을 잘못 공유하면 기능이 손상된다. 에너지도 적을수록 무조건 좋은
것이 아니다. 시냅스 ATP 사용을 낮춘 마우스 V1에서는 정밀 부호화와
시각 변별이 함께 손상되었다
([Padamsey et al., 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC8788933/)).
방해 자극 관련 활동이 피질에 넓게 퍼져도 운동피질의 출력 attractor가
분리되어 행동 영향이 차단될 수도 있다
([Finkelstein et al., 2021](https://www.nature.com/articles/s41593-021-00840-6)).
큰 V1 population의 정보는 뉴런을 더할 때 감소하지 않았지만 중복과
information-limiting correlation 때문에 빠르게 포화했다. 전체 뉴런의
작은 일부만으로 정보의 대부분을 담을 수 있었다
([Rumyantsev et al., 2020](https://www.nature.com/articles/s41467-020-20722-y)).
즉 “더 크면 나쁘다”보다 **추가 자원이 새 독립 정보와 병렬성을 주는지,
중복·공유잡음·통신비용만 더하는지**가 핵심이다.

따라서 다음 실험은 단순한 영역 개수가 아니라 **정확도–latency–
throughput–persistence–energy**의 Pareto 곡선을 그리고, 유효 통신폭과
표현 겹침을 함께 조절해 최소 충분 회로와 interface를 찾는다. 현재
Tafazoli 파일은 pseudo-trial을 이어 붙였고 온전한 반응시간·동시
noise-correlation이 없으므로 이 곡선의 판정은 `TEST_UNAVAILABLE`다.

### 3.5 확산과 drift를 instruction으로 오독하지 않는다

확산·drift·전이는 서로 다른 동역학적 관측량이다. 이름이 instruction과 비슷하다는 이유로 제어 코드의 증거로 읽지 않으며 개입으로 구분해야 한다.

이 문서에서 만나는 비슷한 용어는 서로 다른 관측을 요구한다.

| 용어 | 이 문서에서 허용되는 뜻 | 현재 claim lock |
|---|---|---|
| graph heat diffusion | 연결 그래프 위 신호의 라플라시안 평활화 | 연산 프리미티브는 구현, 신경 instruction 증거는 아님 |
| stochastic drift-diffusion / neural sampling | 결정론적 drift와 무작위 충격을 가진 상태 과정 | 코드에 잡음 이완은 있으나 Tafazoli 자료에서 sampling law를 식별하지 않음 |
| score-based generative diffusion | 학습한 score로 잡음화를 역시간 복원하는 생성 모형 | 현재 구현과 이번 신경 probe의 범위 밖 |
| representational drift | 날짜·학습에 따라 neuron tuning이나 표현이 바뀌는 경험적 현상 | 위 세 확산 중 어느 하나와 자동 동일시하지 않음 |

특히 spike 변동이 확률적이라는 사실만으로 score가 발견된 것도 아니고,
상태 전이를 예측했다는 사실만으로 reverse diffusion이나 instruction이
식별된 것도 아니다. 현재 stationary·switching operator probe는
trial 안의 시간 전이를 비교하는 회귀·대조 분석이며, score network,
reverse-time SDE 또는 수면 단계의 역과정을 학습하지 않는다.

## 4. 최소 형식 가설

최소 가설은 관측 $x_t$를 잠재 상태와 입출력으로 압축하는 식별 가능한 모델 family를 정한다. identifiability는 좌표변환·label switching·동등한 predictor를 배제하는 제약과 holdout 없이는 보장되지 않는다.

동시에 기록한 뉴런 활동을 $x_t$, 외부 입력을 $u_t$, 문맥을 $c_t$,
행동을 $y_t$라고 하자. 후보 assembly $k$에는 학습 자료에서만 정한
encoder $E_k$와 상태 $z_t^k=E_k(x_t)$를 둔다.

$$
(z_{t+1}^k,o_t^k)
=
T_k(z_t^k,u_t,c_t).
$$

`Clarus IR` 가설은 다음을 동시에 요구한다.

1. **경계 충분성**: $z_t^k$가 assembly 내부의 모든 뉴런을 다시 보지
   않아도 다음 경계 출력과 상태를 거의 보존한다.
2. **재사용성**: 같은 $T_k$가 서로 다른 문맥과 과제에서 살아남는다.
3. **합성성**: 따로 학습한 $T_A,T_B$로 보지 않은 $A\!\to B$ 실행을
   예측한다.
4. **호출 제어**: 문맥과 gating state가 다음에 실행될 $T_k$를 예측한다.
5. **인과적 국소성**: $T_k$를 교란하면 그 instruction이 포함된
   프로그램만 선택적으로 손상된다.

assembly는 서로 겹칠 수 있다. 따라서 처음부터 뉴런을 서로소 칸으로
나누지 않고, overlap을 허용한 membership과 공유 뉴런 대조군을 둔다.

## 5. 역공학 루프

아래 loop는 관측 단위에서 시작해 잠재 상태, 재사용성, 인과 개입으로 진행하는 순서다. 앞 단계가 실패하면 다음 단계의 프로그램 해석을 승격하지 않는다.

### Loop 0 — 관측 단위 고정

공통 timebase는 spike·calcium·행동·외부 사건의 대응을 위한 최소 입력이다. clock drift와 missing event가 있으면 이후 operator 추정은 실패로 기록한다.

- spike, calcium, LFP, 행동과 외부 사건의 공통 timebase를 고정한다.
- neuron identity와 assembly latent identity를 별도로 기록한다.
- 훈련·검증·시험을 trial뿐 아니라 session, subject와 task 조합으로
  분리한다.
- assembly 탐색에 쓴 자료를 동일 gate의 시험 자료로 재사용하지 않는다.

### Loop 1 — instruction boundary 후보 찾기

경계 후보는 connectivity·지연정보·저차원 동역학에서 추정하는 가설이다. 후보 수를 holdout 뒤에 늘리면 look-elsewhere 효과가 생긴다.

- recurrent connectivity, 지연 상호정보, 저차원 동역학과 perturbation
  response로 후보 assembly를 만든다.
- 전체 집단을 한 덩어리로 둔 monolithic latent model과 비교한다.
- 같은 크기·차수의 shuffled membership와 time-shifted control을 둔다.

이 단계의 출력은 “함수”가 아니라 고정된 후보 경계다.

### Loop 2 — 상태와 입출력 역추정

잠재 상태는 관측을 압축하는 추정량이며 생물학적 세포형과 동일하지 않다. 상태 차원은 predictive likelihood와 개입 일반화로 선택해야 한다.

- 후보 경계 안의 미시 활동을 작은 상태 $z_t$로 접는다.
- $z_t,u_t,c_t$에서 다음 상태와 경계 출력을 예측한다.
- 전체 미시상태 oracle에 대한 정보 손실과 shuffled boundary 대비 이득을
  함께 보고한다.

압축 모델이 단지 차원이 작아서 regularization 이득을 얻는 것을 막기 위해
동일 차원의 PCA, factor model과 generic state-space baseline을 둔다.

### Loop 3 — 재사용 instruction 찾기

재사용성은 과제 밖 문맥으로 transition을 옮겼을 때의 성능으로 검증한다. 한 session 안의 적합은 재사용 가능한 primitive의 증거가 아니다.

- 한 과제에서 학습한 상태 전이를 다른 과제·문맥에 그대로 옮긴다.
- neuron identity가 아니라 정렬된 latent/interface 수준에서 비교한다.
- 과제별 전용 decoder가 더 좋으면 범용 instruction 주장을 철회한다.

### Loop 4 — 문법과 합성 검사

합성 검사는 primitive 조합이 학습에서 제외한 sequence를 예측하는지 묻는다. 실패하면 문법 가설을 축소하고 단순 sequence model과 다시 비교한다.

primitive `A`, `B`, `C`는 각각 따로 학습한다. 학습에서 제외한
`A→B`, `B→A`, `A→C→B`를 다음 세 모형으로 예측한다.

1. 학습한 primitive operator의 순차 합성
2. 조합별 lookup 또는 task-specific decoder
3. 동일 파라미터 수의 monolithic recurrent model

처음 보는 조합에서 primitive 합성이 이기고, 순서를 바꾸었을 때 예측도
그에 맞게 바뀌어야 “문법” 후보가 된다.

### Loop 5 — 호출과 인과 개입

호출 가설은 cue·gate·phase를 조작했을 때 다음 transition이 바뀌는지로만 시험한다. 관찰 상관은 call graph의 증명이 아니다.

- task cue, thalamic/basal-ganglia gate, oscillatory phase가 다음 primitive
  선택을 예측하는지 본다.
- assembly 전체, 핵심 completion neuron, 동일 수의 임의 뉴런을 각각
  perturb한다.
- 목표 primitive를 포함한 조합만 선택적으로 깨지는지 본다.
- downstream state를 주입했을 때 기능이 rescue되는지 검사한다.

단순한 활동 상관과 선택적 instruction 실행을 가르는 핵심 단계다.

### Loop 5A — 프론트엔드, 공통 callee와 상속 트리

공통 callee는 서로 다른 입력이 공유 transition으로 모이는 계산 가설이다. 영역별 recording coverage가 부족하면 상속 트리의 식별은 미완성이다.

고정 operator 하나가 모든 뉴런에 반복된다고 먼저 가정하지 않는다. 다음
세 구조를 서로 다른 경쟁모형으로 둔다.

1. **직접 동역학**: 각 과제 집단이 자기 상태에서 바로 다음 상태를 만든다.
2. **공통 callee 호출**: 과제별 프론트엔드 상태가 하나의 공통 실행
   assembly로 들어가고, 그 assembly의 출력 규칙을 재사용한다.
3. **상속 트리**: 모든 과제가 공유하는 부모 operator가 있고, 각 과제는
   작은 저차원 residual만 덧붙인다.

공통 callee라면 서로 다른 선행 상태가 같은 병목 상태로 수렴해야 한다.
그 병목에 머무는 동안에는 직전 과제보다 현재 병목 상태가 다음 상태를 더
잘 예측해야 하며, 같은 출력 규칙이 다른 입력 경로에도 그대로 옮겨져야
한다. 단순히 모든 trial이 사건 시각에 맞춰 비슷해지는 것과 구분하기
위해 train fold에서 계산한 사건별 평균을 제거하고, 시간만 쓰는 gate,
역방향 시간과 whole-trial successor shuffle을 함께 비교한다.

상속 트리라면 과제별 operator를 완전히 따로 저장하는 모형보다
`공통 부모 + 작은 자식 residual`이 held-out trial을 더 잘 예측하면서
전체 설명 길이도 짧아야 한다. residual이 부모만큼 커지면 그것은 상속이
아니라 과제별 별도 모형이다.

호출과 상속도 구분한다. 호출은 실행 중 여러 선행 경로가 같은 상태로
합류하는 **시간적 흔적**이고, 상속은 여러 과제의 변환이 한 부모 규칙을
공유하는 **모형 구조**다. 둘은 동시에 참일 수도, 하나만 참일 수도 있다.

실제 call/return까지 주장하려면 callee에 들어오기 전의 caller 정보가
보존되었다가 callee 뒤의 복귀 경로를 선택하는 모습이 필요하다. 한 영역의
processed pseudopopulation만으로는 호출한 세포, 호출된 세포와 복귀선을
직접 구분할 수 없으므로, 여기서는 먼저 latent call-state의
수렴·공통전이·분기라는 약한 proxy만 시험한다.

### Loop 6 — 드리프트와 복제

session drift 아래에서도 interface가 보존되는지는 longitudinal holdout으로 확인한다. neuron identity 변화와 latent 좌표 회전은 별도 정렬 오류로 분리해야 한다.

- neuron tuning이 변해도 latent transition과 interface가 session을 넘어
  정렬되는지 본다.
- 다른 동물, 다른 뇌 영역과 다른 기록 장비에서 반복한다.
- 동일한 primitive library를 강제하지 않고, 보존되는 연산 동치류가
  있는지를 검사한다.

## 6. 실행 gate

표의 gate는 관측 적합, cross-task 재사용, 개입 인과성의 성공·실패를 분리한다. 하나의 gate만 통과해도 언어 가설 전체가 확정되지는 않는다.

| Gate | 질문 | 성공 조건 | 실패가 뜻하는 것 |
|---|---|---|---|
| `NL0-boundary` | 후보 assembly 경계가 예측 정보를 보존하는가 | full-microstate oracle에 가까우며 matched shuffled boundary보다 우수 | 후보 segmentation 폐기 |
| `NL1-state` | 상태가 history 효과를 운반하는가 | input-only/무상태 모형보다 held-out transition 우수 | 함수가 아니라 순간 decoder |
| `NL2-reuse` | 같은 primitive가 문맥을 건너 재사용되는가 | cross-context transfer가 task-specific null보다 우수 | 문맥별 conjunctive code |
| `NL3-compose` | 보지 않은 순서를 operator 합성으로 예측하는가 | lookup·평균·순서무시 대조군보다 우수 | library는 있어도 language 아님 |
| `NL4-control` | 다음 primitive의 호출 규약이 있는가 | gate state가 label-shuffled control보다 우수 | 자발 동역학 또는 사후 분절 |
| `NL5-causal` | instruction 단위의 선택적 결손이 있는가 | targeted perturbation과 rescue가 미리 명시한 방향과 일치 | 상관 구조에 머묾 |
| `NL6-replicate` | 동물·세션·과제 밖에서 반복되는가 | 분할 밖 effect와 interface 동치류 유지 | 데이터셋 특이 해석 |

synthetic toy에서 일부 분석 배관이 통과해도 실제 `NL0`–`NL4`를 통과한
것으로 세지 않는다. 실제 언어 판정에는 실자료 `NL0`–`NL4`에 더해 최소
`NL5`와 `NL6`이 필요하다.

## 7. 반드시 이겨야 하는 경쟁 설명

경쟁 모형은 언어 비유가 불필요한 더 단순 설명을 제공한다. 동일 데이터·compute·holdout에서 이기지 못하면 복잡한 프로그램 해석을 채택하지 않는다.

| 경쟁 모형 | 설명 | 구분하는 대조군 |
|---|---|---|
| 단일 뉴런 code | 소수 neuron이 직접 행동을 운반 | top-neuron과 matched-unit ablation |
| 분산 mixed-selectivity | 고정 instruction 없이 전체 집단이 과제별로 계산 | task-specific decoder와 cross-task transfer |
| monolithic latent dynamics | 작은 잠재계는 있으나 분해 가능한 primitive가 없음 | unseen composition과 operator interchange |
| conjunctive lookup | 각 조합을 별도 상태로 저장 | 학습하지 않은 순서·조합 |
| 프론트엔드 없는 직접 동역학 | 각 입력 경로가 독립적으로 출력까지 계산 | 여러 predecessor의 공통 병목 수렴과 frozen callee transfer |
| 사건시각 기반 가짜 공통 호출 | 같은 자극 시각 때문에 모든 궤적이 함께 움직임 | train-only event-mean 제거, time-only gate와 time reversal |
| 과제별 별도 operator | 공통 부모 없이 각 과제가 자기 규칙을 저장 | parent+child residual의 held-out MDL과 residual 크기 |
| generic low-rank regularization | 작은 차원이 예측을 쉽게 할 뿐 | 동일 차원 PCA/state-space baseline |
| 운동·각성 artifact | assembly가 계산이 아니라 움직임/상태를 읽음 | movement, pupil, reward, timing conditional baseline |

어느 단순 모형이 같은 시험 성능을 더 적은 자유도로 내면
“프로그래밍 언어” 판정을 내리지 않는다.

## 8. 현재 직접 증거가 허용하는 범위

현재 직접 증거는 관측된 decoding과 transition의 범위만 허용한다. 생물학적 module·전역 grammar·의도된 instruction 같은 더 강한 주장은 미완성으로 남는다.

| 결과 | 이 가설에 주는 정보 | 허용 판정 |

## 9. 이 저장소의 기존 결과와 연결

기존 결과는 지정 코드·dataset·preprocessing의 조건부 출력이다. 새 역공학 가설은 그 결과를 재사용할 수 있지만 지위·수치를 자동으로 바꾸지 않는다.

기존 mouse/IBL 루프는 다음 두 결과를 동시에 보존한다.

- pre-stimulus에서 stimulus, pre-movement에서 movement로 가는 low-rank
  population transition은 반복되었다.
- 개별 latent axis identity와 choice-specific residual subspace는
  세션 밖에서 안정적으로 반복되지 않았다.

이는 “고정된 몇 뉴런 또는 고정 축이 명령어”라는 해석보다
“정렬 가능한 집단 동역학의 동치류가 연산 단위”라는 가설과 더 잘 맞는다.
그러나 IBL 과제만으로는 보지 않은 primitive 조합을 시험하기 어렵다.
기존 결과는 `NL0–NL1` 후보 증거이지 `NL3-compose` 통과가 아니다.

AGI 런타임의 `ClarusCellState`는 이 생물학적 결과를 구현한 증거가 아니라,
상태 있는 transducer가 어떤 식으로 실행될 수 있는지 보여 주는 설계
대조군으로만 사용한다.

## 10. 첫 실행 루프의 범위

첫 루프는 synthetic benchmark에서 분석 문법의 식별 가능성을 먼저 시험한다. synthetic 통과는 실제 뇌의 기제 증명이 아니라 blind inverse protocol의 사전 검증이다.

이번 저장소 루프는 먼저 synthetic benchmark에서 분석 문법 자체를
반증 가능하게 만든다.

```text
oracle-labelled stateful primitive library
  → boundary/state sufficiency
  → cross-context reuse
  → unseen A→B composition
  → self-loop / cross-assembly open-loop feedback report

controls
  → shuffled transition targets
  → 같은 true target에 맞춘 tuple lookup
  → seen tuple memorization과 완전 holdout tuple을 분리
  → feedback edge severing
```

구현 경로:

- manifest: `benchmarks/neural_language_synthetic_v1.json`
- 구현: `reality_stone/python/reality_stone/clarus/neural_language_gate.py`
- 실행: `examples/brain/neural_language_gate.py`
- 테스트: `tests/test_neural_language_gate.py`

synthetic gate의 완료 플래그는 방법이 알려진 생성 모형과 반례를 구분하는지만
뜻한다. 다음 플래그는 실제 자료와 인과 개입 전까지 고정해서 끈다.

```text
full_brain_language_identified = False
neural_clarus_assembly_validated = False
causal_instruction_set_validated = False
```

고정 seed 실행 결과는 다음과 같다.

| oracle-labelled 방법 검사 | 결과 | manifest 기준 |
|---|---:|---:|
| held-out context 경계 전이 정확도 | 0.921875 | $\ge 0.85$ |
| held-out 대 leave-one-out 최대 context TV | 0.043852 | $\le 0.08$ |
| nuisance 변수의 추가 예측 이득 | 0.000000 | $\le 0.02$ |
| early-to-late primitive 재사용 정확도 | 0.920750 | $\ge 0.85$ |
| 완전 holdout tuple의 `A→B` 합성 정확도 | 0.859677 | $\ge 0.75$ |
| 같은 holdout의 shuffled-target 정확도 | 0.250806 | $\le 0.35$ |
| 같은 holdout의 tuple-lookup 정확도 | 0.220161 | $\le 0.35$ |
| seen tuple lookup memorization | 0.848670 | $\ge 0.75$ |
| 자기 feedback open-loop 정확도 | 1.000000 | $\ge 0.85$ |
| 자기 feedback edge-severed 정확도 | 0.000000 | gap $\ge 0.40$ |
| 두 assembly feedback open-loop 정확도 | 1.000000 | $\ge 0.85$ |
| 두 assembly edge-severed 정확도 | 0.207500 | gap $\ge 0.40$ |

판정은 `SYNTHETIC_ORACLE_LABELED_METHOD_CONTROL_PASS`다. 다만 이
benchmark는 알려진 경계, 잠재 상태와 primitive label을 생성 단계에서
제공하고 모든 단일 state-token 조합을 관측한다.
따라서 assembly 발견, 입력만 쓰는 무상태 모형과의 `NL1` 비교,
호출/gating인 `NL4`, 실제 인과·복제인 `NL5–NL6`은 아직 시험하지 않았다.
shuffled-target 대조군도 shuffled assembly-membership 대조군과 다르다.
즉 이 통과는 분석 코드의 양성·음성 방법 대조군일 뿐 생물학적
`NL0–NL6` 통과가 아니다.

feedback 검사는 one-step에서 학습한 operator를 깊이 6까지 teacher forcing
없이 전개하고, 연결 메시지를 끊었을 때 성능이 무너지는지 본다. 이는
feedback topology와 깊이 외삽의 sanity check이지, base case, 종료 조건,
call/return stack을 가진 언어적 재귀의 증거가 아니다. 자기 feedback에서는
현재 상태와 되먹임 메시지의 의미가 여전히 완전히 분리되지 않으므로 그
식별성도 다음 loop에 남는다.

## 11. blind inverse loop와 실제 자료의 사전 명세

blind inverse loop는 정답 상태와 primitive label을 분석기에서 숨겨 선택 편향을 줄인다. 데이터·metric·정지 기준을 사전 명세하지 못하면 결과는 탐색적 경험식으로만 남는다.

다음 synthetic loop에서는 정답 상태와 primitive label을 분석기에서 숨긴다.
문맥별 선형 혼합, neuron permutation/dropout과 session drift로 만든
spike-like 관측만 주고, train split에서 경계·encoder·interface를 찾은 뒤
보지 않은 subject/context에서 복원해야 한다. context-specific monolithic
dynamics와 distributed mixed-selectivity 생성기를 음성 대조군으로 둔다.

### 11.1 필요한 최소 과제

factorial task는 primitive와 문맥을 분리해 일반화 실패를 드러내기 위한 입력 조건이다. 과제 난이도나 보상 구조가 바뀌면 operator 비교도 다시 설계해야 한다.

primitive가 명시된 factorial task가 필요하다.

```text
감각 primitive: colour / shape
규칙 primitive: pro / anti
기억 primitive: immediate / delay
행동 primitive: response axis 1 / axis 2
```

일부 단독 primitive와 조합을 훈련에 쓰고, 최소 두 조합은 완전히
holdout한다. 같은 trial을 primitive 발견과 조합 시험에 함께 쓰지 않는다.

### 11.2 필요한 최소 기록

동시 population recording과 행동·사건 timebase는 상태추정의 최소 자료다. 기록 누락·sampling mismatch는 latent boundary의 미탐 원인으로 보고한다.

- 동시 population recording
- 정확한 stimulus, cue, reward와 movement timestamp
- pupil, lick, wheel, EMG 등 행동 artifact
- 여러 task block과 반복 session
- 가능하면 targeted perturbation과 rescue

### 11.3 비교 순서

비교는 단순 baseline에서 복잡한 latent model로 진행해 추가 자유도의 기여를 분리한다. 순서를 어기고 최고 성능만 고르면 프로그램 가설은 반증 불가능해진다.

1. 행동·시간만 사용한 baseline
2. top neuron과 전체 neuron decoder
3. 동일 차원의 generic latent state
4. monolithic recurrent model
5. frozen Clarus instruction library
6. held-out composition
7. targeted perturbation

다섯 번째 모형이 첫 네 모형을 이기더라도 여섯 번째와 일곱 번째가
실패하면 “유용한 latent model”까지만 인정한다.

## 12. 정지 조건

반복된 실패는 더 복잡한 비유를 붙일 이유가 아니라 가설을 강화하지 말아야 할 신호다. 아래 정지 조건은 성능·개입·재사용성의 실패를 명시한다.

다음 중 하나가 반복되면 언어 가설을 강화하지 않는다.

- assembly 경계가 subject/session split마다 완전히 달라진다.
- 압축 상태가 matched generic latent baseline을 이기지 못한다.
- primitive transfer가 task-specific decoder보다 나쁘다.
- unseen composition이 lookup/monolithic model보다 낫지 않다.
- 순서를 바꾸어도 예측이 같아 문법이 필요하지 않다.
- targeted perturbation이 특정 instruction이 아니라 전역 성능만 낮춘다.
- movement, reward, arousal를 조건화하면 효과가 사라진다.

실패하면 뇌에 계산이 없다는 결론이 아니라, **재사용 가능한 이산
instruction library**보다 연속적이고 분산된 동역학 모형이 낫다는
결론으로 돌아간다.

## 13. 현재 결론과 다음 병목

현재 결론은 직접 기록이 허용하는 가장 약한 문장으로 제한한다. 다음 병목은 새로운 이름이 아니라 데이터 경계와 경쟁모형의 분리다.

문헌 전체에서 허용되는 가장 강한 후보 문장은 다음이다.

> 뇌에는 개별 뉴런보다 안정적인 population-level latent dynamics와,
> 일부 과제에서 재사용·순차 결합되는 representational subspace가 있다.
> 이것은 neural intermediate representation과 instruction library의
> 후보지만, 뇌 전체의 프로그래밍 언어 또는 monadic composition system이
> 확인된 것은 아니다.

이번 로컬 재검증은 여기서 한 단계 더 엄격하다. 공식 snapshot의
stationary session-local operator는 정방향이 역방향보다 거의 낫지 않고,
cross-dimension frozen transfer도 target refit에 졌다. 이어서 고정한
state-dependent switching, common-successor와 state-parent+rank1
proxy도 matched VAR·time-only·reverse·event-mean 대조를 통과하지
못했다. 따라서 이 자료에서 `shared directed transition primitive`,
`frontend-to-common-callee observational candidate`와
`task-inheritance tree identified`는 모두 현재 `NO`다. 다음 병목은
전뇌 공통 operator를 더 복잡하게 만드는 일이 아니라, 영역별 local
DSL과 좁은 communication interface, 그것을 학습시키는 분산 optimizer,
최소 충분 회로를 다영역 원자료에서 서로 분리하는 일이다.

## 14. 이번 재검증에서 실제로 복원한 코드 골격

복원한 골격은 지정 processed data에서의 계산적 설명 후보다. 실제 원숭이 뇌가 같은 코드 구조를 의도적으로 실행한다는 생물학적 기제 주장은 별도 개입이 필요하다.

수식 없이 말하면 이 과제의 원숭이는 매번 두 선택을 한다.

1. 화면에서 **모양을 읽을지 색을 읽을지** 고른다.
2. 읽은 결과를 **반응축 1로 보낼지 반응축 2로 보낼지** 고른다.

컴파일러식 이름을 붙이면 다음과 같다.

| 과제 | 첫 명령 | 둘째 명령 | 기록 여부 |
|---|---|---|---|
| `S1` | `READ_SHAPE` | `ROUTE_AXIS_1` | 기록됨 |
| `C1` | `READ_COLOR` | `ROUTE_AXIS_1` | 기록됨 |
| `C2` | `READ_COLOR` | `ROUTE_AXIS_2` | 기록됨 |
| `S2` | `READ_SHAPE` | `ROUTE_AXIS_2` | **빠짐; 사전 예측** |

이 표에서 `S2`는 임의로 만든 이름이 아니다. 두 종류의 읽기 명령과 두
종류의 보내기 명령을 모두 조합하면 유일하게 비어 있는 네 번째 칸이다.
따라서 현재 역공학기가 내놓는 가장 구체적인 예측은 다음이다.

```text
S2 = READ_SHAPE → ROUTE_AXIS_2
```

현재 자료를 디컴파일러 출력처럼 적으면 허용되는 최대 코드는 다음이다.

```text
CANDIDATE ONLY

BELIEF_GATE(task_state)
  → SELECT {READ_SHAPE, READ_COLOR}
  → ENCODE selected category
  → SELECT {ROUTE_AXIS_1, ROUTE_AXIS_2}
  → EMIT action
```

`BELIEF_GATE`는 stimulus 전에 task belief가 decode되고 관련 감각 표현의
크기와 함께 변한다는 관측에서 붙인 후보 이름이다. 실제 함수 호출 경계나
causal gate를 발견했다는 뜻은 아니다.

여기까지는 **과제 설계의 프로그램 골격**을 복원한 것이다. 아직 뇌가 이
두 명령을 실제로 따로 저장하고 순서대로 호출했다는 증거는 아니다.
`S2`를 기록하지 않았기 때문에, 한 과제에서 배운 `ROUTE_AXIS_2`를 모양
읽기에 붙였을 때 신경 궤적과 행동을 맞히는지도 시험되지 않았다.

### 14.1 비유: 세 노선만 본 지하철 관제실

지하철 비유는 부분 관측에서 공통 routing을 추정하는 직관을 돕는다. 보이지 않는 노선·지연·외부 신호가 있으면 같은 관측이 다른 구조에서도 나올 수 있다.

지하철 관제 로그에서 다음 세 운행을 봤다고 하자.

- 빨간 승객을 1번 승강장으로 보낸다.
- 파란 승객을 1번 승강장으로 보낸다.
- 파란 승객을 2번 승강장으로 보낸다.

그러면 “색을 읽는 장치”와 “승강장을 고르는 장치”가 따로 있을 수 있고,
빠진 운행은 “빨간 승객을 2번 승강장으로 보내기”라고 예측할 수 있다.
하지만 세 로그만으로 관제실 안에 정말 두 개의 독립 모듈이 있다고
확정할 수는 없다. 하나의 큰 표가 세 경우를 통째로 외웠을 수도 있고,
연속적인 제어기가 같은 결과를 만들었을 수도 있다. 빠진 네 번째 운행을
미리 예측해 맞히는 것이 모듈 조합과 통암기를 가르는 첫 시험이다.

### 14.2 프론트엔드가 공통 셀을 호출한다는 대안

공통 callee는 관측된 transition을 설명하는 경쟁 가설이며 프론트엔드와 cell의 실제 해부학적 연결을 뜻하지 않는다. perturbation과 cross-area 동시기록이 반증 조건이다.

관제실 비유를 한 단계 더 밀면, 색·모양을 읽는 창구가 열차를 직접 끝까지
운전하지 않을 수 있다. 창구는 목적지만 붙여 공통 운행실에 넘기고,
운행실이 여러 노선에서 재사용되는 출발·정지·방향전환 루틴을 실행할 수
있다. 뇌에서도 과제별 뉴런 집단이 프론트엔드 또는 dispatcher이고, 다른
assembly가 공통 callee일 가능성이 있다.

```text
CANDIDATE CALL GRAPH — 아직 발견된 회로가 아님

TASK_BELIEF
  └─ FRONTEND {READ_SHAPE | READ_COLOR}
       └─ CALL COMMON_ENCODE
            └─ DISPATCH {ROUTE_AXIS_1 | ROUTE_AXIS_2}
                 └─ CALL COMMON_ACTION
```

이 해석은 논문의 가장 강한 관측과도 맞닿는다. 서로 다른 과제에서 감각
subspace와 운동 subspace가 각각 재사용되고, 관련 감각 표현이 먼저 나타난
뒤 과제에 맞는 운동 subspace가 뒤따랐다. 따라서 subspace 수준에서는
`공유 감각 frontend → 과제별 route → 공유 motor backend`가 좋은 후보
아키텍처다. 다만 공개 동적 산출물은 trial별 decoder score의 Pearson
상관이고, 한 과제의 감각축이 미래 운동축을 인과적으로 “호출했다”는
개입 결과가 아니다.

또 다른 가능성은 객체지향식 상속에 가까운 계층이다.

```text
PARENT_TRANSITION
  ├─ SHAPE_CHILD = PARENT_TRANSITION + small shape residual
  ├─ COLOR_CHILD = PARENT_TRANSITION + small color residual
  ├─ AXIS_1_CHILD = PARENT_TRANSITION + small axis-1 residual
  └─ AXIS_2_CHILD = PARENT_TRANSITION + small axis-2 residual
```

이 두 그림은 설명용 가설이지 현재 결과가 아니다. 공통 호출을 지지하려면
서로 다른 frontend 궤적이 같은 중간 상태로 수렴하고, 그 뒤의 frozen
전이가 과제를 건너 살아남아야 한다. 상속을 지지하려면 공통 부모에 작은
residual만 더한 모형이 과제별 독립 모형보다 짧고 정확해야 한다. 현재
공개 snapshot은 LPFC의 27개 작은 세션뿐이고 영역 간 동시 기록과
perturbation이 없으므로, 동일한 생물학적 “공통 셀”을 직접 지목할 수는
없다. 다만 세션 안의 latent call-state와 계층적 parameter sharing은
다음 역공학 loop에서 반증 가능하다.

## 15. 공식 파일을 역추적해 드러난 데이터 구조

공식 파일의 field 구조는 분석 입력의 provenance를 고정한다. field 이름과 checksum은 데이터 의미의 완전한 설명이 아니므로 task protocol과 preprocessing을 함께 확인해야 한다.

공식 `PFC_ClassifierData.mat`의 필드 이름만 보면 403개 뉴런의 거대한
동시 상태처럼 읽기 쉽다. 코드를 거꾸로 따라가 보니 그렇지 않았다.

| 감사 결과 | 실제 뜻 | 잘못 읽었을 때 생기는 오류 |
|---|---|---|
| 403개 열 | 서로 다른 날짜의 기록을 이어 붙인 pseudopopulation | 한 뇌의 403뉴런 동시 상태로 착각 |
| 복원된 그룹 | 27개 기록 세션, 세션당 2–30뉴런 | 세션 경계를 가로질러 가짜 assembly 생성 |
| 동물 | Chico 97뉴런, Silas 306뉴런 | `IncludedNeu4Ana_AnimalNum`의 반대 순서를 그대로 신뢰 |
| 시간축 | 81점, 10ms 간격 | 81개 독립 표본으로 계산 |
| 실제 counting 창 | 100ms 창을 10ms씩 이동 | 이웃 점의 90% 중첩을 무시 |
| classifier 반복 250회 | 독립 동물·trial이 아니라 재표집 반복 | 표본 수를 250으로 부풀림 |
| 저장 내용 | 모든 반복이 아니라 마지막에 덮어쓴 fold-1 snapshot 하나 | 250회 원자료가 보존된 것으로 착각 |

세 차원의 train/test 배열은 각각
`pseudo-trial × neuron × time`이다. 첫째와 셋째 차원은 세션별 제한된
탐색에 쓸 수 있다. 둘째 차원은 전체 rule pool의 평균을 train/test를
나누기 전에 뺀 흔적이 남아 있어, held-out 정보가 전처리에 들어간다.
원자료가 없어 train-only 재중심화를 할 수 없으므로 둘째 차원은 주
발견 분석에서 제외한다.

이것은 포기가 아니라 역공학의 첫 성공이다. 실행 파일의 여러 메모리
덤프를 한 프로세스의 연속 메모리로 잘못 합치던 버그를 찾아낸 것과 같다.
앞으로는 403열 전체 PCA나 HMM을 금지하고, 27개 세션 안에서만 상태와
전이 후보를 찾는다.

### 15.1 공식 결과가 실제로 지지하는 범위

processed classifier 곡선은 지정 task 간 decoding 범위를 지지한다. 이는 latent grammar나 causal operator의 직접 증거가 아니라 경쟁 설명과의 비교 출발점이다.

checksum이 맞는 processed classifier 곡선에서는 다음 과제 간 해독이
재현된다.

| processed 결과 | peak accuracy | 사건 뒤 평균 |
|---|---:|---:|
| 색 `C1→C2` | 0.7182 | 0.5973 |
| 색 `C2→C1` | 0.6621 | 0.5830 |
| 반응 `C1→S1` | 0.9597 | 0.7958 |
| 반응 `S1→C1` | 0.9581 | 0.7947 |

이는 서로 다른 과제에서 공유되는 population 표현의 **후보 증거**다.
그러나 target을 미리 정한 decoder 결과이지, label을 숨긴 채 신경
operator를 발견한 결과는 아니다.

공식 angle artifact 네 항목을 다시 매핑하면 직접적인 shared-colour
비교는 두 번째 항목 하나다. C1 색 축과 C2에서 학습한 색 축의 평균
각도는 76.81도이고 shuffle은 약 90도이며, 저장된 lower-tail 값은
0.000999다. 같은 기간 spike-count 축은 76.51도, 값은 0.005994다.
나머지 두 color–shape 비교를 shared-response 증거로 읽으면 안 된다.
이 파일에는 `ResponseLoc` 축 자체가 없고, 공식 plotting 코드도 첫 두
항목만 그린다.

또 하나의 코드 감사 결과도 중요하다. 이름이
`TransferEntropyAnalysis`인 경로는 실제로 transfer entropy를 계산하지
않는다. smoothed decoder score 사이의 Pearson 상관을 계산하고, 양수
대각선만 투영한다. 유의성 mask도 투영에 쓰지 않는다. 따라서 이 결과는
시간 순서와 호환되는 상관 구조이지 정보 흐름이나 인과 방향의 증거가
아니다.

학습 자료는 task belief가 커질 때 관련 감각 표현이 선택적으로 커지고
무관 표현은 줄어드는 패턴을 보인다. 이것은 “다음에 무엇을 읽을지”
고르는 제어 신호 후보와 맞지만, intervention이 없으므로 인과적 함수
호출이라고 부르지 않는다. 공개 plotting 집계에서 S1→C2→C1 sequence의
task-belief 해독은 약 12.1%p, 색 해독은 약 4.6%p 증가하고, 무관 shape
해독은 약 3.4%p 감소한다. 이 값의 250개 행은 생물학적 반복이 아니라
classifier 반복이다.

### 15.2 세션별 stationary operator를 실제로 역추적한 결과

stationary operator 추정은 session 안에서의 근사다. session drift·neuron turnover·unobserved input이 크면 같은 operator 결론은 반증된다.

공식 체크섬을 다시 확인한 뒤 D1·D3의 train tensor만 읽고, 27개 기록
세션을 각각 분리했다. 전체 trial을 여섯 fold로 나누고 train fold에서만
Anscombe 변환, 뉴런 표준화와 rank 1/2/3/5 PCA를 맞췄다. 100ms 뒤 상태를
예측하되 정답 label, `AllFactors`, D2와 저장된 test row는 전혀 쓰지
않았다.

27개 세션 중앙값은 다음과 같다.

| 경로 | source-grand-mean 대비 설명력 | 역방향 대비 이득 | trial-shuffle 대비 이득 | target-refit 대비 |
|---|---:|---:|---:|---:|
| D1 within | 0.79% | 0.59% | 2.07% | — |
| D3 within | 1.68% | 0.34% | 2.59% | — |
| D1→D3 frozen | 1.22% | 0.19% | 2.87% | −1.75% |
| D3→D1 frozen | 2.56% | 0.97% | 3.18% | −2.54% |

같은 trial의 100ms 자기기억은 trial successor를 뒤섞은 모형보다 조금
나았다. 이것이 약한 `YES session_local_short_memory`다. 그러나 절대
설명력은 작고, source에서 고정한 operator는 target 자료에 다시 맞춘
operator보다 나빴다. train fold의 사건시각 평균 궤적을 제거하면
정방향의 역방향 대비 이득은 D1, D3, D1→D3, D3→D1에서 각각
`+0.13%, −0.26%, +0.03%, −0.09%`로 사라졌다. rank를 바꿔도 방향성
이득은 1%를 넘지 않았다. 서로 90% 겹치는 10ms 시작점을 반복 가중하지
않도록 100ms 간격의 비중첩 시작점만 남긴 민감도 분석에서도 네 경로의
방향성 이득은 `+0.66%, −0.02%, −0.12%, +0.46%`였고 판정은 같았다.

따라서 이 모델 클래스의 답은 명확하다.

```text
YES session-local short memory
NO  shared stationary directed operator
```

여기서 `NO`는 공통 callee나 상속 트리까지 부정하지 않는다. 한 operator가
여러 실행 국면을 평균내며 신호를 지웠거나, 관측한 LPFC가 실행기가 아니라
frontend일 가능성은 별도 모델로 시험해야 한다.

### 15.3 상태 전환, 공통 callee와 상태 계층을 실제로 시험한 결과

이 시험은 label·반응·task를 고정한 조건부 비교다. 상태 계층의 우위는 intervention과 독립 session holdout에서 재현될 때만 강화된다.

두 번째 실자료 loop는 위 대안을 그대로 시험했다. label, 반응, 과제
정보, `AllFactors`, 둘째 차원과 저장된 test tensor는 계속 가렸다.
27개 세션의 D1·D3 train tensor만 사용하고, whole-trial 6-fold,
train-only 잠재좌표, 100ms lag와 서로 겹치지 않는 100ms anchor를
고정했다. gate는 test의 미래나 successor를 받을 수 없고 현재·과거
상태만 받는다.

상태 수 $S=2,3$과 gate 기억 깊이 $P=1,2,3$은 별도 축으로
탐색했다. 판정에는 $S=P$인 같은 복잡도 비교를 사용했다. 상태별
현재상태 map과 `VAR(order=S)`는 동역학 parameter 수가 같고, 상태 gate
좌표와 모형 선택 비용은 held-out Gaussian codelength/BIC proxy에
추가했다. 이 값은 strict 또는 prequential MDL이 아니다.

양수면 왼쪽 모형이 더 짧다는 부호로 기록한 54개
`세션×차원` 중앙값은 다음과 같다.

| 상태 $S$ | 기억 $P$ | switching−VAR 설명력 | switching의 code 이득 | 상태-parent+rank1의 code 이득 | hub의 time-only 대비 설명력 | hub의 code 이득 |
|---:|---:|---:|---:|---:|---:|---:|
| 2 | 2 | −1.41% | −0.4712 bit/scalar | −0.5084 bit/scalar | −0.33% | +0.2284 bit/scalar |
| 3 | 3 | −1.80% | −1.1854 bit/scalar | −1.0538 bit/scalar | −0.73% | −0.0138 bit/scalar |

`S=2` hub는 caller별 모형보다 훨씬 짧고 time-only 모형보다도 parameter
비용을 포함하면 짧았다. 그러나 예측 오차 자체는 time-only보다 나빴고,
정방향은 역방향보다도 나빴다. 사건시각 평균을 제거한 $S=P=2$에서도
switching의 VAR 대비 설명력과 code 이득은 각각 `−1.20%`,
`−0.4725 bit/scalar`, hub의 time-only 대비 설명력은 `−1.52%`였다.
따라서 이것은 “공통 함수를 찾았다”가 아니라 **caller 세부를 버린 작은
모형이 압축에는 유리하지만, 사건시각에 잠긴 연속 궤적보다 미래를 잘
설명하지 못했다**는 near miss다.

공통 callee 후보는 within-dimension hub 하나로 판정하지 않았다. 같은
상태 수에서 hub가 time-only·caller-specific·reverse·event-mean 대조를
모두 이기고, source에서 고정한 표현·gate·operator가 D1↔D3 양방향에서
target-refit까지 이겨야 한다. 이 결합 gate는 실패했다. 상태별 공통
부모+rank-1 residual도 matched VAR보다 짧지 않았다.

따라서 이 processed snapshot과 사전 고정한 모형 클래스의 답은 다음과
같다.

```text
YES              shared representational frontend/backend candidate
NO               state-dependent switching proxy
NO               latent common-successor proxy
NO               frontend-to-common-callee observational candidate
NO               frozen cross-dimension switching transfer
NO               state-parent-plus-rank1 proxy
NO               biological common callee identified
NO               task-inheritance tree identified
TEST_UNAVAILABLE common-callee architecture exists or is absent
TEST_UNAVAILABLE task-inheritance architecture exists or is absent
NO               brain programming language identified
```

마지막 두 계층 판정을 구분해야 한다. 여기서 시험한
`state-parent-plus-rank1`은 한 과제 안의 잠재 **상태**들이 affine
부모를 공유하는지 묻는 압축 proxy다. 과제 상속을 시험하려면 D1·D3를
같은 trial 행처럼 붙이지 않고, 같은 세션의 두 과제에서 정당화한 공통
좌표를 train fold만으로 만든 뒤 `공통 task 부모+작은 task residual`이
pooled 부모와 과제별 독립 모형을 모두 이겨야 한다. 현재 파일은 D1·D3
행이 짝지어진 생물학적 trial이 아니므로 그 과제 상속 시험은 만들 수
없다.

## 16. 현재 질문별 판정

질문별 판정은 관측 사실, 계산 가설, 생물학적 기제를 한 문장으로 합치지 않기 위한 장치다. 각 판정은 다음 gate가 실패하면 축소될 수 있다.

한 문장으로 뭉뚱그리지 않고 질문마다 판정한다.

| 질문 | 판정 | 정확한 뜻 |
|---|---|---|
| 공식 processed 결과를 checksum 기준으로 다시 읽었나 | `YES` | 저자 가공 산출물 무결성·기술통계 재현 |
| 과제의 두 칸짜리 코드 골격을 복원했나 | `YES` | task design의 factorization |
| 공유 감각 frontend·운동 backend의 인터페이스 후보를 지지하나 | `YES` | 색·반응 표현의 양방향 cross-decoding과 과제별 routing |

## 17. 다음 역공학 루프: 전역 언어가 아니라 국소 DSL인가

국소 DSL 가설은 전역 operator보다 영역·문맥별 일반화를 예측한다. 동일 compute의 hierarchical·flat baseline과 cross-area holdout이 반증 기준이다.

두 번째 실자료 loop까지 끝났다. 한 stationary operator가 epoch를
평균내서 실패했다는 대안도, 상태 수를 늘린 switching·공통 successor·
상태 계층 proxy가 matched VAR와 대조군에 패하면서 현재 snapshot 안에서는
닫혔다. 이것은 “뇌에 언어가 없다”가 아니라 **이 LPFC processed
pseudopopulation에서 하나의 공유 실행 언어를 찾는 모델이 맞지 않았다**는
뜻이다.

다음 loop는 언어의 단위를 바꾼다. 전뇌 공통 opcode보다 **영역별 국소
DSL과 좁은 통신 인터페이스**를 우선 가설로 둔다. V1과 V2의 동시 기록에서
영역 전체 활동이 아니라 저차원 communication subspace를 통해 상호작용한
결과는 이 그림과 양립한다. 이는 언어의 증명이 아니라 다음 모형 선택의
근거다.

1. 각 영역은 자기 좌표계와 국소 동역학을 따로 학습한다. 모든 영역을 한
   latent에 먼저 붙이지 않는다.
2. 영역 사이에는 전체 상태가 아니라 작은 communication subspace만
   통과시킨다. source에서 고정한 interface가 target과 새 과제에
   전이되는지 본다.
3. 전역 monolithic model, 영역별 독립 model, `local DSL + narrow
   interface`를 같은 held-out 예측·parameter·에너지 budget으로 비교한다.
4. 사용 영역 수뿐 아니라 열린 communication rank와 표현 overlap을
   따로 늘리며 정확도, single-item latency, independent-item throughput,
   persistence, 설명 길이와 spike/대사 비용을 함께 그린다. 이 Pareto
   곡선에서 최소 충분 회로와 최소 충분 interface를 고른다.
5. 비슷한 과제의 전이는 공유 subspace가, 서로 간섭하는 과제의 보존은
   직교 또는 분리된 subspace가 더 나은지 시험한다.
6. “누가 최적화하는가”를 단일 중앙 주체로 두지 않는다. 빠른 국소
   Hebbian/STDP·억제 경쟁, 지연된 보상/도파민 eligibility, 더 느린
   수면·replay consolidation의 세 시간척도 모형을 행동과 동시에 맞춘다.
7. 각 optimizer 성분을 선택적으로 막았을 때 예측한 학습 단계만
   손상되는지 perturbation과 rescue로 검증한다.

이 구조에서도 실제 “언어” 판정은 더 엄격하다. 서로 다른 영역의 local
tokenizer와 interface가 복원되고, 보지 않은 `S2` 및 순서 반전 조합을
기존 local primitive의 합성으로 예측하며, 특정 primitive의 교란과
interface-level rescue까지 성공해야 한다. 그 전의 가장 강한 이름은
`distributed local-DSL candidate`다.

## 18. 유한 tree-algorithm 전수조사

전수조사는 가설을 계속 추가하는 대신 유한 후보군을 같은 좌표·비용으로 비교하는 protocol이다. 후보군 밖의 모델에는 결론을 일반화하지 않는다.

가설을 하나씩 추가하는 loop는 여기서 중단한다. 알고리즘 이름을 그대로
세면 논문마다 변형이 늘어 끝이 없으므로, 같은 관측 지문을 내는 변형을
하나의 **동작 동치류**로 접었다. 사전등록 census는 5개 동치류와 18개
family로 닫힌다.

| 동작 동치류 | 대표 family | 현재 snapshot |
|---|---|---|
| state-space routing | VAR, CART/M5, oblique·soft tree, HME, rSLDS, TrSLDS | 7개 `TESTABLE`, sparse routing 1개 `PARTIAL` |
| latent temporal segmentation | HMM, HSMM, HHMM, context tree | HMM·context `TESTABLE`, HSMM·HHMM `PARTIAL` |
| control semantics | options, behavior tree, HTN | 3개 `UNAVAILABLE` |
| recursive memory | pushdown/call-return | `UNAVAILABLE` |
| relational tree | tree metric, Chow–Liu | `PARTIAL` / `UNAVAILABLE` |

`TESTABLE`은 이 processed snapshot에서 예측 지문을 screen할 수 있다는
뜻이지, 뇌가 그 알고리즘을 구현했다는 뜻이 아니다. `PARTIAL`은 핵심
지문의 일부가 없고, `UNAVAILABLE`은 필요한 관측 변수 자체가 없다는
뜻이다.

### 18.1 1차 토너먼트

첫 라운드는 현재 표본에서 직접 경쟁 가능한 family를 평가한다. seed·split·metric을 고정하지 않으면 순위는 탐색 노이즈일 수 있다.

첫 라운드는 현재 표본 크기에서 같은 좌표와 비용으로 직접 경쟁시킬 수
있는 다음 family만 실행한다.

1. matched continuous `VAR`
2. 기존 flat $K=2/3$ switching
3. axis-aligned hard model tree
4. 고정된 2-sparse 방향 사전의 oblique model tree
5. parent+rank1 contrast tree

모든 family는 같은 session-local D1/D3 latent, 최대 history anchor,
100ms 비중첩 시점과 whole-trial 6-fold를 쓴다. 깊이, 기억 길이, leaf
크기와 split은 outer-train 내부 3-fold에서만 고르고, outer test는
선택이 끝난 뒤 한 번만 본다. topology, threshold, 방향 support와 전체
family-grid search 비용도 codelength에 포함한다. D1·D3의 같은 행 번호를
paired trial로 쓰지 않는다.

바깥 test에서 가장 좋아 보이는 family도 이 자료에서 다시 확정하지
않는다. `ELIMINATED`, `SCREENING_SURVIVOR`,
`TEST_UNAVAILABLE`로만 나누고, 생존 후보는 독립 원자료로 넘긴다.
시간 역전, event-time-only, train-fold event mean 제거와 Chico/Silas
분리 판정을 동시에 통과하지 못하면 탈락한다.

### 18.2 뒤 라운드와 데이터 대기함

뒤 라운드는 더 많은 데이터나 다른 time resolution을 요구하는 family를 보류한다. 보류는 실패가 아니라 현재 식별 가능성의 경계다.

2차는 soft tree/HME, HMM 대 HSMM, fixed-order Markov 대 context tree,
flat rSLDS 대 TrSLDS 순서다. 반면 options·behavior tree·HTN에는
행동·보상·목표·성공/실패·termination이, pushdown에는 가변 nesting과
LIFO resume가 필요하다. 이 변수가 없는 현재 파일에 억지 점수를 만들지
않는다.

tree-sparse routing은 사용자의 속도·처리량 가설을 가장 직접 겨냥하지만,
현재 10ms 점들은 100ms 창이 90% 겹친 결과이므로 latency나 throughput이
아니다. 실제 활성 경로 비율, causal latency, 단위 시간당 병렬 처리량,
에너지와 branch perturbation을 동시에 기록할 때까지 `PARTIAL`이다.

## 19. 흔들림의 모양을 묻는 실제 diffusion probe

diffusion probe는 평균 transition과 변동 공분산을 구분해 묻는다. 여기의 확산은 통계적 동역학 모형이며 axonal diffusion이나 instruction 실행의 직접 관측은 아니다.

앞의 loop는 평균적인 상태 전이와 tree·switching 구조를 물었다. 이번
probe는 그 평균 경로에서 벗어난 **잔차의 흔들림**을 묻는다. 목적은
“확산을 찾는 것”이 아니라, 현재 snapshot에서 어느 잡음 모형이 보지 않은
자료를 가장 짧게 설명하는지와 그 짧은 설명이 시간척도를 바꿔도 유지되는지
검사하는 것이다.

### 19.1 비유: 흔들리는 쟁반 위의 구슬

구슬 비유는 평균 drift와 noise shape를 구분하는 데 도움을 준다. 실제 신경계에는 다중 입력과 비정상성이 있어 단일 potential 비유의 적용 범위가 제한된다.

쟁반 위에서 구슬이 굴러가는 짧은 영상을 생각하자. 먼저 구슬이 평균적으로
어느 방향으로 움직이는지 추정한다. 그 뒤에도 실제 궤적은 평균선 주위에서
흔들린다. 이 흔들림에는 적어도 여섯 설명이 있다.

1. 어느 방향으로나 같은 세기로 흔들린다.
2. 축마다 흔들림의 세기가 다르다.
3. 여러 축이 서로 묶여 비스듬한 방향으로 함께 흔들린다.
4. 구슬의 위치가 아니라 촬영 시각에 따라 흔들림이 달라진다.
5. 구슬이 현재 놓인 위치에 따라 흔들림이 달라진다.
6. 흔들림이 바뀐 것이 아니라 애초에 평균 경로가 휘어 있었는데 직선으로
   잘못 그렸다.

보지 않은 영상에서도 첫 설명이 가장 경제적이라면, 말할 수 있는 것은
“이 짧은 구간의 잔차는 둥글고 단순한 흔들림으로 압축된다”까지다. 쟁반
밑에 실제 확산 장치가 있다는 뜻은 아니다.

한 검사가 더 필요하다. 100ms 영상에서 배운 운동 법칙을 고정한 뒤 두 번,
세 번 이어 붙여 200ms와 300ms를 예측한다. 같은 안정된 법칙이라면 직접
그 시간 길이에 맞춘 모형과 크게 어긋나지 않아야 한다. 짧은 구간에서는
맞지만 세 번 이어 붙였을 때 무너지면, 그것은 국소적인 속기이지
시간척도를 관통하는 생성 법칙이 아니다.

### 19.2 이번에 물은 질문

질문들은 평균·분산·family 선택을 분리해 각각 반증 가능하게 만든다. 한 metric의 개선이 모든 동역학 특성을 설명하는 것은 아니다.

이번 실행은 다음 질문을 서로 분리했다.

- 1차 affine 평균 전이를 제거한 뒤 잔차는 등방성, 축별, 상관된
  공분산 중 무엇으로 가장 잘 압축되는가.
- 잡음의 변화처럼 보이는 것이 event 시각, 현재 상태, 또는 잘못 지정한
  비선형 평균 경로 때문인가.
- 관측된 저차원 상태의 다음 값을 설명하는 데 1차, 2차, 3차 기억 중
  무엇이 필요한가.
- 100ms에서 맞춘 하나의 법칙이 200ms와 300ms까지 합성되는가.
- 정방향과 역방향 중 어느 쪽의 기술 길이가 더 짧은가.

마지막 질문은 시간 방향의 기술통계일 뿐이다. 인과 방향, 생물학적 역과정,
score function 또는 생성형 reverse diffusion을 묻는 검사가 아니다.

### 19.3 사전등록 프로토콜

사전등록은 대상 checksum·분할·family·판정식을 결과 전에 고정한다. 사후 변경은 탐색 결과로 기록하고 독립 검증으로 세지 않는다.

분석 대상은 MD5
`04e42460ccae245ec16fcd9801ddea4a`로 고정한 공식 processed snapshot이다.
27개 물리 세션을 각각 독립적으로 처리했고, D1과 D3만 사용했다. D1·D3의
같은 행 번호를 paired trial로 간주하지 않았고, 403개 뉴런의 동시
population으로 재조립하지도 않았다.

각 세션은 원자료형 `raw`와 outer-train에서만 event-time 평균을 제거한
`event-demean` 두 방식으로 다시 돌렸다. whole-trial 6-fold의 바깥 test는
모든 parameter·공분산·state gate 추정이 끝난 뒤 점수 계산에만 사용했다.
따라서 1차 판정 단위는
27세션 × 2차원 × 2전처리, 모두 108개
`session × dimension × mode` 단위다.

같은 test target에서 다음 여섯 family를 경쟁시켰다.

| family | 사람이 읽을 때의 뜻 | 맡은 반증 역할 |
|---|---|---|
| `OU_ISO` | 1차 affine 평균 전이 + 한 개의 등방성 분산 | 가장 단순한 incumbent |
| `OU_DIAG` | 같은 평균 전이 + 축마다 다른 분산 | 고정 anisotropy |
| `OU_FULL` | 같은 평균 전이 + 축 사이 상관까지 허용 | 고정된 상관 잡음 |
| `TIME_SCALE` | full 공분산의 크기가 event 시각에 따라 변함 | 시간표 confound |
| `STATE_SCALE` | full 공분산의 크기가 현재 상태에 따라 변함 | state-dependent noise |
| `QUADRATIC_DRIFT_FULL_Q` | 휜 평균 경로 + 고정 full 공분산 | 평균 경로 오지정 대조군 |

`OU`는 여기서 모형 family의 이름이다. 생물학적 OU 과정이 식별됐다는
표지가 아니다. 평가는 held-out Gaussian NLL과 모형 복잡도를 합친
codelength proxy로 했다. 아래의 “A over B advantage”는 양수면 A가 더
짧고, 음수면 A가 B에 졌다는 뜻이다. 실용적 승리는 미리 고정한
0.01 bits/scalar 이상과 세션 단위 절반 이상의 승률을 함께 요구했다.
`STATE_SCALE`은 full·time·quadratic 대조군을 raw와 event-demean,
Chico와 Silas 분리 집계에서 모두 이겨야 생존하도록 잠갔다.

Markov order와 100→200/300ms 합성은 2차 민감도 검사로 두어 1차 family
경쟁의 독립 표본처럼 중복 계산하지 않았다. 합성 통과 허용치는 직접
재적합한 모형보다 0.02 bits/scalar 이내였다. 정·역방향 비교는 처음부터
descriptive-only로 잠갔다.

### 19.4 실제 결과

결과는 지정 raw·집계·family 조건의 출력이다. 다른 동물·epoch·sampling에 대한 일반화는 별도 holdout으로 시험해야 한다.

먼저 `raw`, 전체 동물 집계의 여섯-family 경쟁 결과다.

| 비교 | median total advantage | held-out NLL advantage | 판독 |
|---|---:|---:|---|
| diagonal over isotropic | -0.0690 | +0.0002 | 미세한 적합 이득이 복잡도 비용을 못 넘었다 |
| full over isotropic | -0.1755 | -0.0027 | 상관 공분산도 isotropic에 패했다 |
| time-scale over full | -0.1778 | -0.0037 | event 시각 의존 scale이 패했다 |
| state-scale over full | -0.2521 | -0.000061 | 상태 의존성은 held-out 이득 없이 복잡도만 늘렸다 |
| state-scale over time-scale | -0.0755 | +0.0032 | 작은 적합 이득이 복잡도 비용을 못 넘었다 |
| state-scale over quadratic drift | +0.4064 | +0.0345 | 휜 평균 경로 대조군 하나에는 이겼다 |

이 순위는 사전등록한 여섯 Gaussian family 안에서만 성립하는
`model-relative` 결과다. 비-Gaussian 잔차 family와 보정된 절대
goodness-of-fit 검사를 실행하지 않았으므로, isotropic Gaussian proxy의
상대 우위를 Gaussianity 자체의 식별로 올릴 수 없다.

마지막 한 번의 양수만 떼어 “상태 의존 잡음”이라고 읽으면 안 된다.
`STATE_SCALE`은 quadratic 대조군보다 짧았지만, 더 직접적인 full과
time-scale 대조군에 모두 졌다. 사전등록한 결합 gate의 의미는 세 대조군을
전부 넘어야 한다는 것이므로 생존하지 못했다.

event-time 평균을 제거해도 핵심 결론은 같았다.

| event-demean 비교 | median total advantage |
|---|---:|
| state-scale over full | -0.2544 |
| state-scale over time-scale | -0.0713 |

결합 state survivor의 승률은 raw와 event-demean 모두 0이었다. 전체,
Chico, Silas로 나눈 여섯 집계에서도 모두 0이었다. 따라서 이
snapshot에서 미리 정한 state-dependent transition-noise 지문은 `NO`다.

관측 Markov order는 더 단순했다.

| 결과 | 실제 값 |
|---|---:|
| 1차 기억 선택 | 108 / 108 단위 |
| 1차가 2차보다 짧은 median advantage | 0.3177 bits/scalar |
| 1차가 3차보다 짧은 median advantage | 0.6411 bits/scalar |

이는 **관측된 rank-limited latent의 국소 예측**이 1차 기억과 양립한다는
뜻이다. 전체 신경 상태가 진짜 1차 Markov라는 뜻은 아니다. 숨은 영역이나
관측되지 않은 상태를 투영하면 더 긴 기억이 1차처럼 보일 수도, 그 반대가
될 수도 있다.

가장 중요한 경계는 시간척도 합성에서 나왔다.

| mode | horizon | frozen 100ms 법칙의 median excess | 허용치 이내 비율 |
|---|---:|---:|---:|
| raw | 200ms | 0.01935 bits/scalar | 0.519 |
| raw | 300ms | 0.06677 bits/scalar | 0.0185 |
| event-demean | 200ms | 0.01720 bits/scalar | 0.648 |
| event-demean | 300ms | 0.05927 bits/scalar | 0.0185 |

200ms는 중앙값이 사전 허용치 근처이고 통과율도 절반 안팎이라 혼합된
결과다. 300ms에서는 두 전처리 모두 54개 중 사실상 1개만 통과했다.
따라서 **하나의 stationary OU proxy가 100ms 법칙을 그대로 합성해
300ms까지 설명한다는 scale consistency는 실패**했다. 이것은 숨은 상태,
event drive, 투영 오차, 관측 잡음 또는 실제 비정상성 중 무엇 때문인지
아직 구분하지 못한다.

정·역방향 기술 길이는 역방향이 더 짧은 단위가 73개, 정방향이 더 짧은
단위가 35개였다. 이 수는 방향 비대칭의 기술통계다. event locking,
저차원 투영과 조건화만으로도 바뀔 수 있으므로 인과 화살표나 생성형
역과정의 증거로 사용하지 않는다.

### 19.5 판정

표의 판정은 현재 질문과 데이터 범위에 한정된다. 생물학적 mechanism의 확정이나 전역 언어의 증명으로 확대하지 않는다.

| 판정 질문 | 답 | 정확한 뜻 |
|---|---|---|
| 여섯 family의 session-local probe를 완주했나 | `YES` | checksum·fold·checkpoint가 고정된 108단위 비교 완료 |
| 시험한 여섯 family 중 local affine+isotropic Gaussian proxy가 model-relative winner인가 | `YES` | 현재 100ms 저차원 잔차에서의 상대 codelength 순위 |
| Gaussianity 자체를 식별했나 | `NO` | 비-Gaussian family와 보정된 절대 goodness-of-fit을 시험하지 않음 |
| 하나의 stationary OU가 300ms까지 scale-consistent한가 | `NO` | frozen 100ms 합성의 통과율이 두 mode 모두 0.0185 |
| 고정 anisotropic covariance 지문이 생존했나 | `NO` | diagonal·full이 isotropic incumbent에 패함 |
| event-time-dependent diffusion 지문이 생존했나 | `NO` | time-scale이 full에 패함 |
| state-dependent diffusion 지문이 대조군을 모두 넘었나 | `NO` | joint survivor 승률이 모든 mode·animal 집계에서 0 |
| 생물학적 diffusion 기전을 식별했나 | `NO` | Gaussian 잔차 모형은 생물학적 알고리즘이 아님 |
| score function 또는 생성형 reverse process를 식별했나 | `NO` | density-gradient·denoising score·학습된 역과정을 맞추지 않음 |
| 인과적 잡음 생성 기전을 식별했나 | `NO` | perturbation·rescue·noise intervention이 없음 |
| 해부학적 spatial graph diffusion을 식별했나 | `NO` | session latent 좌표는 해부학적 graph가 아님 |
| 뇌에 diffusion 또는 graph diffusion이 존재하지 않는가 | `TEST_UNAVAILABLE` | 단일 LPFC processed snapshot으로 보편적 존재·부재를 판정할 수 없음 |
| 이 snapshot으로 denoising diffusion 가설을 직접 시험할 수 있나 | `TEST_UNAVAILABLE` | 알려진 corruption level·score target·원시 동시 기록이 없음 |

따라서 가장 강하게 말할 수 있는 문장은 하나다.

> 현재 snapshot의 100ms 국소 전이에서, 시험한 여섯 Gaussian family 중
> 1차 affine 평균 + isotropic Gaussian 잔차 proxy가 model-relative
> winner였다. Gaussianity 자체는 식별되지 않았으며, 이 proxy도
> 300ms까지 합성되는 하나의 stationary 생성 법칙으로 승격되지 않는다.

이 문장은 단순 모형의 **상대 우위**와 분포·생물학·생성 기전의
**식별 실패**를 동시에 보존한다.

### 19.6 다음 병목과 loop 재시작

다음 병목은 family를 더 늘리는 일이 아니라 국소 시간해상도와 개입 자료를 확보하는 일이다. 새 loop는 이전 failure criterion을 유지한 채 시작해야 한다.

지금 병목은 공분산 family를 하나 더 붙이는 일이 아니다. 100ms 국소
속기와 여러 시간척도를 관통하는 실제 전이 법칙을 분리할 관측이 없다.
다음 loop는 아래 순서로 좁힌다.

1. pseudotrial이 아니라 trial identity가 보존된 raw spike와 동일 뉴런의
   동시 population을 세션별로 확보한다. 먼저 observation noise와 process
   noise를 분리한다.
2. 겹치지 않는 창으로 50·100·200·300ms의 직접 적합과 frozen 합성을
   사전등록한다. 어느 척도에서 처음 깨지는지를 하나의 결과로 보고한다.
3. event drive, 숨은 상태, 비선형 평균 경로, observation model을 같은
   held-out budget에서 경쟁시킨다. 이 대조를 넘기 전에는 잔차 분산을
   신경 계산의 primitive로 부르지 않는다.
4. score 가설에는 알려진 corruption level과 denoising target을,
   spatial graph 가설에는 해부학적 adjacency와 다영역 동시 기록을
   별도로 요구한다. 현재 파일에서 두 점수를 억지로 만들지 않는다.
5. 반복 자료에서도 scale consistency가 살아남은 후보만 perturbation과
   rescue로 넘긴다. 그때도 정·역방향 codelength 대신 선택적 noise
   intervention이 예측한 변화만 일으키는지 본다.
6. neural programming-language loop에서는 이 잡음 모형을 opcode로
   취급하지 않는다. 시간척도를 가로질러 재사용되는 전이와 영역 간
   interface가 먼저 복원된 뒤, 잔차 구조가 그 실행을 보조하는지 따로
   시험한다.
