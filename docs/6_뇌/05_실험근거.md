# 뇌 이론 제5장: 실험 근거

이 파일은 실험 근거 장의 짧은 입구다. 세부 내용은 `05_실험근거/` 아래에 나누어 둔다.

독자는 실험 설계, holdout과 효과크기의 기본 뜻을 안다고 가정한다. 입력은 사전정의된 관측·개입·시간창이고 출력은 반증 가능한 예측이다. 성공은 독립 자료에서 재현되는 것이며, 모델 비유와 상관을 인과 증거로 바꾸는 것은 실패다.

## 요약

이 장은 측정 가능한 항목과 모델 해석을 분리한다. 각 항목은 데이터 provenance·시간척도·성공 기준을 함께 가져야 한다.

이 장은 뇌 이론에서 실제로 검증 가능한 항목을 정리한다. 기준은 세 가지다.

```text
수식이 있는가
관측 proxy가 있는가
baseline보다 예측력이 좋은가
```

현재 실험 프로그램은 전역 뇌 방정식의 각 항을 한 번에 믿지 않는다. 과제, 항상성, 그래프, 시냅스, 느린 회복 항을 따로 검증한 뒤, 마지막에 full equation이 ablation을 이기는지 본다.

## 신경 언어 가설의 별도 gate

decode 가능성은 정보가 있다는 증거일 뿐 프로그래밍 언어·instruction의 증명은 아니다. 개입·합성·cross-task holdout이 실패하면 가설은 미완성으로 남는다.

집단 활동에서 행동을 decode할 수 있다는 사실은 신경 코드의 증거이지,
함수 호출이나 프로그래밍 언어의 증거가 아니다. 재사용 가능한 국소 연산,
보지 않은 조합의 합성, 호출 gating과 선택적 인과 결손은
[`10_신경프로그래밍언어_역공학.md`](10_신경프로그래밍언어_역공학.md)에서
별도 gate로 관리한다. 실제 원자료와 perturbation을 통과하기 전 판정은
`Open hypothesis`다. 현재 공식 processed 자료에서는 과제의 두-slot 코드
골격, 공유 표현 frontend/backend 후보와 27개 기록 session을 복원했다.
그러나 stationary operator뿐 아니라 $K=2/3$ switching, 잠재
common-successor, D1↔D3 frozen transfer와 state-parent+rank1 proxy도
matched VAR·time-only·reverse·event-mean 대조를 함께 이기지 못해
`NO`다. 이 상태 proxy는 과제 상속이 아니다. 빠진 `S2`, 다영역 실제
callee/과제 상속의 존재·부재와 인과 개입은 `TEST_UNAVAILABLE`로 따로
기록한다.
