# 4. CE 물리 난제 상태 장부

공통 기호·주장 지위는 [수학적 완결성 계약](00_수학적_완결성_계약.md)을,
조건부로 복구된 명제의 증명은 [보강 정리 부록](15_보강_정리와_증명.md)을
따른다.

## 4.1 판정 원칙

이 문서는 ``해결 개수''를 세지 않는다. 현재 살아 있는 실행 근거는
[`../../tests/test_chapter1_numeric_contract.py`](../../tests/test_chapter1_numeric_contract.py),
[`../../tests/test_ce_residual_forward_model.py`](../../tests/test_ce_residual_forward_model.py),
[`../../examples/physics/ce_residual_forward_model.py`](../../examples/physics/ce_residual_forward_model.py)이며,
수치 근접·조건부 수학·물리적 해결을 분리한다. 존재하지 않는 별도 상태표를
권위 원천으로 가정하지 않고 이 문서의 controlled vocabulary를 사용한다.

| 등급 | 의미 |
|---|---|
| `Exact conditional` | 열거한 최소 충분가정 아래 정리와 증명이 닫힘 |
| `Definition` | 객체·함수형·정규화를 정의해 산술적으로 닫힘 |
| `Selection` | 이산 규칙, branch 또는 모형 클래스를 사전 선택 |
| `Calibration input` | 외부 입력 또는 이미 본 자료로 경계값·함수형을 고정 |
| `Calibration output` | calibration input을 대입해 재현한 값; 독립 예측이 아님 |
| `Open` | action, physical matching, observable 또는 독립 likelihood가 미완 |
| `Rejected` | 완전히 지정한 benchmark가 내부 gate 또는 자료에서 실패 |

같은 관측으로 식을 선택하고 다시 그 관측과 일치시킨 경우 그 관측은
`Calibration input`, 재현값은 `Calibration output`이다. 한 항목 안에 증명된 보조정리와 열린 물리 bridge가 함께
있을 때 표의 “현재 판정”은 더 강한 물리 주장에 대한 terminal status를 쓰고,
증명된 부분은 두 번째 열에 `Exact conditional`로 별도 표시한다.

## 4.3 현재 명시적으로 기각된 항목

- late-time 3-sector canonical density
  $(0.04863826,0.26108817,0.69027357)$를 외부 $H_0=67.4$,
  external-input $r_d=147.09\,{\rm Mpc}$ 및 $w=-1$과 결합한 DESI DR2
  BAO-only full-cov package:

$$
\chi^2=40.20145,\quad {\rm dof}=13,\quad p=1.2828\times10^{-4}.
$$

- $\Omega_b=0.04863826$을 유지하고
  $\Omega_{\rm rad}=9.192332266\times10^{-5}$를 배정한 뒤 남은 dark sector를
  $R_{\rm CE}$로 재분할한 4-sector EH `Selection` package. 여기에는 외부
  $H_0,T_{\rm CMB}$, 표준 $N_{\rm eff}=3.044$와 Eisenstein--Hu drag fit의
  $r_d=151.50842877\,{\rm Mpc}$를 쓴다:

$$
\chi^2=41.90607733,\quad {\rm dof}=13,\quad
p=6.78476334\times10^{-5}.
$$

**보조정리 4.1 (고정 Gaussian gate, `Exact conditional`).** 13-component
residual \(r\)가 모형 아래 평균 0인 Gaussian이고 등록 covariance \(C\)가
positive definite이며 이 13개 값으로 fit한 parameter가 0개라고 가정하면

$$
\chi^2=r^{\mathsf T}C^{-1}r\sim\chi^2_{13},\qquad
p=Q\!\left(\frac{13}{2},\frac{\chi^2}{2}\right).
$$

따라서 위 두 \(\chi^2\)는 각각 표시한
\(p=1.2828\times10^{-4}\), \(6.7848\times10^{-5}\)를 주며 실행 코드와 같은
등록 기준 \(p<0.0027\)에서 `Rejected`다.

**증명.** whitening \(z=C^{-1/2}r\)을 하면 \(z\sim N(0,I_{13})\)이고
\(\chi^2=\sum_{i=1}^{13}z_i^2\)다. chi-square survival function을 평가하면
표시한 값이 나온다. 수치는 4.1절에 링크한 같은 구현의 회귀 테스트가
재현하며, 독립 계산이나 독립 자료 검증을 뜻하지 않는다.
\(\square\)

이 nominal \(p\)-value는 **고정된 package 하나**의 Gaussian residual
diagnostic이다. early-universe/EH branch와 DR2 자료가 선택 과정에 사용됐다면
DR2는 untouched holdout이 아니므로 trial/post-selection correction 전의
confirmatory 유의도로 읽지 않는다. 따라서 여기의 `Rejected`는 표시한 고정
package의 내부 gate 판정이지, 가능한 모든 CE model family의 일괄 기각이 아니다.

두 결과는 $r_d$만 바꾼 ablation이 아니라 서로 다른 고정
background·$r_d$ 분기의 판정이다. EH 값은 precision recombination 결과가
아닌 derived `Selection`이다. 이 두 **완전히 지정된 package**의
`Rejected` 판정은 유지된다. CMB·SN·growth까지 푸는 경우 background,
sound horizon, perturbation 또는 nuisance가 달라지는 새 동역학 모형이며 그
별도 모형의 상태가 `Open`이다. 추가 자료가 동일 고정 package의 BAO 잔차를
소급해 지우지는 않는다.

- nonnegative bare mass에서 legacy \(29.65\) MeV 또는 current
  \(29.699\) MeV와 Track A의 \(\lambda_{H\Phi}=\delta_A^2\)를 같은 scalar pole로
  두는 benchmark.
- 기존 light/legacy Higgs-portal benchmark의 invisible-Higgs-width 조건.
- 0초 teleport와 기존 Casimir SI 변환.

기각된 benchmark를 ``다른 marginal 중앙값은 가깝다''는 이유로 해결 목록에 되돌리지 않는다.

## 4.4 조건부로 닫히는 대체 구성

아래는 “난제가 해결됐다”는 목록이 아니라, 기존의 직접 모순을 피하면서
최소 가정 아래 증명 가능한 부분을 가진 construction이다.

1. **strong CP (`Open`).** CP-even $\Phi$와 별도
   compact pseudoscalar $a\sim a+2\pi f_a$를 두고, 유일한
   \(\bar\theta+a/f_a\) 의존 potential이

   $$
   V_{\rm QCD}=\chi[1-\cos(\bar\theta+a/f_a)],\qquad \chi>0
   $$

   라고 가정하면 모든 global minimum에서
   \(\bar\theta_{\rm eff}=\bar\theta+a/f_a=0\pmod{2\pi}\)다.
   실제로 stationary point는 \(\sin\bar\theta_{\rm eff}=0\)이고
   \(V''=(\chi/f_a^2)\cos\bar\theta_{\rm eff}>0\)인 점이 바로 위 해다.
   위 최소점 계산은 `Exact conditional`인 보조정리지만 explicit breaking,
   anomaly coefficient, cosmology·nEDM gate는 아직 닫히지 않았다.
2. **Higgs (`Calibration input`).** $M_h/M_Z$ 수치식 대신
   $\lambda_{\rm CE}(M_Z)$ boundary와 모든 SM running input을 고정한다.
   주어진 loop order에서 beta function이 locally Lipschitz이면 RG initial
   value problem은 첫 singularity 전까지 유일하고 pole matching도 지정한
   counterterm convention 안에서 재현 가능하다. 이 정리는 boundary 값
   자체나 hierarchy naturalness를 예측하지 않는다.
3. **CKM/PMNS (`Open`).** 하나의 Yukawa/Majorana
   mass matrix를 먼저 구성한다. 임의의 finite complex Yukawa matrix는 SVD로
   \(Y_f=U_{fL}\Sigma_fU_{fR}^\dagger\)가 되므로
   \(V_{\rm CKM}=U_{uL}^\dagger U_{dL}\)은 구성상 unitary다. Majorana
   symmetric matrix도 Takagi factorization으로 하나의 unitary PMNS 장부를
   준다. 이 SVD/Takagi 부분은 `Exact conditional`이지만 texture의 자연
   선택과 공동 likelihood는 아직 닫히지 않았다.
4. **neutrino (`Open`).** exact $Z_2$ inert doublet과
   Majorana $N_k$ 및 Yukawa $h_{ik}\bar L_i\widetilde\eta N_k$를 지정하면
   \(t>0,M^2>0\)에서 연속 loop function을

   $$
   F(t;M^2):=
   \begin{cases}
   \dfrac{t}{t-M^2}\ln\dfrac{t}{M^2},&t\ne M^2,\\
   1,&t=M^2
   \end{cases}
   $$

   로 정의하면 one-loop Majorana matrix는

   $$
   (M_\nu)_{ij}=\sum_k\frac{h_{ik}h_{jk}M_k}{32\pi^2}
   \left[F(m_R^2;M_k^2)-F(m_I^2;M_k^2)\right]
   $$

   로 대칭이고 apparent \(0/0\) 지점에서도 연속이며 \(m_R=m_I\) 극한에서
   0이 된다. UV spectrum, flavour,
   LFV·cosmology fit은 `Open`이다.
5. **Koide (`Open`).** flavour triplet potential의 vacuum
   constraint로 $Q_K=2/3$을 부과하면 tree-level stationary point에서 그
   등식은 정의상 성립한다. vacuum uniqueness와 loop 안정성이 증명되기
   전에는 질량관계의 동역학적 설명이 아니다.
6. **inflation (`Calibration output`).** finite-$\xi=0.49$ canonical map,
   $A_s$로 고정된 $\lambda_4$, 지정한 $N_*$ 아래의 $(n_s,r)$ 계산은
   조건부로 재현된다. exact-$Z_2$ annihilation/preheating이 그 $N_*$와
   thermal history를 실제로 만드는지는 별도 `Open` 문제다.

## 4.5 결론

CE에는 재사용 가능한 고정점 정리, projector 대수, finite positive
sub-Markov 실현과 여러 조건부 construction이 있다. 그러나 현재 ``16/21
해결, 76%'' 같은 비율은 proof-status와 독립성 구조를 반영하지 않으므로
폐기한다. 물리적 해결로 승격하기 위한 **최소 필요조건**은 공변 action,
anomaly·unitarity·stability, renormalized observable, RG/threshold matching,
식별 가능한 likelihood와 untouched holdout을 해당 문제에 맞게 닫는 것이다.
이 조건들은 문제별로 추가 UV/EFT 또는 실험 조건을 요구할 수 있으므로
그 자체를 보편적 충분조건이라고 부르지 않는다.
