# 4. CE 물리 난제 상태 장부

## 4.1 판정 원칙

이 문서는 ``해결 개수''를 세지 않는다. 최신 권위 판정은 `0_검증과감사/PROOF_STATUS_MATRIX.md`이며, 수치 근접·조건부 수학·물리적 해결을 분리한다.

| 등급 | 의미 |
|---|---|
| `Exact under assumptions` | 명시한 수학 모형 안에서 증명 |
| `Selection` | 이산 규칙/branch 선택 |
| `Bridge` | 두 물리 객체의 식별 또는 matching 필요 |
| `Phenomenology` | 유효식/benchmark가 자료와 비교 가능 |
| `Open` | action, observable 또는 likelihood가 아직 닫히지 않음 |
| `Rejected` | 명시한 benchmark가 내부 gate 또는 자료에서 실패 |

같은 관측으로 식을 선택하고 다시 그 관측과 일치시킨 경우는 예측이 아니라 calibration이다.

## 4.3 현재 명시적으로 기각된 항목

- canonical density $(0.04863826,0.26108817,0.69027357)$를 외부 $H_0=67.4$, $r_d=147.09\,{\rm Mpc}$ 및 $w=-1$과 결합한 DESI DR2 full-cov package:

$$
\chi^2=40.20145,\quad {\rm dof}=13,\quad p=1.2828\times10^{-4}.
$$

- 같은 canonical density에 외부 $H_0,T_{\rm CMB}$, 표준 $N_{\rm eff}$와 EH-hybrid $r_d=151.50523\,{\rm Mpc}$를 쓴 package:

$$
\chi^2=41.19455,\quad {\rm dof}=13,\quad p=8.8602\times10^{-5}.
$$

- nonnegative bare mass에서 legacy \(29.65\) MeV 또는 current
  \(29.699\) MeV와 \(\lambda_{H\Phi}=\delta_N^2\)를 같은 scalar pole로
  두는 benchmark.
- 기존 light/legacy Higgs-portal benchmark의 invisible-Higgs-width 조건.
- 0초 teleport와 기존 Casimir SI 변환.

기각된 benchmark를 ``다른 marginal 중앙값은 가깝다''는 이유로 해결 목록에 되돌리지 않는다.

## 4.4 작동하는 대체 모형

1. **strong CP:** CP-even $\Phi$와 별도 compact pseudoscalar $a$를 두고
   $V_{\rm QCD}=\chi[1-\cos(\bar\theta+a/f_a)]$로 $\bar\theta_{\rm eff}=0$을 만든다.
2. **Higgs:** $M_h/M_Z$ 수치식 대신 $\lambda_{\rm CE}(M_Z)$ boundary를 정하고 SM RG+pole matching을 한다.
3. **CKM/PMNS:** 원소별 보정을 버리고 한 unitary matrix와 한 Yukawa/Majorana mass matrix를 구성한다.
4. **neutrino:** inert doublet+$N_i$ scotogenic completion에서 실제 loop integral로 $M_\nu$를 만든다.
5. **Koide:** flavour triplet potential의 vacuum condition으로 $Q_K=2/3$을 만들고 loop 안정성을 시험한다.
6. **inflation:** finite-$\xi=0.49$ canonical map, $A_s$로 고정된 $\lambda_4$, exact-$Z_2$ annihilation/preheating을 함께 푼다.

## 4.5 결론

CE에는 재사용 가능한 고정점 수학, projector invariant와 여러 정합한 benchmark construction이 있다. 그러나 현재 ``16/21 해결, 76%'' 같은 비율은 proof-status와 독립성 구조를 반영하지 않으므로 폐기한다. 해결로 승격하는 유일한 경로는 각 표의 action·renormalized observable·full covariance gate를 실제로 닫는 것이다.
