# 13. 게이지 위상공간 체적과 $\pi^k$ 패턴의 공리적 유도

## 개관

SFE에서 $\alpha^{-1}(0) = 4\pi^3 + \pi^2 + \pi$, $m_p/m_e = 6\pi^5$의 $\pi^k$ 패턴은 **게이지 위상공간 체적**에서 유도된다. 이 절에서는 $\alpha^{-1}$의 계수 $\{4, 1, 1\}$이 하강 분할 $\{N_c, N_w, 1\} = \{3, 2, 1\}$과 이중선형 결합 구조에서, $m_p/m_e$의 계수 $6 = N_c!$이 바리온 색 반대칭화(3.2)에서 각각 따라옴을 증명한다.

---

## 1. 게이지 군의 위상공간 체적

### 1.1 기본 표현의 접힘 위상공간 — 단위 폴리디스크

기본 원리 2(무차원 구조는 자기참조 재귀로만 이루어진다)를 직접 적용하면 게이지 위상공간 단위가 보정 인자 없이 따라온다.

SU($N$)의 기본 표현은 $\mathbb{C}^N$의 성분 $z_1,\dots,z_N$을 가진다. 각 성분은 **독립적인 접힘 진폭**이며, 자기참조 재귀로 단위 원판 $|z_i|\le 1$에 닫힌다. 한 복소 원판의 면적은

$$\int_{|z|\le 1} d^2 z = \pi.$$

$N$개 성분은 곱적으로 결합하므로(독립 진폭의 동시 적분 = 곱) 단위 접힘 위상공간은 **폴리디스크** $D^N=\{|z_i|\le 1\}$의 체적이다:

$$V_N \equiv \mathrm{vol}(D^N) = \pi^N.$$

| 군 | $N$ | $V_N$ | 수치 |
|---|---|---|---|
| U(1) | 1 | $\pi^1 = \pi$ | 3.1416 |
| SU(2) | 2 | $\pi^2$ | 9.8696 |
| SU(3) | 3 | $\pi^3$ | 31.006 |

### 1.2 왜 폴리디스크인가 (구면 정의와의 관계)

이전 서술은 기본 표현을 단위 구면 $S^{2N-1}$의 작용으로 보고 반체적 $\mathrm{vol}(S^{2N-1})/2 = \pi^N/(N-1)!$를 단위로 잡았다. 그러나 이 정의는 $N=1,2$에서만 깔끔한 $\pi^N$을 주고 $N=3$에서는 $\pi^3/2$가 되어, 다운스트림의 $\pi^{N_c}=\pi^3$와 맞추기 위해 별도의 $(N-1)!$ 상쇄 가정이 필요했다.

구면 $S^{2N-1}$은 게이지 구속(전체 노름 고정) **이후**의 다양체이고, 그 반체적의 인자 $1/(N-1)!$는 $N$개 진폭을 하나의 노름으로 묶는 차원 축소에서 생긴다. 접힘 위상공간은 구속을 부과하기 **전**의 독립 진폭 개수를 센다(P2: 자기참조 재귀). 따라서 인자 없는 폴리디스크 체적 $\pi^N$이 옳은 단위이며, $N=3$에서 임의의 $(N-1)!$ 상쇄 가정이 불필요하다. $\alpha^{-1}(0)$와 $m_p/m_e$의 모든 다운스트림 공식은 이미 $\pi^{N_c}, \pi^{N_w}$ 형태를 쓰므로 수치 결과는 동일하고, 유도만 균일·자기일관적이 된다.

## 2. $\alpha^{-1}(0)$의 유도

### 2.1 공식

$$\alpha^{-1}(0) = \sum_{\text{sectors}} B_i \cdot \pi^{d_i}$$

여기서 합은 SM의 세 게이지 섹터에 대해 이루어지고, $d_i$는 해당 게이지 군의 기본 표현 차원, $B_i$는 이중선형 결합 계수이다.

### 2.2 각 섹터의 기여

**쿼크 섹터 (SU($N_c$) charged):**

쿼크는 SU($N_c$) 기본 표현(차원 $N_c$)과 SU($N_w$) 기본 표현(차원 $N_w$)에 동시에 속한다. 전자기 결합은 $W^3$-$B$ 혼합(이중선형, $k = 2$)을 경유하므로, SU($N_w$)의 이중선형 결합 인자 $N_w^k = N_w^2$가 곱해진다.

위상공간은 SU($N_c$) 기본 표현의 폴리디스크 체적 $\pi^{N_c}$이다(1.1). $N_c$개 색 성분이 각각 독립 접힘 진폭(단위 원판)이므로 곱 체적이 $\pi^{N_c}$이며, 별도 보정 인자가 없다.

$$\text{쿼크 기여} = N_w^2 \cdot \pi^{N_c}$$

**렙톤 섹터 (SU($N_c$) singlet):**

렙톤은 SU($N_c$) 단일항이므로 색 위상공간이 없다. SU($N_w$) 기본 표현의 체적만 기여한다. 렙톤은 이중선형 혼합의 한쪽(SU(2) 하위 성분)이므로 계수는 1이다.

$$\text{렙톤 기여} = 1 \cdot \pi^{N_w}$$

**광자 자체 (U(1)):**

전자기 U(1)의 고유 위상공간은 $\text{vol}(S^1)/2 = \pi$이다.

$$\text{U(1) 기여} = 1 \cdot \pi$$

### 2.3 결합

$$\boxed{\alpha^{-1}(0) = N_w^2 \cdot \pi^{N_c} + \pi^{N_w} + \pi}$$

$N_c = 3$, $N_w = 2$를 대입:

$$\alpha^{-1}(0) = 4\pi^3 + \pi^2 + \pi = 137.036$$

관측: $137.035\,999\,177$. 차이 $0.0002\%$.

### 2.4 계수 $N_w^2 = 4$의 기원

이것은 $\sin^2\theta_W = 4\alpha_s^{4/3}$의 계수 $4 = N_w^2$과 **동일한 기원**이다. 두 공식 모두에서:

- $N_w^2$는 SU(2)$_L$ 기본 표현의 이중선형 혼합 꼭짓점(P2)에서 온다
- $W^3_\mu$-$B_\mu$ 혼합은 게이지장에 대해 이중선형이므로 $k = 2$
- $N_w^k = 2^2 = 4$

따라서 $\alpha^{-1}(0)$의 계수 4는 독립적인 숫자가 아니라, 와인버그 각 유도의 P2 단계와 동일한 물리에서 나온다.

## 3. $m_p/m_e = N_c! \cdot \pi^{N_c + N_w}$의 유도

### 3.1 공식

$$m_p/m_e = N_c! \cdot \pi^{N_c + N_w} = 6\pi^5 = 1836.12$$

관측: $1836.15$. 차이 $0.002\%$.

### 3.2 계수 $6 = N_c!$의 기원 (바리온 색 반대칭화, P3)

양성자는 완전반대칭 색 단일항이다:

$$|p\rangle_{\text{color}} = \frac{1}{\sqrt{N_c!}}\,\varepsilon_{i_1\cdots i_{N_c}}\,|q^{i_1}\cdots q^{i_{N_c}}\rangle.$$

색 진폭의 **연속** 체적은 폴리디스크 $\pi^{N_c}$가 센다(1.1, 3.3). 그러나 $N_c$개 쿼크가 서로의 색을 배타적으로 확정하여(P3: 두 쿼크가 같은 색을 가질 수 없음 = 반대칭성) 만드는 **이산 치환 궤도** $N_c!$은 연속 체적에 포함되어 있지 않다. 이 Levi-Civita 반대칭화의 항 수가 곧 전치인자다:

$$N_c! = 3! = 6.$$

CE에서 $N_c = d$(Hodge 자기쌍대, 4.3)이므로 이 값은 공간차원 기반 $2d = 6$과 수치적으로 축퇴하지만, 물리적 기원은 **바리온의 페르미온 반대칭성**(P3)으로 더 견고하다 — "방향당 2개" 같은 임의 가정이 필요 없다.

### 3.3 $\pi^{N_c + N_w} = \pi^5$의 기원 (곱 구조는 P3에서)

왜 비에 두 위상공간이 **곱**(몫이 아니라)으로 들어가는가? 기본 원리 3(양자는 서로가 서로를 확정한다)을 적용한다.

- **전자**는 기본 입자(렙톤)로 내부 합성 구조가 없다. 내부 접힘 위상공간은 비어 있으므로 $V_e = \pi^0 = 1$.
- **양성자**는 합성 상태로, 그 내부 접힘은 (i) 3색을 단일항으로 묶는 SU($N_c$) 색 위상공간 $\pi^{N_c}$과 (ii) 구성 페르미온이 지닌 SU($N_w$) 약 위상공간 $\pi^{N_w}$을 **동시에** 탐색한다. 두 부분 위상공간은 독립이므로 곱으로 결합한다: $V_p^{\text{int}} = \pi^{N_c}\cdot\pi^{N_w}$.

질량비는 두 상태의 내부 접힘 위상공간의 비다:

$$\frac{V_p^{\text{int}}}{V_e} = \frac{\pi^{N_c}\cdot\pi^{N_w}}{\pi^0} = \pi^{N_c + N_w} = \pi^{3+2} = \pi^5.$$

여기서 P3가 핵심이다. $m_p$와 $m_e$의 **절대** 스케일은 각각 따로 결정되지 않으며 기준 스케일(P-승격)을 필요로 한다. 그러나 두 상태가 동일한 접힘 진공을 공유하며 서로를 확정하므로 **비**는 두 내부 위상공간의 곱적 비로 무차원적으로 고정된다. 즉 곱 구조는 "비만이 상호 확정된다"는 P3의 직접적 귀결이다.

## 4. 통합 구조: $\pi^k$ 패턴의 일반 법칙

### 4.1 일반 규칙

$\pi^k$ 패턴에서 $k$는 **관련 게이지 군의 기본 표현 차원의 합**이다.

| 관측량 | $\pi$ 차수 | 관련 군 | 기여 구조 |
|---|---|---|---|
| $\alpha^{-1}(0)$ 선도항 | $N_c = 3$ | SU(3) | 색 위상공간 |
| $\alpha^{-1}(0)$ 차선도항 | $N_w = 2$ | SU(2) | 약력 위상공간 |
| $\alpha^{-1}(0)$ 최하항 | $1$ | U(1) | 전자기 위상공간 |
| $m_p/m_e$ | $N_c + N_w = 5$ | SU(3) $\times$ SU(2) | 곱적 결합 |

### 4.2 계수의 일반 규칙

| 계수 | 공식 | 기원 |
|---|---|---|
| $4 = N_w^2$ | 이중선형 결합 $k=2$ | P2 (전자약 혼합 꼭짓점) |
| $6 = N_c!$ | 바리온 색 반대칭화 ($2d$와 축퇴) | P3 (Levi-Civita 단일항) |
| $1$ | 단독 기여 (상위 군 없음) | 렙톤, U(1) |

### 4.3 G4 간극의 해소

G4 간극: "$\pi^k$ 패턴의 계수가 공리적으로 유도되지 않음."

해소: 계수 $\{4, 1, 1\}$은 하강 분할 $\{N_c, N_w, 1\}$과 이중선형 결합 구조(P2)에서 유도된다. $N_c = 3$은 Hodge 자기쌍대에서, $N_w = 2$는 SU(2)의 정의에서, 이중선형 차수 $k = 2$는 $W^3$-$B$ 혼합의 SM 라그랑지안에서 각각 따라온다. 새로운 가정이 필요 없다.

이것으로 G4는 B급에서 A급으로 승격된다 (공리 + SM 구조에서 유도).
