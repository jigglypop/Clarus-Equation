# 경로적분과 응용: 수학적 완결성 계약

이 파일은 01--14장의 공통 type, 주장 지위, 반례와 승격 조건을 고정한다.
각 장의 식이 이 계약보다 강한 물리적 결론을 말하면 그 결론은 자동으로
`Open`으로 내려간다. 수치가 잘 맞는다는 사실은 `Bridge`를 증명하지 않는다.
계약에서 살아남는 명제의 구체적 구성과 증명은
[`15_보강_정리와_증명.md`](15_보강_정리와_증명.md)에 모았다. 따라서 오류를
단순히 삭제하는 대신, 최소 충분가정 아래 증명되는 가장 강한 버전을 먼저
사용한다.

## 1. 주장 지위

| 지위 | 뜻 |
|---|---|
| `Definition` | 기호나 관측량의 뜻을 정한다. 예측이 아니다. |
| `Exact` | 표시한 domain에서 추가 물리 가정 없이 증명된 수학 명제다. |
| `Exact conditional` | 열거한 가정을 모두 둘 때만 증명되는 명제다. |
| `Convention` | 단위, 부호, 정규화 또는 좌표 선택이다. |
| `Selection` | 여러 가능한 구조 중 CE가 고른 가정이다. |
| `Bridge` | 서로 다른 type의 대상을 연결하는 추가 물리 가정이다. |
| `Phenomenology` | 명시한 유효모형과 자료 범위에서 시험하는 후보 관계다. |
| `Calibration input` | 계수나 초기조건을 정하는 데 사용한 관측 입력이다. |
| `Calibration output` | 입력을 대입해 재현한 값이며 독립 예측이 아니다. |
| `Open` | action, observable, matching 또는 likelihood가 닫히지 않았다. |
| `Rejected` | 사전 지정한 식이나 benchmark가 내부 또는 관측 gate에서 실패했다. |

`Candidate`, `Diagnostic`, `Model construction`처럼 필요한 보조 설명은 위
지위 중 하나 뒤에 평문으로 붙인다. 둘 이상의 지위를 슬래시로 합쳐 책임
범위를 흐리지 않는다.

## 2. type이 다른 핵심 기호

| 기호 | type과 domain | 허용되는 뜻 |
|---|---|---|
| \(d\in\mathbb N_0\) | 정수 | formal 공간차원 label; Hodge 정리는 \(d>0\), \(d=0\) 물리화는 별도 Selection |
| \(D\ge0\) | 실수 control parameter | 재귀 깊이 또는 평균 trigger를 만들기 위한 좌표 |
| \(\kappa\ge0\) | inverse-depth rate | \(D\)의 정규화; 불변 조합은 \(\tau=\kappa D\), 비자명 감쇠에는 \(\kappa>0\) |
| \(q_{\rm trig}\in[0,1]\) | 확률 | Poisson branching trigger의 eventual extinction probability |
| \(p_{\rm trig}=1-q_{\rm trig}\) | 확률 | 같은 trigger process의 survival probability |
| \(x_{\rm path}\in[0,1]\) | 양의 측도 비율 | sub-Markov path kernel 아래 살아남은 질량의 비율 |
| \(x_E\in[0,1]\) | 에너지 비율 | 공변 stress-energy readout으로 정의한 sector fraction |
| \(\Omega_i\) | 임계밀도 비율 | FLRW 해와 지정 epoch에서의 물리적 density parameter |
| \(\delta_{\rm proj}\) | projector overlap | 정규화한 Hilbert-space 또는 field-space 기하량 |
| \(\delta_A\) | 등록된 대수 출력 | \(s_A^2(1-s_A^2)\); 물리적 projector와 자동 동일하지 않음 |
| \(R_{\rm CE}\in(0,\infty)\) | 등록된 scalar 출력 | dark-density ratio 후보; Ricci scalar \(R\), Casas--Ibarra 행렬 \(R_{\rm CI}\)와 구별 |
| \(C_5=C_5^T\) | 차원 \(-1\)의 flavour matrix | Weinberg operator coefficient; inverse-depth rate \(\kappa\)와 구별 |
| \(z_\Phi=\Phi/M_P\) | 무차원 scalar-field 좌표 | inflation 구간 좌표; path/energy 비율 \(x_{\rm path},x_E\)와 구별 |
| \(s_{\rm ent}>0\) | entropy density | scalar field \(s\)와 구별 |
| \(\mathcal V_N=\pi^N\) | measure feature | 선택한 unit-polydisc/Gaussian 정규화의 수치 |

따라서 다음 등식은 정리가 아니다.

\[
D=d,\qquad q_{\rm trig}=x_{\rm path}=x_E=\Omega_b,
\qquad \delta_A=\delta_{\rm proj}.
\]

각 등호에는 독립된 `Bridge`와 기각 가능한 실현이 필요하다. \(P\)는 projector
기호로 예약하고 transition kernel은 \(\mathsf K\), 확률은 \(\Pr\)로 쓴다.
\(\pi^N\)에는 \(\mathcal V_N\)을 사용한다.

## 3. 생존 semigroup와 고정점 정리

연속 함수 \(S:[0,\infty)\to(0,1]\)가

\[
S(0)=1,\qquad S(D_1+D_2)=S(D_1)S(D_2)
\]

를 만족하면 어떤 \(\kappa\ge0\)에 대해

\[
S(D)=e^{-\kappa D}
\]

다. 비자명 감쇠를 원하면 \(\kappa>0\)을 별도로 가정한다. \(\kappa=1\)은
\(D\)를 mean trigger count로 정의한 좌표에서는 `Convention`이지만,
\(D=3+\delta_A\)를 먼저 고정했다면 독립 `Selection`이다.

normalized binary complement, scalar sufficiency와 mixture affinity를 가정하면

\[
K(x)=1-x
\]

가 유일하다. 여기에 Poisson zero-trigger law 또는 같은 exponential law를
추가하면

\[
x=e^{-\kappa D(1-x)}
\]

를 얻는다. 임계조건은 \(D=1\)이 아니라 \(\kappa D=1\)이다. 이 식 자체는
`Exact conditional`이며 \(x\)의 물리적 이름은 추가 `Bridge`가 정한다.

## 4. branching 의미와 물리 경로 의미

유한 \(n\)과 entrywise 비음수 mean-offspring matrix
\(A\in[0,\infty)^{n\times n}\)인 다형 Poisson Galton--Watson 과정에서는

\[
q_i=\exp\!\left[-\sum_jA_{ij}(1-q_j)\right]
\]

의 componentwise 최소해가 extinction vector다. branching survival은
\(p_i=1-q_i\)다. \(x=q_{\rm trig}\)를 물리적 path survival로 읽으려면

\[
\{\text{path survives}\}
\Longleftrightarrow
\{\text{its suppressor-trigger genealogy becomes extinct}\}
\tag{B-surv}
\]

를 독립 `Bridge`로 둔다. 이 경우에도 \(1-x\)를 suppressed path mass로
식별하려면 보존적 two-channel kernel이 추가로 필요하다.

\(A\)가 irreducible이면 \(\rho(A)\le1\)일 때
\(\boldsymbol q=\boldsymbol1\)이고, \(\rho(A)>1\)일 때 모든
\(q_i<1\)이다. reducible \(A\)에서는 type \(i\)가 내부 Perron radius가
1보다 큰 strongly connected component에 도달할 수 있을 때만 \(q_i<1\)이다.
예를 들어

\[
A=\operatorname{diag}(2,1/2),\qquad
\boldsymbol q=(0.20318786998,1)
\]

이므로 \(\rho(A)>1\)만으로 모든 성분의 비자명성을 결론낼 수 없다.

## 5. 경로측도의 최소 정의

고전적 생존분율에는 measurable space \((\Gamma,\mathcal F)\), 유한 양의 기준
측도 \(0<\mu(\Gamma)<\infty\), positive sub-Markov kernel
\(\mathsf K_D\)를 둔다.

\[
(\mathcal T_D\mu)(B)
=\int_\Gamma \mathsf K_D(\gamma,B)\,d\mu(\gamma),\qquad
0\le \mathsf K_D(\gamma,\Gamma)\le1.
\]

그러면

\[
x_{\rm path}[\mu]
=\frac{(\mathcal T_D\mu)(\Gamma)}{\mu(\Gamma)}\in[0,1]
\]

가 well-defined다. full path bookkeeping에는

\[
\mathsf K_D^{\rm surv}(\gamma,\Gamma)
+\mathsf K_D^{\rm supp}(\gamma,\Gamma)=1
\]

인 두 채널을 둔다. 단지
\(\mathcal T_D:\mathcal M(\Gamma)\to\mathcal M(\Gamma)\)라고 쓰는 것은
충분하지 않다. \(\mathcal T\mu=\mu(\Gamma)\nu_0\)는 모든 path 정보를 지우고,
\(\mathcal T\mu=2\mu\)는 분율을 2로 만든다.

Lorentzian 양자 경로적분의 가중치는 일반적으로 복소수다. 따라서 위 positive
measure를 쓰려면 decoherent histories, Euclidean reconstruction 또는 실제
POVM/readout으로 가는 별도 `Bridge`가 필요하다.

## 6. 동역학 계약

고정점과 fixed-\(D\) gradient flow는 서로 다른 주장이다. 공변 폐쇄계 작용은
2차 Euler--Lagrange 방정식을 주며 마찰을 자동 생성하지 않는다. 1차

\[
\dot y=-\Gamma\,\partial_yV
\]

를 사용하려면 bath와 coarse graining을 둔 open-system effective equation으로
표시하고 fluctuation--dissipation noise와 유효범위를 제시한다.

\(D\)가 동역학적일 때 potential의 \(D\)-only 항도 \(D\)의 힘을 바꾼다.
그러므로 \(D\to0\) subtraction은 단순한 상수 제거가 아니라 renormalization
condition이며, action과 동시에 선언한다.

## 7. 물리 Bridge 승격 조건

| 후보 등식 | 현재 지위 | 최소 승격 조건 |
|---|---|---|
| \(d=3\Rightarrow N_c=N_{\rm gen}=3\) | `Selection` | gauge group·representation·anomaly·spectrum을 유일하게 정하는 action |
| \(\delta_A=\delta_{\rm proj}\) | `Bridge` | canonical kinetic metric의 spectral projector와 RG/scheme matching |
| \(q_{\rm trig}=x_{\rm path}\) | `Bridge` | B-surv 사건 동일시를 구현하는 microscopic kernel |
| \(x_{\rm path}=x_E\) | `Bridge` | path weight에서 renormalized \(T^{\mu\nu}\)로 가는 positive readout |
| 가정된 readout에서 \(x_E=\Omega_b\)라는 함의 | `Exact conditional` | total/baryon stress readout 보존, flat Friedmann constraint, 지정 epoch |
| CE action이 위 readout 가정을 실현 | `Open` | baryon projector, transfer equation, FLRW solution과 epoch evolution |
| \(R_{\rm CE}=\Omega_{DM}/\Omega_{DE}\) | `Phenomenology` | 공변 dark-sector action, perturbation stability, full joint likelihood |
| \(Q_{\rm GER}\mapsto A_s\) | `Open` | canonically normalized perturbation action과 Mukhanov--Sasaki 계산 |
| \(\mathcal V_N\mapsto\alpha,m_p/m_e\) | `Rejected` as exact | 관측 상수를 입력하지 않은 regulator-independent RG/lattice derivation |

## 8. 통계와 유효숫자 계약

관측값을 계수, branch 또는 초기조건에 사용했다면 같은 관측값을 성공
holdout으로 다시 세지 않는다. 하나의 \(\alpha_s\)에서 나온 여러 파생량은
독립 예측이 아니며 공통 input covariance와 formula-selection trials를
함께 전파한다.

대표 입력 \(\alpha_s(M_Z)=0.1180\pm0.0009\)만 전파해도 등록식은 대략

\[
x=0.0486383\pm0.000069
\]

를 준다. 이 오차는 `Bridge`와 이론 계통오차를 포함하지 않는다. 따라서
10자리 수치는 소프트웨어 회귀검사용 fingerprint이지 물리적 유효숫자가 아니다.

정확한 상수식으로 읽은 \(4\pi^3+\pi^2+\pi\)와 \(6\pi^5\)는 현재 정밀값에서
각각 \(10^4\sigma\), \(10^6\sigma\) 이상 벗어나므로 `Rejected`다. 근사
mnemonic으로 기록할 수는 있지만 예측으로 집계하지 않는다.
