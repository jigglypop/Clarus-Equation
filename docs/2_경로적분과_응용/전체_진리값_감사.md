# 경로적분과 응용: 형식 구조 원장

이 문서는 [형식적 출처 규약](./00_검증_규약.md), 01--14장,
[참고문헌](./참고문헌.md), [통합 검증기](./validate_manuscript.py), 삭제 회귀 엔진,
후속 계산 엔진과 변조 방어 테스트를 연결한다. 수치는 읽기용 스냅샷이며,
기계 재현 시점의 출력이 우선한다.

지위를 부여하지도 않는다.

## 2. 이론 사슬

```text
정의
  ├─ 증명 가능한 명제 ──> 정리
  └─ 독립 모형 전제 ───> 공리
정의 + 공리 + 정리 + 명시 입력
  └────────────────────> 산출
외부 수치 공급 ────────> 공리(외부 입력)
자료 선택 ansatz·fit ──> 경험식
필요 조건 미충족 ──────> 미완성
사전 고정 관측 명제 ───> 예측
```

관측 비교는 이 사슬과 별도 축이다. 수치 일치가 공리를 정리로 바꾸지 않고,
관측 불일치가 동일한 수학 구조의 조건부 정리를 자동으로 없애지도 않는다.

## 3. 이론물리 감사 분류

관측 폐쇄가 없다는 이유만으로 수학적으로 닫힌 조건부 결과를 낮추지 않았다.
반대로 식의 내부 산술이 맞아도 확률변수와 장, 고정점과 밀도, 위상과 관측량을
잇는 사상이 없으면 그 물리적 동일시는 정리가 아니다.

### 3.2 일관된 공리적 toy·EFT 모형

| 모형군 | 보존 범위 | 정리로 읽지 않는 부분 |
|---|---|---|
| 차원 label branch | \(N_c:=d\), \(N_{\rm gen}:=d\), \(\{3,2,1\}\)의 게이지인자 label 대응 | 자연이 그 bridge를 선택한다는 주장, 표현·하이퍼전하의 기원 |
| 결합 closure | 동일 scale에서 세 결합식과 외부 \(\alpha_{\rm em}\), 두 양의 근 및 별도 큰-근 분기 선택 | 표준모형 RG에서의 기원 또는 무입력 유일예측 |
| scalar bootstrap | affine complement, Poisson closure, \(q\leftrightarrow\Omega_b\), 후기우주 분할·투영 readout | 확률과 stress tensor·관측연산자를 잇는 미시적 물리 사상 |

## 5. 삭제 경계와 회귀 보존

완전한 반증 증인이 확보된 부모 명제와 그 명제에 의존한 식·표·설명은 정본
Markdown에 두지 않는다. 재도입 방지 정보는
[`rejection_loop_engineering.py`](./rejection_loop_engineering.py)의 코드 내부
registry에만 있다. 현재 registry는 18개의 고정 fingerprint와 실행 predicate를
가지며, 문서에는 부모 문장이나 증인의 상세를 복제하지 않는다.

전제, 장 내용, 매개변수 또는 benchmark를 바꾼 후속 모형은 별도 식별자를 갖는다.
그 모형의 조건부 계산은 `[공리]`와 `[산출]`로 기록하며 삭제된 문장의 복원 근거로
사용하지 않는다.

현재 작업본과 `HEAD`의 01--14 차이도 같은 기준으로 역검토했다. 삭제 과정에서
함께 빠졌던 표준 QFT/EFT/GR·확률론 결과 가운데 독립 전제와 짧은 증명을 붙여
닫을 수 있는 Weyl 변환, 선택규칙, EFT matching, branching 정리, 연속 원
조화항등식, semigroup와 Haar 결과만 새 식별자로 복원했다. 반례가 완전한 부모식과
그 부모식에 의존하는 후손은 복원하지 않았고, 재등장 여부는 코드 witness가 맡는다.

## 6. 관측 자료와 provenance

원시 진폭 비교에는
\(A_s\times10^9=2.099\pm0.029\)의 Planck 2018 스냅샷을 입력으로 사용한다.
이 값으로 정규화한 \(\lambda_4\)는 `[산출]` 또는 `[경험식]`이며 독립 예측이 아니다.

외부 자료를 쓰는 계산은 판본·해시·단위·공분산을 코드의 provenance lock으로
고정한다. 기본 실행은 저장소에 포함된 snapshot만 검사하며, 외부 원본 파일은
경로가 제공된 실행에서만 검사한다.

## 7. 재현 명령

다음 명령은 `docs` 디렉터리에서 실행한다. `--json`은 기계 판독 가능한 전체
원장을 출력한다.

```powershell
python .\2_경로적분과_응용\validate_manuscript.py
python .\2_경로적분과_응용\rejection_loop_engineering.py --self-test
python .\2_경로적분과_응용\improvement_loop_engineering.py --self-test
python -m pytest .\2_경로적분과_응용\test_manuscript_loop_engineering.py -q
```

통합 검증기는 문서 표지, 금지된 구형 표지, 삭제 문장의 본문 재등장, 링크·인코딩,
수학·수치 회귀와 두 하위 엔진을 함께 검사한다. 외부 원본까지 확인하는 release
실행은 개선 엔진에 네 파일 경로와 `--require-live-artifacts`를 제공한다.

## 8. 현재 이론적 경계

현재 원고에서 형식적으로 단단한 부분은 명시된 정의역의 고정점 수학, Hodge 차원
계수, 지정 작용의 조건부 장론 계산과 여러 대수 항등식이다. 우주 성분, 결합상수,
입자 질량, 인플레이션 정규화와 관측 readout에는 독립 공리 또는 외부 입력이 남아
있다. 따라서 이론적 출처는 각 문장의 표지에서 읽고, 자연에 대한 비교는 별도의
자료·오차·우도 주석에서 읽는다.
