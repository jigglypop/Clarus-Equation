# CE 이론물리 보존 원장

이 문서는 CE의 특정 물리 모형을 완성했다고 주장하지 않는다. 서로 독립적으로
참인 미분기하, 변분법, 유클리드 상관함수, 국소 양자채널과 얇은 껍질
중력의 결과를 전제와 함께 보존한다. 이 결과를 CE의 장, 입자, 측정 장치에
대응시키는 단계는 별도의 물리 사상이다.

## 7. 무차원 지수 규약

다음 조합만 지수와 로그의 인자로 사용한다.

| 상황 | 무차원 조합 |
|---|---|
| 유클리드 경로 가중치 | $\mathcal I_E=S_E/\hbar$ 또는 명시한 $S_E/S_*$ |
| 열적 가중치 | $E/(k_BT)$ |
| 곡률 가중치 | $\widetilde R=R/R_c=RL_c^2$ |
| 스펙트럼 kernel | $E=\mathcal E t_*/\hbar$, $t=t_{\rm phys}/t_*$에 대한 $Et$ |
| Gibbs 선택 | $e^{-\beta\mathcal I}$, $\beta,\mathcal I$ 모두 무차원 |

## 8. 남은 물리 사상

다음 항목은 위 정리들에서 나오지 않으며 **[미완성]**이다.

- CE 독립장과 공변·gauge-fixed 양자 유효 작용
- Hessian, stress tensor와 observable vertex 사이의 구체적 사상
- 양의 유클리드 측도, analytic continuation, LSZ를 잇는 모형
- 경로공간 prior와 실험적 readout instrument의 구성
- exotic stress의 재규격화된 원천, backreaction과 비선형 안정성

이 항목을 추가할 때에는 작용, 정의역, 경계조건, 단위와 관측 사상을 먼저
고정해야 한다.
