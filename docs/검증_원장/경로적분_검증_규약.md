# 경로적분과 응용: 형식적 출처 규약

이 문서는 01--14장의 각 문장이 어디서 나오는지를 구분하는 최소 규범이다.
수학적 성립 여부와 자연에 대한 관측 적합성은 서로 다른 축으로 기록한다.
실행 가능한 회귀 검사와 외부 자료 provenance는
[형식 구조 원장](경로적분_전체_진리값_감사.md)에 둔다.

## 1. 본문 표지

- **[정의]**: 기호, 정의역, 단위 또는 대상을 선언한다. 참·거짓을 판정하는
  명제가 아니며 다른 결과의 전제가 된다.
- **[정리]**: 명시된 전제와 정의역에서 증명이 완결된 명제다. 항등식,
  해석적 증명, 또는 닫힌 유한 집합의 전수검사가 여기에 속한다.
- **[공리]**: 모형이 채택한 독립 전제다. 분기, 경계조건, 정규화, 장 내용,
  물리 사상과 외부 입력·scale의 연결을 포함한다. 필요하면 `모델 선택`,
  `물리 사상`, `외부 입력`을 덧붙인다. 이후 수학이 정확하더라도 공리 자체가
  자연에서 강제됐다는 뜻은 아니다.
- **[산출]**: 표시한 정의·공리·정리와 입력에서 추가 선택 없이 계산되는
  조건부 결과다. 어떤 입력에 의존하는지 같은 문단에 적는다.
- **[경험식]**: 자료에서 고른 ansatz, fit 또는 경험적 readout이다. 계산에
  공급하는 관측값 자체는 `[공리] 외부 입력`으로 분리하고, 기준 자료,
  불확도, scheme과 scale을 가능한 범위에서 함께 적는다.
- **[미완성]**: 필요한 정의, 증명, 작용, 동역학, 원자료, 우도 또는 독립
  검사가 아직 없다. 결론이나 계산 입력으로 사용하지 않는다.
- **[예측]**: 데이터 확인 전에 식, 입력, 허용범위와 비교 절차를 고정한
  미결 관측 명제다. 관측 결과는 이론적 출처 표지와 별도 기록한다.

판정 단위는 장이 아니라 개별 문장과 식이다. 조건부 정리는 전제를 문장 안에
고정하고, 직접 산술은 정리와 구분해 `[산출]`로 적는다. 물리적 동일시가 하나라도
들어가면 그 동일시는 `[공리]`이며, 그 뒤의 계산만 `[산출]`이 될 수 있다.

명시한 작용·확률법칙·EFT 연산자·경계조건이 자연에서 선택됐다는 증거가 없어도
그것들은 일관된 조건부 이론의 `[공리]`로 둘 수 있다. 그 공리 안에서 정의역,
가지, 대칭과 오차차수까지 닫힌 명제는 관측 비교 없이 `[정리]`이며, 수치 대입은
`[산출]`이다. 반대로 물리 사상이 비어 있다는 이유만으로 이미 증명된 조건부
정리까지 `[미완성]`으로 내리지 않는다.

## 2. 완전한 반례 처리

전제와 정의역을 만족하는 단일 사례가 보편 명제를 부정하면 그 부모 명제와
그 명제를 전제로 한 식·표·서술은 정본 본문에서 삭제한다. 삭제된 문장을
본문의 별도 등급으로 보존하거나 반례 목록으로 재수록하지 않는다.

재도입 방지는 코드 내부의 고정 fingerprint와 실행 predicate가 담당한다.
전제·장 내용·매개변수·benchmark를 바꾼 수선은 새 공리를 가진 별도 모형이며,
그 결과가 성립해도 삭제된 부모 명제를 되살리지 않는다. 유한 탐색에서 반례를
찾지 못한 사실만으로 `[정리]`를 부여하지 않는다.

## 3. 관측 비교의 분리

관측 비교는 이론적 출처와 독립된 주석이다. 다음을 함께 기록한다.

1. 비교한 데이터 판본, 기준값과 불확도
2. 사용한 likelihood, 공분산, nuisance와 자유도
3. 입력으로 사용한 관측량과 비교에만 사용한 관측량의 구분
4. 내부 교차검증인지 비중첩 외부 표본인지의 구분

관측 불일치는 해당 모형이 그 자료를 설명한다는 경험 명제를 제거할 수 있지만,
동일한 수학 구조의 조건부 정리까지 자동으로 부정하지 않는다. 반대로 수치
일치는 공리나 경험식을 정리로 바꾸지 않는다.

## 4. 기계 검사의 범위

검증기는 문서 구조, 표지 인벤토리, 수치 회귀, 입력 provenance와 삭제 문장의
재도입 여부를 검사한다. 콘솔의 성공·오류 상태는 실행 결과일 뿐 본문의 이론적
출처 표지가 아니다. 외부 자료를 공급하지 않은 검사는 미실행 상태를 그대로
기록한다.

외부 관측값과 표준 장론 결과의 기준 출처는 [공통 참고문헌](../2_경로적분과_응용/참고문헌.md)에
두며, 현재 형식 구조와 재현 명령은
[형식 구조 원장](경로적분_전체_진리값_감사.md)을 따른다.
