# 13. 우주론 비교 원칙과 열린 항목

이 문서는 우주론 readout의 수학적 출처와 관측 비교 규칙을 분리한다.
판본·Claim ID는 [우주론 판본·주장 원장](00_우주론_원장.md), 관측 release와
covariance 역할은 `benchmarks/cosmology/observations_v1.json`을 기준으로 한다.

## 1. 출처 구분

- **[정의]** 관측량의 기호, 데이터셋과 공분산의 정의.
- **[정리]** 명시한 함수의 대수 항등식과 오차변환.
- **[경험식]** 관측 자료나 유효 계수를 사용하는 readout.
- **[미완성]** 대수 변수를 우주론 관측량에 잇는 물리 사상과 full likelihood.

관측 중심값에 가까운 수치는 수학적 유도의 전제가 아니다. 중심값, 오차와
공분산은 같은 데이터 릴리스와 likelihood에서 가져와 별도 비교 자료로 기록한다.

## 2. 관측 비교의 수학 규칙

### 2.1 동일 데이터셋 규칙

표준화 잔차

\[
z=\frac{x_{\rm model}-\mu_{\rm data}}{\sigma_{\rm data}}
\]

를 사용할 때 \(\mu_{\rm data}\), \(\sigma_{\rm data}\)와 공분산은 동일한
데이터셋·모형·likelihood의 산출이어야 한다. 서로 다른 분석의 중심값과
오차를 결합한 \(z\)는 그 어느 분석의 통계량도 아니다.

### 2.2 \(A_s\) 로그 변수의 오차변환

**[정리]** \(y=\ln(10^{10}A_s)\)이면

\[
A_s=10^{-10}e^y,\qquad
\sigma_{A_s}=A_s\,\sigma_y+O(\sigma_y^2).
\]

따라서 로그 변수의 오차를 선형 \(A_s\)의 오차처럼 직접 사용하지 않는다.
구체적인 관측값은 데이터 릴리스와 함께 별도 비교표에 둔다.

### 2.3 look-elsewhere 규칙

여러 무차원 조합을 탐색한 뒤 관측값에 가까운 식만 고르면 근접도는 독립
증거가 아니다. 후보 집합, 선택 규칙과 판별 관측량을 자료를 보기 전에
고정한 경우에만 **[예측]** 비교로 분류한다.

## 3. 반투영 맵의 대수 항등식

**[정의]** \(g(x)=(1-x)/2\)라 두면

\[
g(g(x))
=g\!\left(\frac{1-x}{2}\right)
=\frac{1+x}{4}.
\]

**[정리]** 이 등식은 \(g\)의 정의로부터 모든 허용 \(x\)에 대해 성립한다.
더 일반적으로

\[
g^{\circ n}(x)=\frac13+
\left(-\frac12\right)^n\left(x-\frac13\right).
\]

따라서 \(g:[0,1]\to[0,1/2]\)는 contraction이고 모든
\(x\in[0,1]\)에서 유일한 고정점 \(1/3\)으로 수렴한다.

**[공리: 이산 toy dynamics]** \(x_{n+1}=g(x_n)\)를 실제 coarse-grained
시간진화로 택하면 이 안정성은 모형 내부의 정확한 산출이다. \(x\)를 특정
밀도 분율과 동일시하거나 한 iteration을 물리적 시간 간격으로 읽는 사상은
별도다.

## 4. Gaussian likelihood의 닫힌 부분

**[공리]** 데이터 벡터 \(y\in\mathbb R^n\), 모형 평균
\(\mu(\vartheta)\)와 양의 정부호 covariance \(C\)를 사전에 고정한다.

**[산출]**

\[
-2\log\mathcal L(\vartheta)
=(y-\mu)^TC^{-1}(y-\mu)+\log\det C+n\log(2\pi).
\]

이는 multivariate Gaussian 모형의 정확한 likelihood다. 따라서 이
형식을 쓰는 관측 비교는 수학적으로 닫을 수 있다. 남는 것은 실제
데이터 release, \(C\), nuisance parameter와 selection function의 공급이다.

## 5. 남은 증명 의무

- readout마다 데이터셋·likelihood·공분산을 고정한다.
- 대수 변수와 우주 성분 사이의 사상을 독립 작용 또는 확률모형에서 제시한다.
- 경험식의 계수를 학습 자료와 독립된 관측량에서 검증한다.
