# 격자 기본량과 결합 입력

이 문서는 차원·게이지 격자와 결합상수 관계의 수학적 출처를 분리한다.

## 1. 차원 방정식

**[정리]** 양의 정수 \(d\)가

\[
d=\frac{d(d-1)}2
\]

를 만족하면 \(d=3\)이다. 실제로 \(d(d-3)=0\)이고, 전체 정수해는
\(d=0,3\)이므로 양의 정수 조건이 비자명 분기를 고른다.

[자족 증명](../참조/핵심_정리_증명.md#exterior-dimension)

방향과 metric을 함께 주면 더 강한 기하 진술이 성립한다.

**[정리]** Hodge 연산자가 2-form을 1-form으로 보내는 차원은
\(d=3\)이다.
[증명](../참조/핵심_정리_증명.md#hodge-closure)

## 2. 게이지 격자 **[공리]**

다음은 대수 정리의 결론이 아니라 CE의 모델 식별이다.

\[
N_c=d,\qquad N_w=d-1.
\]

따라서 \(d=3\) 분기에서 \(N_c=3\), \(N_w=2\)를 사용한다. 이 식별만으로
표준모형 게이지군이나 물질 표현이 유도되지는 않는다.

## 3. 결합 입력과 관계

- **[공리]** \(\alpha_s(M_Z)\)는 외부 입력이다.
- **[공리]** 결합 합 규칙
  \[
  \alpha_s+\alpha_w+\alpha_{em}=\frac1{2\pi}
  \]
  에서 우변의 정수 선택 \(n=1\)을 모델 규칙으로 둔다. 이 식은 세
  physical running coupling의 RG 불변 합법칙이 아니라 \(M_Z\)에서
  고정한 normalization ansatz다.
- **[경험식]** 같은 기준 스케일에서
  \[
  s_W^2\equiv\sin^2\theta_W=4\alpha_s^{4/3}
  \]
  를 사용한다.
- **[정의]** \(\alpha_{em}=s_W^2\alpha_w\)로 쓴다.

이 입력들로부터

\[
\alpha_w=\frac{1/(2\pi)-\alpha_s}{1+s_W^2},\qquad
\alpha_{em}=s_W^2\alpha_w
\]

를 얻는다.

## 4. 수치 산출

**[산출]** \(\alpha_s(M_Z)=0.11789\)를 넣으면

\[
s_W^2\simeq0.2312,\qquad
\alpha_w\simeq0.03352,\qquad
\alpha_{em}(M_Z)\simeq0.00775.
\]

이 값들은 외부 \(\alpha_s\), 합 규칙과 경험식을 함께 사용한 대입 결과다.
관측값은 관계식의 수학적 출처가 아니라 별도 비교 자료로만 둔다.

## 5. 대각 toy ansatz

응용 계산에서 채널 독립성을 시험하려면

\[
K_{ij}=k_i\delta_{ij},\qquad k_i\geq0.
\]

를 **[공리]**로 둘 수 있다.

**[정리]** 작용과 측도가
\(S=\sum_iS_i[\phi_i]\),
\(\mathcal D\phi=\prod_i\mathcal D\phi_i\)로 분해되면

\[
Z=\prod_iZ_i,\qquad
\langle\mathcal O_i\mathcal O_j\rangle_c=0\quad(i\ne j)
\]

이다. 이는 Fubini 정리를 적용할 수 있는 유한 격자에서 직접 따른다.
대각 kernel은 이 독립 channel 모형을 구현한다.

대각성은 인과성 자체가 아니라 상호작용이 없는 toy sector의 조건이다.
실제 gauge interaction은 일반적으로 비대각 vertex를 가진다.
