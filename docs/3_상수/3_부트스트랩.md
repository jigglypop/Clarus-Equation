# 부트스트랩 고정점

## 1. 정의

**[정의]** 단일 초기 개체 \(Z_0=1\)에서 시작하고 평균 분기수 \(D>0\)인
Poisson Galton--Watson 과정의 소멸확률을 \(q_{\rm ext}\), 생존확률을
\(s_{\rm branch}=1-q_{\rm ext}\)로 쓴다.

## 2. 최소 소멸 고정점

**[정리]** 소멸확률은

\[
q=e^{-D(1-q)}
\]

의 \([0,1]\) 안 최소해다. \(D\leq1\)이면 \(q_{\rm ext}=1\)이고,
\(D>1\)이면 \(q=1\) 외에 유일한 해 \(q_{\rm ext}\in(0,1)\)가 있다.
비자명 해는

\[
q_{\rm ext}=-\frac1D W_0(-De^{-D})
\]

로 쓸 수 있다.

[축소사상·Lambert·Poisson 최소해 증명](../참조/핵심_정리_증명.md#poisson-fixed-point)

**[산출]** \(D=D_{\rm eff}\simeq3.1778\)을 넣으면
\(q_{\rm ext}\)와 \(s_{\rm branch}=1-q_{\rm ext}\)가 수치적으로 정해진다.
이 단계의 \(q_{\rm ext}\)는 소멸확률이지 생존확률이 아니다.

## 3. 다형 확장

**[공리]** type \(i\)가 type \(j\) 자손을 독립
\(\operatorname{Poisson}(A_{ij})\)로 만든다고 둔다.

**[정리]** 최소 소멸확률 벡터는

\[
q_i=\exp\!\left[-\sum_jA_{ij}(1-q_j)\right]
\]

의 최소해다. \(A\boldsymbol1=D\boldsymbol1\)이면
\(\boldsymbol q=q_{\rm ext}\boldsymbol1\)로 정확히 축약되고, 비자명
균일해의 반복 Jacobian은 \(J=q_{\rm ext}A\),
\(\rho(J)=q_{\rm ext}D<1\)이다.

[증명](../참조/핵심_정리_증명.md#multitype-poisson)

따라서 스칼라식은 “재귀 type이 하나뿐”이라는 가정 외에도 공통 행합
sector에서 정확히 보존된다.

## 4. 항등 사상의 출처

**[정리]** 연속함수 \(I:(0,1]\to(0,1]\)가

\[
I(PQ)=I(P)I(Q),\qquad I(1)=1
\]

을 만족하면 \(I(P)=P^c\)인 \(c\geq0\)가 존재한다. \(I\)가 상수가
아니거나 \(I(0^+)=0\)을 더하면 \(c>0\)이다.

[자족 증명](../참조/핵심_정리_증명.md#multiplicative-readout)

**[공리]** CE readout에서는 1차 계수를 보존하도록 \(c=1\), 즉
\(I(P)=P\)를 선택한다. 이 선택은 에너지 보존만으로 도출되지 않는다.

**[정의]** \(\Omega_b:=\rho_b(t_0)/\rho_{\rm crit}(t_0)\)를 현재
바리온 밀도분율로 둔다.

**[공리: 우주론 branch]** \(q_{\rm ext}\mapsto\Omega_b\)를 물리
readout으로 선택할 수 있다. 이 선택을 포함한 모형은 논리적으로
완결되지만, 그 사상을 CE+SM stress tensor와 Boltzmann 방정식에서
도출하는 미시적 설명은 **[미완성]**이다.

## 5. 해석함수

비자명 가지에서 \(u=s_{\rm branch}=1-q_{\rm ext}\)로 두면

\[
1-u=e^{-Du},\qquad
D(u)=-\frac{\log(1-u)}u,\qquad 0<u<1.
\]

**[정리]**

\[
D(u)=\sum_{n=0}^{\infty}\frac{u^n}{n+1}
=\int_0^1\frac{dt}{1-ut}.
\]

따라서 \(D(u)\)는 \((0,1)\)에서 양수이고 증가하며 볼록하다. 또한
\(a>0\), \(a\ne1\)에서 Mellin 적분은

\[
\int_0^1D(u)u^{a-1}\,du
=\frac{\psi(a)+\gamma}{a-1}
\]

이다. 여기서 \(\psi\)는 digamma 함수, \(\gamma\)는 Euler--Mascheroni
상수다. \(a=1\)에서는 연속극한 \(\pi^2/6\)을 취한다. 이들은 순수 해석학
결과이며 우주 성분의 단조성이나 관측값 대응을 뜻하지 않는다.
