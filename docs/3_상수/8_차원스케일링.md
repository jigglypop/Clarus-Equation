# 8층: 차원 스케일과 provenance

## 개관

dimensionful quantity의 수치가 단위계에 의존한다는 사실과, 서로 다른 물리 scale의 **무차원 비율**이 설명을 필요로 한다는 사실을 구분한다. $c,\hbar,k_B$를 자연단위에서 1로 둘 수 있어도 $\bar M_{\rm Pl}/v$ 또는 $M_{\rm Pl}/v$, $m_e/v$, $H_0/v$ 같은 비율은 사라지지 않는다.

이 문서는 무차원 CE 코어를 전자약 입자량으로 scale-promote할 때 \(v\)를
대표 reference로 쓴다.

$$
\boxed{\Lambda_{\rm anchor}=v=(\sqrt2G_F)^{-1/2}=246.22\ {\rm GeV}}
$$

다른 scale은 \(v\)와의 dimensionless ratio가 모형에서 실제로
유도되었거나 입력 장부에 기록된 경우에만 복원한다. 관측에서 공급한
\(H_0/v\), \(m_p/v\), \(T_{\rm CMB}/v\), \(M_{\rm Pl}/v\) 같은 ratio는
표기만 무차원일 뿐 독립 물리 입력을 제거하지 않는다.

## 8.1 대표 reference를 이용한 단위 복원

자연단위에서 어떤 출력이 dimensionless $r_X$이면

$$
E_X=v\,r_X,\qquad
t_X=\frac{\hbar}{v}\,r_t,\qquad
\ell_X=\frac{\hbar c}{v}\,r_\ell,\qquad
T_X=\frac{v}{k_B}\,r_T.
$$

이 식은 단위 복원 규칙이지 $r_X$의 물리 유도가 아니다. 예를 들어

$$m_f=\frac{v}{\sqrt2}y_f$$

에서 $y_f$가 입력 또는 texture parameter면 $m_f$도 그 provenance를 상속한다.

## 8.2 기본 provenance 표

| 양 | 종류 | 이 문서의 처리 |
|---|---|---|
| $v$ | 대표 dimensionful reference | $G_F$에서 입력; electroweak scale-promotion 기준 |
| $c$ | SI conversion/정의 | spacetime 단위 변환; 자연단위에서 1 |
| $\hbar$ | SI conversion/정의 | action 단위 변환; 자연단위에서 1 |
| $k_B$ | SI conversion/정의 | energy-temperature 변환; 자연단위에서 1 |
| $N_A,e$ | SI 정의/측정 체계 | mol/charge unit 복원 |
| $y_f$ | dimensionless physics | Yukawa texture 또는 외부 fit; 단위 관례가 아님 |
| $\alpha_s,\alpha_{em}$ | dimensionless running inputs/outputs | scale·scheme과 함께 기록 |
| $\bar M_{\rm Pl}/v$ | reduced gravitational hierarchy | inflation/EFT convention; 독립 유도 없으면 외부 입력 |
| $M_{\rm Pl}/v$ | unreduced gravitational hierarchy | \(M_{\rm Pl}=G^{-1/2}=\sqrt{8\pi}\bar M_{\rm Pl}\); de Sitter/Planck-time convention |
| $H_0/v$ | dimensionless cosmological hierarchy | horizon readout 유도 없으면 외부 calibration |
| $\Lambda_{\overline{\rm MS}}/v$ | dimensionless QCD output | $\alpha_s(\mu)$, RG order, thresholds에서 계산 |

두 convention을

$$
G=\frac1{8\pi\bar M_{\rm Pl}^2}
$$

및 \(G=M_{\rm Pl}^{-2}\)로 구분한다. \(\bar M_{\rm Pl}=2.435\times10^{18}\,{\rm GeV}\), \(M_{\rm Pl}=1.2209\times10^{19}\,{\rm GeV}\)이며 한 식 안에서 섞지 않는다. SI 숫자는 단위 의존이지만 두 Planck/electroweak 비율은 물리적 hierarchy다. 7층의 exponential ansatz가 radiative/threshold-stable derivation을 통과하기 전에는 이 비율을 `유도 완료`로 세지 않는다.

## 8.3 QCD와 hadron scale

Track A의 QCD construction에서는 별도 \(\Lambda_{\rm QCD}\) 숫자를
임의로 추가하지 않고, \(v\)로 정한 reference scale과 dimensionless
gauge data에서 dimensional transmutation을 계산한다. 예를 들어
tree-level running relation \(M_Z=v\sqrt{g^2+g'^2}/2\)를 reference로
쓰되 pole scale에는 electroweak matching을 포함하고,

$$
\Lambda_{\overline{\rm MS}}^{(n_f)}
=M_Z\exp\left[-\frac{2\pi}{\beta_0\alpha_s(M_Z)}\right]
\times\{\text{higher-loop/threshold factors}\}.
$$

hadron mass는

$$
m_h=\Lambda_{\overline{\rm MS}}
F_h(m_q/\Lambda,\alpha_{em})
$$

로 lattice QCD+QED에서 계산한다. 이때 quark-mass ratios, lattice scale
setting, perturbative matching을 외부에서 공급했다면 그 provenance도
입력 장부에 남긴다. 관측 \(m_p\)를 직접 쓰는 다른 응용 트랙은 이를
독립 dimensionful input으로 기록해야 한다. \(m_p/m_e=6\pi^5\)를 scale
복원 규칙으로 사용하지 않는다.

## 8.4 파생 SI 상수

| 양 | 식 | 필요한 physics input |
|---|---|---|
| $a_0$ | $\hbar/(m_ec\alpha)$ | $y_e$, $v$, $\alpha$ |
| $R_\infty$ | $m_ec\alpha^2/(2h)$ | 동일; 통상 spectroscopic wavenumber convention |
| $E_h$ | $m_ec^2\alpha^2$ | 동일 |
| $\lambda_C$ | $h/(m_ec)$ | $y_e$, $v$ |
| $\mu_B$ | $e\hbar/(2m_e)$ | $y_e$, $v$ |
| $\mu_N$ | $e\hbar/(2m_p)$ | QCD RG+lattice $m_p$ |
| $R_K$ | $h/e^2$ | SI conversion과 QED charge |
| $R=N_Ak_B$ | SI 정의 조합 | 새 CE prediction 아님 |
| $\mathcal F=N_Ae$ | SI 정의 조합 | 새 CE prediction 아님 |

한 input에서 algebraically 파생된 여러 SI 수를 서로 독립적인 CE 예측으로 세지 않는다.

## 8.5 온도와 우주론

Kelvin 값은 $k_B$로 energy를 변환한 것이다. 그러나 $T_{\rm CMB}/v$ 자체는 물리적 dimensionless output이다. 이를 얻으려면 baryon-to-photon ratio, recombination history와 expansion history를 Boltzmann/recombination 계산으로 닫아야 한다. 관측 $T_{\rm CMB}$나 $H_0$를 중간 단계에 넣었다면 최종 Kelvin 또는 km/s/Mpc 값을 무입력 예측으로 세지 않는다.

## 8.6 출력 계약

1. 무차원 코어의 electroweak scale-promotion reference는 \(v\)로
   통일하되, 응용/관측 변환에 공급한 \(H_0,T_{\rm CMB},m_p,M_{\rm Pl}\)
   등 추가 dimensionful inputs를 숨기지 않는다.
2. $\bar M_{\rm Pl}/v$ 또는 $M_{\rm Pl}/v$, $H_0/v$, Yukawa eigenvalues처럼 남는 모든 dimensionless scale ratio는 **convention과 유도식 또는 입력**으로 별도 기록한다.
3. $c,\hbar,k_B$의 SI 값은 conversion이며 physics prediction 수에 포함하지 않는다.
4. GeV, MeV, K, m, s로 복원하기 전에 사용한 $r_X$, scale, scheme, RG order를 표에 남긴다.
5. 기존 '45개 상수에 유일한 차원 입력 하나' 주장은 사용하지 않는다.
   dimensionless hidden inputs와 추가 scale까지 포함한 full manifest를
   대신 제시한다.
