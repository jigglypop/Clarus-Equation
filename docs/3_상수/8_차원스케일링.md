# 차원 스케일과 단위 환산

## 1. 단위 규약

**[정의]** SI에서는 다음 상수가 단위 정의에 의해 정확한 수치값을 갖는다.

\[
c=299\,792\,458\ {\rm m\,s^{-1}},\qquad
h=6.62607015\times10^{-34}\ {\rm J\,s},
\]

\[
\hbar=\frac{h}{2\pi},\qquad
k_B=1.380649\times10^{-23}\ {\rm J\,K^{-1}}.
\]

이 값들은 CE의 물리 예측이 아니라 단위 규약이다.

## 2. 외부 물리 스케일

**[공리]** 수치 계산에서 \(G\), \(v_{\rm EW}\), \(m_e\), \(m_p\)와 각
재규격화 스케일의 결합상수는 외부 측정 입력으로 둔다. 차원 없는 관계만으로
이 스케일들의 절대값은 정해지지 않는다.

## 3. 표준 정의에서의 산출

**[산출]** 외부 입력과 단위 규약을 넣으면 예를 들어

\[
\ell_P=\sqrt{\frac{\hbar G}{c^3}},\qquad
t_P=\frac{\ell_P}{c},\qquad
m_P=\sqrt{\frac{\hbar c}{G}}
\]

를 계산할 수 있다.

또한

\[
\mu_B=\frac{e\hbar}{2m_e},\qquad
\mu_N=\frac{e\hbar}{2m_p}
\]

는 표준 정의다. 여기서 \(e\), \(m_e\), \(m_p\)는 외부 입력이며 두
자기모멘트의 수치 대입만 **[산출]**이다.

온도·에너지·주파수 변환도 \(E=k_BT=\hbar\omega\)라는 정의와 단위
규약에 따른 산출이다.

## 4. 경계

무차원 결합 하나가 정해졌다고 해서 다른 결합, 질량, CKM·PMNS 원소나
전자약 스케일이 자동으로 정해지지는 않는다. 그러한 관계에는 별도
**[공리]**, **[경험식]** 또는 동역학적 증명이 필요하다.

## 5. 공변 scalar EFT의 차원

자연단위 \(c=\hbar=1\)인 4차원에서

| 대상 | 질량차원 |
|---|---:|
| \(d^4x\) | \(-4\) |
| \(\phi,H\) | \(1\) |
| \(R\) | \(2\) |
| \(m_\phi,M_{\rm Pl},v\) | \(1\) |
| \(\Lambda_0,V\) | \(4\) |
| \(\xi,\lambda_\phi,\lambda_{H\phi}\) | \(0\) |

따라서

\[
\int d^4x\sqrt{-g}
\left[\frac12(M_{\rm Pl}^2-\xi\phi^2)R
-\frac12(\nabla\phi)^2-V(H,\phi)\right]
\]

은 무차원 작용이다.

고정점의 지수 \(D(1-q)\), semigroup의 \(\chi A\),
saddle의 \(\Delta S_E/\hbar\)와 flavor spurion
\(\langle\Theta\rangle/\Lambda_F\)도 모두 무차원이다.

**[정리]** 이 차원 조건은 식이 물리적으로 참이기 위한 필요조건이지
충분조건이 아니다. 부호, 대칭, 안정성, renormalization과 관측 사상은
별도로 검사해야 한다.
