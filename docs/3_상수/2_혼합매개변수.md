# 혼합 매개변수와 유효 차원

## 1. 정의

**[정의]** \(0\leq\theta_W\leq\pi/2\)에서

\[
s\equiv\sin^2\theta_W,\qquad
c\equiv\cos^2\theta_W=1-s,\qquad
\delta\equiv sc=s(1-s)
\]

로 쓴다.

## 2. 대수적 성질

**[정리]**

\[
0\leq\delta\leq\frac14.
\]

이는 \(s(1-s)=\tfrac14-(s-\tfrac12)^2\)이기 때문이다. 최대 혼합은
\(s=1/2\), 즉 \(\theta_W=\pi/4\)에서 일어난다.

[자족 증명](../참조/핵심_정리_증명.md#delta-bound)

**[공리]** 외부 장론으로 one-Higgs-doublet 표준모형과
\(\tan\theta_W=g'/g\), \(M_Z^2=(g^2+g'^2)v^2/4\)를 사용한다.

**[산출]** 표준 \((W^3,B)\) 게이지 기저의 중성 보손 질량행렬에서

\[
\frac{|\mathcal M^2_{W^3B}|}{M_Z^2}
=\frac{gg'}{g^2+g'^2}
=\sin\theta_W\cos\theta_W.
\]

이 등식은 지정한 기저에서의 행렬 대입 결과다.

## 3. CE 물리 사상

**[공리]** 위 혼합 진폭의 제곱을 유효 차원 증분으로 읽는다.

\[
\delta=\sin^2\theta_W\cos^2\theta_W.
\]

끝점에서 0이고 \(s\leftrightarrow1-s\) 대칭인 최소차수 다항식을 택한다는
모델 선택이다. 이 조건만으로 모든 가능한 함수 가운데 유일해지는 것은
아니다.

**[공리]** 공간 차원과 혼합 증분을 선형으로 결합한다.

\[
D_{\rm eff}=d+\delta.
\]

이 선형식을 내부적으로 정확히 실현하는 확률모형은 다음과 같다.

**[공리]** \(B\geq0\), \(B\boldsymbol1=\boldsymbol1\)인
row-stochastic matrix에 대해

\[
A=dI+\delta B
\]

를 다형 Poisson offspring 평균행렬로 둔다.

**[정리]**

\[
A\boldsymbol1=(d+\delta)\boldsymbol1
\]

이므로 균일 부분공간은 고정점 사상에 불변이고 그 스칼라 깊이는 정확히
\(D_{\rm eff}=d+\delta\)다.
[다형 축약 증명](../참조/핵심_정리_증명.md#multitype-poisson)

따라서 \(D_{\rm eff}\)는 이 toy family 안에서는 완결된 모형 산출이다.
CE+SM 양자진폭에서 \(A\)를 얻는 미시적 bridge는 별도다.

## 4. 외부 결합과 수치

**[경험식]** 기준 스케일을 고정하고 외부 입력 \(\alpha_s(M_Z)\)에 대해

\[
\sin^2\theta_W=4\alpha_s^{4/3}
\]

를 사용한다.

**[산출]** \(d=3\), \(\alpha_s(M_Z)=0.11789\)를 넣으면

\[
s\simeq0.2312,\qquad
\delta\simeq0.1778,\qquad
D_{\rm eff}\simeq3.1778.
\]

관측값은 경험식 평가를 위한 별도 비교 자료다. \(\delta\)를 완전양의
reduced dynamics의 jump rate와 연결해 위 \(A\)를 도출하는 단계는
**[미완성]**이다.
