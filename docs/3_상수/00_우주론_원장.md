# CE 우주론 판본·주장 원장

이 문서는 우주론 코드와 문서가 사용하는 수치를 하나의 숫자로 덮어쓰지 않고,
같은 원장 안에서 역할과 판본을 분리한다. 정밀 계산값, 과거 재현값, 런타임
호환값과 관측 자료는 서로 다른 대상이다.

## 1. 판본 규칙

**[정의]** 각 항목은 최소한 다음 필드를 가진다.

- `config_id`: 계산 또는 호환 판본의 고유 이름
- `role`: 정밀 코어, 과거 재현, 런타임 호환, 관측 외부 입력 중 하나
- `claim_id`: 수치가 의존하는 최소 주장
- `status`: 이 문서의 형식 지위
- `provenance`: 식, 외부 입력 또는 관측 manifest의 출처
- `precision`: 저장·표시 자릿수와 residual 규약

**[공리]** 기존 소비자가 사용하는 이름은 호환 별칭으로 유지한다. 별칭을
조용히 정밀값으로 바꾸지 않으며, 새 과학 계산은 `config_id`를 명시해야 한다.

## 2. 고정점 코어

**[공리] 외부 입력:** 이 저장소의 기준 산술에는
\(\alpha_s(M_Z)=0.11789\)를 사용한다. scale과 scheme이 붙은 측정 입력이므로
수학상수가 아니다.

**[공리] 모형 선택:**

\[
s_W^2=4\alpha_s^{4/3},\qquad
\delta=s_W^2(1-s_W^2),\qquad
D=3+\delta.
\]

**[정리]** \(D>1\)에서

\[
q=e^{-D(1-q)}
\]

의 작은 근은 \((0,1/D)\)에 유일하고 \(Dq<1\)이다.

**[정의]** `C-Q-01`의 \(q_{\rm ext}\)는 소멸확률이다.
`C-Q-02`의 생존확률은

\[
s_{\rm branch}=1-q_{\rm ext}
\]

이다. 두 이름을 서로 바꾸어 쓰지 않는다.

### 2.1 `CE_CORE_EXACT_V1`

**[산출]** 위 외부 입력과 모형 선택을 full-precision 사슬로 계산하면

| 양 | 값 |
|---|---:|
| \(s_W^2\) | \(0.231222068260755116590565382964\ldots\) |
| \(\delta\) | \(0.177758423409973817923268877860\ldots\) |
| \(D\) | \(3.177758423409973817923268877860\ldots\) |
| \(q_{\rm ext}\) | \(0.048646719644028206426163828128\ldots\) |
| \(s_{\rm branch}\) | \(0.951353280355971793573836171872\ldots\) |
| \(m=Dq_{\rm ext}\) | \(0.154587523120074076002229959713\ldots\) |

이 표의 정밀도는 계산 재현을 위한 것이며 입력의 물리 불확도를 0으로 만들지
않는다.

### 2.2 `LEGACY_DELTA_5DP_V1`

**[공리] 호환 판본:** \(\delta=0.17776\), \(D=3.17776\)을 먼저 반올림한
과거 계산은

\[
q_{\rm ext}=0.0486466333372140763\ldots
\]

를 준다. `CE_CORE_EXACT_V1`과의 차이는 약 \(8.63\times10^{-8}\)이다.
과거 결과 재현에는 이 판본을 유지하지만 정밀 코어의 출력으로 표기하지 않는다.

### 2.3 `LEGACY_ROUNDED_RUNTIME_V1`

**[공리] 런타임 호환 판본:** 기존 엔진의 세 비율

\[
(0.0487,\ 0.2623,\ 0.6891)
\]

은 표시·샘플 할당용 경계값이다. 원시 합은 \(1.0001\)이다. 평탄 후기 배경에
사용한 정규화값은 별도의 양이며

\[
(\widehat\Omega_m,\widehat\Omega_\Lambda)
=(0.310968903109689\ldots,0.689031096890311\ldots)
\]

이다. 원시값과 정규화값을 같은 key로 직렬화하지 않는다.

## 3. 확률에서 밀도로 가는 주장

### 3.1 과거 직접 사상

**[공리] `C-B-LEGACY-01`:** `LEGACY_DIRECT_READOUT_V1`은

\[
q_{\rm ext}\mapsto\Omega_b
\]

를 채택한 과거 경계모형이다. 고정점 정리가 current, stress tensor, total
yield 또는 critical-density 정규화를 제공하지 않으므로 이 사상은 정리나
사전 관측량이 아니다. 값과 재현 코드는 보존하되 새 유도의 결론으로 사용하지
않는다.

### 3.2 소멸 조건부 조성

**[정리] `C-B-COND-01`:** offspring 생성함수가
\(f(z)=\exp[D(z-1)]\)이고 전체 소멸 사건을 \(E\)라 하면

\[
K\mid E\sim\operatorname{Poisson}(Dq_{\rm ext}).
\]

**[산출] `C-B-COMP-01`:** 모든 node가 같은 보존 에너지를 갖고 aggregate
descendant detector를 먼저 고정한 경우, 많은 소멸 tree를 합친 descendant
energy fraction은

\[
f_b^{(m)}=Dq_{\rm ext}
\]

로 수렴한다. species label, current와 detector 선택은 추가 공리다.

### 3.3 전이 면의 합성식

**[산출] `C-B-TRANSIENT-ALG-01`:** 같은 공변 전이 면 \(\Sigma_*\)에서

\[
f_b^{(m)}=Dq_{\rm ext},\qquad
\Omega_m=\frac1D
\]

가 서로 독립적으로 성립하면

\[
\Omega_b\big|_{\Sigma_*}=q_{\rm ext}
\]

다. 이는 곱셈 항등식이며 두 물리 전제를 대신하지 않는다.

**[산출] `C-B-TRANSIENT-SUBSYS-01`:** matter--vacuum subsystem의
단조 crossing을 사용하고 radiation을 full 분모에 남기면

\[
\Omega_m\big|_{\Sigma_*}=\frac{1-\Omega_r}{D},\qquad
\Omega_b\big|_{\Sigma_*}=q_{\rm ext}(1-\Omega_r).
\]

이 경로는 crossing이 유일하지만 radiation 보정이 남는다. full-density
trigger는 \(\Omega_b=q_{\rm ext}\)를 정확히 만들 수 있으나 표준
radiation--matter--vacuum 역사에서 일반적으로 두 crossing을 가지므로 별도
clock 또는 memory가 필요하다.

**[미완성] `C-B-TRANSIENT-PHYS-01`:** microscopic action이 다음을 동시에
보여야 한다.

1. conditioned node를 conserved species current로 바꾸는 과정
2. finite-rate 전이에서 유일한 \(\Sigma_*\)와 freeze 값
3. heat, radiation, wall과 dark stress를 포함한 total 보존
4. 전이 뒤 baryon current 보존과 안정한 perturbation
5. 관측 밀도를 넣지 않은 absolute yield와 전이 시각

이 목표는 유지되지만 위 항목이 닫히기 전에는 오늘의 밀도 예측으로 표기하지
않는다.

## 4. 배경과 지평선의 서로 다른 척도

**[정의] `C-HOR-01`:** 다음 세 양은 서로 다른 시각과 정의를 가진다.

\[
H_L^2:=\frac{\rho_{\rm vac}}{3M_{\rm Pl}^2},\qquad
H_*:=H(\Sigma_*),\qquad
H_0:=H(t_0).
\]

**[정리] `C-HOR-DS-01`:** 진짜 asymptotic de Sitter entropy가 읽는 것은
\(H_L=H_\Lambda\)다. 평탄한 mixed background에서는

\[
H_\Lambda^2=\Omega_\Lambda H_0^2.
\]

따라서 \(H_\Lambda\)와 \(H_0\)의 동일시는 일반적 항등식이 아니다.

**[공리] `C-HOR-AH-01`:** 현재 apparent horizon에 phase-area law를
대응시켜 \(H_0\)를 읽는 경로는 별도의 epoch·지평선 선택이다. 같은
entropy--Friedmann 항등식에서 \(H\)와 vacuum density를 두 독립 산출로 세지
않는다.

## 5. 관측 자료

**[공리] `C-OBS-01`:** 관측 중심값, 오차, 공분산과 posterior는 CE 상수가
아닌 외부 입력이다. 기계 원장은
`benchmarks/cosmology/observations_v1.json`에 release, model, likelihood,
units, source, covariance와 blind role을 함께 기록한다.

서로 다른 posterior의 성분을 합친 tuple, 단일 출처가 없는 값과 이미 본 자료는
활성 관측 근거나 독립 holdout으로 사용하지 않는다. 현재 독립 confirmatory
holdout은 배정되지 않았다.

## 6. 구현 불변식

1. 새 과학 API는 `config_id`를 명시한다.
2. 기존 상수 이름은 `LEGACY_ROUNDED_RUNTIME_V1`의 호환 별칭이다.
3. 정밀 고정점 solver와 반올림 입력 solver를 서로 다른 model ID로 기록한다.
4. 모든 scientific output은 role, model, claim과 provenance를 가진다.
5. 관측 record는 source와 covariance 역할이 없으면 채점 대상이 아니다.
6. 물리 브리지가 미완성인 상태를 수치 잔차 0으로 승격하지 않는다.

수치 검산과 형식 지위는 별개다. 이 원장은 과거 결과를 보존하면서도 어떤
판본과 전제가 쓰였는지를 숨기지 않는 통합 경계다.
