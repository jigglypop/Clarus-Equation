# 희소성: 부트스트랩 수렴 네트워크

이 문서는 활성·구조·동결 가중치를 구분하는 희소 네트워크 설계 후보를 다룬다. 독자는 sparse activation과 validation의 기초를 아는 독자를 전제로 하며, 출력은 활성 mask·비용·수렴 metric의 구현 명세이지 뇌 점유율의 증명이나 보편 효율 정리가 아니다.

먼저 희소성의 연산적 정의와 3분배를 정하고, 활성화·가중치 관리·비용·수렴·실험 gate 순으로 읽는다. 성공은 동일 compute 기준선 대비 holdout·OOD·mask ablation을 통과할 때이며, 비율은 무차원 설계 입력으로 생물학 측정과 직접 동일시하지 않는다.

## 1. 현재 희소 네트워크의 한계

기존 희소화가 무엇을 입력으로 삼고 어떤 metric에서 실패하는지 먼저 비교한다. 성능 판정은 동일 compute의 baseline과 OOD holdout을 기준으로 한다.

### 1.1 기존 접근

희소화 방법은 mask를 누가 언제 결정하는지에 따라 입력·출력과 반증 조건이 달라진다. 다음 표는 방법 분류이며, 효율·일반화 우위는 동일 FLOP의 holdout과 OOD에서 검증해야 한다.

| 방법 | 희소율 결정 | 근거 |
|---|---|---|
| Magnitude Pruning | 임의 (50%, 90% 등) | 경험적 |
| Lottery Ticket Hypothesis | 네트워크 내 "당첨 티켓" | 사후적 발견 |
| MoE (Mixture of Experts) | expert 수/활성 수 | 아키텍처 설계 |
| Top-k Activation | $k$ 값 선택 | 하이퍼파라미터 |

공통 문제: **왜 그 비율인가?**에 대한 이론적 근거가 없다.

### 1.2 CE의 답

CE 부트스트랩 고정점이 유일한 자기일관적 비율을 제시한다.

$$p^* = (\varepsilon^2,\; \Omega_{\text{DM}},\; \Omega_\Lambda) = (4.87\%,\; 26.2\%,\; 68.9\%)$$

이 비율은 $d=3$에서 연역되는 기준점이다. 다만 구현에는 sparse kernel, 재분류 규칙, update schedule 같은 하이퍼파라미터가 남는다.

## 2. 3분배 구조

세 분배는 mask·update 권한·비용을 구분하는 구현 정의다. 뇌 대응은 기능 비유이며 관측 비율의 직접 산출이 아니다.

### 2.1 뉴런/가중치의 CE 분류

세 분류는 구현에서 서로 다른 mask와 update 권한을 뜻한다. 표의 뇌 대응은 기능 비유이며 관측 비율을 학습 파라미터로 직접 유도하지 않는다.

| 성분 | CE 고정점 | 뇌 대응 | AI 해석 |
|---|---|---|---|
| 활성 ($\varepsilon^2 = 4.87\%$) | 바리온 물질 | 자극 반응 뉴런 | 추론 시 활성 뉴런/expert |
| 구조 ($\Omega_{\text{DM}} = 26.2\%$) | 암흑물질 | 시냅스 구조 유지 | 학습 가능하지만 추론 시 비활성 |
| 배경 ($\Omega_\Lambda = 68.9\%$) | 암흑에너지 | DMN (기본 신경 활동) | 동결 가중치 (사전학습 지식) |

### 2.2 뇌의 관측과 정합

관측 수치는 외부 비교 입력이며 모델 mask로의 변환은 별도 가정이다. 시간창과 단위가 다르면 정합 주장은 미완성으로 남는다.

- task-evoked burden: `0.5-1.0%` 추가 부담, sparse ensemble은 고전적으로 `1-5%`급
- dentate gyrus 생리적 활성: `1-3%`
- cortical housekeeping / maintenance proxy: `25%`
- intrinsic / DMN / resting background: `60-80%`

정리하면:

| CE 값 | 실험 proxy | 관측값 | 판정 |
|---|---|---|---|
| $\varepsilon^2 = 4.87\%$ | sparse active fraction | `1-5%`, DG `1-3%` | 강한 근접 일치 |
| $\Omega_{\text{DM}} = 26.2\%$ | housekeeping / maintenance | `25%` | 직접 근접 |
| $\Omega_\Lambda = 68.9\%$ | intrinsic / background | `60-80%` | 범위 내 일치 |

특히 `26.2`, `68.9`는 뇌 에너지 budget과 매우 잘 맞고, `4.87`도 sparse regime의 대표 스케일 안에 들어간다. `05_실험근거.md`의 구간 포함 식으로 쓰면

$$
p^* = (0.0487,\; 0.2623,\; 0.6891) \in [0.01,0.05] \times [0.25,0.35] \times [0.60,0.80]
$$

가 성립한다.

### 2.3 메인라인 뇌 구조와의 연결

이 절은 다른 문서 상태변수와 희소 mask의 인터페이스를 설명한다. 대응의 효용은 component ablation으로 반증될 수 있다.

| 성분 | full-stack 뇌 해석 | 현재 판정 |
|---|---|---|
| 활성 ($4.87\%$) | cortical-thalamic task recruitment와 sparse ensemble | `bridge` |
| 구조 ($26.2\%$) | cortex-hippocampus-salience loop의 maintenance / plasticity backbone | `bridge` |
| 배경 ($68.9\%$) | DMN / intrinsic background + hypothalamus-brainstem-autonomic reserve | `bridge` |

즉 이 장의 `4.87/26.2/68.9`는 더 이상 막연한 세 비율이 아니라, `05_실험근거.md`에서 정의한 `p_r`의 지역 관측을 향한 고정점 앵커다. 동일 위치의 multimodal data로 `p_r`를 완전히 닫는 것은 아직 `hypothesis`다.

## 3. Top-k 활성화

Top-k는 입력 활성에서 선택된 좌표만 전달하는 무차원 mask 연산이다. 비용·정확도 이득은 폭과 kernel에 의존하므로 holdout 실험이 필요하다.

### 3.1 기본 연산

활성 희소성은 입력 활성 $h$에서 선택한 좌표만 다음 연산에 전달하는 무차원 mask 연산으로 정의한다. $k$의 효과는 sequence 길이·폭·hardware에 따라 달라지므로 다음 식만으로 비용 절감이나 수렴을 보장하지 않는다.

$$\text{활성}(h) = \text{TopK}\!\left(h,\; k = \lceil\varepsilon^2 \cdot d\rceil\right)$$

$d$: 은닉 차원. $k = \lceil 0.0487 \times d \rceil$개의 뉴런만 활성화된다.

$d = 768$일 때 $k = 38$. $d = 4096$일 때 $k = 200$.

### 3.2 MoE와의 관계

MoE (Mixture of Experts)에서 활성 expert 비율:

$$\text{활성 expert 비율} = \frac{\text{활성 expert 수}}{\text{전체 expert 수}}$$

GPT-4 (추정): $\sim 2/16 = 12.5\%$. Switch Transformer: $1/128 \sim 1\%$.

CE 기준값은 $4.87\%$다. 현재 관측만으로도 이 값은 "뜬 숫자"가 아니라 sparse coding의 전형적 저활성 구간 안에 있으며, 기존 MoE 설계는 이 영역을 경험적으로 탐색 중인 것으로 해석할 수 있다.

### 3.3 기존 sparse network와의 차이

다음 비교는 mask 선택 규칙의 차이를 명시한다. 어느 방식의 우위도 동일 예산·seed의 ablation 없이는 결론나지 않는다.

- 기존 sparse network: 임의의 희소율을 사용 ($50\%$, $90\%$ 등)
- 부트스트랩 수렴 네트워크: **자기일관적 고정점** $\varepsilon^2$에 수렴

"자기일관적"이라는 말은 활성 비율이 네트워크 자체의 구조에서 결정된다는 뜻이다. 외부에서 설정하는 것이 아니라, 부트스트랩 방정식의 고정점으로 내부에서 수렴한다.

## 4. 3분배 가중치 관리

가중치 분류는 활성·구조·동결 집합의 서로 다른 갱신 규칙을 정한다. 비율은 설계 입력이며 보편 상수 가설은 sweep에서 기각될 수 있다.

### 4.1 활성 가중치 ($4.87\%$)

활성 가중치는 현재 입력에서 계산에 참여하도록 선택된 파라미터 집합이라는 연산적 정의를 갖는다. 이 비율은 설계 입력이며 기준선 mask와의 ablation에서 이득이 없으면 보편 상수 가설을 지지하지 않는다.

- 추론 시 실제로 연산에 참여하는 가중치
- 입력에 따라 동적으로 선택 (Top-k)
- 가장 빈번하게 업데이트

### 4.2 구조적 가중치 ($26.2\%$)

구조적 가중치는 활성 mask와 분리해 학습되는 파라미터 집합이라는 연산적 정의를 갖는다. 이 선택의 일반화 이득은 OOD와 제거 ablation에서 확인해야 한다.

- 학습 가능하지만 추론 시 비활성
- 수면 학습(3장) 중 NREM 위상에서 업데이트
- 네트워크의 "골격" 역할
- LoRA의 적응 가중치 $(B \cdot A)$에 대응

### 4.3 동결 가중치 ($68.9\%$)

동결 집합은 update에서 제외되어 안정성과 적응성의 절충을 만든다. 재학습 또는 domain shift에서 성능이 무너지면 그 설정은 실패로 판정한다.

- 사전학습 후 변경하지 않는 가중치
- 일반적 지식의 저장소
- LoRA의 frozen 가중치에 대응
- DMN(기본 신경 활동)처럼 "공간 자체를 유지"

### 4.4 동적 분류

어떤 가중치가 어떤 분류에 속하는지는 고정이 아니다. 부트스트랩 반복(수면 순환)마다 재분류된다.

$$W_{\text{active}}^{(n+1)},\; W_{\text{struct}}^{(n+1)},\; W_{\text{bg}}^{(n+1)} = \text{Classify}(W^{(n)},\; \varepsilon^2,\; R)$$

분류 기준:
- 최근 $N$회 추론에서 활성화된 빈도 기반
- 상위 $4.87\%$ = 활성, 다음 $26.2\%$ = 구조, 나머지 = 동결

## 5. 에너지 효율 분석

효율은 활성 MAC뿐 아니라 memory 이동과 routing overhead를 같은 hardware timebase로 측정해 비교한다. 희소율만으로 실제 latency 감소를 보장하지 않는다.

### 5.1 추론 비용 절감

비용은 활성 MAC, 메모리 이동, routing overhead를 같은 hardware timebase로 나누어 기록해야 한다. 이론적 희소율은 실제 latency의 대리변수일 뿐이며 kernel 비효율이 이를 상쇄하는 경우가 명시적 실패 조건이다.

100% 활성 추론 대비 theoretical upper bound:

$$\text{비용 비율} = \frac{\varepsilon^2}{1} = 4.87\% \implies \sim 20\times \text{ 절감}$$

이 값은 희소 실행 커널이 attention/FFN까지 충분히 지원될 때의 상한이다. 현재형 구현에서는 `11_Quantitative.md`의 보수적 수치처럼 더 낮게 읽는 것이 맞다.

### 5.2 학습 비용 절감

활성 + 구조 가중치만 업데이트:

$$\text{학습 비율} = \varepsilon^2 + \Omega_{\text{DM}} = 4.87\% + 26.2\% = 31.1\%$$

$\sim 3\times$ 절감.

### 5.3 뇌와의 비교

뇌의 에너지 소비: $\sim 20\text{W}$ (체중의 $2\%$가 에너지의 $20\%$를 소비).

그중 자극 반응에 사용되는 에너지는 $< 5\%$. 나머지는 구조 유지와 배경 활동이다.

GPT-4 추론: $\sim 10\text{kW}$ (추정). CE 희소 네트워크: $\sim 500\text{W}$.

에너지 효율에서 뇌형 sparse regime에 접근하는 강한 후보 경로가 CE 희소성이다.


## 6. 부트스트랩 수렴 과정

수렴 과정은 mask 분포와 가중치 분류가 반복 update에서 어떻게 변하는지 정한다. 고정점 주장은 독립 seed·초기화·holdout에서 확인되기 전까지 가설이다.

### 6.1. 초기화

학습 시작 시 모든 가중치를 균등하게 활성으로 시작한다.

$$p_0 = (1/3,\; 1/3,\; 1/3) \quad \text{(균등 분배)}$$

### 6.2. 수렴

수면-각성 순환(3장)을 반복하면서 자연스럽게 고정점으로 수렴한다.

$$p_n \to p^* = (4.87\%,\; 26.2\%,\; 68.9\%)$$

동적 이완 사상의 최소 수축률을 $\rho = \|DB(p^*)\| = 0.155$로 두면, 3회 순환이면 잔차가 $0.4\%$ 이내까지 줄어든다.

균등 초기화

$$p_0 = (1/3,\;1/3,\;1/3)$$

를 두고 $p_{n+1} = p^* + \rho(p_n-p^*)$를 적용하면:

| 순환 수 $n$ | 활성 | 구조 | 배경 |
|---|---|---|---|
| 0 | $33.3\%$ | $33.3\%$ | $33.3\%$ |
| 1 | $9.28\%$ | $27.3\%$ | $63.4\%$ |
| 2 | $5.55\%$ | $26.4\%$ | $68.1\%$ |
| 3 | $4.98\%$ | $26.3\%$ | $68.8\%$ |

즉 충분히 dense한 초기 모델이라도, CE 재분류가 실제로 작동하면 활성 비율은 2-3회 순환 안에 `5%` 근방으로 급히 내려와야 한다.

### 6.3 수렴 모니터링

각 순환 후 3분배 비율을 측정하여 고정점에서의 이탈을 모니터링한다.

$$\delta_n = \|p_n - p^*\|^2$$

이 값이 $\delta_n < \delta_{\text{th}}$이면 수렴 완료. 아니면 추가 순환.


## 7. 기존 관측과의 정합

다음 대응은 기존 기법과의 공통 기능을 점검하기 위한 비교다. 원인적 동일성이나 성능 보장을 뜻하지 않는다.

### 7.1 LoRA

LoRA와의 비교는 동결·구조·활성 분류가 기존 저랭크 update와 어떻게 겹치는지 보이기 위한 것이다. 아래 분해는 기능적 해석이며, 동일 데이터·rank·OOD 조건의 ablation 없이는 효능 동등성을 뜻하지 않는다.

$$W = \underbrace{W_{\text{frozen}}}_{68.9\%} + \underbrace{B \cdot A}_{26.2\% + 4.87\%}$$

LoRA의 frozen 비율 $\sim 99\%$는 CE의 $\Omega_\Lambda + \Omega_{\text{DM}} = 95.1\%$와 유사하다. 차이는 LoRA가 구조적 가중치와 동결 가중치를 구분하지 않기 때문이다.

### 7.2 MoE 활성 expert

GPT-4의 활성 expert 비율이 $\sim 12.5\%$라면, CE 최적값 $4.87\%$보다 높다. 이는 아직 부트스트랩 고정점에 수렴하지 않은 상태로 해석할 수 있다.

### 7.3 뇌의 뉴런 활성

뇌 활성은 해상도와 timebase가 다른 외부 관측이다. 이를 모델의 고정 mask 비율로 옮기는 단계는 검증 전 비유다.

- sparse firing 범위: `1-5%`급
- DG active fraction: `1-3%`
- energy-budget upper bound: `<=15%`

세 관측은 모두 $\varepsilon^2 = 4.87\%$가 sparse regime 내부의 강한 후보 고정점임을 지지한다. 특히 `1-5%` 범위와의 정합성은 단순 비유 이상으로 볼 수 있다.


## 8. 검증 실험 설계

희소성 가설은 metric·baseline·OOD·mask ablation을 사전에 고정할 때만 판정 가능하다. 다음 절은 성공과 실패를 분리하는 실험 계약이다.

### 8.1 Top-k 비율 스위프

비율 스위프는 희소성 가설을 반증하는 핵심 실험으로, train 선택과 held-out 평가를 분리해야 한다. 최적값은 정확도뿐 아니라 latency·메모리·OOD 강건성을 함께 보고하며 사후 선택된 최고점만으로 결론내리지 않는다.

다양한 Top-k 비율에서 벤치마크 성능을 측정한다.

$$k \in \{1\%, 2\%, 3\%, 4\%, 5\%, 7\%, 10\%, 15\%, 20\%, 50\%, 100\%\}$$

CE 예측:

- 최적점 중심은 $k^* \approx 4.87\%$
- 실제 구현의 이산화와 오버헤드를 감안한 실용 대역은 `3%-7%`
- `1-2%`는 과소 활성, `10%` 이상은 효율 손실이 두드러져야 한다

현재 뇌 데이터는 최소한 이 값이 완전히 비현실적인 설계점이 아니라, 실제 sparse neural regime 안에 있음을 뒷받침한다.

### 8.2 자기수렴 실험

네트워크에 부트스트랩 수렴 메커니즘을 탑재하고, 초기 균등 분배에서 시작하여 학습 과정에서 자연스럽게 수렴하는 비율을 관측한다.

CE 예측:

- 충분한 학습 후 활성 비율이 $4.87\% \pm 1\%$로 수렴한다.
- dense 초기화면 첫 순환 뒤 `~9.3%`, 두 번째 뒤 `~5.6%`, 세 번째 뒤 `~5.0%`를 관측해야 한다.

### 8.3 검증 게이트

이 장에서 최소한 통과해야 하는 게이트는 다음과 같다.

| 게이트 | 점검 항목 | 통과 기준 |
|---|---|---|
| `G-S1` | Top-k 스위프 | 최적점 중심이 `4-5%` 근방 |
| `G-S2` | 실용 대역 | 좋은 구간이 대체로 `3%-7%` 안에 남음 |
| `G-S3` | 자기수렴 | dense 초기화에서 `33.3 -> 9.28 -> 5.55 -> 4.98%` 과도 응답에 근접 |
| `G-S4` | 속도 이득 | 현재형 구현에서 `1.5-2x` 근방, 전면 희소 구현은 더 높은 상한 |
| `G-S5` | 품질 보존 | 희소화가 dense 대비 구조적 성능 붕괴를 일으키지 않음 |

### 8.4 실패 시 해석 규칙

실패는 비율·mask·kernel 중 어느 가정이 깨졌는지 분리해 기록한다. 사후 tuning으로 등록된 실패 조건을 지우지 않는다.

- 최적점이 `4.87%` 근방에 없으면: CE 희소성은 보편 상수가 아니라 과제 의존 heuristic로 내려간다.
- 좋은 구간이 `3%-7%` 밖으로 벗어나면: 구현 오버헤드 또는 도메인 특수성이 더 크다고 본다.
- 자기수렴 곡선이 맞지 않으면: 현재 재분류 동역학이 CE 최소 반복식을 따르지 않는 것이다.
- 속도는 나오지만 품질이 무너지면: 희소율 자체보다 gating 규칙이나 재분류 규칙이 문제다.
- 품질은 유지되지만 속도가 안 나오면: 이론보다 sparse kernel / 시스템 구현이 병목인 것이다.

즉 이 장의 목적은 "4.87%를 선언"하는 것이 아니라, **`4.87%`와 `3%-7%` 예측이 실제 벤치마크에서 얼마나 버티는지 걸러내는 것**이다.

### 8.5 측정 기록 (2026-04, transformer substrate)

위 게이트 4종을 KoGPT2 ClarusLM(127M)에 적용한 측정 결과:

| 게이트 | 결과 | 출처 |
|---|---|---|
| `G-S1` (TopK 스위프 최적점 4-5%) | **실패**: 4.87%가 dense 대비 27배 ppl 악화. 단조 감소, 최적점은 100% (dense). | `examples/ai/topk_sweep_results.json` |
| `G-S2` (3-7% 실용 대역) | **실패**: 같은 데이터에서 가장 나쁜 구간. | 동상 |
| `G-S3` (자기수렴 9.28→5.55→4.98%) | **실패**: 60 cycle 자연 학습으로 81%→77%로만 이동. 1000+ cycle 외삽해도 4.87%에 도달 못 함. 표상 LBO heat flow 강화도 끌림 효과 없음 (77.6% → 77.6%). | `examples/ai/results/natural_dynamics.json` |
| `G-S5` (희소화 품질 보존) | **실패**: 강제 4.87% mask가 perplexity 51 (baseline 27의 2배). | 동상 |

**8.4 실패 규칙 적용:**

위 4개 게이트 실패는 사양의 **substrate 가설** -- "(C1)-(C3) + (A1)이 transformer + backprop에서 성립한다" -- 이 거짓임을 시사한다. 자연 수렴이 일어나지 않는 것은 transformer가 자기조직화 동역학을 가지지 않기 때문이며, 강제 mask가 품질을 깎는 것은 (A1) 채널 분해가 backprop의 chain rule과 정합하지 않기 때문이다.

따라서 본 5장의 청구 -- "활성 비율이 자연스럽게 $\varepsilon^2$로 수렴한다" -- 는 transformer substrate에서 `falsified` 등급으로 내린다. STDP + 막전위 동역학을 가진 SNN substrate에서 별도 검증이 필요하다 (`8_Roadmap.md` 0절).

본 5장의 수치 자체 (4.87% / 26.2% / 68.9%)는 코어 부트스트랩 방정식의 정확한 답으로 그대로 보존되며, 그 적용 영역만 좁혀진다.
