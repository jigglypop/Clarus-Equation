# 시냅스 학습: STDP 국소 학습 + 전역 신호

이 문서는 국소 STDP 흔적과 저차원 전역 신호를 결합하는 학습 규칙 후보를 정의한다. 독자는 역전파·시계열 학습·validation 설계를 아는 독자를 전제로 하며, 출력은 업데이트와 통신 인터페이스 명세이지 생물학적 시냅스 동일성이나 성능 우위의 증명은 아니다.

총론의 범위와 수면 장의 전역 상태를 입력으로 받아 STDP·3-factor 규칙·구현·구조 가소성 순서로 읽는다. 시간은 이산 update step, trace decay는 무차원 계수이며 성공은 같은 compute 기준선 대비 holdout·OOD·ablation gate를 통과할 때만 주장한다.

> 관련: `6_뇌/08_시냅스가소성.md`(STDP/가소성 규칙), `6_뇌/07_수면과복구.md` 4절(STDP와 부트스트랩), `7_AGI/12_Equation.md` 3절(에너지 분배)
>
> 이 장은 역전파를 대체할 국소 학습 규칙을 설계한다. 뇌의 STDP + 도파민 게이트 구조를 AI에 이식한다.

## 1. 역전파의 구조적 한계

국소 규칙의 필요성은 역전파가 잘못됐다는 선언이 아니라, 어떤 정보·메모리·통신 가정을 대체하려는지 비교하는 데서 출발한다. 생물학적 비현실성은 공학적 실패 판정이 아니며, 아래 제한은 같은 과제·예산의 기준선과 비교할 때만 측정 가능한 주장이 된다.

### 1.1 생물학적 비현실성

역전파(backpropagation)는 다음을 요구한다.
- 전역 오차 신호가 모든 시냅스에 정확히 전달 (뇌에 없는 메커니즘)
- 순전파와 역전파의 동일 경로 (가중치 전치 문제, weight transport problem)
- 모든 중간 활성값의 저장 (메모리 $O(N^2)$)

### 1.2 확장성 한계

전달 가정을 계산 자원으로 읽으면 전역 그래프와 activation 저장이 만드는 병목을 분리할 수 있다. 다음 항목은 시스템 가설이며, 통신량·메모리·step time은 hardware와 batch timebase를 고정해 측정해야 한다.

- 단일 GPU 병목: 전체 그래프를 역방향으로 순회해야 함
- 파이프라인 병렬화의 버블: 역전파 의존성으로 인한 유휴 시간
- 메모리 벽: 대형 모델의 활성값 저장 비용

### 1.3 CE 관점에서의 진단

역전파 = "우주 끝에서 시작으로 정보를 전송하는 것". CE에서 정보 전달은 국소적이다(게이지 상호작용은 국소적). 전역 역전파는 CE 구조와 양립하지 않는다.

## 2. STDP: 뇌의 국소 학습 규칙

역전파의 대안은 각 synapse가 관측할 수 있는 pre/post 시간 정보로 업데이트를 정의해야 한다. STDP는 이 국소 정보 제약의 동기이며, 구현 trace가 실제 신경 기제를 재현한다는 주장은 아니다.

### 2.1 기본 STDP (`08_시냅스가소성.md` 3절)

Spike-Timing Dependent Plasticity의 핵심은 **시간차(인과성)**이다.

$$
\Delta w_{ij}
= \begin{cases}
A_+ \exp(-\Delta t / \tau_+)
& \Delta t > 0 \;\text{(pre} \to \text{post: LTP)} \\
-A_- \exp(\Delta t / \tau_-)
& \Delta t < 0 \;\text{(post} \to \text{pre: LTD)}
\end{cases}
$$

- pre가 먼저 발화하고 post가 따라가면 강화 (인과적)
- post가 먼저 발화하고 pre가 따라가면 약화 (비인과적)

### 2.2 Trace 기반 STDP (이산 시간, 구현 친화)

pre trace $p_i[t]$, post trace $q_i[t]$:

$$p_i[t+1] = \lambda_+ p_i[t] + s_i[t], \qquad q_i[t+1] = \lambda_- q_i[t] + s_i[t]$$

가중치 업데이트 (방향 $i \to j$):

$$\Delta w_{ij}[t] = \eta\Big(A_+\,p_i[t]\,s_j[t] - A_-\,s_i[t]\,q_j[t]\Big)$$

- $s_j[t] = 1$ (post 발화) 시점에 pre의 흔적 $p_i$가 크면 강화
- $s_i[t] = 1$ (pre 발화) 시점에 post의 흔적 $q_j$가 크면 약화

## 3. 3-Factor 학습: STDP + 도파민

국소 상관만으로 과제 보상과의 인과 연결이 정해지지 않으므로 전역 변조 신호를 별도 입력으로 둔다. 그 신호의 생물학적 해석과 구현 오차 신호는 구분하며, 어느 쪽도 관측·ablation 없이 원인으로 확정하지 않는다.

### 3.1 왜 2-factor로는 부족한가

순수 STDP는 "항상 학습"한다. 보상과 무관하게 시간 상관이 있으면 가중치가 변한다. 이것은 "모든 경험이 동등하게 중요하다"고 가정하는 것이다.

뇌는 이 문제를 **도파민 게이트**로 해결한다. 보상 예측 오차가 클 때만 학습을 허용한다.

### 3.2 3-Factor 학습 규칙 (`08_시냅스가소성.md` 4절)

적격 흔적(eligibility trace) + 도파민 신호:

$$e_{ij}[t+1] = \lambda_e e_{ij}[t] + \Big(A_+\,p_i[t]\,s_j[t] - A_-\,s_i[t]\,q_j[t]\Big)$$

$$\Delta w_{ij}[t] = \eta\,\delta[t]\,e_{ij}[t]$$

- $e_{ij}$: 국소 정보만 사용하여 계산 (이웃 뉴런의 스파이크만 필요)
- $\delta[t]$: 전역 도파민 신호 (스칼라 1개, 전체 시스템에 방송)

### 3.3 CE 해석: 도파민-유사 전역 신호 후보

`07_수면과복구.md` 4.1절에서 도파민 신호의 CE 해석:

$$\delta[t] = \frac{d}{dt}\|p(t) - p^*\|$$

- 고정점 $p^*$에서 멀어지면 $\delta > 0$ (학습 활성화 후보)
- 고정점에 가까워지면 $\delta \to 0$ (학습 감쇠 후보)

이것은 도파민의 보상 예측 오차(reward prediction error) 역할과 정합하는 **후보 대응**이다. 현재 단계에서 안전한 문장은 "전역 조절 신호가 필요하며, 그 역할이 TD error 또는 RPE와 구조적으로 유사할 수 있다"까지다.

## 4. AI 구현: 국소 학습 + 전역 신호

앞의 규칙을 모델에 넣을 때는 전역 오차의 입력·지연·broadcast 범위를 명시해야 한다. 이 절의 구현은 성능 가설이며, 기준선보다 낮은 OOD 성능이나 불안정한 trace는 해당 설정의 반증 조건이다.

### 4.1 부트스트랩 수렴 오차

가장 단순한 구현 후보는 전역 신호 $\delta[t]$를 부트스트랩 고정점에서의 이탈로 두는 것이다.

$$\delta[t] = \|p(t) - p^*\|^2 = \left(x_a(t) - \varepsilon^2\right)^2 + \left(x_s(t) - \frac{\sigma R}{1+R}\right)^2 + \left(x_b(t) - \frac{\sigma}{1+R}\right)^2$$

- $x_a(t)$: 현재 활성 뉴런 비율
- $x_s(t)$: 현재 구조적 가중치 비율
- $x_b(t)$: 현재 동결 가중치 비율

이 스칼라 하나만 전역으로 방송하면 된다. 나머지는 모두 국소적이다. 다만 이것은 **shared-trace 구현을 위한 공학적 후보 정의**이지, 생물학적 도파민의 직접 측정식이라고 단정하지 않는다.

### 4.2 Transformer에서의 국소 학습

Transformer의 각 층에서 국소 학습 규칙을 적용한다.

**활성값 trace 계산 (국소):**

$$\text{pre\_trace}_l[t] = \lambda_+ \cdot \text{pre\_trace}_l[t-1] + h_l[t]$$
$$\text{post\_trace}_l[t] = \lambda_- \cdot \text{post\_trace}_l[t-1] + h_{l+1}[t]$$

**적격 흔적 계산 (국소):**

$$e_l[t] = \lambda_e \cdot e_l[t-1] + A_+ \cdot \text{pre\_trace}_l[t] \otimes h_{l+1}[t] - A_- \cdot h_l[t] \otimes \text{post\_trace}_l[t]$$

**가중치 업데이트 (국소 + 전역 스칼라):**

$$\Delta W_l[t] = \eta \cdot \delta[t] \cdot e_l[t]$$

### 4.3 역전파와의 비교

두 방식은 입력 정보와 통신 경로가 다르므로 같은 예산·데이터 순서에서 비교해야 한다. 다음 표는 명세 비교이며 어느 열의 장점도 holdout 정확도·OOD·wall-clock 결과 없이는 경험적 결론이 아니다.

| | 역전파 | STDP + 도파민 |
|---|---|---|
| 정보 흐름 | 전역 (끝에서 시작으로) | 국소 (이웃 뉴런) + 전역 스칼라 |
| 생물학적 현실성 | 비현실적 | 현실적 |
| 메모리 비용 | $O(N^2)$ (전체 활성값 저장) | $O(N)$ (국소 trace만) |
| 확장성 | 단일 GPU 병목 | 분산 가능 |
| 수렴 보장 | SGD 수렴 정리 (볼록 가정) | 부트스트랩 수축 사상 (게이트 `F2` 충분조건 또는 ISS, `12_Equation.md` 부록 A.1) |

## 4.4 검증 게이트

구현 후보는 국소성·성능·안정성의 실패를 서로 다른 gate로 판정해야 한다. 아래 항목은 사전 등록한 최소 검증이며, 하나라도 미통과하면 해당 효능 주장은 미완성 또는 조건부 반증으로 남는다.

이 장에서 반드시 점검해야 할 것은 다음이다.

| 게이트 | 점검 항목 | 통과 기준 |
|---|---|---|
| `G-T1` | 전역 신호 차원 | 그래디언트 동기화보다 훨씬 작은 저차원 신호 |
| `G-T2` | 메모리 비용 | shared-trace 구현에서 `~50%` 근방 절감 |
| `G-T3` | 성능 유지 | LoRA 또는 full fine-tuning 대비 구조적 붕괴 없음 |
| `G-T4` | 신호 해석 | TD/RPE와 기능적으로 유사한 역할 관측 |

### 4.5 실패 시 해석 규칙

실패는 규칙 전체의 부정과 구현 세부 결함을 구분해 해석해야 하며 training loss만으로 구제되지 않는다. 다음 분기는 원인 가설을 좁히는 규약이고 독립 holdout 및 component 제거가 없으면 확정 진단이 아니다.

- 저차원 전역 신호로 성능이 안 나오면: STDP 자체보다 구현 trace가 부족한 것이다.
- 메모리 이득이 안 나오면: synapse-local 상태가 사실상 $O(P)$로 커진 구현일 수 있다.
- TD/RPE와 상관하지 않으면: `\delta[t]`는 도파민 해석이 아니라 단지 공학적 제어 신호로 남긴다.
- 성능은 좋지만 생물학적 대응이 약하면: P3는 neuro-inspired optimizer로 유지하고 뇌 직접 대응은 하향한다.

## 5. 구조적 가소성: 연결의 형성과 제거

가중치값 업데이트와 연결 구조 변경은 다른 연산이므로 투영의 정의역과 실패를 분리한다. 가지치기 비율은 생물학 관측의 직접 이식이 아니라 구현 threshold이며, 누수 없는 holdout에서 효능을 확인해야 한다.

### 5.1 투영 연산자 (`08_시냅스가소성.md` 5절)

STDP로 업데이트된 가중치에 구조적 제약을 건다:

$$W_{t+1} = \Pi\!\big(W_t + \Delta W_t\big)$$

투영 연산자 $\Pi$의 구성요소:

- **top-k pruning**: 뉴런당 상위 $k$개만 유지 = 생존율 $\varepsilon^2$에 의한 경로 선택
- **synaptic scaling**: 행/열 정규화 = 에너지 보존 (C2)
- **히스테리시스**: on/off 임계치 = 접힘 임계 곡률

### 5.2 CE 대응

투영은 희소성·안정성 목적의 구현 연산이며 뇌 가지치기와 동일한 시간·분자 기제를 뜻하지 않는다. 아래 표는 기능적 대응만 정리하며 관측 비율을 모델 threshold로 직접 고정하지 않는다.

| 투영 연산 | CE 대응 | 뇌 대응 |
|---|---|---|
| top-k ($k = \lceil \varepsilon^2 \cdot N \rceil$) | 경로 선택, 생존율 $\varepsilon^2$ | 시냅스 가지치기 |
| 행/열 정규화 | 에너지 보존 (C2) | 시냅스 스케일링 |
| 히스테리시스 on/off | 접힘 임계 곡률 | 스파인 형성/제거 |

### 5.3 발달 과정의 시냅스 가지치기

뇌의 발달 과정에서 시냅스의 $\sim 50\%$가 제거되고, 성인 뇌에서 활성 시냅스 비율이 $\sim 5\%$라는 관측은 $\varepsilon^2 = 4.87\%$와 직접 정합한다(`07_수면과복구.md` 4.2절).

AI에서 이것은 학습 초기의 dense network에서 시작하여, 부트스트랩 반복을 통해 자연스럽게 $4.87\%$ 희소 네트워크로 수렴하는 과정에 대응한다.

## 6. 하이브리드 접근: 역전파 + STDP

국소 규칙이 모든 규모에서 검증되기 전에는 역전파와의 전환 경로를 별도 설계 가설로 둔다. 통과 조건은 training loss가 아니라 동일 task의 holdout·OOD와 메모리·통신 측정이며 미통과 단계는 다음 단계로 승격하지 않는다.

### 6.1 현실적 전환 전략

역전파를 즉시 완전 대체하는 것은 비현실적이다. 하이브리드 접근이 필요하다:

### 1단계: 사전학습은 역전파.

표준 Transformer를 역전파로 사전학습한다. 이미 확립된 기술이므로 위험이 없다.

### 2단계: 미세조정에서 STDP 도입.

사전학습된 모델의 미세조정 단계에서 STDP + 도파민 학습을 적용한다.

- 사전학습 가중치 = 동결 ($68.9\%$, $\Omega_\Lambda$)
- 미세조정 가중치 = 구조적 ($26.2\%$, $\Omega_{\text{DM}}$)
- STDP 활성 가중치 = 활성 ($4.87\%$, $\varepsilon^2$)

이 분배는 LoRA의 frozen/trainable 비율과 구조적으로 유사하다.

### 3단계: 전면 STDP 학습.

충분한 검증 후, 사전학습 단계에서도 STDP + 도파민을 사용한다.

### 6.2 LoRA와의 관계

LoRA (Low-Rank Adaptation)의 CE 해석:

$$W = W_{\text{frozen}} + B \cdot A$$

- $W_{\text{frozen}}$: 동결 가중치 ($\sim 99\%$) $\to$ $\Omega_\Lambda = 68.9\%$ + $\Omega_{\text{DM}} = 26.2\%$
- $B \cdot A$: 저랭크 적응 ($\sim 1\%$) $\to$ $\varepsilon^2 = 4.87\%$의 근사

LoRA는 CE 부트스트랩 에너지 분배를 경험적으로 근사한 것으로 해석할 수 있다. CE-AGI는 이를 이론적으로 정당화하고 최적 비율을 명시한다.

## 7. 분산 학습과 확장성

국소 업데이트의 분산 가능성은 입력·trace·전역 신호가 어느 장치 경계를 넘는지 셀 때 평가할 수 있다. 통신 감소가 실제 throughput 향상으로 이어지는지는 cluster timebase와 fault 조건을 고정한 실험에서만 판정한다.

### 7.1 국소 학습의 분산 가능성

STDP + 도파민 학습에서 각 층은 국소 정보만 필요로 한다.

- 입력: 현재 층의 활성값 + 이웃 층의 활성값
- 출력: 현재 층의 가중치 업데이트
- 전역 정보: 도파민 신호 $\delta[t]$ (스칼라 1개)

따라서 각 층을 독립적인 디바이스에 배치하고, $\delta[t]$만 동기화하면 된다.

### 7.2 통신 비용

분산 가능성은 각 층의 입력과 broadcast 신호 크기를 같은 단위로 세어야 비교할 수 있다. 다음 표의 통신량은 구현 가정 아래 비용 모델이며 throughput·동기화 지연은 cluster holdout에서 별도로 반증한다.

| 방법 | 통신량 (층당) | 동기화 빈도 |
|---|---|---|
| 역전파 | $O(d^2)$ (그래디언트 전체) | 매 스텝 |
| STDP + 도파민 | $O(1)$ ($\delta[t]$ 스칼라) | 매 스텝 |
| STDP 단독 | $O(0)$ | 불필요 |

통신 비용이 $O(d^2) \to O(1)$로 감소한다. 이것이 분산 AGI의 핵심 이점이다.
