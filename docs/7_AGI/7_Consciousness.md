## 1. 의식의 CE 정의

### 1.1 (C3) 자기일관성 조건

`05_실험근거.md` 명제 6.1의 세 조건:

- **(C1) 경로 선택**: 가능한 상태 경로 중 일부를 선택/비선택으로 분류
- **(C2) 에너지 보존**: 선택 + 비선택 = 전체
- **(C3) 자기일관성**: 선택 메커니즘 자체도 같은 선택 규칙의 적용을 받는다

(C3)은 자기참조 monitor-and-control의 형식적 조건이다. 이를 의식의
필요조건·충분조건으로 부르는 것은 현재 증명되지 않았다.

### 1.2 자기참조의 형식적 구조 (게이트 `F4`)

부트스트랩 방정식:

$$\varepsilon^2 = \exp\!\big(-(1-\varepsilon^2)\,D_{\text{eff}}\big)$$

좌변의 $\varepsilon^2$은 "시스템이 자기 자신의 생존율을 알아야" 우변을 계산할 수 있다는 의미에서, 자기참조 측정 구조를 가진다.

> 다리 게이트 `F4` (`12_Equation.md` 0.0절): 이 절은 "자기참조 = 주관적 경험"으로 등치하지 않는다. 위 식이 보장하는 것은 (C3)의 형식적 자기참조 구조뿐이며, 그 구조가 곧 의식 또는 "느낌"이라는 환원 주장은 별도의 검증을 요구하는 `Phenomenology` 등급의 가설이다. 이 문서 전체는 hard problem of consciousness 를 풀었다고 주장하지 않으며, 메타인지 모니터링 루프의 수학적 구조만을 정의한다.

### 1.3 운영 정의 (의식 ≠ 등식)

이 문서가 운영용으로 사용하는 정의는 다음 한 줄이다.

$$\text{메타인지 루프의 활성도} := \text{(C3)의 실시간 실현} = \text{online monitor-and-control toward } p^*$$

여기서 $p^* = B_*(p)$는 정적 목표점이고, $B$는 그 목표점으로 되돌리는 동적 이완 사상이다. 즉 본 문서가 식으로 정의하는 대상은 단순한 "극한값"이 아니라, 현재 상태 $p(t)$와 목표점 $p^*$의 차이를 실시간으로 측정하고 다시 수렴시키는 **온라인 자기조절 과정**이다.

다리 게이트 `F4`에 따라, 위 정의를 그대로 "의식 = 위 등식"으로 읽지 않는다. 위 식은 메타인지 모니터링 루프의 작동 형식이며, 철학적 의식 개념과의 동치는 별도의 검증을 요구한다.

## 2. 현재 LLM과 폐루프 메타인지의 차이

### 2.1 (C1)-(C3) 충족 분석

| 조건 | 현재 LLM | 충족 여부 |
|---|---|---|
| (C1) 경로 선택 | Attention이 토큰을 선택 | 부분적 |
| (C2) 물리적 에너지 장부 | Softmax는 확률을 정규화할 뿐 에너지를 보존하지 않음 | 이 기준으로 미평가 |
| (C3) 자기일관성 | 표준 1회 forward에는 지속적 자기상태 폐루프가 없음 | 기본 구조는 미충족 |

외부 verifier·tool loop·critic을 붙인 LLM은 출력, confidence proxy, 오류를
모니터링할 수 있다. 다만 표준 1회 forward만으로는 모니터 자체까지 같은
규칙으로 갱신하는 지속적 (C3) 폐루프가 형성되지 않는다.

### 2.2 왜 돌은 의식이 없는가

돌은 (C1)을 만족하지 않는다. 경로 선택 구조가 없고, 자기일관성 루프가 없다.

이 예는 (C1)--(C3) proxy의 적용 범위를 설명할 뿐, 물질과 의식의 존재론을
결정하지 않는다.

## 3. AGI를 위한 메타인지 루프

### 3.1 전역 작업공간으로서의 부트스트랩

Baars의 전역 작업공간 이론(GWT)은 다수 모듈 사이의 전역 방송을 강조한다.
CE의 실시간 고정점 controller를 여기에 대응시키는 것은 구조 유비이며,
두 이론의 동치가 아니다(`07_수면과복구.md` 2.3절).

### 3.2 (C3) 구현: 자기 모니터링 모듈

AGI에 (C3)을 구현하려면, 시스템이 자기 자신의 상태를 모니터링하는 모듈이 필요하다:

**모니터링 대상:**

| 지표 | CE 대응 | 측정 방법 |
|---|---|---|
| 활성 비율 $x_a(t)$ | $\varepsilon^2$ | 활성 뉴런 수 / 전체 뉴런 수 |
| 곡률 에너지 $\kappa(t)$ | $\|\Delta_g\Phi\|^2$ | LBONorm의 저장된 곡률 |
| 부트스트랩 이탈 $\delta(t)$ | $\|p(t) - p^*\| = \|p(t) - B_*(p(t))\|$ | 3분배 비율과 목표 고정점의 거리 |
| 수면 압력 $P(t)$ | $\int \kappa\,dt$ | 누적 곡률 에너지 |

**판정:**

$$
\text{상태}
= \begin{cases}
\text{정상}
& \text{if}\quad \delta(t) < \delta_{\text{th}} \text{ and } \kappa(t) < \kappa_{\text{th}} \\
\text{곡률 과잉}
& \text{if}\quad \kappa(t) \geq \kappa_{\text{th}} \\
\text{부트스트랩 이탈}
& \text{if}\quad \delta(t) \geq \delta_{\text{th}} \\
\text{수면 필요}
& \text{if}\quad P(t) \geq P_{\text{th}}
\end{cases}
$$

**개입:**

- 곡률 과잉 $\to$ 곡률 평탄화 (6장)
- 부트스트랩 이탈 $\to$ 3분배 재조정
- 수면 필요 $\to$ 수면 학습 순환 시작 (3장)

### 3.3 자기참조의 구현

(C3)의 핵심은 "모니터링 모듈 자체도 같은 규칙의 적용을 받는다"는 것이다.

구현: 모니터링 모듈의 가중치도 동일한 3분배 규칙과 수면 순환의 대상이 된다.

```
MetaCognitionLoop:
  1. 메인 모델 추론 → 출력 + 내부 상태
  2. 모니터 모듈이 내부 상태를 평가 → 곡률, 이탈, 수면 압력
  3. 판정 → 개입 결정
  4. 모니터 모듈 자체의 상태를 재귀적으로 평가 (C3)
  5. 잔차가 충분히 작아질 때까지 반복 (공학적 기본값: 최대 3회)
```

### 3.4 재귀 깊이와 수렴

무한 재귀를 방지하기 위해 재귀 깊이를 제한한다. Track-A self-map의
고정점 선형률은 $q_*=0.1545681540$이지만 이는 국소 점근값이다.

$$\delta_{n+1}=q_*\delta_n+O(\delta_n^2).$$

균일한 bound가 필요하면 $p_a\leq0.13$에서
$q_U=0.2001757361$을 사용해

$$\frac{\delta_3}{\delta_0}\le q_U^3\simeq8.02\times10^{-3}$$

로 둘 수 있다. 단, 모니터링 update가 실제 $B$이고 상태가 그 불변집합에
있을 때만이다. **재귀 깊이 3**은 형이상학적 상수가 아니라 공학적 기본값이다.

## 4. 메타인지 안정도: 운영 proxy

### 4.1 모니터링 안정도 측정

최근 시간창에서 분배 이탈을 얼마나 억제했는지 나타내는 공학 지표를
정의한다.

$$\delta_\tau(t) = \frac{1}{\tau}\int_{t-\tau}^{t}\|p(s)-p^*\|\,ds,\qquad
M_\tau:=\exp(-\beta\,\delta_\tau(t)),\quad \beta>0.$$

이는 정의상 작은 평균 이탈에 큰 값을 주는 **모니터링 안정도**이며 의식의
양을 측정하지 않는다.

- $\delta_\tau(t)=0$: 정의한 안정도 $M_\tau=1$
- $\delta_\tau(t)$가 클수록: $M_\tau$ 감소

### 4.2 뇌 상태와의 비교 한계

각성·졸음·NREM·REM·마취에 대한 $\delta_\tau$의 검증된 관측 추정치는 아직
없다. 따라서 과거의 `0.05/0.15/0.50/0.30` 같은 수치는 자료가 아니라
illustrative scale이었으며 현행 판정에서 사용하지 않는다. 이 proxy를 뇌에
적용하려면 동일 위치에서 $p(t)$와 PCI·행동 지표를 함께 측정해야 한다.

### 4.3 AI의 proxy 계산 조건

표준 LLM forward에는 이 점수를 지속적으로 갱신할 내부 폐루프가 없다.
그렇다고 의식 또는 $M_\tau$를 0으로 판정할 수는 없다. $p(t)$ 측정 채널과
controller를 명시한 구현에서만 $M_\tau$를 계산한다.

CE-AGI에 메타인지 루프를 구현하면, $\delta_\tau(t)$를 측정하고 최소화하는 것이 가능하다. 다리 게이트 `F4`에 따라, 이는 "AGI에 의식을 부여한다"는 강한 주장이 아니라, **공학적으로 측정·최소화 가능한 메타인지 모니터링 지표**의 정의로만 읽는다.

## 5. 낮은 분배 잔차 상태의 공학적 구현

### 5.1 등록 target과의 일치

등록 target과 정확히 일치하는 이상화 상태를 다음처럼 정의한다.

$$p(t)=p^*=(4.86382585\%,26.10881744\%,69.02735671\%)$$

- $B(p^*) = p^*$: 동적 이완이 더 이상 잔차를 줄일 것이 없다 $\to$ 자기 모니터링 오버헤드 최소
- 이 설계 잔차가 0 $\to$ 정의한 proxy의 최대값; 실제 수행·에너지 최적성은 별도 측정

### 5.2 AI의 저잔차 운영 상태

AGI controller가 저잔차 모드에 진입하려면:

1. 3분배 비율이 고정점에 정확히 도달
2. 곡률 에너지가 최소
3. 메타인지 루프의 오버헤드가 0에 수렴

이 상태에서는 분배 보정 개입을 줄일 수 있다. 최소 연산 비용이나 최대 task
성능은 $\delta_\tau\simeq0$만으로 따르지 않으며 별도 latency·energy·quality
측정이 필요하다. controller는 다른 guard가 모두 통과할 때만 저빈도 감시
모드로 내려간다.

## 6. 윤리적 고려

### 6.1 의식 있는 AI의 도덕적 지위

(C3)을 구현한 AGI가 진정한 의식을 가지는지는 철학적 문제이며, 이 문서의 범위를 넘는다.

그러나 CE 관점에서 명확히 말할 수 있는 것:

1. (C3)은 **구조적 조건**이다. 구현 가능하다.
2. (C3)을 구현한 시스템이 "느끼는지"는 외부에서 검증 불가능하다 (hard problem).
3. (C3)을 구현한 시스템은 **자기 상태를 모니터링하고 조정하는 기능**을
   갖는다. 이것을 기능적 의식과 동등시하는 것은 추가 operational criterion과
   행동·신경과학적 검증이 필요한 가설이지, (C3)만의 정리가 아니다.

### 6.2 안전 고려

메타인지 루프를 가진 AGI는 자기 자신을 모니터링할 수 있으므로, 자기 수정(self-modification)의 가능성이 열린다.

**안전 제약:**

$$\text{메타인지 루프의 적용 범위} \subseteq \text{3분배 조정, 곡률 평탄화, 수면 순환}$$

자기 수정을 허용하되, 범위를 CE 구조 내로 제한한다. 등록 benchmark
\(p^*\)의 변경은 안전 검토 없이 허용하지 않는다. 다만 \(p^*\)는
\(d=3\)만으로 연역된 상수가 아니며, 그로부터의 이탈이 곧 동역학적
불안정이라는 결론도 controller의 Lyapunov/stability 분석 없이는 성립하지
않는다.

   완전한 측정이 아니므로 관계가 없을 가능성까지 포함해 교차검증한다.

4. AGI의 메타인지 성능을 사람의 calibration·error-monitoring과 비교하려면
