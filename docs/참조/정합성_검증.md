# CE 문서 정합 규칙

이 문서는 CE 문서군을 읽고 편집할 때 적용하는 형식 규칙을 정의한다.
내부 점수나 실행 상태 문자열은 수학적 참거짓 또는 경험적 확증을 뜻하지 않는다.

## 1. 형식 출처

| 표지 | 범위 |
|---|---|
| **[정의]** | 기호·대상·정의역 선언; 참거짓 명제가 아님 |
| **[정리]** | 명시한 전제와 정의역에서 증명이 완결된 명제 |
| **[공리]** | 단위·정규화·가지·물리 사상으로 채택한 조건 |
| **[산출]** | 정리와 공리를 대입해 얻는 직접 결과 |
| **[경험식]** | 관측 자료·보정·유효 계수를 사용하는 관계 |
| **[미완성]** | 정의·증명·작용·사상이 남아 있는 항목 |
| **[예측]** | 입력과 판별 기준을 사전에 고정한 관측량 |

## 2. 기호와 대상

- **[정의]** \(R\)은 계량에서 정의되는 Ricci scalar다.
- **[정의]** \(\mathcal H_\gamma=\delta^2S/\delta\gamma^2\)는
  경로공간 Hessian operator 또는 kernel이다.
- **[정의]** \(\Phi_H[\gamma,\eta]\)는 probe \(\eta\)를 고정한 Hessian의
  scalar projection이다.
- **[정의]** 독립 물리장 \(\phi\), Hessian projection \(\Phi_H\), 곡률
  \(R\)은 별도 대상이다.
- **[정의]** \(q_{\rm ext}\)는 지정 Poisson 분지모형의 최소 소멸 고정점이고
  \(s_{\rm branch}=1-q_{\rm ext}\)는 생존확률이다.

두 기호를 동일시하려면 정의역, 차원과 사상 규칙을 별도로 적는다.

## 3. 정합 조건

1. \(\exp\), \(\log\), 확률 고정점의 인자는 무차원이어야 한다.
2. 정리에는 전제, 정의역과 증명을 함께 둔다.
3. 수학적 변수를 물리량에 대응시키는 단계는 정리와 분리해 **[공리]** 또는
   **[미완성]**으로 기록한다.
4. 관측 중심값·오차·공분산은 수학적 출처 표와 분리하며 동일한 데이터셋과
   likelihood에서 가져온다.
5. 수치 실행은 식의 구현을 검산할 뿐 물리 사상을 증명하지 않는다.
6. 허용 정의역의 완전한 반례가 있는 보편 명제와 그 부모 식·표는 활성
   문서에서 제거한다.

## 4. 의존성 기록

**[산출]** 항목은 사용한 정의·정리·공리를 역추적할 수 있어야 한다.
**[경험식]**은 자료와 유효 계수의 출처를 기록한다. **[예측]**은 holdout
자료, 불확도와 판별 기준을 계산 전에 고정한다. 이 조건을 충족하지 못한
물리적 연결은 **[미완성]**으로 둔다.

## 5. 정리 승격 게이트

| 후보 주장 | 정리에 필요한 최소 자료 | 자료가 없을 때의 지위 |
|---|---|---|
| Hessian의 좌표 불변성 | 장공간 connection과 공변 Hessian | 좌표를 고정한 계산 또는 **[미완성]** |
| Hessian이 stress tensor라는 식별 | 공변 작용의 명시적 metric variation | **[미완성]** 물리 사상 |
| Gibbs 최소점 농축 | 무차원 cost, 유한 partition function, compactness 또는 exponential tightness, recovery mass | 정의한 유한 모형의 **[공리]** |
| \(\Gamma\)-극한의 최소자 수렴 | \(\Gamma\)-liminf, recovery sequence, equicoercivity | **[미완성]** |
| 경로 prior의 continuum limit | 공통 measurable space, tightness와 joint-limit scale | 격자별 **[공리]** |
| 2점 함수의 입자 pole | 양의 spectral measure, analytic continuation, isolated atom과 LSZ 조건 | 상관길이 **[산출]**만 허용 |
| 측정확률 | 상태공간, CPTP instrument와 outcome map | **[공리: 물리 사상]** |
| exotic stress의 실재화 | renormalized \(\langle T_{\mu\nu}\rangle\), backreaction, 경계조건과 안정성 | **[미완성]** |

정리의 전제를 좁혀 참인 명제를 얻을 수 있으면 그 좁은 정리를 보존한다.
반례가 보편 부모 명제의 허용 정의역 안에 있으면 부모 명제는 다른 표지로
내리지 않고 활성 문서에서 제거한다. 반례 자체가 주는 식별 불가 또는
no-go 정리는 정확한 정의역과 함께 남긴다.

## 6. 독립 검증 층

1. **수식 층:** 정의역, 단위, 분모, 가지, 극한 순서와 증명을 검사한다.
2. **모형 층:** 작용, prior, kernel, boundary condition과 물리 사상을
   공리로 분리한다.
3. **수치 층:** 같은 수식을 독립 구현해 회귀를 검사한다.
4. **관측 층:** holdout 자료, covariance와 판정량을 계산 전에 고정한다.

뒤 층의 계산 성공은 앞 층에서 누락된 정의나 증명을 대신하지 않는다.
수학적으로 참인 조건부 정리는 관측 불일치만으로 삭제하지 않고, 물리 사상과
분리해 보존한다.
