# 05. CE 경로공간 브리지

## 0. 범위

이 장은 등호 이전 수학을 경로공간에 적용할 수 있는 정확한 조건과, 그
수학을 CE 물리량으로 읽을 때 추가되는 공리를 분리한다.

| 연결 | 형식 출처 | 현재 지위 |
|---|---|---|
| Borel 경로공간의 Gibbs 재가중 | good-rate와 recovery mass | **[정리]** |
| 실제 CE 경로공간·prior·작용의 선택 | 물리 모형 자료 | **[공리: 물리 모형]** 또는 **[미완성]** |
| 비선택 subprobability의 kernel 적분 | measurable pushforward | **[정리]** |
| kernel 적분을 독립장 \(\phi\)로 읽기 | 국소성·공변성·작용 필요 | **[미완성]** |
| 유한 \(\beta\) 분포를 측정 readout으로 읽기 | instrument와 outcome map 필요 | **[미완성]** |

## 1. 무차원 형식 package

**[정의]** \(X\)를 metric pathspace, \(\mu_0\in\mathcal P(X)\)를 Borel
probability, \(\mathcal I:X\to\mathbb R\cup\{+\infty\}\)를 무차원
lower-semicontinuous functional이라 하자. 다음을 가정한다.

1. \(\mathcal I_{\min}:=\inf_X\mathcal I>-\infty\).
2. 모든 \(c<\infty\)에 대해 \(\{\mathcal I\leq c\}\)는 compact다.
3. \(M:=\{\mathcal I=\mathcal I_{\min}\}\ne\varnothing\).
4. 모든 \(\delta>0\)에 대해
   \[
   \mu_0\{\mathcal I<\mathcal I_{\min}+\delta\}>0.
   \]

\(\beta>0\)는 무차원 선택 scale이고

\[
\mu_\beta(d\gamma)
=
\frac{e^{-\beta\mathcal I(\gamma)}}{Z_\beta}\,\mu_0(d\gamma),
\qquad
Z_\beta=\int_Xe^{-\beta\mathcal I}\,d\mu_0
\]

로 둔다.

**[정리]** 모든 열린집합 \(U\supset M\)에 대해

\[
\mu_\beta(X\setminus U)\longrightarrow0
\qquad(\beta\to\infty).
\]

**증명.** \(X\setminus U=\varnothing\)이면 자명하다. 그렇지 않으면
good-rate 조건으로
\[
\Delta_U:=\inf_{X\setminus U}\mathcal I-\mathcal I_{\min}>0.
\]
그렇지 않으면 \(X\setminus U\) 안의 near-minimizer 수열이 compact
sublevel 안에서 \(M\)의 점으로 수렴하여 \(U\)가 열렸다는 사실과
모순된다. \(0<\delta<\Delta_U\)를 택하면 recovery mass와 분자·분모
추정으로
\[
\mu_\beta(X\setminus U)
\leq
\frac{\mu_0(X\setminus U)}
{\mu_0\{\mathcal I<\mathcal I_{\min}+\delta\}}
e^{-\beta(\Delta_U-\delta)}
\to0.
\quad\square
\]

이 정리는 위 네 조건을 만족하는 probability 모형의 결과다. Lower
semicontinuity와 full support만으로 4번이 자동으로 나오지는 않으며,
mesh와 \(\beta\)를 함께 보내는 극한에는 uniform recovery scale이 더
필요하다.

## 2. 작용의 무차원화

실제 Euclidean action 후보가 정의되어 있을 때에는

\[
\mathcal I_E[\gamma]
:=\frac{S_E[\gamma]}{\hbar}
\]

또는 명시한 기준 작용 \(S_*>0\)에 대해
\(\mathcal I_E=S_E/S_*\)로 둔다. Suppression 항도 처음부터 무차원인
\(\mathcal I_{\rm supp}\)로 정의하고

\[
\mathcal I_{\rm fold}
=
\mathcal I_E+\mathcal I_{\rm supp}
\]

를 사용한다. \(\exp(-\beta S_E)\)처럼 차원 있는 작용을 그대로 지수에
넣지 않는다.

**[정리]** \(\mathcal I_E\)가 good-rate이고
\(\mathcal I_{\rm supp}\geq0\)가 lower-semicontinuous이면
\(\mathcal I_{\rm fold}\)의 sublevel은 compact다.

**증명.**
\[
\{\mathcal I_{\rm fold}\leq c\}
\subseteq
\{\mathcal I_E\leq c\}
\]
이고 왼쪽 집합은 lower-semicontinuity로 닫혀 있으므로 compact 집합의
닫힌 부분집합이다. \(\square\)

실제 CE의 \(S_E\), \(\mathcal I_{\rm supp}\), 경계항과 gauge fixing은
아직 **[미완성]**이다.

## 3. 서로 섞을 수 없는 pathspace route

| route | 후보공간 | prior | 정확한 경계 |
|---|---|---|---|
| Sobolev | \(W^{1,p}_{x_i,x_f}\), \(p>1\) | Sobolev--Gaussian 또는 dense atomic | \(C^0\) compactness와 recovery를 별도 확인 |
| Brownian | \(C^0_{x_i,x_f}\) | Brownian/diffusion bridge | \(C^0\) full support이나 \(W^{1,p}\) 질량은 0 |
| finite mesh | \(M^{N-1}\) 또는 유한 후보집합 | 양의 mesh prior | continuum joint limit에 scale 조건 필요 |

각 route의 정리와 반례는
[05f_CE_action_topology_package.md](05f_CE_action_topology_package.md),
[05g_CE_prior_support_package.md](05g_CE_prior_support_package.md),
[05h_CE_finite_to_continuum.md](05h_CE_finite_to_continuum.md),
[05i_CE_physical_path_prior.md](05i_CE_physical_path_prior.md)에 있다.

어느 route가 CE의 물리 prior인지 정하는 것은 **[공리: 물리 모형]**이다.
형식 기호 \(\mathcal D\gamma\)만으로 countably additive measure나
support theorem이 생기지 않는다.

## 4. 선택과 비선택의 측도론적 분리

**[정의]**
\[
M=\operatorname*{argmin}_{\gamma\in X}\mathcal I_{\rm fold}(\gamma),
\qquad
N=X\setminus M.
\]

유한 \(\beta\)에서 비선택 부분은 probability가 아니라 subprobability

\[
\nu_{{\rm ns},\beta}(B)
:=
\mu_\beta(B\cap N)
\]

다. \(\mu_\beta(N)>0\)일 때에만 조건부 probability

\[
\overline\nu_{{\rm ns},\beta}
=
\frac{\nu_{{\rm ns},\beta}}{\mu_\beta(N)}
\]

를 따로 정의할 수 있다.

**[산출]** 1절 정리에서 \(M\)의 임의의 이웃 밖 질량은 0으로 간다.
따라서 정규화하지 않은 비선택 질량이 유한한 독립 에너지로 남는다는
결론은 농축 정리에서 나오지 않는다. 조건부 정규화
\(\overline\nu_{{\rm ns},\beta}\)는 총 비선택 질량 정보를 제거하므로
두 대상을 혼동하지 않는다.

## 5. Kernel pushforward

**[정의]** spacetime 또는 상태공간 \(Y\)와 measurable kernel
\(K:Y\times X\to\mathbb R\)를 택하고, 각 \(y\)에서
\(\int_N|K(y,\gamma)|\,\mu_\beta(d\gamma)<\infty\)라 하자.

\[
\phi_\beta(y)
:=
\int_NK(y,\gamma)\,\mu_\beta(d\gamma)
\]

로 정의하면 이는 well-defined measurable residual readout이다.
공통 적분가능 지배함수 아래에서는 dominated convergence로 \(y\)에 대한
연속성도 전달된다.

\(\phi_\beta\)를 CE의 독립 국소장으로 읽으려면 다음이 더 필요하다.

1. \(K\)의 공변성·국소성·단위와 normalization
2. \(\phi_\beta\)를 포함하는 action과 Euler--Lagrange equation
3. metric variation으로 정의한 stress tensor
4. renormalization과 관측 연산자

이 물리 사상은 **[미완성]**이다.

## 6. Readout과 측정

유한한 \(\beta_{\rm obs}\)를 택하면
\(\mu_{\beta_{\rm obs}}\)라는 분포는 정의할 수 있다. 그러나 물리
readout에는 상태공간, outcome sigma-algebra와 CPTP instrument가
필요하다. \(\beta_{\rm obs}\)의 선택은 **[공리: 물리 사상]**이고,
\(\beta\to\infty\) 최소자 선택은 반복 측정의 Born frequency 정리가
아니다.

양자 분지의 조건부 사상은
[06_측정문제와Born.md](06_측정문제와Born.md),
유한 분할 위 branch-count 정리는
[06a_Born_prior_유도.md](06a_Born_prior_유도.md)에 분리한다.

## 7. 현재 닫힌 범위

- good-rate와 recovery mass 아래 Gibbs 농축
- 비음이 아닌 lower-semicontinuous suppression을 더했을 때 compact
  sublevel의 보존
- 비선택 subprobability와 조건부 probability의 구분
- 적분가능 measurable kernel의 pushforward

다음은 **[미완성]**이다.

- CE가 채택할 pathspace route와 물리 prior
- 공변 Euclidean action과 suppression functional
- residual kernel의 국소 장·stress 사상
- 실제 측정 instrument와 \(\beta_{\rm obs}\)
