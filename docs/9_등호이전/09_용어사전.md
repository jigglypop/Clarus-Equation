# 09. 용어사전

이 용어사전은 등호 이전 문서에서 쓰는 canonical 용어의 정의역·형식 지위·관련 문서를 고정해 동음이의와 과장된 해석을 막는다. 용어 결정은 바꾸지 않으며, 각 항목의 정의가 물리적 동일시나 경험적 참을 뜻하지 않는 경우를 함께 적는다.

독자는 01–05의 수학적 정의를 먼저 읽고 이 문서를 참조표로 사용한다. 형식 출처, 후보·조건·energy·manifest·residual, Born/AGI runtime 순서로 확인하며 관련 문서의 세부 가정을 우선한다.

## 0. 목적

목적은 같은 기호가 정의·정리·공리·미완성 다리를 넘나드는 것을 막는 것이다. 용어의 canonical 정의역 밖 사용은 관련 문서에서 새로 선언해야 한다.

`9_등호이전` 문서군은 후보분포, 잔류장, CE 물리 사상, Born prior와 AGI
runtime을 한 폴더에서 연결한다. 같은 단어가 서로 다른 층에서 섞이면 정의,
증명, 독립 전제와 관측 비교가 뒤섞인다. 이 문서는 핵심 용어의 정의역과
형식 출처를 고정한다.

## 1. 형식 출처 표지

형식 출처 표지는 문장이 어디에서 오는지 표시한다. 표지는 증명·외부입력·채택 선택의 차이를 지우지 않으며 관련 정본의 범위를 따라야 한다.

| 표지 | 의미 |
|---|---|
| `[정의]` | 기호, 대상, 함수, 계산 규약과 정의역을 고정한다. 정의만으로 존재·유일성이나 물리적 실재를 주장하지 않는다. |
| `[정리]` | 명시한 전제와 정의역에서 결론까지 증명이 완결된 명제다. |
| `[공리]` | 후보공간, prior, 정규화, 분기 또는 물리 사상으로 독립 채택한 전제다. 필요하면 `수학 공리`, `모델 선택`, `물리 사상`, `외부 입력`을 덧붙인다. |
| `[산출]` | 앞선 정의·공리·정리를 추가 선택 없이 대입해 얻은 식이나 수치다. |
| `[경험식]` | 자료, 보정, 유효 계수 또는 사후 탐색을 포함하는 관계다. |
| `[미완성]` | 필요한 정의, 작용, 증명, 물리 사상 또는 독립 자료가 남아 있다. |
| `[예측]` | 입력, 범위와 비교 절차를 자료 확인 전에 고정한 관측량이다. 의존 공리와 산출을 함께 적는다. |

이 표지는 점수나 기계 검사 결과가 아니다. 한 문장에 여러 층이 있으면
수학 명제, 물리 사상과 관측 비교를 분리해서 쓴다.

## 2. 후보와 상태

후보와 상태는 지정한 유한집합·metric space·measurable space 같은 정의역 위에서만 정의된다. 후보분포를 물리적 존재 확률이나 agent belief로 자동 해석하지 않는다.

| 기호 | 정의역 | 의미 | 출처 |
|---|---|---|---|
| $A$ | finite set, metric space, $\mathbb R^n$ | 값 후보공간 | `[정의]` |
| $K$ | finite set 또는 measurable space | 조건 후보공간 | `[정의]`; 실제 공간 선택은 `[공리: 모델 선택]` |
| $\Gamma$ | path space | CE 경로 후보공간 | `[정의]`; topology와 허용 경로는 `[공리: 모델 선택]` |
| $\mu_0$ | probability measure on $A$ | 초기 상태 또는 prior | `[공리: 모델 선택]` |
| $\mu_\beta$ | probability measure on $A$ | 조건 작동 후 Gibbs 상태 | `[정의]`; well-defined 조건과 농축은 `[정리]` |
| $\rho$ | probability on $K\times A$ | 조건-값 joint 상태 | `[정의]` |

후보는 참인 값의 집합이 아니라, 조건 작동 전에 허용한 readout 표면이다.

## 3. 조건과 에너지

조건과 energy는 readout score 또는 defect functional의 역할로 정의된다. 단위·normalization·temperature가 없으면 서로 다른 energy를 비교하거나 물리 action으로 동일시할 수 없다.

| 기호 | 의미 | 출처 |
|---|---|---|
| $C$ | 조건 | `[정의]`; 실제 조건은 `[공리: 모델 선택]` |
| $E_C$ | 조건 에너지 | `[정의]`; 함수형 선택은 `[공리: 모델 선택]` |
| $E_{\mathrm{val}}(C,a)$ | 조건이 값에 부여하는 잔차 | `[정의]` |
| $E_{\mathrm{cond}}(C)$ | 조건 자체의 안정성 또는 상위 적합도 | `[미완성]` 또는 지정 모형의 `[공리]` |
| $E_{\mathrm{fold}}$ | CE 접힘 억압 functional | `[미완성]`; 작용과 topology가 고정된 경우에만 조건부 정리를 적용 |
| $E_{\mathrm{meas}}$ | 측정장치 조건 에너지 | `[미완성]` |
| $E_{\mathrm{ctx}}$ | token/action context energy | `[경험식]` |

$E$가 존재한다고 해서 물리 의미가 자동으로 정해지지 않는다. 별도 선언
없이 순수수학 Gibbs 식에 나타나는 $E$와 $\beta$는
무차원 cost와 무차원 선택 scale을 뜻한다. 물리 에너지·작용을 대입할
때에는 $E/(k_BT)$, $S_E/\hbar$ 또는 기준량의 비를 사용한다.
$E$와 prior가 주어졌을 때 Gibbs 재가중이 잘 정의되는 조건은 별도의
수학 명제다.

## 4. Manifest

manifest는 명시한 Gibbs/readout 규칙에서 최소집합 또는 선택 output을 뜻한다. 유일성, 실제 관측 발생, 물리 collapse는 별도 가정이다.

| 용어 | 의미 | 출처 |
|---|---|---|
| manifest | $\beta\to\infty$ 극한 또는 지정 readout에서 표면에 나타난 후보 | `[정의]` |
| manifest set | $A_*=\operatorname*{argmin}_{\operatorname{supp}\mu_0}E$ | `[정의]` |
| unique manifest | $A_*=\{a_*\}$이고 $\mu_\beta\Rightarrow\delta_{a_*}$인 경우 | `[정의]`; 수렴은 전제 아래 `[정리]` |
| joint manifest | $(k,a)\in K\times A$ 쌍이 선택되는 경우 | `[정의]` |

manifest는 진리값과 다르다. 예를 들어 실수 후보공간에서
$x^2+1=0$의 최소잔차 manifest가 $x=0$이어도 실수해가 생기는 것은 아니다.

## 5. Residual

residual은 선택되지 않은 후보의 raw/conditional 측도 또는 그 readout을 뜻한다. 독립 에너지·암흑 성분·기억으로 읽는 해석은 canonical 정의에 포함되지 않는다.

| 용어 | 식 | 의미 | 출처 |
|---|---|---|---|
| non-selected set | $A_{\mathrm{ns}}=A\setminus A_*$ | 선택되지 않은 후보 | `[정의]` |
| raw residual | $\nu_{\mathrm{ns}}=\mathbf1_{A_{\mathrm{ns}}}\mu_\beta$ | 비선택 총 질량을 보존한 제한측도 | `[정의]` |
| residual mass | $q_{\mathrm{ns}}=\nu_{\mathrm{ns}}(A)$ | 선택되지 않은 질량 | `[정의]` |
| conditional residual | $\widehat\mu_{\mathrm{ns}}=\nu_{\mathrm{ns}}/q_{\mathrm{ns}}$ | 비선택 후보의 조건부 모양 | `[정의]`; $q_{\mathrm{ns}}>0$ 필요 |

residual은 오류 답의 목록이 아니다. 현재 readout에서 선택되지 않은 후보를
다음 readout이나 물리 사상에 전달할 수 있도록 보존한 측도다.

## 6. $\phi$, $\mathcal H_\gamma$와 $\Phi_H$

이 기호들은 모두 잔류 또는 이차 변분과 관련되지만 정의역·codomain·지위가 다르다. 아래 항목은 표기 통일과 금지할 동일시를 명시한다.

### 6.1 잔류 readout $\phi$

$\phi$는 measurable kernel을 비선택 측도에 적분한 출력 함수다. kernel의 locality·unit·identifiability가 없으면 물리장으로 승격하지 않는다.

`[정의]`

$$
\phi_\beta(x)
=
\int K_\phi(x,\gamma)\,\nu_{\mathrm{ns},\beta}(d\gamma).
$$

| 층 | 출처 |
|---|---|
| 적분의 존재 | $K_\phi(x,\cdot)\in L^1(\nu_{\mathrm{ns},\beta})$ 아래 `[정리]` |
| 커널 $K_\phi$ 선택 | `[공리: 모델 선택]` |
| 물리장 또는 AGI 상태와의 동일시 | `[공리: 물리 사상]`; 동역학이 없으면 `[미완성]` |

### 6.2 Hessian operator와 scalar projection

Hessian operator와 scalar projection은 action·path·functional derivative의 정의역을 먼저 요구한다. 연산자와 그 readout scalar를 같은 객체로 부르는 것은 금지한다.

`[정의]` 작용의 2차 변분은 일반적으로 scalar가 아니라 operator 또는 kernel이다.

$$
\mathcal H_\gamma=\delta^2S[\gamma].
$$

probe $\eta$와 경계조건을 고정하면 scalar readout을

$$
\Phi_H[\gamma,\eta]
=
\frac{\langle\eta,\mathcal H_\gamma\eta\rangle}
{\langle\eta,\eta\rangle}
$$

로 정의할 수 있다. 독립 물리장 $\phi(x)$, operator $\mathcal H_\gamma$,
probe별 수 $\Phi_H$는 자동으로 같은 대상이 아니다.

### 6.3 금지할 혼동

금지 항목은 정의역이 다른 기호의 무단 동일시를 막는다. 유사한 비유는 가능하더라도 공리 또는 검증 bridge 없이 등식·증명으로 쓰지 않는다.

$$
\phi=\mathcal H_\gamma,
\qquad
\phi=\Phi_H
$$

는 정의가 아니다. 이를 쓰려면 타입이 맞는 kernel, probe, 단위와 경계조건을
고정한 `[공리: 물리 사상]`이 필요하다. 해당 사상이나 동역학이 없으면
`[미완성]`이다.

## 7. Readout

readout은 분포·측도·state에서 지정한 output space로 가는 명시적 map이다. measurement, observation, manifestation은 필요한 instrument와 data provenance가 있을 때만 더 좁게 쓴다.

| readout | 식 | 의미 | 출처 |
|---|---|---|---|
| joint readout | $\rho_\beta(k,a)$ | 조건-값 쌍 전체 | `[정의]` |
| condition readout | $\nu_\beta(k)=\sum_a\rho_\beta(k,a)$ | 조건 marginal | `[산출]` |
| value readout | $\mu_\beta(a)=\sum_k\rho_\beta(k,a)$ | 값 marginal | `[산출]` |
| residual readout | $\phi=\int K_\phi\,d\nu_{\mathrm{ns}}$ | 비선택 후보를 장 또는 벡터로 읽음 | `[정의]`; kernel은 `[공리]` |

marginal readout은 일반적으로 정보를 잃는다. 값 marginal만으로 조건
marginal을 복원할 수 있으려면 추가 식별가능성 정리가 필요하다.

## 8. Born prior

Born prior는 유한 branch assignment의 공리적 조건과 결론을 가리킨다. 물리 Born rule, decoherence, frequency를 이미 유도한 용어로 사용하지 않는다.

| 용어 | 의미 | 출처 |
|---|---|---|
| Born prior | $\mu_0(i)=|c_i|^2$ | `[공리: 모델 선택]`; branch refinement 전제 아래의 counting 결과는 `[정리]` |
| equal branch | 모든 미세분지의 계수 크기가 같은 경우 | `[정의]` |
| branch refinement | coarse 후보를 동일 진폭 미세분지로 나누는 과정 | `[공리: 모델 선택]` |
| continuity extension | 유리 진폭에서 일반 진폭으로 확장 | 연속성 전제 아래 `[정리]` |
| 실제 측정 확률과의 동일시 | 측정 사상 | `[공리: 물리 사상]`; 독립 동역학은 `[미완성]` |

PreEq는 Born prior를 전제 없이 생성하지 않는다. prior가 주어지면 그 prior가
측정 조건 아래 어떻게 재가중되는지를 다룬다.

## 9. AGI runtime 용어

AGI runtime 용어는 tensor shape·producer/consumer·timebase를 가진 구현 명세다. 생물학·의식·일반지능 비유는 toy ablation과 독립 검증 전에는 canonical 정의가 아니다.

| 용어 | 의미 | 출처 |
|---|---|---|
| token/action 후보 | finite candidate set | `[정의]` |
| logits prior | $\mu_0=\operatorname{softmax}(l)$ | `[공리: 모델 선택]` |
| context energy | goal/risk/tool/memory penalty | `[경험식]` |
| $\phi$ 재주입 | score에 $\alpha_\phi\langle h(a),\phi_t\rangle$ 추가 | `[경험식]` |
| hallucination gate | claim energy로 후보를 억압 | `[경험식]` |
| 사전등록 ablation | 고정된 데이터와 지표의 비교 | `[예측]` |

$\phi$ 재주입의 성능은 수학 정리가 아니다. 입력·지표·중단 규칙을 먼저
고정한 뒤 `07b_gate_ablation_protocol.md`의 절차로 비교한다.

## 10. 결론

용어의 canonical 정의와 지위를 지키면 수학 contract와 물리/AGI 해석의 경계가 유지된다. 새 용어 또는 정의역 확장은 관련 정본·fixture·반례 조건을 함께 추가해야 한다.

$$
\boxed{
\text{수학적 재가중}
\ne
\text{물리적 동일시}
\ne
\text{런타임 성능 주장}
}
$$

첫 번째 대상은 정의와 정리로 다룬다. 물리적 동일시는 공리로 기록하며,
자료 기반 관계는 경험식으로 둔다. 독립 비교 절차가 사전 고정된 경우에만
예측 표지를 쓴다. 필요한 사상이나 증명이 없으면 미완성으로 남긴다.
