# 09. 용어사전

## 0. 목적

`9_등호이전` 문서군은 후보분포, 잔류장, CE bridge, Born prior, AGI runtime을 한 폴더에서 연결한다. 이때 같은 단어가 서로 다른 층에서 섞이면 증명된 것과 선택한 것, 실험해야 할 것이 뒤섞인다.

이 문서는 핵심 용어의 domain과 판정 지위를 고정한다.

## 1. 판정 등급

| 용어 | 의미 |
|---|---|
| `Exact` | 유한합, 확률분포, 커널, log-sum-exp처럼 추가 물리 식별 없이 증명되는 층 |
| `Exact under assumptions` | compactness, coercivity, measurability, integrability 같은 명시 가정 아래 증명되는 층 |
| `Selection` | 후보공간, readout, 커널, 정규화 규약 중 하나를 선택하는 층 |
| `Bridge` | 수학 구조를 CE 물리, 양자 측정, AGI runtime 같은 외부 의미에 대응시키는 층 |
| `Phenomenology` | 유효모형, 보정, 관측 readout, 데이터 기준을 포함하는 층 |
| `Open/Experiment` | 증명이 아니라 반례, ablation, 외부 데이터로 판정해야 하는 층 |

## 2. 후보와 상태

| 기호 | domain | 의미 | 판정 |
|---|---|---|---|
| \(A\) | finite set, metric space, \(\mathbb R^n\) | 값 후보공간 | `Exact/Assumption` |
| \(K\) | finite set | 조건 후보공간 | `Exact/Selection` |
| \(\Gamma\) | path space | CE 경로 후보공간 | `Bridge` |
| \(\mu_0\) | probability measure on \(A\) | 초기 모호함 상태/prior | `Exact`, 물리 prior는 `Bridge` |
| \(\mu_\beta\) | probability measure on \(A\) | 조건 작동 후 posterior | `Exact` |
| \(\rho\) | probability on \(K\times A\) | 조건-값 joint 상태 | `Exact` |

주의:

> 후보는 참인 값의 집합이 아니다. 조건 작동 전 살아 있는 가능한 readout 표면이다.

## 3. 조건과 에너지

| 기호 | 의미 | 판정 |
|---|---|---|
| \(C\) | 조건 | `Selection` |
| \(E_C\) | 조건 에너지 | 수학적으로는 `Exact`, 선택은 `Selection` |
| \(E_{\mathrm{val}}(C,a)\) | 조건이 값에 부여하는 잔차 | `Exact/Selection` |
| \(E_{\mathrm{cond}}(C)\) | 조건 자체의 안정성/상위 적합도 | `Selection/Bridge` |
| \(E_{\mathrm{fold}}\) | CE 접힘 억압 functional 후보 | `Bridge` |
| \(E_{\mathrm{meas}}\) | 측정장치 조건 에너지 후보 | `Bridge` |
| \(E_{\mathrm{ctx}}\) | token/action context energy | `Bridge/Tooling` |

주의:

> \(E\)가 존재한다고 해서 그 물리 의미가 자동으로 닫히지 않는다.  
> 닫히는 것은 \(E\)가 주어졌을 때의 Gibbs 재가중이다.

## 4. Manifest

| 용어 | 의미 |
|---|---|
| manifest | \(\beta\to\infty\) 또는 선택 readout에서 표면에 나타난 후보 |
| manifest set | \(A_*=\operatorname*{argmin}_{\operatorname{supp}\mu_0}E\) |
| unique manifest | \(A_*=\{a_*\}\)이고 \(\mu_\beta\Rightarrow\delta_{a_*}\)인 경우 |
| joint manifest | \((k,a)\in K\times A\) 쌍이 선택되는 경우 |

주의:

> manifest는 진리값과 다르다.  
> 예를 들어 실수 후보공간에서 \(x^2+1=0\)의 최소잔차 manifest는 \(x=0\)일 수 있지만, 이는 해가 아니다.

## 5. Residual

| 용어 | 식 | 의미 | 판정 |
|---|---|---|---|
| non-selected set | \(A_{\mathrm{ns}}=A\setminus A_*\) | 선택되지 않은 후보 | `Exact` |
| raw residual | \(\nu_{\mathrm{ns}}=\mathbf1_{A_{\mathrm{ns}}}\mu_\beta\) | 비선택 총 질량 보존 | `Exact` |
| residual mass | \(q_{\mathrm{ns}}=\nu_{\mathrm{ns}}(A)\) | 선택되지 않은 질량 | `Exact` |
| conditional residual | \(\widehat\mu_{\mathrm{ns}}=\nu_{\mathrm{ns}}/q_{\mathrm{ns}}\) | 비선택 후보의 모양 | `Exact if q>0` |

주의:

> residual은 실패한 답이 아니다.  
> 표면에서 선택되지 않았지만 다음 readout, bridge, memory, curvature로 내려갈 수 있는 제한측도다.

## 6. \(\phi\)와 \(\Phi\)

### 소문자 \(\phi\)

이 폴더에서 소문자 \(\phi\)는 residual readout field다.

$$
\phi_\beta(x)
=
\int K_\phi(x,\gamma)\,\nu_{\mathrm{ns},\beta}(d\gamma).
$$

판정:

| 층 | 판정 |
|---|---|
| 적분 정의 | `Exact under assumptions` |
| 커널 선택 \(K_\phi\) | `Selection` |
| 물리/AGI 의미 | `Bridge/Open test` |

### 대문자 \(\Phi\)

대문자 \(\Phi\)는 CE 문서군에서 경로 접힘/억압 자유도 또는 작용의 이차변화와 연결되는 기호다.

대표 후보:

$$
\Phi\sim\frac{\delta^2S}{\delta\gamma^2}.
$$

판정:

`Bridge`

### 금지할 혼동

아래 등식은 정의가 아니다.

$$
\phi=\Phi
$$

허용되는 말은 조건부 bridge다.

$$
K_\phi(x,\gamma)
=
\frac{\delta^2S}{\delta\gamma^2}(x;\gamma)
\quad\Longrightarrow\quad
\phi_{\mathrm{curv}}=\Phi_{\mathrm{res}}
$$

단, \(S\), Hessian, integrability, raw/conditional 규약을 모두 명시해야 한다.

## 7. Readout

| readout | 식 | 의미 |
|---|---|---|
| joint readout | \(\rho_\beta(k,a)\) | 조건-값 쌍 전체 |
| condition readout | \(\nu_\beta(k)=\sum_a\rho_\beta(k,a)\) | 어떤 조건이 manifest 되는가 |
| value readout | \(\mu_\beta(a)=\sum_k\rho_\beta(k,a)\) | 어떤 값이 manifest 되는가 |
| residual readout | \(\phi=\int K_\phi\,d\nu_{\mathrm{ns}}\) | 비선택 후보를 장/벡터로 읽음 |

주의:

> marginal readout은 정보를 잃는다. 값만 알면 어떤 조건이 manifest 되었는지 일반적으로 복원할 수 없다.

## 8. Born prior

| 용어 | 의미 | 판정 |
|---|---|---|
| Born prior | \(\mu_0(i)=\lvert c_i\rvert^2\) | finite branch 공리 아래 `Exact`, 물리 측정은 `Bridge` |
| equal branch | 모든 미세분지의 계수 크기가 같은 경우 | `Exact` |
| branch refinement | coarse 후보를 동일 진폭 미세분지로 나누는 과정 | `Selection/Assumption` |
| continuity extension | 유리 진폭에서 일반 진폭으로 확장 | `Exact under continuity` |

주의:

> PreEq는 Born prior를 자동 생성하지 않는다.  
> Born prior가 주어지면 그 prior가 측정 조건 아래 어떻게 manifest 되는지를 설명한다.

## 9. AGI runtime 용어

| 용어 | 의미 | 판정 |
|---|---|---|
| token/action 후보 | finite candidate set | `Exact` |
| logits prior | \(\mu_0=\operatorname{softmax}(l)\) | `Tooling` |
| context energy | goal/risk/tool/memory penalty | `Bridge/Tooling` |
| \(\phi\) 재주입 | score에 \(\alpha_\phi\langle h(a),\phi_t\rangle\) 추가 | `Open/Experiment` |
| hallucination gate | claim energy로 후보 억압 | `Bridge/Open test` |

주의:

> \(\phi\) 재주입의 성능은 증명하지 않는다.  
> `07b_gate_ablation_protocol.md`의 ablation으로 판정한다.

## 10. 결론

이 폴더에서 가장 중요한 언어 규칙은 다음이다.

$$
\boxed{
\text{수학적 재가중}
\ne
\text{물리적 동일시}
\ne
\text{런타임 성능 주장}
}
$$

각 등호를 건너갈 때마다 `Selection`, `Bridge`, `Open/Experiment` 판정이 필요하다.
