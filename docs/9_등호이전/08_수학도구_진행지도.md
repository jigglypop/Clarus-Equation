## 3. 증명하면 안 되는 자리

| 자리 | 이유 |
|---|---|
| Born prior 전체 | Gleason류 외부 정리 또는 Hilbert 측도 공리가 필요 |
| CE \(\Phi=E_{\mathrm{fold}}\) 동일시 | 물리 커널과 경로공간 정의가 먼저 필요 |
| AGI \(\phi\) 재주입 성능 | 증명이 아니라 ablation 실험 대상 |
| 순수 Gamma만으로 Gibbs 분포 전체 결정 | positive-mass recovery와 내부 선택 정보가 빠짐 |

## 4. 진행 원칙

| 층 | 다음 행동 |
|---|---|
| `Exact` | 정리와 증명을 쓴다 |
| `Exact under assumptions` | 가정을 명시하고 외부 검증 가능한 statement로 닫는다 |
| `Selection` | 어떤 readout/공간/커널을 고르는지 표로 분리한다 |
| `Bridge` | 정의 체크리스트를 먼저 채운다 |
| `Open/Experiment` | 반례, ablation, 수치실험으로 보낸다 |
