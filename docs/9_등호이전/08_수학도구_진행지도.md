# 08. 등호 이전 수학 진행지도

이 문서는 등호 이전 폴더의 정리·공리·미완성 bridge를 읽기 순서와 closure gate로 정리하는 독자 지도다. 지도는 지위를 새로 판정하지 않으며, 각 문서의 현재 형식 범위와 다음에 필요한 입력을 연결한다.

독자는 01–02c의 농축 기초부터 읽고, 03–04의 조건·범주 도구, 05의 CE bridge, 06의 Born 경계, 07의 runtime gate로 진행하면 된다. 표와 목록은 각 단계의 prerequisite와 다음 검증을 찾기 위한 것이며 물리 결론의 요약이 아니다.

## 0. 원칙

진행지도는 정리·채택 공리·경험 입력·미완성 다리를 섞지 않는다는 원칙을 따른다. 관측 근접이나 코드 통과는 별도의 closure gate 없이는 지위 승격 근거가 아니다.

이 지도는 수학적 정리, 모델 선택과 물리 사상을 분리한다. 실행 결과는
구현 회귀를 검사하지만 정리의 증명이나 물리 사상을 대신하지 않는다.

## 2. 현재 단단한 수학

이 절은 명시한 유한성·topology·recovery 가정 아래에서 닫힌 결과만 묶는다. 각 도구의 적용에는 해당 절이 말하는 prerequisite를 다시 확인해야 한다.

### 2.1 농축

농축 정리는 energy gap, compactness와 prior mass를 사용한다. 다음 closure gate는 실제 후보공간에서 이 세 입력을 확인하는 것이다.

- 유한 후보공간에서 양의 prior와 무차원 energy를 고정하면 Gibbs
  probability는 최소집합으로 농축한다.
- Compact 공간에서는 연속 cost와 full-support prior가 같은 결론을 준다.
- Noncompact 공간에서는 coercivity 또는 exponential tightness가
  mass escape를 막아야 한다.
- Scale-dependent functional에는 $\Gamma$-liminf, recovery sequence,
  equicoercivity가 필요하다.
- 여러 최소자가 있으면 최소집합 농축과 그 내부의 branch 선택은 별도
  문제다.

### 2.2 경로공간

경로공간 결과는 선택한 topology와 reference prior에 상대적이다. 다음 gate는 action sublevel·support·finite-to-continuum consistency를 같은 route에서 검증하는 일이다.

- $W^{1,p}$, $p>1$의 고정 끝점 경로와 coercive convex-velocity
  functional에는 직접법을 적용할 수 있다.
- Kinetic bound는 $C^0$ compactness를 줄 수 있지만 $C^1$
  compactness를 주지 않는다.
- Sobolev--Gaussian은 선택한 $H^1$ Hilbert 경로공간에서 full support
  prior를 만들 수 있다.
- Brownian bridge는 $C^0$에서 full support지만
  $W^{1,p}$에는 질량 0을 준다.
- Finite mesh의 fixed-$N$ 농축과 $N,\beta_N$ joint limit은 서로
  다른 정리다.

### 2.3 Suppression과 조건화

suppression·hard constraint·조건화는 normalization과 feasible mass에 의존한다. 영측도 조건과 penalty limit order는 별도 반례 gate를 통과해야 한다.

무차원 기준 cost를 $\mathcal I_0$라 하면

$$
e^{-\beta\mathcal I_0-B},\qquad
e^{-\beta(\mathcal I_0+\mathcal J)},\qquad
\mathbf1_Ae^{-\beta\mathcal I_0}
$$

는 각각 bounded tilt, $\beta$-coupled cost와 hard constraint다.

- Bounded $B$는 zero-temperature 최소집합을 바꾸지 않는다.
- $\mathcal I_0+\mathcal J$가 good-rate이고 recovery mass가 있으면
  그 합의 최소집합으로 농축한다.
- Hard constraint는 $\mu_0(A)>0$일 때만 정의되며 restricted
  support의 최소집합을 사용한다.

### 2.4 Gaussian과 mean-field

Gaussian/mean-field 도구는 독립성·covariance·moment 가정의 결과다. noise·model discrepancy·identifiability의 경험 입력을 대체하지 않는다.

- $U_N=\frac12\sum z_j^2$는
  $\operatorname{Gamma}(N/2,1)$이고 quantile은
  $N/2+z_q\sqrt{N/2}+o(\sqrt N)$다.
- 이 결과는 선택한 독립 Gaussian prior의 정리이며 Kennard 부등식에서
  유도되지 않는다.
- Intensive 독립·유계 mode 합에서는 mean-field 비가
  $1+O(N^{-1})$지만, extensive $U_N$에서는
  $(e/2)^{N/2}$로 발산한다.
- 평균만으로 Laplace transform, 분산이나 mode 수를 식별할 수 없다.

### 2.5 고정점

고정점 도구는 contraction·complete space·properness 같은 정칙성을 요구한다. 일반 동역학과 CE 선택의 물리 해석은 후속 bridge다.

무차원 $D\geq0$에서
$$
x=e^{-D(1-x)}
$$
는 $D\leq1$일 때 $x=1$만, $D>1$일 때 안정한 최소해
$q(D)\in(0,1/D)$와 불안정한 $x=1$을 갖는다. $q(D)$를 특정
밀도분율로 읽는 것은 이 정리에 포함되지 않는다.

## 3. 보존해야 할 exact no-go

no-go는 실패한 부모 주장을 막는 적극적 증인이다. 각 반례의 정의역을 좁히지 않고 우회하는 서술은 재도입 금지다.

| 부모 주장 | 정확한 경계 |
|---|---|
| lower-semicontinuity와 full support이면 recovery가 자동 | 일반적으로 거짓; minimizer continuity, atom 또는 tube mass가 더 필요 |
| 모든 finite weight가 양수이면 joint mesh-temperature 극한도 안전 | 일반적으로 거짓; $-\log$ recovery mass가 $\beta_N$보다 느리게 커져야 함 |
| Brownian prior를 finite kinetic action 집합으로 조건화 가능 | 그 집합의 Brownian 질량이 0 |
| kinetic bound가 $C^1$ compactness를 보장 | 고주파 작은진폭 수열이 반례 |
| $\Gamma$-수렴만으로 Gibbs 내부 선택까지 결정 | 최소집합 내부의 작은 scale과 prior가 남음 |
| 평균 $\mathbb E\Phi$가 $\mathbb Ee^{-\Phi}$를 결정 | strict convexity의 두 점 분포가 반례 |
| Hessian이 고차 vertex 또는 stress tensor를 결정 | action jet과 metric variation이 별도 |
| 유한 2점 자료가 spectral density를 유일하게 결정 | augmented kernel에 nullspace가 있으면 양의 해가 비유일 |

반례가 부모의 정의역 안에 있는 경우 부모 문장은 활성 이론으로 되돌리지
않고, 위 no-go와 참인 좁은 정리만 남긴다.

## 4. 아직 물리 입력인 자리

다음 항목은 수학 도구가 제공하지 않는 물리 모델·외부 데이터·instrument 선택이다. 다음 closure gate는 필요한 입력·단위·provenance·반증 기준을 명시하는 것이다.

### 4.1 CE pathspace

CE pathspace는 topology·sigma-algebra·gauge·causality와 prior를 함께 선택해야 한다. 수학적 후보의 존재만으로 물리 prior가 정해지지 않는다.

- 실제 path topology와 route
- countably additive physical prior
- 공변 Euclidean action과 gauge fixing
- 무차원 suppression functional
- finite mesh와 continuum의 공동 scaling

### 4.2 Residual field

residual kernel은 measurable readout을 만들 수 있지만 locality·covariance·action·stress mapping은 미완성이다. kernel 식별성과 대조 실험이 다음 gate다.

- kernel의 국소성, 공변성, 단위와 normalization
- subprobability readout과 독립장 사이의 action
- metric variation stress와 observable map

### 4.3 측정

측정 bridge에는 Hilbert state, instrument, outcome, decoherence와 Born prior의 독립 정당화가 필요하다. Gibbs update만으로 이 gate를 닫지 않는다.

- Hilbert state에서 outcome으로 가는 CPTP instrument
- finite branch refinement와 실제 apparatus refinement의 대응
- 반복측정 frequency와 preparation independence

### 4.4 AGI

AGI residual은 shape·timebase·fixture 수준의 구현 가설이다. ablation·OOD·failure threshold를 통과해도 의식 주장은 별도 범위다.

- embedding metric, residual kernel과 feedback coefficient
- baseline, seed, split과 통계 검정
- 계산 toy의 이득을 일반 시스템으로 옮기는 외삽

### 4.5 우주론

우주론 forward map은 background·nuisance·covariance 외부 입력을 사용한다. locked prediction과 independent data split이 다음 반증 gate다.

- residual에서 $\rho(a),p(a),T_{\mu\nu}$로 가는 사상
- 배경 보존식과 perturbation closure
- recombination·BBN·growth·lensing observable
- 공분산과 nuisance parameter를 포함한 독립 likelihood

이 항목은 각각 **[공리]**, **[경험식]** 또는 **[미완성]**으로 둔다.

## 5. 승격 순서

승격은 먼저 정의역·입력·정리 조건을 고정하고, 다음에 독립 검증과 반례 탐색을 거치는 순서다. 계획 문서를 완료 주장으로 읽지 않는다.

1. 대상의 type, topology, sigma-algebra와 단위를 **[정의]**한다.
2. 모델이 선택하는 prior, action, kernel과 branch를 **[공리]**로
   분리한다.
3. Compactness, lower-semicontinuity, recovery와 integrability를
   증명한다.
4. 그 전제에서만 **[정리]**와 **[산출]**을 쓴다.
5. 자료 의존 보정은 **[경험식]**, 사전 고정 관측량은 **[예측]**으로
   기록한다.

## 6. 검증

검증은 링크·수식·fixture 같은 기계 gate와 수학·물리 지위 판단을 분리한다. 기계 통과는 문서 contract의 확인일 뿐 이론의 참 판정이 아니다.

유한 코어와 toy 계산의 회귀는 다음 명령으로 검사한다.

$$
\texttt{python -m pytest tests/test\_pre\_eq.py -q}
$$

$$
\texttt{python -m pytest tests/test\_pre\_eq\_toy\_gate.py -q}
$$

$$
\texttt{python -m pytest tests/test\_pre\_eq\_fraction.py -q}
$$

$$
\texttt{python -m pytest tests/test\_pre\_eq\_universal.py -q}
$$

회귀 대상은 finite Gibbs normalization, layer-cake, Gamma moment·quantile,
조건 합성과 toy ablation이다. 수치 일치는 physical prior, Born
instrument, residual stress 또는 우주론 사상을 증명하지 않는다.
