### 완료: CE 경로공간 실제 데이터 감사

[05d_pathspace_audit.md](05d_pathspace_audit.md)를 추가해 실제 CE 문서의 \(\mathcal P_I\), \(\mu_{\mathrm{ref}}\), \(W\), \(F\), \(\mathcal P_{\mathrm{ns}}\), \(K_\phi\)를 05c checklist와 대조했다.

닫힌 것:

- \(W\)가 가측이고 \(0<\int e^{-W}d\mu_{\mathrm{ref}}<\infty\)이면 CE 확률측도는 존재한다.
- \(F=W+c\)이면 선택 최소자와 Gibbs 가중치는 동일하다.
- \(F\)의 sublevel 정의를 쓰면 near-minimizer와 비선택 경로공간의 가측성이 닫힌다.
- \(K_\phi(x,\cdot)\in L^1(\mu_{\mathrm{ns}})\)이면 잔류장 readout은 well-defined다.

남은 병목:

$$
E_{\mathrm{fold}}(\gamma)=W[\gamma]-W_{\min}
$$

가 실제 경로공간에서 l.s.c., coercive/good rate, positive-mass recovery를 만족하는지 증명해야 한다.

판정:

조건부 `Exact`, 남은 `Bridge`

### 완료: CE good-rate theorem

[05e_CE_good_rate_theorem.md](05e_CE_good_rate_theorem.md)를 추가해 CE action 농축을 조건부 정리로 닫았다.

닫힌 것:

- \(E\)가 l.s.c.이고 compact sublevel을 가지며 recovery mass가 있으면 Gibbs 측도는 minimizer set으로 농축한다.
- \(W-W_{\min}\) shift는 minimizer와 Gibbs 비율을 보존한다.
- \(S_E\)가 compact sublevel을 만들고 \(S_{\mathrm{supp}}\ge0\)가 l.s.c.이면 \(W=S_E/\hbar+S_{\mathrm{supp}}\)도 good-rate function이다.
- finite mesh, \(H^1/C^0\) Tonelli package, \(C^1+\ddot\gamma\) penalty package를 충분조건으로 분리했다.

핵심 문장:

$$
W[\gamma]=S_E[\gamma]/\hbar+S_{\mathrm{supp}}[\gamma]
$$

이 good-rate이고 \(\mu_{\mathrm{base}}\)가 recovery mass를 주면

$$
\mu_\beta\Rightarrow\delta_{\gamma_*}
$$

또는 최소집합 근방으로 농축한다.

판정:

`Exact under assumptions`

### 완료: CE action/topology package

[05f_CE_action_topology_package.md](05f_CE_action_topology_package.md)를 추가해 CE continuum 기본 package를 고정했다.

닫힌 것:

- bare \(C^1\)+kinetic action은 compact sublevel이 실패한다는 반례를 썼다.
- continuum 수학 코어는 \(W^{1,p}/C^0\) Tonelli package로 고정했다.
- \(S_{\mathrm{supp}}\ge0\)이고 \(C^0\)-l.s.c.이면 \(W=S_E/\hbar+S_{\mathrm{supp}}\)가 good-rate임을 증명했다.
- finite mesh는 계산/검증 exact approximation으로 분리했다.
- \(C^1\) pathspace는 \(\ddot\gamma\), curvature, acceleration penalty가 있는 강화판에서만 쓰도록 분리했다.

판정:

`Exact under assumptions`, `Selection`

### 완료: CE prior/support package

[05g_CE_prior_support_package.md](05g_CE_prior_support_package.md)를 추가해 CE 농축 정리의 마지막 support 조건을 분리했다.

닫힌 것:

- full support와 l.s.c.만으로는 recovery mass가 나오지 않는다는 반례를 썼다.

- \(\mu_{\mathrm{CE}}\)의 near-minimum 질량은 \(\mu_{\mathrm{ref}}\)의 near-minimum 질량과 동치임을 보였다.

### 완료: CE finite-to-continuum package

[05h_CE_finite_to_continuum.md](05h_CE_finite_to_continuum.md)를 추가해 finite mesh 농축과 continuum CE 농축의 joint limit 조건을 분리했다.

닫힌 것:

- fixed \(N\) finite positive prior는 \(\beta\to\infty\)에서 discrete minimizer로 농축함을 다시 증명했다.
- 모든 finite weight가 양수여도 joint \(N,\beta_N\) limit에서는 minimizer가 사라질 수 있다는 반례를 썼다.
- recovery mass가 \(e^{-o(\beta_N)}\)보다 빨리 죽지 않으면 finite mesh Gibbs measure가 continuum minimizer set으로 농축함을 증명했다.
- compact/continuous package에서 fixed-\(\beta\) finite Gibbs ensemble이 continuum Gibbs ensemble로 약수렴함을 증명했다.
- fixed-\(\beta\) convergence와 continuum zero-temperature concentration을 diagonal argument로 합치는 방법을 정리했다.

판정:

`Exact under assumptions`, physical continuum prior는 `Bridge/Open`

### 완료: CE physical path prior package

[05i_CE_physical_path_prior.md](05i_CE_physical_path_prior.md)를 추가해 물리적 continuum prior를 scaled Brownian bridge로 고정했다.

닫힌 것:

- Brownian bridge는 \(W^{1,p}\)에 질량을 주지 않으므로 raw kinetic density \(e^{-S_E/\hbar}\)는 recovery mass가 실패함을 장애물 정리로 썼다.
- Brownian bridge의 \(C^0_{x_i,x_f}\) full support와 Route W(Feynman-Kac) fixed-\(\beta\) CE 측도 존재를 증명했다.
- \(\sqrt\hbar\)-scaled bridge의 LDP rate가 정확히 \(S_E-\min S_E\), 즉 \(E_{\mathrm{fold}}\)의 kinetic part임을 증명했다.
- bounded \(S_{\mathrm{supp}}\)는 manifest set을 못 바꾸고, \(\beta\)-coupled \(e^{-S_{\mathrm{supp}}/\hbar}\) tilt만 \(\operatorname{argmin}(S_E+S_{\mathrm{supp}})\) 농축을 줌을 증명했다.
- 05g의 recovery mass 공리와 05h의 scaled recovery mass 공리가 이 prior에서는 LDP lower bound 정리로 내려옴을 확인했다.

판정:

`Exact under assumptions`, 남은 `Selection/Open`

`Audit/Selection`, 남은 `Open`

## 3. 증명하면 안 되는 자리

| 자리 | 이유 |
|---|---|
| Born prior 전체 | Gleason류 외부 정리 또는 Hilbert 측도 공리가 필요 |
| CE \(\Phi=E_{\mathrm{fold}}\) 동일시 | action/topology package와 물리 커널 선택이 먼저 필요 |
| Brownian prior가 유일한 물리 prior라는 주장 | 05i는 충분조건 package이지 유일성 정리가 아님 |
| AGI \(\phi\) 재주입 성능 | 증명이 아니라 ablation 실험 대상 |
| 순수 Gamma만으로 Gibbs 분포 전체 결정 | positive-mass recovery와 내부 선택 정보가 빠짐 |
