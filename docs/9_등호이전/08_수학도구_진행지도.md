닫힌 것:

- \(W\)가 가측이고 \(0<\int e^{-W}d\mu_{\mathrm{ref}}<\infty\)이면 CE 확률측도는 존재한다.

- \(F\)의 sublevel 정의를 쓰면 near-minimizer와 비선택 경로공간의 가측성이 닫힌다.
- \(K_\phi(x,\cdot)\in L^1(\mu_{\mathrm{ns}})\)이면 잔류장 readout은 well-defined다.

남은 병목:

$$
E_{\mathrm{fold}}(\gamma)=W[\gamma]-W_{\min}
$$

가 실제 경로공간에서 l.s.c., coercive/good rate, positive-mass recovery를 만족하는지 증명해야 한다.

판정:

조건부 `Exact`, 남은 `Bridge`

### 완료: CE good-rate theorem

[05e_CE_good_rate_theorem.md](05e_CE_good_rate_theorem.md)를 추가해 CE action 농축을 조건부 정리로 닫았다.

닫힌 것:

- \(E\)가 l.s.c.이고 compact sublevel을 가지며 recovery mass가 있으면 Gibbs 측도는 minimizer set으로 농축한다.
- \(W-W_{\min}\) shift는 minimizer와 Gibbs 비율을 보존한다.
- \(S_E\)가 compact sublevel을 만들고 \(S_{\mathrm{supp}}\ge0\)가 l.s.c.이면 \(W=S_E/\hbar+S_{\mathrm{supp}}\)도 good-rate function이다.
- finite mesh, \(H^1/C^0\) Tonelli package, \(C^1+\ddot\gamma\) penalty package를 충분조건으로 분리했다.

핵심 문장:

$$
W[\gamma]=S_E[\gamma]/\hbar+S_{\mathrm{supp}}[\gamma]
$$

이 good-rate이고 \(\mu_{\mathrm{base}}\)가 recovery mass를 주면

$$
\mu_\beta\Rightarrow\delta_{\gamma_*}
$$

또는 최소집합 근방으로 농축한다.

판정:

`Exact under assumptions`

### 완료: hard constraint suppression package

[05k_CE_hard_constraint.md](05k_CE_hard_constraint.md)를 추가해 threshold 조건화를 닫았다.

닫힌 것:

- continuum kinetic action 위의 hard constraint는 null set 조건화라 정의 불능임을 증명했다(05i 장애물의 따름).
- finite-\(N\) 모드 모델에서 조건화는 항상 존재하고, 고정 분율 \(q\)를 주는 threshold는 \(u_{\mathrm{th}}(N)=N/2+z_q\sqrt{N/2}+o(\sqrt N)\)뿐임을 증명했다. 즉 접힘 통과 조건은 절대 작용 scale이 아니라 평균 대비 \(-1.66\sigma\) 요동 조건이다.
- 등분배 정리(경로적분.md 3.2.1)의 경로분율-에너지분율 일치는 유지되지만 central regime 수렴율은 \(O(1/N)\)이 아니라 \(O(N^{-1/2})\)임을 보정했다.
- \(S_{\mathrm{th}}>m\)이면 조건화는 recovery를 보존하고 manifest set을 바꾸지 못함을 증명했다. supp:hard도 분율 층에 속한다.
- layer-cake 항등식 \(\langle e^{-\Phi}\rangle=\int_0^\infty e^{-t}\mu(\Phi\le t)dt\)로 tilt와 threshold 독법을 정확히 연결했다.
- mean-field \(e^{-\langle\Phi\rangle}\)는 Jensen 하한이고 오차는 \(\operatorname{Var}(\Phi)\)로 통제됨을 증명했다. bootstrap 평균장 단계에 반증 가능 조건이 생겼다.

`Exact under assumptions`, 남은 `Selection/Open`

### 완료: PreEq 보편 스킴

[04c_PreEq_보편스킴.md](04c_PreEq_보편스킴.md)를 추가해 "등호 수학 전반에 적용 가능"이라는 주장을 순수수학 명제로 분해했다.

닫힌 것:

- metric target을 갖는 모든 등호 \(F(x)=G(x)\)가 continuous defect \(d(F,G)\)를 받음을 증명했다(residual 인코딩).
- 해집합 수준의 보편성은 자명함을 분리했다. 내용은 defect의 정칙성에 있다.
- 선형 등호 \(Ax=b\)의 manifest가 Moore-Penrose 해 \(A^+b\)이고, \(\ker A\) 방향에는 prior가 잔류함을 증명했다. 퇴화 등호의 selection을 prior가 닫는 정확한 사례다.
- 축약사상 고정점 defect의 거리 하한 \(d(x,x_*)\le\delta(x)/(1-L)\)과 농축, 유한 논리(SAT/max-SAT) 농축을 닫았다.
- 같은 zero set의 defect들이 manifest는 공유하지만 finite-\(\beta\) 잔류 구조는 다름을 증명했다. PreEq 데이터는 등호보다 엄격히 많은 정보다.
- 계산 불가능성, 알고리즘 비용, size 문제는 PreEq가 우회하지 못함을 경계표로 분리했다.
- defect 비증가 사상 category와 근사해 보존 정리를 닫았다. Gibbs 배정의 functor 승격은 `Open`이다.
- 정리 2.1은 `tests/test_pre_eq_universal.py`로 회귀검사를 내렸다(pinv 일치, kernel 방향 prior 분산 보존, least-squares manifest).

판정:

`Exact`, functor 승격은 `Open`

### 완료: \(\Phi\) mode 분해 실재성 감사

[05m_CE_mode_decomposition_audit.md](05m_CE_mode_decomposition_audit.md)를 추가해 05l 정리 5.1의 적용 조건을 감사하고 \(N_{\mathrm{eff}}\)의 관측 하한을 유도했다.

닫힌 것:

- A1 "곱적 분해"가 \(\langle\Phi\rangle\)의 **평균 채널 분해**일 뿐 요동 통계의 분해가 아님을 확정했다(U1-U5 감사). \(\Phi\)의 분포 선언은 문서군에 부재한다.
- 결정론 독법(R1)은 불확정성 floor와 모순, 차원=모드 독법(R2, \(N_{\mathrm{eff}}=D_{\mathrm{eff}}\))은 비율 \(3.78\), 함의 \(\Omega_b=0.184\)로 관측과 약 \(135\sigma\) 충돌하여 배제했다.
- 주장된 \(0.05\sigma\) 일치로부터 유도된 필요조건: \(\operatorname{Var}(\Phi)\le0.041\), Gaussian-mode benchmark에서 \(N_{\mathrm{eff}}\ge445\), 모드 평균 상관 \(\bar\rho\le2.2\times10^{-3}\). mean-field가 가정에서 반증 가능 조건으로 바뀌었다.
- 누적량 흡수와 \(D_{\mathrm{eff}}=3+\delta\) 제1원리성의 양립 조건이 정확히 분산 예산임을 분리했다.
- tilt의 \(\Phi\)(intensive)와 threshold의 \(S_E\)(연장적)가 다른 scaling의 다른 대상임을 분리했다. 총 작용에 mean-field는 불가능하다.
- 정리 3.2-3.3과 4.1은 `tests/test_pre_eq_fraction.py`로 회귀검사를 내렸다(닫힌 형태 vs Monte Carlo 일치, R2 배제, \(N_{\mathrm{eff,min}}=445\), 상관 상한 역수 = \(N_{\mathrm{eff}}\) 하한).

남은 긴장 (`Open/Experiment`):

- 상호작용 \(O(g^2)\approx1.9\%\)가 쌍별 상관으로 들어오면 허용치 \(2.2\times10^{-3}\)를 한 자릿수 초과한다. 상관의 부호와 구조 계산이 필요하다.
- \(N_{\mathrm{eff}}\)의 물리값(컷오프, 부피) 제1원리 추정은 열려 있다.

판정:

`Audit`/`Exact under assumptions`, 남은 `Open/Experiment`

## 3. 증명하면 안 되는 자리

| 자리 | 이유 |
|---|---|
| Born prior 전체 | Gleason류 외부 정리 또는 Hilbert 측도 공리가 필요 |
| CE \(\Phi=E_{\mathrm{fold}}\) 동일시 | action/topology package와 물리 커널 선택이 먼저 필요 |
| Brownian prior가 유일한 물리 prior라는 주장 | 05i는 충분조건 package이지 유일성 정리가 아님 |
| 불확정성에서 \(z_q\) 또는 \(\varepsilon^2\) 값 유도 | 05l은 요동 scale만 고정함. 분위수는 독립 원리 필요 |
| \(N_{\mathrm{eff}}\)의 물리값과 모드 상관 \(\bar\rho\) | 05m은 관측 하한/상한만 줌. 값은 장론 계산 또는 실험 대상 |
| AGI \(\phi\) 재주입 성능 | 증명이 아니라 ablation 실험 대상 |
| 순수 Gamma만으로 Gibbs 분포 전체 결정 | positive-mass recovery와 내부 선택 정보가 빠짐 |
