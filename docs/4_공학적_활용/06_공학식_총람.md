표시한 정의역 밖의 수치 외삽은 별도 모형이다.

## 6.1 공통 단위 규약

**[정의]** 장론 식에서는 \(c=\hbar=k_B=1\)을 기본으로 하고, SI 식에는
\(\hbar,k_B,c,\mu_0\)를 표시한다.

| 양 | 자연단위 질량차원 | 무차원 core에 넣는 방법 |
|---|---:|---|
| \(m,E,k_BT,\hbar\omega\) | 1 | 같은 energy scale로 나눈다 |
| \(t,r\) | \(-1\) | \(Et,\ Er\) |
| scalar field \(\phi\) | 1 | \(\phi/E_{\rm ref}\) |
| \(G_{\rm WKB},\lambda,Q,\chi\) | 0 | 직접 사용 가능 |
| \(S_\beta(\omega)|Y_T(\omega)|^2d\omega\) | 0 | 전체 적분으로 사용 |

**[공리] 외부 benchmark:**
\[
M_\star=29.65\ {\rm MeV}.
\]
이 값은 공학 scan의 비교 scale일 뿐 입자 pole이나 물질 공명의 선언이
아니다.

## 6.2 핵융합 식

### 6.2.1 scalar 교환

**[정리]**
\[
\mathcal L_{\rm int}=-g_i\phi\bar N_iN_i
\quad\Longrightarrow\quad
V_\phi(r)=-\frac{g_1g_2}{4\pi}\frac{e^{-m_\phi r}}r
\]
는 Born·정적·점입자 극한에서 성립한다. 유한 핵에는 form factor가
필요하다.

### 6.2.2 장벽 투과

**[정리]**
\[
G(E)=\frac1\hbar\int_{r_1}^{r_2}
dr\sqrt{2\mu[V_{\rm eff}(r)-E]},\qquad
\log\mathcal T=-2G+o(G)
\]
는 smooth two-turning-point semiclassical barrier의 선도 지수다.
\(G\)는 무차원이다.

### 6.2.3 구동 모드

**[정리]**
\[
\ddot q+2\gamma\dot q+\omega_0^2q=f_0\cos\omega t,
\qquad
A(\omega)=
\frac{f_0}{\sqrt{(\omega_0^2-\omega^2)^2+4\gamma^2\omega^2}}.
\]
\[
Q=\frac{\omega_0}{2\gamma},\qquad
A(\omega_0)=Q\frac{f_0}{\omega_0^2}.
\]
이 \(Q\)는 실제 normal mode의 선형 진폭에만 직접 적용된다.

### 6.2.4 thermal reactivity

**[정리]**
\[
\langle\sigma v\rangle_T=
\left(\frac8{\pi\mu}\right)^{1/2}(k_BT)^{-3/2}
\int_0^\infty dE\,E\sigma(E)e^{-E/(k_BT)}.
\]
\(\sigma(E)\)가 microscopic scattering 입력이다.

## 6.3 열린 양자계와 오류보정

### 6.3.1 GKSL

**[정리]**
\[
\dot\rho=-\frac{i}{\hbar}[H,\rho]
+\sum_{a,b}C_{ab}\left(
F_a\rho F_b^\dagger-\frac12\{F_b^\dagger F_a,\rho\}
\right),\qquad C\succeq0
\]
는 finite-dimensional Markov branch의 completely positive,
trace-preserving semigroup를 생성한다.

### 6.3.2 thermal spectrum

**[정리]**
\[
G_{ab}(\omega)=\int dt\,e^{i\omega t}
\langle B_a(t)B_b(0)\rangle_\beta,\qquad
G_{ab}(-\omega)=e^{-\beta\hbar\omega}G_{ba}(\omega).
\]
첫 식의 positive-type correlator가 Kossakowski matrix의 positivity를
보장하고 둘째 식은 KMS thermal branch의 detailed balance다.

### 6.3.3 Gaussian filter

**[정리]**
\[
W(T)=e^{-\chi(T)},\qquad
\chi(T)=\frac12\int\frac{d\omega}{2\pi}
S_\beta(\omega)|Y_T(\omega)|^2.
\]
\(\chi\)는 무차원이고 이 식은 stationary Gaussian pure dephasing에
한정된다.

### 6.3.4 정확한 code 조건

**[정리]**
\[
PE_a^\dagger E_bP=c_{ab}P
\]
는 고정 error set의 exact quantum correction을 위한
Knill--Laflamme 필요충분조건이다.

## 6.4 초전도 식

### 6.4.1 gap equation

**[정리]**
\[
\Delta_{\mathbf k}=-\sum_{\mathbf k'}
V_{\mathbf k\mathbf k'}
\frac{\Delta_{\mathbf k'}}{2E_{\mathbf k'}}
\tanh\!\left(\frac{E_{\mathbf k'}}{2k_BT}\right).
\]

상수 \(s\)-wave attraction과 \(\lambda=N(0)|V|\ll1\)에서는
\[
k_BT_c=\frac{2e^\gamma}{\pi}\hbar\omega_c e^{-1/\lambda},
\qquad
\frac{2\Delta(0)}{k_BT_c}=\frac{2\pi}{e^\gamma}.
\]

### 6.4.2 spectral glue

**[정리]**
\[
V_\phi(i\Omega,\mathbf q)=
-\frac{g_e^2}
{\Omega^2+\mathbf q^2+m_\phi^2+\Pi_E(i\Omega,\mathbf q)}
\]
는 quadratic scalar를 적분소거한 별도 linear-Yukawa branch다.
exact unbroken \(Z_2\)가 있으면 이 선형 coupling은 허용되지 않는다.

### 6.4.3 Floquet·parametric branch

**[정리]**
\[
H_{\rm vV}
=H_0+\sum_{n\ge1}\frac{[H_n,H_{-n}]}{n\hbar\Omega}
+\mathcal R_2,\qquad
\|\mathcal R_2\|
=O\!\left(\frac{J^3}{(\hbar\Omega)^2}\right)
\]
는 \(J=\sum_n\|H_n\|\ll\hbar\Omega\)인 finite bounded branch의
van Vleck 고주파 전개 첫 항이다. \(H_{\rm vV}\)는 stroboscopic
\(H_F(t_0)\)와 periodic micromotion conjugation으로 연결되어 같은
quasienergy를 갖는다. 약한 parametric oscillator에서는
\[
s=-\gamma+\frac{h\omega_0}{4}+\cdots,
\qquad
h_{\rm th}=\frac{4\gamma}{\omega_0}
+O\!\left(\frac{\gamma^2}{\omega_0^2}\right).
\]
이는 \(0<h\ll1\), \(\gamma/\omega_0\ll1\), exact resonance에서의
rotating-wave 선도식이다. collective mode의 선형 안정성을 말하며 gap
equation을 대신하지 않는다.

## 6.5 인과성과 통신

**[정리]** twist-free null congruence와 null energy condition 아래
\[
\frac{d\theta}{d\lambda}
\le-\frac12\theta^2
\]
이므로 초기 \(\theta<0\)인 congruence는 유한 affine parameter 안에
focus한다.

**[정리]** canonical scalar는
\[
T_{\mu\nu}k^\mu k^\nu=(k^\mu\nabla_\mu\phi)^2\ge0
\]
이어서 최소 branch에서 null energy condition을 만족한다.

**[정리]** 국소 trace-preserving quantum operation은 원격 subsystem의
outcome-averaged reduced state를 바꾸지 않는다. quantum teleportation에는
classical message가 필요하다.

## 6.6 사용 전 점검표

| 질문 | 필요한 입력 |
|---|---|
| 지수·로그 인자가 무차원인가 | energy/time/reference scale |
| scalar branch가 exact-\(Z_2\)와 양립하는가 | charge와 vacuum |
| \(Q\)가 실제 매질 mode의 값인가 | retarded self-energy와 pole width |
| WKB가 유효한가 | turning point, smoothness, semiclassical parameter |
| GKSL가 유효한가 | weak coupling, stationary bath, secular timescale |
| BCS 닫힌형 식이 유효한가 | weak coupling, cutoff, DOS, pairing symmetry |
| Floquet 전개가 유효한가 | drive norm/frequency와 heating timescale |
| 공학 성능을 주장할 수 있는가 | 같은 장치의 transport·thermal·control ledger |

## 6.7 남은 항목

**[미완성]** 현재 공통으로 빠진 것은 CE에서 material/nuclear coupling을
정하는 UV matching, 매질 spectral function, correlated uncertainty,
동일 sample 또는 reactor의 transport 계산과 독립 실험 likelihood다.
따라서 이 총람은 조건부 계산의 출발점이지 점화, 고온 초전도, 양자 우위,
시간조작 또는 물질전송의 수치 예측표가 아니다.
