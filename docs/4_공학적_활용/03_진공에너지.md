# 진공 에너지 공학의 현재 경계

이 문서는 우주론적 진공 에너지와 국소 장치에서 교환 가능한 에너지를
구분한다. 현재 CE에는 두 대상을 연결하는 동역학이 없다.

## 1. 관측 비교 자료

**[정의]** \(\rho_\Lambda^{\rm obs}\)는 선택한 우주론 자료와 모형에서
추정한 진공 에너지 밀도를 뜻한다. 이 값은 CE 작용이나 결합상수의 수학적
출처가 아니며, 모델을 고정한 뒤 사용하는 별도 비교 자료다.

## 2. 일반 제약

**[정리]** 아래로 유계인 해밀토니언 \(H\)의 바닥상태
\(\rho_0\)에서 시작해 최종 해밀토니언도 \(H\)로 돌아오는 unitary
cycle \(U\)에 대해
\[
\operatorname{Tr}(U\rho_0U^\dagger H)
-\operatorname{Tr}(\rho_0H)\geq0.
\]
이는 바닥에너지의 최소성에서 바로 따른다. 따라서 이런 cycle이 장에서
꺼내는 순일은 양수가 될 수 없다. 국소적인 경계조건 변화로 에너지 차이가
생길 수는 있지만, 경계를 만들고 되돌리는 일까지 포함한 전체 에너지 수지를
계산해야 한다.

**[정리]** 공변 작용의 상수항

\[
S_0=-\int\sqrt{-g}\,V_0\,d^4x
\]

은 \(T_{\mu\nu}=-V_0g_{\mu\nu}\), \(p=-\rho\)를 준다.
[증명](../참조/핵심_정리_증명.md#vacuum-stress)

**[정리: 이상적 경계 모형]** 완전도체 평행판, 영온도, 판 넓이에 비해
간격 \(a\)가 충분히 작은 이상화에서 전자기장의 renormalized 에너지차와
압력은

\[
\frac{E_C}{A}=-\frac{\pi^2\hbar c}{720a^3},\qquad
\frac FA=-\frac{\pi^2\hbar c}{240a^4}.
\]

이는 경계조건에 따른 양자장 모드의 에너지 차다. 유한 전도도, 온도,
표면 거칠기와 기하 보정은 별도 입력이다. 판을 원래 위치로 되돌리는
완전 cycle에서는 구동기가 같은 potential 차이를 다시 공급해야 한다.

상수 \(V_0\)의 cosmological stress와 경계 Casimir 에너지차는 서로 다른
renormalized 관측량이다. 후자만으로 새로운 스칼라장, 그 질량, 물질 결합
또는 우주론적 암흑에너지의 추출 경로가 정해지지는 않는다.

## 3. 살릴 수 있는 CE 장치 toy model

**[공리]** 유한 영역 \(\mathcal R\)에서 안정한 \(Z_2\) scalar EFT와
시간의존 경계 매개변수 \(\lambda_{\rm wall}(t)\)를 택한다.

**[정의]** 장치가 장에 한 일은

\[
W_{\rm on\,field}
=\int dt\,\dot\lambda_{\rm wall}
\left\langle
\frac{\partial H_\phi}{\partial\lambda_{\rm wall}}
\right\rangle
\]

로 정의한다. 이는 구동기가 장에 한 일이다.

**[정리]** 닫힌 전체 계에서

\[
\Delta E_{\rm field}+\Delta E_{\rm wall}
+\Delta E_{\rm drive}=0
\]

이다. 따라서 경계 이동으로 순간적인 장 에너지 감소를 얻을 수 있지만,
장치 복귀와 손실까지 포함한 순환 순일은 Hamiltonian 바닥상태의
passivity를 넘지 못한다.

이 toy model은 장치 에너지 수지를 계산할 일관된 출발점이다. 양의 순일
장치가 아니라 동적 Casimir 방출, 경계 work와 손실을 정량화하는 모형으로
살린다.

## 4. CE 응용에서 남은 입력 **[미완성]**

진공 에너지 장치를 정의하려면 최소한 다음 항목이 필요하다.

- 부호와 경계항을 포함한 공변 작용
- 안정한 진공과 섭동 스펙트럼
- 표준모형 물질과의 독립적으로 정해진 결합
- 유한한 장치 기하에서의 경계값 문제
- 구동·제어·복귀 과정을 포함한 전체 에너지 수지
- 사전에 고정한 관측량과 재현 가능한 실험 규약

이 자료가 주어지기 전에는 특정 보손 질량, 포탈 세기, 상관 길이, 카시미르
에너지, 장치 효율 또는 개발 일정을 CE의 산출이나 예측으로 기록하지 않는다.
