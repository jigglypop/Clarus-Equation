# 2. 열린 양자계와 오류보정: 조건부 CE 공학 모형

이 장은 CE가 양자 오류를 자동으로 없앤다고 주장하지 않는다. 유한차원
열린 양자계의 GKSL 동역학, bath spectral density, filter function,
양자오류보정 조건과 선형 추정에서 보존되는 표준 구조를 정리한다.

## 2.1 계·환경·benchmark의 분리

**[정의]** 계의 Hilbert space를 \(\mathcal H_S\), 환경을
\(\mathcal H_B\), density operator를
\(\rho\in\mathcal B(\mathcal H_S)\),
\(\rho\succeq0\), \(\operatorname{Tr}\rho=1\)로 쓴다. 환경 연산자와 독립 scalar
field, Ricci scalar, Hessian readout은 서로 동일시하지 않는다.

**[공리] 모델 선택:** 특정 주파수 스캔에서는
\[
M_\star:=29.65\ {\rm MeV}
\]
를 외부 benchmark energy scale로 둘 수 있다. 이는 bath에 실제 pole이
있다는 명제가 아니다. 비교변수는
\(x_\star=\hbar\omega_S/M_\star\)처럼 무차원이어야 한다.

## 2.2 GKSL 생성자

**[공리] Markov branch:** 유한차원 계에서 시간동차이고 norm-continuous한
양자 dynamical semigroup를 가정한다.

**[정리]** 그 생성자는 적절한 Hermitian \(H_{\rm eff}\), 연산자
\(F_a\), positive-semidefinite Kossakowski matrix \(C=(C_{ab})\)를 써서
\[
\frac{d\rho}{dt}
=-\frac{i}{\hbar}[H_{\rm eff},\rho]
+\sum_{a,b}C_{ab}
\left(
F_a\rho F_b^\dagger
-\frac12\{F_b^\dagger F_a,\rho\}
\right)
\]
꼴로 쓸 수 있다. 반대로 \(C\succeq0\)인 이 식은 trace를 보존하는
completely positive semigroup를 생성한다. 이는 GKSL 정리이며, \(C\)의
수치와 연산자 \(F_a\)는 microscopic coupling에서 별도로 구해야 한다.

**[미완성]** 비-Markov memory, 초기 계--환경 상관, 강결합 또는
time-dependent generator가 중요한 장치에는 위 semigroup 근사가 충분하지
않다.

## 2.3 bath correlator와 spectral rate

**[공리] 약결합 branch:** 상호작용을
\[
H_{\rm int}=\sum_a S_a\otimes B_a
\]
로 두고 \(S_a,B_a\)를 Hermitian basis로 택한다. 정지 bath,
Born--Markov 및 secular 근사를 채택한다.

**[정의]** thermal correlator의 Fourier transform을
\[
G_{ab}(\omega)=
\int_{-\infty}^{\infty}dt\,e^{i\omega t}
\langle B_a(t)B_b(0)\rangle_\beta
\]
로 정의한다. SI 단위에서는 지수의 \(\omega t\)가 무차원이고
\(\beta\hbar\omega\)도 무차원이다.

**[정리]** physical bath state의 positive-type correlator에서 각
\(\omega\)의 matrix \(G(\omega)\)는 positive semidefinite다. thermal
KMS 상태에서는
\[
G_{ab}(-\omega)=e^{-\beta\hbar\omega}G_{ba}(\omega)
\]
가 성립한다. 계의 Bohr-frequency component \(S_a(\omega)\)에 이 matrix를
대입하면 2.2절의 양의 rate matrix를 얻는다.

**[산출]** 한 개 channel에서
\(H_{\rm int}=\hbar g A\otimes B\)이고 \(G\)가 시간 차원을 갖는 convention을
쓰면 rate는 \(\gamma(\omega)=g^2G(\omega)\)다. 결합의 단위나
\(G\)의 normalization을 바꾸면 \(\hbar\)와 단위계수를 다시 넣어야 한다.

## 2.4 독립 scalar bath의 조건부 스펙트럼

**[공리] 별도 EFT branch:** 자유 massive scalar
\[
S_\phi=\int d^4x\left[
-\frac12(\partial\phi)^2-\frac12m_\phi^2\phi^2
\right],\qquad m_\phi>0
\]
와 구체적인 계 연산자 \(S\)에 대한 선형 coupling을 택한다. 이 절의
장론 식에는 \(c=\hbar=1\)을 쓴다.

**[정리]** 자유장의 한-particle spectral measure는
\[
\omega^2=\mathbf k^2+m_\phi^2
\]
위에 지지된다. 따라서 energy-momentum을 보존하는 진공의 on-shell
단일입자 방출은 계의 가용 energy가 threshold보다 작으면 없다. 그러나
local detector가 보는 \(G(\omega)\)의 prefactor와 threshold power는
공간차원, coupling operator와 form factor에 의존하며 질량 하나로 정해지지
않는다.

**[미완성]** CE가 실제 scalar field, coupling operator, bath state와
\(m_\phi\)를 선택한다는 microscopic action은 없다. 기존 전자기·phonon·TLS
잡음도 이 branch를 추가한다고 사라지지 않는다.

## 2.5 Gaussian dephasing과 filter function

**[공리] 모델 선택:** zero-mean stationary Gaussian angular-frequency
noise \(\beta(t)\)가
\[
H_{\rm noise}(t)=\frac{\hbar}{2}\beta(t)y(t)\sigma_z
\]
로 결합하고, 제어 pulse를 \(y(t)\in\{-1,1\}\)로 나타낸다.
두-sided spectrum과 filter를
\[
S_\beta(\omega)=\int dt\,e^{i\omega t}
\langle\beta(t)\beta(0)\rangle,\qquad
Y_T(\omega)=\int_0^Tdt\,y(t)e^{i\omega t}
\]
로 정의한다.

**[정리]** 이 Gaussian branch의 coherence는
\[
W(T)=e^{-\chi(T)},\qquad
\chi(T)=\frac12\int_{-\infty}^{\infty}
\frac{d\omega}{2\pi}\,
S_\beta(\omega)|Y_T(\omega)|^2 .
\]
\(\chi\)는 무차원이다. pulse design은 filter의 지지를 줄일 수 있지만,
모든 주파수의 noise를 동시에 없앤다는 결론은 나오지 않는다.

## 2.6 정확한 양자오류보정 조건

**[정의]** code projector를 \(P\), 고려하는 error operator 집합을
\(\{E_a\}\)라 한다.

**[정리]** 이 error 집합이 code subspace에서 정확히 교정 가능할 필요충분
조건은 Knill--Laflamme 관계
\[
P E_a^\dagger E_b P=c_{ab}P
\]
가 어떤 Hermitian matrix \(c\)에 대해 성립하는 것이다. 이 정리는 특정
수치 threshold를 정하지 않는다.

**[미완성]** fault-tolerance threshold는 code family, decoder, locality,
leakage, syndrome circuit와 noise correlation을 고정한 뒤 finite-size
scaling으로 구해야 한다. 하나의 무차원 상수를 보편 threshold와 동일시할
근거는 없다.

## 2.7 측정과 no-signalling

**[정의]** 측정 outcome \(m\)을 completely positive instrument
\(\mathcal I_m\)로 나타내면
\[
p_m=\operatorname{Tr}\mathcal I_m(\rho),\qquad
\rho_m=\frac{\mathcal I_m(\rho)}{p_m}.
\]
\(\sum_m\mathcal I_m\)은 trace preserving이다.

**[정리]** bipartite state \(\rho_{AB}\)에 Alice가 국소 trace-preserving
map \(\mathcal E_A\)를 적용하고 outcome을 Bob에게 보내지 않으면
\[
\operatorname{Tr}_A[(\mathcal E_A\otimes I_B)(\rho_{AB})]
=\operatorname{Tr}_A\rho_{AB}.
\]
따라서 국소 측정과 얽힘만으로 Bob의 무조건부 통계를 바꾸거나 초광속
신호를 보낼 수 없다. 조건부 state update에는 classical outcome 정보가
필요하다.

## 2.8 선형 Gaussian 추정기

**[공리] 공학 모형:** 숨은 상태와 관측을
\[
z_{n+1}=Az_n+w_n,\qquad y_n=Cz_n+v_n
\]
으로 두고 \(w_n,v_n\)를 독립 zero-mean Gaussian noise로, covariance를
\(Q_n,R_n\succ0\)로 공급한다. 초기상태 \(z_0\)도 알려진 mean과
covariance를 갖는 Gaussian이고 모든 noise와 독립이라고 둔다.

**[정리]** 이 전제 아래 Kalman recursion은 관측 history에 조건부인
최소 mean-square linear estimator이며 Gaussian이면 전체 conditional
mean과 covariance를 준다. Riccati covariance는 모델에 공급한
\(A,C,Q_n,R_n\)에 의존한다.

**[미완성]** 상태 성분을 ADM 변수나 CE field와 동일시하려면 실제 sensor
map, process equation, calibration data와 out-of-sample 성능이 필요하다.
