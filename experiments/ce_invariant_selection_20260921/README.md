# CE-IS1: the missing action-selection premise

The proof is in
[chapter 33](../../paper/후속연구_기록과_상태선택/33_공통작용의_최소_불변항과_진공선택_반례.md).

For a single traceless Hermitian 3 by 3 matrix, invariant zero-derivative
polynomials are generated by the quadratic and cubic traces. On the original
fixed-moment family, the cubic trace is the first nonconstant invariant.
The finite term beta tr(Y^3)/s respects the retained conjugation symmetry,
mass gap, moment constraints, dimensions and infinite-mass decoupling.
It changes the choice between the two endpoint mass orderings.

The analytic phase boundary, its uniform bounds, the full normal Hessian on the
fixed-moment manifold, and reverse response formulas are written in the chapter.
The script compares spectral logarithms with independent resolvent integrals,
checks exact invariant algebra, and verifies the response inversion.
This is not a refutation of chapter 81 when its explicit prohibition on added
shape potentials is retained. It refutes the inference that the other listed
conditions already imply that prohibition.

Run from the repository root:

    .venv\Scripts\python.exe experiments/ce_invariant_selection_20260921/derive_selection.py

No observational data, fit, new field, or assertion of full-goal completion is
used. The example keeps s and epsilon fixed; it proves shape selection and
nonuniqueness, not radius, absolute scale, or full quantum-gravity stability.
