# 사전등록 계약

우주론·양자 holdout의 v1·v2 계약 네 개와 `validate_holdout_manifest.py`를 유지한다.
`rendering_predictions_v1.json`은 43장 렌더링 식 체계의 예측 10개를 2026-09-23에 동결한 계약이며,
`rendering_predictions_v2.json`은 v1을 보존한 채 CMB 단독 H0 예측을 철회하고 θ* 교정·비율 예측 P11을 더했다.
`rendering_predictions_v3.json`은 v1·v2를 보존한 채 R-Pl로 h 적합을 없애고 CMB 단독 H0 예측을 식으로 복원했다.
`rendering_predictions_v4.json`은 BAO 눈금 예측 P14(h r_d)를, `v5`는 나선 긴장 비 P15를, `v6`은 무적합 S8 P16을, `v7`은 중성미자 질량 P17–P19와 사건 척도 P20을 더했다. `v8`은 중성미자 장부 정정(이른 우주 ω_c에서 CE ω_ν 제외)으로 P13·P14·P16을 갱신했다. `v9`는 W1 기각과 W2(진공 기울기, ν=1/2) 채택으로 P16을 갱신하고 P21·P22(w(z))를 더했다. `v10`은 확률 무게 중력에서 P23(BMV 얽힘 0)과 P24(Ω_k = 0)를 더했다. `v11`은 CMB–BAO 그라데이션 G1m에서 P25(BAO 척도 기울기)를 더했다. `v12`는 증명 불가 항목을 P26(사이렌 H0)·P27(κ_λ)·P28(M_H/M_Z) 예측으로 더했다.
`v13`–`v24`는 P29–P41을 더하고 지위 주석을 쌓았다(P17은 `v22`에서 등록 문구 기준 기각). `v25`(2026-09-25)는
감사와 허점 공략(43장 §43.87–43.98)의 지위 변화를 적고 P42(GQuEST 무신호)·P43(우주 시계 H₀ 67.77)을 더했으며,
렌더링 모듈 86개 전부의 해시를 잠갔다. `v26`(2026-09-25)은 43장 §43.99–43.105의 지위 변화를 적고
P44(기록되지 않은 결정 진동자의 슈뢰딩거–뉴턴 자기 중력)를 더했으며, 새 모듈 7개를 더해 93개의 해시를 잠갔다.
판본별 변경 내역은 43장의 각 “사전 등록” 산출 문단과 매니페스트의 `deltas_from_vNN`에 있다.
v1–v24는 2026-09-23–24에, v25와 v26은 2026-09-25에 동결되었다.
`tests/test_rendering_registry.py`가 판본별 자기 해시·코드 해시·예측 재현을 검사한다.
계약의 원문과 해시는 바꾸지 않았다. v1은 v2의 선행 판본 검증에 필요하다.

## 등록 전 문헌 점검

새 예측은 동결하기 전에 kill 조건이 이미 공개된 자료로 충족되는지 확인한다. 충족되면 예측으로 등록하지 않고
기각된 가설로 기록한다. 동결일 뒤에 공개된 자료만 holdout 판정으로 센다. 동결 전 자료로 한 확인은 “보류 자료
확인”이며 적중으로 세지 않는다. P17은 이 점검이 없어 등록 석 달 전의 상한(arXiv:2606.17994, 2026-06)으로
기각되었다(43장 §43.74 정정, §43.87 (나)). 2026-09-25 현재 동결 뒤 자료로 판정된 예측은 0건이다.
v25는 이 점검을 거쳤다. P42와 P43의 kill 조건은 동결일에 공개된 자료로 충족되지 않는다(GQuEST 결과 없음,
우주 시계 H₀ 66.7 ± 5.3). v26의 P44도 같은 점검을 거쳤다. 슈뢰딩거–뉴턴 영역에 이른 실험은 없고 제안만 있다
(PRD 93, 096003; PRD 93, 124049; PRD 96, 044008; arXiv:2310.18072; arXiv:2507.02845; arXiv:2607.06967).

## v25에서 처리한 항목

v24 이후 대기하던 항목은 모두 v25의 `deltas_from_v24`와 model 필드에 옮겼다.
- E4: 보른 배가 근거를 철회하고, 조건부 정리 C6 + E1′ + D + CC로 다시 세웠다(§43.88).
- O1: π/8은 입력이 아니다. 논리값 73.52·1.0848은 P07·P11의 주석으로 달았다(§43.89).
- 사상 M: 고유시간 판본 P로 확정했다(§43.90).
- 코어 네 식: 설명 길이 회계에서 매개변수로 센다(§43.93).
- P17: 등록 시점 주석을 달았다.
- P42·P43: 등록했다.
- HT-δ: 강등했고 등록하지 않는다(§43.98).
- 재가열: 요구 조건으로 적었다(§43.95).

다음 판본의 대기 항목은 아직 없다.

`tests/test_holdout_preregistration.py`가 동결·해시·자료 역할·재피팅 금지를 검사한다.
실제 holdout 배정과 입력 확보는 별도 조건이며, 문법 통과가 평가 준비 완료는 아니다.
삭제된 과거 파일을 참조하는 계약은 실행 가능하다고 표시하지 않는다.

```powershell
python -B -m experiments.preregistration.validate_holdout_manifest --no-verify-artifacts
python -B -m pytest -p no:cacheprovider tests/test_holdout_preregistration.py -q
```

별도 도메인의 미사용 계약과 탐색 노트는 제거했다. 새 계약은 현재 검증기와 연결되는
독립 실험에만 추가하며, 이미 동결한 계약을 결과에 맞춰 수정하지 않는다.
