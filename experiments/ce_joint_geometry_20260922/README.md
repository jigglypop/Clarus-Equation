The rank-three frame has 39 complex ambient components. At the declared
background, real normal variations span six metric components, and horizontal
matrix variations independently span 27 Hermitian connection components.
The code checks every connection basis direction, including spatial variation
of its coefficient, and the joint rank 33.

For the intrinsic local Berry symplectic structure, the trace connection smeared
against a divergence-free vector is a spatial-transport momentum map. Thus it
does not Poisson-commute with the metric. Full Grassmannian gradient evaluations
and the exact torus integral give 9*pi^3*ell^2/(4*hbar), where independent
metric and gauge configuration coordinates would give zero.

A separately supplied joint cotangent structure can retain both fields. Its
microscopic origin, global inverse, record degrees of freedom, and quantum
constraint closure remain open. This is not a completed unification model.
