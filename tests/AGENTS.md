# tests 작업 규약

- `tests/`에는 pytest 회귀·계약 검사만 둔다. 재사용 물리 구현은 `examples/` 또는
  `verify/`, 실험 정의는 `experiments/`, 이론 주장은 `paper/`에 둔다.
- 테스트 통과는 구현·회귀 증거다. 목표·가정·물리 명제를 `[정리]`나 `[예측]`으로
  승격하지 않는다.
- 관측 비교 테스트는 기준·자료·공분산·자유도·허용오차를 고정하고 후보별 재피팅을
  금지한다. 결과를 본 뒤 문턱을 바꾸지 않는다.
- 변경 파일에 가장 가까운 집중 테스트부터 실행한다. 공용 import·경로·수집 규칙을
  바꾸면 `--collect-only`를 추가한다.
- 활성 집합은 `test_repository_harness.py`의 `ESSENTIAL_TESTS` 12개로 제한한다. 새 회귀는
  가능하면 기존 대표 파일에 합치고, 별도 파일이 반드시 필요하면 중복 파일을 대체하며
  allowlist와 이 안내를 함께 갱신한다.
- 활성 테스트의 저장소 경로는 `test_support.paths`의 의미 상수를 사용한다. 테스트 파일에서
  `__file__`의 부모 깊이로 루트를 다시 계산하지 않는다.
