# 뇌 증거 사다리 하네스

Status: `ACTIVE / POLICY`

Date: 2026-08-22

뇌·기억·의식 연구의 주축을 재정의한다. 주 질문은 두 개다:

1. **기전 실재성** — 실제 뇌가 그 연산을 쓰는가.
2. **데이터 검증** — 실제 뇌 데이터로 반증을 시도했는가.

시뮬레이터 성립은 보조 증거이며, 이 두 질문에 답하지 못한 결과는 "추상
알고리즘" 트랙이다. 이 문서가 정본이고 `.claude/CLAUDE.md`와
`.codex/AGENTS.md`의 뇌 절이 이를 참조한다.

## 1. 원시 연산 허용 목록 (bio-established primitives)

뇌 주장을 겨냥하는 run은 아래 확립 기전만 원시 연산으로 쓴다. 각 항목은
1차 실험 문헌 등급이 있다.

| 원시 연산 | 실험 지위 | 근거 계열 |
|---|---|---|
| 스파이크 이벤트 + 간선별 전도 지연 | 확립 | 전기생리 표준 |
| STDP 커널 (스파이크 시차 가소성) | 확립 | Bi & Poo 1998 계열 |
| 3-인자 학습 (eligibility trace × 신경조절 broadcast) | 확립 | 도파민 게이팅 계열 |
| 측방 억제로 창발하는 경쟁 (별도 억제 집단) | 확립 | 억제 뉴런 회로 |
| Dale 법칙 (뉴런은 흥분성 또는 억제성) | 확립 | 표준 |
| 항상성 scaling (목표 발화율) | 확립 | Turrigiano 계열 |
| 2시간척도 간선 동역학 (강도 분~시간 / 존재 일~월) | 확립 | LTP·spine turnover 기준선 |
| 수면 선택적 하향 스케일링 (+replay) | 확립 (SHY vs 형성 논쟁 병기) | de Vivo 2017 / Yang 2014 |

**비허용 원시 연산** (사용 시 그 run은 추상 알고리즘 트랙으로 강등, 뇌
주장 금지): 부호 자유 가중치(Dale 위반), 알고리즘적 WTA(회로 창발이 아닌
argmax 직접 호출), 전역 구조 열거, 생물 대응 없는 supervisory 신호.
강등은 결과 무효가 아니라 주장 상한의 재분류다.

## 2. 증거 사다리

| 단계 | 내용 | 통과 시 주장 상한 |
|---|---|---|
| **L0** | 합성 시뮬레이터 성립 (기전 자유) | "이 알고리즘은 성립한다" — 뇌 무관 |
| **L1** | 관측 무차원 비율 동시 재현 (turnover, 수면 스케일링, 안정분율 등 — sourcer 검증 기준선) | "관측 비율과 정합" |
| **L2** | 부과하지 않은 창발 통계 일치 (log-normal 가중치·발화율 분포, 희소성) | "창발 통계까지 정합" |
| **L3** | 공개 실기록 held-out 예측 전이에서 대안 모델 우위 (DOI 데이터, 사전 고정 비교) | "실데이터 예측 정합" |
| **L4** | 개입(perturbation) 데이터에서 기전 동일성 판별 | 여기서만 "뇌가 이렇게 동작한다" 후보 |

**철칙: L4 이전에는 어떤 문서·보고에도 "뇌가 이렇게 동작한다"를 쓰지
않는다.** L1–L3 통과는 전부 "정합(consistent)"이며 동일성이 아니다. 이는
하네스의 소심함이 아니라 관측만으로 기전을 식별할 수 없다는 인식론적
한계의 명문화다.

## 3. 운영 규정

- 모든 뇌 run의 기계 상태 문자열에 사다리 위치를 명기한다 (예:
  `BIO_EVIDENCE_L1`). 원장 행에도 기록한다.
- L1의 비율 기준선과 L3의 데이터는 ce-physics-sourcer 검증(출처·판·오차)을
  거쳐야 하며, UNVERIFIED 수치는 게이트에 쓰지 않는다.
- L3 이상은 공개 데이터 DOI 매니페스트 필수, 데이터 반출 게이트 준수
  (원본 미커밋, 매니페스트·요약만).
- 승급 요건: 같은 모델 판본이 아래 단계를 유지한 채 위 단계를 통과해야
  한다. 단계별로 파라미터를 다시 맞추면 승급이 아니라 별개 적합이다.
- 기존 BA-TR 시리즈는 **L0으로 소급 재라벨**한다. 단 식별 가능성
  no-go(TR7·TR22·TR28)는 기질 무관 정보 논증이므로 사다리와 독립으로
  유효하다.
- 실패 처리: L1/L2 불합격은 그 원시 연산 조합의 STOP이며 산출이다.
  사다리를 내려가 L0 결과로 재포장하지 않는다 — 상한만 정직하게 기록한다.

## 4. 다른 하네스와의 관계

- 불일치 진단·교정은 `empirical_calibration_loop.md` (D→I→P→C→B→T)를
  따른다. 사다리 단계 간 잔차에서 T(이론) 확정 시 식 개정은 같은 문서
  §8 프로토콜.
- simulator 승격 금지·후보 정렬·재시도 퇴역은 기존 "뇌 알고리즘 경로
  선택" 규율이 그대로 적용되고, 이 사다리는 그 위의 주장 상한 체계다.
