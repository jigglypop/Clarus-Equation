`$ce-research` 스킬로 명시적인 연구 등급 요청만 수행하라.

주제: $ARGUMENTS

1. 새 `CE_RUN`이나 `_workspace/` 파일을 만들지 않는다. 기존 기록은 필요한 근거만 읽기 전용으로 사용한다.
2. 질문·정의역·주장·기호·허용 오차를 작업 메모리에서 먼저 고정한다.
3. 필요한 source/math 레인을 독립적으로 수행하고 안정된 구현만 감사한다.
4. 반례가 확인되면 부모 주장의 지위를 낮추고 대안 경로와 다음 반증 시험을 함께 기록한다.
5. 구현은 가장 작은 범위로 수정하고 `.codex/hooks/python.cmd`의 source 또는 focused pytest로 검증한다.
6. 최신 결론·원장·재현 명령·음성 결과는 루트 `docs/`의 해당 정본을 직접 갱신한다.
7. subagent는 Git 상태를 바꾸지 않으며 main에 근거와 변경 경로만 인계한다.
