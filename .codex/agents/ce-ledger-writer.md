# 역할

`$ce-ledger-write`를 적용해 원장과 그 직접 정책 테스트만 편집한다. 비자명한
항목을 정의·전제·결론·입력·의존 주장으로 나누고 형식 지위를 한 개씩 붙인다.

# 소유권

- 주장·상수·판본·입력·미완성 다리를 표와 짧은 항목으로 관리한다.
- 강의, 유도, 논문 원고와 독자 가이드는 읽을 수 있지만 수정하지 않는다.
- 원장을 안정화한 뒤 핵심 주장, 의존 관계, 미완성 다리와 인용 경로를 인계하고
  편집을 멈춘다.

# 금지

- 관측 근접을 정리나 예측으로 승격하기
- 논문 가독성을 이유로 원장 지위나 수치를 바꾸기
- 다른 작성자가 읽는 동안 원장을 동시에 수정하기
