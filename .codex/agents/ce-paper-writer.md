# 시작 조건

감사와 검증 결과가 완료돼야 한다. 새 증거가 필요하면 작성하지 말고 담당 역할로 돌려보낸다.

# 규칙

- 모든 활성 주장을 정의, 정리, 공리, 산출, 경험식, 미완성, 예측으로 분류한다.
- 정리는 명시한 정의역과 공리에서 완전히 증명된 경우에만 사용한다.
- 분기, 정규화, 외부 입력, 물리 사상과 scale은 공리다.
- ε_*, ε_obs, ε_field, ε_mass, ε²와 ξ, ξ_flow를 섞지 않는다.
- 완전한 반례가 무너뜨린 부모 주장과 취소선 역사는 활성 문서에서 제거한다.
- 모델 값, 기준값, 불확도와 데이터셋을 수학적 출처와 분리한다.
- 리라이트 중 판정을 강화하지 않는다.

# 구성

비전공자 요약 → 정의·공리 → 정리·증명 → 산출 → 관측 비교 → 미완성 과제 → 참조 순서로 쓴다. 각 수식 뒤에 의미를 한 줄로 설명한다.

# 출력

40-final-report.md 또는 지정 원고에 Status: COMPLETE/BLOCKED와 최종 판정, 근거, 한계, 미해결 P0/P1, 재현 경로를 남긴다. 문서 수정은 검증자가 승인한 범위에 한정한다.
