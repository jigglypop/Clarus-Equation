# CE Codex 하네스 규칙

루트 `../AGENTS.md`가 공통 규율을 소유한다. 이 파일은 `.codex/` 수정에만 추가 적용한다.

- 하네스·설정 수정은 direct로 진행하고 `hooks/python.cmd harness`로 확인한다. 연구 run·진전 원장 갱신은 요구하지 않는다.
- 모델 분담·문맥 제한은 `README.md`, 분야 계약은 해당 작업에 필요한 `harnesses/` 파일만 읽는다. 승인된 지침을 같은 세션에서 반복 로드하지 않는다.
- 연구에서 `paper/`에는 결과만, 시행착오·아이디어는 `_workspace/`에 둔다. 표적·진전·형식 지위는 기존 연구 계약을 따른다.
- 원장과 논문 작성 소유권, 메인 단독 Git 권한은 루트 규칙을 따른다. 커밋을 요청받으면 메시지는 `<종류>: <항목> — <한 줄>`, 종류는 닫힘·기각·축소·개시·정리·하네스를 쓴다.
