# CE Codex 하네스 규칙

## 저장 정책 (최우선)

- direct 모드. run 파이프라인은 은퇴했고 `reality_stone`을 전제하지 않는다.
- `paper/`에는 **결과만**. 시행착오·중간 계산·아이디어 주차장은 `_workspace/` 노트(상한은 그 README, harness가 강제).
- 현황판 `paper/진전_원장.md` §2가 유일한 표적이다. 세션은 §2로 시작하고 §2·§7 갱신으로 끝난다. 진전 정의는 `harnesses/closure_budget.md`, 매몰 방지는 `harnesses/goal_pursuit.md`.

루트 `../AGENTS.md`가 기본 정본이다. 이 파일은 `.codex/` 수정 시만 추가 적용. 구조·부채는 `README.md`.

## 라우팅·판정

- 하네스 수정은 direct. 연구 요청은 맞는 스킬 하나만 읽고 독립 레인만 병렬화. 원장 먼저, 논문은 읽기 전용.
- 진전은 예측(추측 카드 채택)·닫힘·기각·축소 넷뿐. 새 장·항목·게이트 분할은 개시·정리다. 새 질문은 식(예측식·예산식)을 먼저 세우고 사다리로 증명한다. 재발견은 축소가 아니라 확장 신호다. 기계 PASS와 관측 근접은 증명이 아니다.
- 새 아이디어는 주차장에 한 줄, 현재 단계 완료 전 실행 금지. 표적 변경은 사용자의 `[범위변경]`뿐.

## 검증

- FAST→STANDARD. 하네스 변경은 `python.cmd harness`, `paper/` 변경은 `python.cmd links`(필수)와 `lint`(권고).
- `harnesses/`의 분야 계약은 그 분야를 검증할 때만 읽는다.

## Git·발행

- 루트 AGENTS의 main-only 규율과 `check-large-data.cmd` preflight를 따른다.
- 커밋 메시지 `<종류>: <항목> — <한 줄>`, 종류는 닫힘·기각·축소·개시·정리·하네스. "new" 금지.

## 설명

- 수학·물리 판단은 1학년 LaTeX와 문과 비유로. 영어 용어는 첫 등장에 한국어 병기 후 한국어만, 새 용어는 폴더 용어사전에 등록.
