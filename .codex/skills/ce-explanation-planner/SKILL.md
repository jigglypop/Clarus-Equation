# 설명 우선 플래너

사용자가 판단을 따라갈 수 있도록 계획과 중간 결론을 채팅으로 설명한다. 구현·연구·감사 스킬의 권한과 지위를
대신하지 않으며, 그 결과를 읽기 쉬운 증명 순서로 번역한다.

## 적용 범위

- 수학식이나 물리 모형의 판단을 내리고 그 이유를 설명해야 할 때 사용한다.
- CE 전체 이론을 설명할 때는 `paper/5_유도/00_선택과_접힘.md`를 먼저 읽고
  **끼임(환경이 선택을 강제함) → 접힘(비선택 성분을 보존함) → 암흑 표현
  (접힌 에너지의 우주론 readout)** 순서를 서사의 뼈대로 삼는다.
- 단순 파일 이동, 포맷 수정, 한 줄 계산처럼 설명 계획이 실질적으로 필요 없는
  작업에는 자동으로 끼어들지 않는다.

## 채팅 설명 계약

판단을 보고할 때 다음 정보를 짧은 순서로 제공한다.

1. 질문을 한 문장으로 다시 말하고, 현재 아는 것과 아직 모르는 것을 분리한다.
2. 기호·정의역·단위를 먼저 선언한다. 지수·로그·확률에 들어가는 인자는
   무차원인지 확인하고, 차원 있는 양은 기준척도로 정규화한다.
3. 핵심 유도를 한 단계씩 정확한 LaTeX로 쓴다. 각 등식 옆에 사용한 공리나
   이전 정리를 표시하고, 계산 결과와 수치 검사를 증명으로 혼동하지 않는다.
4. 같은 내용을 문과 독자도 이해할 수 있는 짧은 비유로 번역한다. 비유는
   수식을 대체하지 않고 어떤 항·경계·선택을 가리키는지 명시한다.
5. 반례·경계·다른 해 가지를 말한다. 한 경로가 막히면 `중단`으로 끝내지
   말고, 목표량과 고정된 전제를 유지한 채 증명 순서를 바꾼 다음 독립 경로를
   제시한다. 새 공리를 넣으면 무엇을 추가했는지 한 줄로 고정한다.
6. 마지막에 각 주장에 `[정리]`, `[공리]`, `[산출]`, `[경험식]`, `[미완성]`,
   `[예측]` 중 하나의 지위를 붙이고, 다음으로 닫아야 할 최소 증명 의무를
   한 문장으로 적는다.

## 설명 깊이

대상 독자는 대학 1학년 수준의 미적분·선형대수·기초역학을 안다고 가정한다.
텐서, 함수공간, 경로적분을 쓰면 바로 뒤에 한 줄짜리 뜻풀이를 붙인다. 예를
들어 Hessian은 “작게 흔들었을 때 에너지가 얼마나 휘는지 재는 행렬”, Schur
보정은 “내부 방을 먼저 정리한 뒤 외부 방에 남는 효과”라고 설명한다. 비유가
실제 가정(경계조건, 측도, 부호)을 숨기지 않게 한다.

## 계획 템플릿

채팅 응답은 필요에 따라 다음 소제목을 사용한다.

- **현재 질문과 결론:** 한 문장 요약과 잠정 결론
- **증명 순서:** 정의 → 가정 → 유도 → 검산
- **직관:** 수식의 역할을 나타내는 비유
- **경계와 다음 고리:** 반례, 미완성 다리, 다음 최소 작업

논문·원장 파일을 수정하는 경우에는 각각 `ce-paper-write`와
`ce-ledger-write`의 소유권을 지킨다. 이 스킬은 문서의 진리값을 승격하지
않으며, 하네스의 기계적 검사 결과를 수학적 증명이라고 부르지 않는다.
