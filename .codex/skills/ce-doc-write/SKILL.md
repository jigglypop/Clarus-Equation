# CE 문서 작성 라우터

이 스킬은 문서 지위를 직접 판정하거나 본문을 대신 쓰지 않는다. 문서 유형을
구분하고, 알맞은 작성 역할이 서로의 파일을 침범하지 않게 한다.

## 형식 지위

활성 주장은 `[정의]`, `[정리]`, `[공리]`, `[산출]`, `[경험식]`, `[미완성]`,
`[예측]` 가운데 하나로 관리한다. 관측 근접은 수학적 증명이 아니며, 외부 입력과
사후 calibration은 독립 예측으로 승격하지 않는다.

## 라우팅

- 주장·상수·판본·진리값 원장은 `$ce-ledger-write`와 `ce-ledger-writer`가
  소유한다.
- 강의·유도·독자 가이드·논문 원고는 `$ce-paper-write`와
  `ce-paper-writer`가 소유한다.
- 두 유형이 함께 바뀌면 원장을 먼저 안정화하고 편집을 멈춘다. 논문 작성자는
  안정화된 원장을 읽기 전용 입력으로 사용한다.
- 두 작성자는 같은 파일이나 지위를 동시에 수정하지 않는다. 원고에서 충돌을
  발견하면 원장 파일·주장 ID·필요한 보조정리를 보고하고 직접 고치지 않는다.

## 문서 유형

원장은 비교와 감사가 목적이므로 표와 짧은 항목을 사용한다. 논문형 문서는 독자가
논증을 따라가는 서사가 목적이므로 태그 블록이나 표만 나열해 본문을 대신하지
않는다.

강의(`paper/1_강의`)와 유도(`paper/5_유도`)를 포함한 논문형 문서는 첫 두 문단에서
무엇을 보이는지, 왜 필요한지, 어떤 순서로 진행하는지 밝힌다. 처음 등장하는
기호를 사용 전에 정의하고, 각 절은 앞 절의 결과와 현재 목적을 잇는 문장으로
시작한다. 유도는 적용한 정의·가정·근사를 밝혀 종이와 펜으로 재현할 수 있게
쓴다.

## 완료 조건

- 원장과 원고의 지위·기호·수치가 일치한다.
- 완전한 반례가 있는 부모 주장은 활성 문서에서 제거한다.
- 외부 입력의 판본·단위·불확도·인용 경로가 남아 있다.
- 논문형 문서를 처음 읽는 독자의 관점에서 정의 순서와 절 사이 연결을 다시
  검사한다.
