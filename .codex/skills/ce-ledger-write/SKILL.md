# CE 원장 작성

원장은 주장의 출처와 현재 지위를 빠르게 감사하기 위한 문서다. 논문처럼 설득하거나 서사를 전개하지 않는다.

## 형식 규약

- 모든 항목에 `[정의]`, `[정리]`, `[공리]`, `[산출]`, `[경험식]`, `[미완성]`, `[예측]` 중 하나의 지위를 붙인다.
- 출처가 있는 외부 입력은 판본, 단위, 불확도와 인용 경로를 기록한다.
- 관측 일치는 형식적 증명이 아니다. 관측 비교와 정리 지위를 분리한다.
- 완전한 반례가 있는 부모 주장은 활성 원장에서 제거하고 반례 경로를 보존한다. 좁혀서 살아남는 명제만 새 항목으로 둔다.
- 지위 승격은 필요한 증명 또는 독립 검증이 실제로 추가됐을 때만 한다.

## 소유 경계

- 주장·수치·판본·입력·미완성 다리를 표와 짧은 항목으로 관리한다.
- 강의, 유도, 논문 원고와 독자 가이드의 문장을 고치지 않는다.
- 원장과 원고를 함께 갱신해야 하면 원장을 먼저 안정화하고, 원장 경로와 의존 관계를 논문 작성자에게 넘긴 뒤 편집을 멈춘다.
- 논문 작성자가 읽는 동안 원장의 지위나 기호를 바꾸지 않는다.

## 절차

1. `docs/axium.md`와 대상 원장의 기존 기호·판본을 확인한다.
2. 비자명한 주장을 최소 단위로 나누고 정의역, 전제, 결론, 입력, 의존 주장을 기록한다.
3. 각 주장에 형식 지위를 하나 부여한다. 복합 주장은 지위가 다른 부분으로 분리한다.
4. 완전한 반례가 있는 부모 주장은 활성 원장에서 삭제하고, 보존 가능한 좁은 명제만 새 항목으로 쓴다.
5. 원장 절은 정의와 정의역 → 공리 → 정리 → 산출 → 관측 비교 → 미완성 과제 순으로 배열한다.
6. 논문 작성자가 쓸 수 있도록 핵심 기여 후보, 정리 의존 관계, 미완성 다리와 인용 경로를 짧게 인계한다.
7. 뇌/AGI 원장은 `.codex/harnesses/real_brain_equation_discovery_loop.md`의 생물 기준식, CE 추가항, 측정모형, 데이터 판본·split, observables, residual, falsifier, matched controls, model selection, revision trigger와 claim ceiling을 분리 기록한다. 새 판본은 구 식의 반례·잔차 링크와 독립 confirmation 계획이 없으면 만들지 않는다.

## 출력 기준

- 표와 목록은 비교·감사에만 쓴다.
- 관측 근접을 형식 지위 판정과 같은 셀에 섞지 않는다.
- 독자 설득용 비유, 장황한 서론, 논문 결론을 원장에 넣지 않는다.
- 수학 내용을 임의로 보완하지 않는다. 증명 공백은 `[미완성]`으로 남기고 필요한 보조정리를 적는다.
