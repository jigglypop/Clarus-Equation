# CE 논문 작성

논문 작성자는 안정화된 원장의 주장과 지위를 읽어, 독자가 따라갈 수 있는 논증으로 바꾼다. 원장의 지위를 새로 판정하거나 수정하지 않는다.

## 소유 경계

- 강의, 유도, 논문 원고, 독자 가이드만 편집한다. 원장은 읽기 전용 입력이다.
- 원장의 지위·기호·수치가 원고에 맞지 않아 보여도 직접 고치지 않는다. 충돌 위치와 필요한 원장 수정을 보고한다.
- 같은 작업자가 원장과 원고를 오가며 동시에 편집하지 않는다.

## 정본 위치

- 상세 논문 정본은 `paper/<분야>/<논문>/`에 둔다. `00_논문목차.md`가 제목·초록·핵심 결론과 `## 논문 조립 순서`를 제공하고, 역할이 겹치지 않는 장별 Markdown을 읽는 순서대로 연결한다.
- 기존 장은 제자리에서 갱신한다. 새 장은 독립된 목적이 있을 때만 추가하고 `_new`, `v2`, `final` 사본을 만들지 않는다.
- 짧은 강의·유도·독자 가이드는 분야 파일을 갱신한다. 한 파일이 여러 독립 절을 반복하거나 논문 길이가 되면 같은 입구+장 구조로 분할한다.
- `_workspace/`와 run의 `artifacts/`에 논문 사본을 두지 않는다. run의 `40-final-report.md`에는 `DOCS_PAPER: paper/<분야>/<논문>/00_논문목차.md`와 결론·증거 경로만 적는다.
- `paper/README.md`와 분야 읽기 지도에는 목차 입구만 한 번 연결하고 장 본문을 복제하지 않는다.

## 개요 게이트

본문보다 먼저 아래 개요를 고정한다. 사용자가 완성 원고를 바로 요청했으면 이 개요를 내부 기준으로 삼고 확인을 기다리지 않는다.

1. 핵심 기여를 한두 문장으로 고정한다.
2. 전제 독자를 "이 주제를 1년 전에 처음 배우던 저자"로 적는다.
3. 문서 유형을 독립 논문, 강의, 유도, 독자 가이드 중 하나로 정한다.
4. 정의 → 보조정리 → 핵심 정리 → 따름정리의 의존 관계를 적는다.
5. 각 절의 목적과 앞 절에서 넘겨받는 결과를 한 문장씩 적는다.
6. 공리, 외부 입력, 근사, 경계조건, 미완성 다리를 본문보다 먼저 목록화한다.

## 구조

독립 수학 논문은 제목 → 초록 → 서론 → 본론 → 남은 문제 → 참고문헌 순으로 쓴다. 별도 결론 절은 두지 않고 서론 앞부분에 핵심 결과를 제시하며, 표준 정의는 필요한 자리로 미룬다.

강의·유도·독자 가이드는 논문의 절 이름을 복제하지 않는다. 첫 두 문단에서 무엇을 보이는지, 왜 필요한지, 어떤 순서로 진행하는지 밝히고 각 절을 목적 문장으로 시작한다.

## 논증

- 원장 지위 `[정의]`, `[정리]`, `[공리]`, `[산출]`, `[경험식]`, `[미완성]`, `[예측]`을 강화하거나 섞지 않는다. 지위 태그는 문단의 표지로만 쓰고, 태그 사이에는 앞 결과와 다음 목적을 잇는 산문을 둔다.
- 완전한 반례로 폐기된 부모 주장은 원고에서 제거하고, 살아남는 좁은 명제와 반례 범위를 함께 밝힌다.
- 외부 입력은 원출처와 판본을 인용하고, 관측 정합을 증명처럼 쓰지 않는다.
- 정의는 그것을 쓰는 정리보다 앞에 둔다. 정리, 보조정리, 따름정리를 구분한다. 본문 증명은 "증명."으로 시작해 `□`로 끝낸다. 정본 증명 원장을 링크할 때는 링크의 범위와 전제를 한 문장으로 요약한다.
- 실증 원고는 독자가 원장을 열지 않아도 표본·판본·단위·estimand·분모·QC·불확도·핵심 수치와 한계를 재구성할 만큼 상세히 쓴다. 계산 성공과 과학적 증명, 기술 bootstrap과 모집단 추론, 같은 자료의 사후 재분석과 독립 확인을 구분한다.
- 직관은 "직관적으로는" 또는 "참고(Remark)"로 표시하고 증명과 섞지 않는다.
- 저자의 독자적 제안은 "본 논문에서 제안하는"이라고 밝힌다. 논증 공백은 문장으로 메우지 않고 원장 작성자에게 돌려보낸다.

## 문체

- 한다체 평서형으로 쓴다. 능동태를 기본으로 하고 이중피동(되어진다, 보여진다)을 금지한다. 조사와 어미를 생략하지 않는다("수렴 확인. 오차 감소." 같은 전보체 금지).
- 한 문단에는 한 아이디어만 둔다. "본 절에서는 ~를 설명한다" 식 매뉴얼투를 쓰지 않는다.
- 번역투는 발견 즉시 교정한다.

| 금지 | 교정 |
|---|---|
| ~에 있어(서), ~함에 있어 | ~에서, ~할 때 |
| ~을 통해 (남용) | ~로, 또는 동사에 녹인다 |
| ~에 대한 분석 | ~ 분석 |
| ~에 중요한 역할을 한다 | 하는 일을 구체 동사로 |
| 존재한다 (남발) | 있다 |
| ~라고 할 수 있다 | 단정할 수 있으면 단정 |
| ~하는 것 (명사화 연쇄) | 동사문으로 |

- AI 상투구 금지: "단순한 A가 아니라 B"와 "A를 넘어 B"(대조는 두 문장으로 나눈다), 문두 매크로(결론적으로, 요약하자면, 핵심은 ~이다), 과장어(흥미롭게도, 혁신적, 획기적, 극적으로), "첫째, 둘째" 병렬, 구어 동사(박다, 얹다, 돌리다). "다만"은 문서당 2회 이하.
- 한 개념에 한 용어만 쓴다. 반복을 피하려는 동의어 변주를 금지한다. 영어 혼입("robust하게")을 금지하고, 용어는 첫 등장에만 "강건성(robustness)"으로 병기한 뒤 한국어만 쓴다.
- 주장 동사는 근거 세기에 맞춘다. 증명했다(완결 증명) > 보였다(수치·계산) > 시사한다(간접) > 추정한다(부분). 한 단계도 올려 쓰지 않는다.

## 수식과 유도

- 인라인 수식은 `$...$`, 별행 수식은 `$$...$$`로 쓴다. 문장 속 기호와 변수도 항상 수식 모드로 쓴다(유니코드 λ가 아니라 `$\lambda$`).
- 처음 등장하는 기호는 사용 전에 문장으로 정의한다: "여기서 $\lambda>0$는 감쇠율이다." 문장을 기호나 숫자로 시작하지 않고, 산문의 논리 기호는 말로 푼다.
- 별행 수식도 문장의 일부다. 앞 문장과 조사로 잇고 블록 마지막에 쉼표나 마침표를 둔다.
- 가정, 정의역, 경계조건, 수렴 조건은 유도를 시작하기 전에 밝힌다.
- 유도는 `aligned` 블록으로 쓴다. 첫 줄에만 좌변을 쓰고 이후 줄은 `&=`로 잇는다. 한 줄에 한 변형만 하고, 각 줄 끝에 `&& \text{...}`로 적용한 정의·가정·법칙을 밝혀 독자가 종이와 펜으로 재현할 수 있게 한다.
- 부호 선택, 근사, 수렴 논거처럼 비약이 생기는 지점에서는 블록을 끊고 산문 한두 문장으로 이유를 쓴 뒤 새 블록을 연다. "자명하다", "쉽게 알 수 있다"로 건너뛰지 않는다.
- 근사 단계는 `=` 대신 `\approx`로 쓰고 오차 차수를 `O(\cdot)`로 명시한다.
- 본문에서 다시 참조할 결과식만 별도 블록으로 빼서 `\tag{n}`을 붙이고 "식 (n)"으로 참조한다.

예시. 유도는 아래 형식을 따른다.

```markdown
감쇠율 $\lambda>0$를 가정한다. 정규화에 필요한 적분 $I$는 다음과 같이 얻는다.

$$
\begin{aligned}
I &= \int_0^\infty e^{-\lambda t}\,dt && \text{정의 대입} \\
  &= \Big[ -\tfrac{1}{\lambda}\, e^{-\lambda t} \Big]_0^\infty && \text{원시함수 계산} \\
  &= 0 - \Big( -\tfrac{1}{\lambda} \Big) && \text{$\lambda>0$이므로 상한에서 소멸} \\
  &= \tfrac{1}{\lambda}.
\end{aligned}
$$

따라서

$$
I = \frac{1}{\lambda} \tag{1}
$$

이고, 식 (1)은 3.2절의 정규화 상수 계산에 쓰인다.
```

## 탈고 게이트

처음 읽는 독자의 눈으로 처음부터 다시 읽고 기호의 첫 등장, 정의 사용 순서, 절 사이 연결, 종이와 펜 재현 가능성을 검사한다. 문자열 검색으로 문체를 점검한다. "단순한/단순히, 에 있어, 되어진, 보여진, 첫째"는 0회, "다만"은 2회 이하, "통해"는 3회 이하, "결론적으로, 핵심은"은 0회. 원장 표처럼 읽히는 강의·유도 원고는 완성으로 보고하지 않는다.
