# 클라루스장 구현 계약 사전등록 (감사 §8 승인 순서 2)

작성: 2026-08-12. 지위: LOCKED_BEFORE_RESULTS — 이 문서 이후 임계·법칙·격자 변경 금지 (ce-design-freedom-ledger 준수). 실행(승인 순서 3)은 컴퓨트 소요가 커서 사용자 승인 후 개시.

## 대상 계

CF-1·2·3·5가 닫힌 결합계: 유한 그래프 $G$ (기본: $N=64$ 무작위 정칙 그래프, 차수는 $D_{\text{eff}}$ 반올림), 디퓨전 $\partial_\tau\phi=-\Delta_G\phi+r\,\mathbf{1}^\top|s|-\lambda\phi$ (D1의 $r=0.1$, $\lambda=0.5$ — 여기서 고정), 국소 latch $s_i'=(1-g_i)s_i+g_i\tanh(\cdot)$, **경성 게이트**(S3): $g_i=\mathbb{1}[e_i>\theta]$, $e_i=\|m\odot x_i\|^2$.

## 상 분류 임계 (고정)

- $\theta_g$: 경성 게이트와 동일 $\theta$ (활성 $\iff$ 게이트 열림).
- $\theta_s = 0.1\,\bar r/\lambda$ (P2-d 무차원화 반영).

## 트랙과 arm

1. **baseline (A-E2 외생 게이트)**: 고정 $\theta$ 2종 — 신호율 매칭 $\theta_{\text{cal}}$, 비매칭 $\theta_{\text{cal}}\times 2$. CF-3 정리 커버리지 확인용.
2. **R-A1 변형 트랙 (P1-3 분기 (나) — 예측 전용, CF-3 커버리지 주장 없음)**: $\theta\leftarrow\theta\exp(\eta[\hat\pi_A-e^{-(1-\hat\pi_A)D_{\text{eff}}}])$, $\eta=0.05$, EMA 창 $0.005$ (route 레인 값 동결). AH1 공리 채택 — 변형 원장 1/3 소모 (계약 기입 완료).
3. **대조군 2종**: (a) 열림률 매칭 무작위 게이트 — R-A1은 게이트 특이성을 주장하지 않으므로 **대조군의 동일 수렴은 사망 조건이 아니라 예상 결과**임을 여기 사전 명기(사후 재해석 봉쇄), (b) 셔플 입력.
4. **R-A3 검정**: 평형에서 binding 차수 분포의 Poisson($D_{\text{eff}}$) 적합(카이제곱, α=0.05 사전 고정)과 비결속 분율 vs $a^*$ 겹침.

## Killing tests (CF-4, 허용 오차 $\|\bar\pi-p^*\|_\infty\le 0.02$)

- KT-1: 신호율 {0.049, 0.12, 0.30}에서 R-A1 트랙의 $\bar\pi_A\to a^*\pm0.02$ — 하나라도 이탈하면 R-A1 사망.
- KT-2: 신호율 2배 계단 섭동 후 burn-in 내 $a^*\pm0.02$ 복귀.
- KT-3: $D'\in\{2,3,D_{\text{eff}},4,5\}$ 스캔 — $\bar\pi_A$가 $a^*(D')$ 곡선(사전 계산 격자)과 전 점 $\pm0.02$ 적합. 실패 시 "부트스트랩 방정식 실현" 해석 사망.
- KT-4: 무작위 게이트 대조군과 셔플 입력에서의 거동 기록 (판정 아님, 특이성 상한 문서화).
- $\pi_S,\pi_F$에 대한 $p^*$ 성분 일치는 **탐색적 기록만** — $(s,b)$가 경험식 공리(P1-1 수리 반영)이므로 판정 게이트로 쓰지 않는다.
