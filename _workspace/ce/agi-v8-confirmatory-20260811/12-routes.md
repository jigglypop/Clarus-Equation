# Alternative routes

Status: COMPLETE

Pre-validation route selection chose R1 from disclosed development data.
After the V8 failure, the retired validation block was used only for route
diagnosis. Tested alternatives were metric-aligned scalar and structured
gains, prefix-local shrinkage, and temporal multi-origin sparse aggregation.

All converged near the same fixed shrinkage solution or performed worse. The
hindsight mean-optimal global scalar `0.8235` still had a negative V5 lower
endpoint. Therefore output readout tuning is closed as the next route.

The successor direction is a training-fitted, two-timescale latent residual
state with a symmetric dense control and a new contraction certificate. It is
not yet preregistered and has no confirmatory status.
