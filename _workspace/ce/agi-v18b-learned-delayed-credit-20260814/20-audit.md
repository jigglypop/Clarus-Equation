## 3. Counterexample and hidden-premise audit

The D3 quantifier is indispensable. Independent but individually
sign-independent distractors or update seeds can drive different same-law
actions in the two branches, producing realized pair accuracy 0, $1/2$, or 1.
The final contract therefore couples the full delay/distractor/message/
topology/update/ensemble/policy tuple and resets each branch to one checkpoint.
The general stochastic claim is explicitly narrowed to expectation.

E2 depends on the exact public marker and latch. Unmarked distractors are
model-defined no-ops, not evidence that relevance was learned. The dense
queries are held-out linear compositions inside the same teacher family, not
semantic OOD. A3 matches A1's real-coordinate count but has no registered
FLOP, memory-traffic, or wall-time equivalence, so no compute-superiority
claim is permitted.

A2's trace lesion must reset its factor to canonical identity while retaining
the active tag until reward; a zero factor would leave SPD(9). Its reward
transition must reread the current factor, preventing a cached-cue bypass.
The homogeneous factor has 45 independent coordinates but 81 dense serialized
entries; neither number is an information-capacity theorem.

E3 is a symmetry no-go for one registered aliasing task, not a claim that an
exact-real SPD matrix has finite memory capacity. Registered finite ensemble
scores do not prove a countable or infinite-depth SCC. Any countable extension
keeps the V17 joint-coupling, measurable-product, and compatibility premises.

The fixed manifest alone would not close ordinary Python package imports,
because executing `clarus/__init__.py` can load unsealed repository modules.
The final contract resolves this by making production self-contained and
requiring the evaluator to load it directly from the sealed file and reject
any unsealed repository module in the live execution closure. Installed
Python/NumPy dependencies are version-recorded but are not cryptographically
sealed. The exclusive receipt is procedural evidence, not secrecy or an
external signature.
