# Validation plan

Status: COMPLETE

No new algorithm experiment was run in this audit. The requested output was a plan and implementation-gap inventory.

Validation hierarchy for subsequent work:

1. Contract tests: causality, shape/type, feature-off equivalence, persistence continuity.
2. Mechanism tests: uncertainty affects trust, critic affects modulation, modulation affects runtime, memory operations are auditable.
3. Stability tests: full augmented belief-state Jacobian or conservative weighted block norm, not component radii alone.
4. Functional ablations: held-out task gain for world model, credit assignment, memory, planning, and sleep.
5. Fresh confirmatory evaluation only after implementation lock and preregistration.

Promisingness score should be computed only after Checkpoint 1 closes. Before that, architecture counts are misleading because the principal causal loop is incomplete.
