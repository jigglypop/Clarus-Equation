가설에서 정리로 올리는 것이 정합이다. 추가 선택이 없다. 증명은 종류 불일치이지 새 포락이 아니다. $E1$--$E2$는 죽지 않는다. 이 기록이 $H1$ 정리 지위의 ce-closure-gate다.

| 「비트값 $K$면 충분하다」 / 「a bit-valued $K$ is enough」 / 「비트값 내부 커널이면 충분하다」 | **활성 삭제.** 완전 반례: 임의의 $K_{\mathrm{bit}}:S\to\{0,1\}$에 대해 $K_{\mathrm{bit}}(H)=\Phi(H)$는 공역이 다르다. 우변은 여섯 칸 튜플. 역사·기각만 남김 |
| 「부분 튜플이면 충분하다」 | **활성 삭제.** $K_{\mathrm{act}}$의 공역은 $[0,1]^2$. $E1$--$E2$는 안 죽음 |
| 「셋째 큐브가 필요하다」 | 선행 기각 유지. 이 레인이 되살리지 않음. 승격 금지 |
| $P$-$A0$--$P$-$A2$, $L4$--$L8$ 공리 | 삭제·강등 금지 |
| 자율 $A$, BrainRuntime, 셋째 큐브, AGI | 승격 금지 |

삭제 수 2 (활성 전칭 「비트값 $K$면 충분하다」, 「부분 튜플이면 충분하다」). $E1$--$E3$와 $H1$은 보존. $L8$-$C6$은 재삭제가 아니다.

좁혀 보존할 참 명제: 등록 $S$에서 공역이 $H$인 $K=\Phi$는 한 스텝 $\Phi$와 같다 ($L8$-$E1$). 같은 $S$에서 $o^{\mathrm{A}}$는 $\Phi(H)$의 충분통계가 아니다 ($L8$-$E2$). 비트값 맵은 그 등식을 종류에서 못 준다 ($L8$-$H1$).

## 9. P0 / P1 / P2

### P0

없음. $L8$-$E1$을 칸 불일치로 죽이는 등록 점이 없다. $E2$를 같게 만드는 작용 $(m',b')$가 없다. $H1$을 공역 등식으로 죽이는 값이 없다. 「비트값 $K$면 충분하다」의 반례는 부모만 죽이고 $E1$--$E3$를 안 죽인다.

### P1

없음. $E1$은 형과 칸 조립이다. $E2$의 작용 차는 선행 $L6$-$E1$ 인용이다. 센서 $u=0$은 한 스텝 부호다. $H1$은 공역 불일치이지 새 포락 공백이 아니다. 수정 루프 불필요.

### P2

1. $K=\Phi$는 $L8$-$D3$ 구성이다. $E1$은 새 맵의 발견이 아니다.
2. 센서 $b'$가 $L6$ 작용 $b'$와 같은 것은 경계 식이 $u$를 보지 않기 때문이다. 새 정리가 아니다.
3. $q'=3/4$는 선행 표지 맵의 형 완결이다. $L6$ 관측량이 아니다.
4. $E3$의 「다음 호스트 공간으로의 맵」은 $o^{\mathrm{A}}$의 공역 $\{0,1\}$보다 느슨하다. 종류 불일치가 더 강하다. 결론은 유지된다.

## 10. 구현 권한

열린 P0가 없고 $E1$--$E3$, $H1$ 지위가 근거와 맞으므로 G-CODE의 감사 전 보류는 해제된다.

- 인가는 기존 커널 위의 작은 형 헬퍼. 쌍의 함수로 충분하면 새 서브시스템 클래스를 두지 않는다.
- V15--V18b, `runtime`, BrainRuntime 배선 금지.
- 셋째 큐브를 더하지 않는다.
- $L8$-$E1$--$E3$와 $H1$을 구성 검사로 잠글 수 있다. 「비트값 $K$면 충분하다」를 산 주장으로, 자율 $A$·BrainRuntime·셋째 큐브·AGI를 코드 주석에 복사하지 않는다. `L8 INTERNAL KERNEL GO`를 `AGI GO`로 쓰지 않는다.
