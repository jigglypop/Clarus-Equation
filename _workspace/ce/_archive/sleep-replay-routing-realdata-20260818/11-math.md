## Definitions and estimands

Let $a$ index animals (or participants), $s$ independently recorded sessions, and $w$ prespecified non-overlapping analysis windows.  Let $Q_{asw}$ be a replay-fidelity score constructed without using the tested routing statistic; $B_{asw}$ a prespecified effective-branching estimator; $H_{asw}$ a transition-entropy estimator; $F_{asw}$ a firing-rate/active-unit covariate; and $C_{asw}$ the remaining prespecified confounders (SWR count, awake time, and protocol nuisance terms).  The H1 estimand is the held-out, animal-level predictive association of either $B$ or $H$ with $Q$, conditional on $F,C$.  It is not a causal effect of branching on replay.

Windows are repeated observations, not independent experimental units.  The independent confirmation unit is an animal when animals are available; otherwise it is an explicitly independent session with no animal contributing to both sides of a split.  A session must never be divided across train and test.

For E19, write $r=\mathrm{REM}$ and $n=\mathrm{SWS}$.  The ratio $r/n$ is not a primary covariate because it discards total sleep and is undefined or unstable near $n=0$.  Use $(\log(r/n),\log(r+n))$ after a preregistered positive-duration rule, or use $r,n$ directly with a stated collinearity diagnostic.  This separates composition from dose.

## Independent derivations and failure modes

### A. Subsampled branching is not invariant

For a stationary count process $X_t$ with $\operatorname{E}[X_{t+1}\mid X_t]=mX_t+c$, suppose each active unit is observed independently with probability $p$, so $Y_t\mid X_t\sim\operatorname{Binomial}(X_t,p)$.  The population lag-regression slope becomes

$$
b_Y=\frac{\operatorname{Cov}(Y_t,Y_{t+1})}{\operatorname{Var}(Y_t)}
=\frac{p m\operatorname{Var}(X_t)}{p\operatorname{Var}(X_t)+(1-p)\operatorname{E}[X_t]}.
$$

Except at $p=1$ (or degenerate limiting cases), $b_Y\ne m$.  Thus an across-window H1 coefficient can be generated by changes in detected-unit fraction, firing rate, or stationarity even when the underlying branching parameter is fixed.  A time-varying observation probability makes the problem worse because it need not be a simple attenuation.

Required control: estimate on fixed, quality-controlled unit sets; include active-unit/firing-rate and detection-quality covariates; assess a prespecified thinning sensitivity curve; and use only within-session standardization if it is applied identically to train and test.  Neither the reported $B$ nor an entropy estimate may be interpreted as an absolute criticality parameter under subsampling.

Nonstationarity is separately fatal to the simple estimator: if $c$ or the mean rate drifts within a window, lag covariance contains the common drift.  Test stationarity on the training data with prespecified rate-change and autocorrelation diagnostics; either split/discard failing windows by a fixed rule or fit a state-space/nuisance-time model chosen before test labels are examined.  Choosing bin size, threshold, state count, or detrending after inspecting the association is look-elsewhere selection.

### B. Transition entropy requires a frozen state map

$H(S_{t+1}\mid S_t)$ changes with bin width, alphabet/state discretization, unit set, and the finite-sample smoothing rule.  The plug-in entropy estimator is downward biased with sparse transition cells.  State mapping, smoothing, bin width, and any bias correction must be fitted/fixed on training animals and then applied unchanged to held-out animals.  Report occupied states, transition counts, and a minimum-count exclusion fixed before outcome analysis.  A lower entropy result with fewer observed neurons is not evidence of altered routing.

### C. Replay windows create pseudoreplication

Adjacent/overlapping replay windows share spikes, SWRs, and slow state.  Treating $N_w$ windows as iid gives an artificial information increase.  Mixed-model random intercepts alone are insufficient if residual serial dependence remains.  Use non-overlapping primary windows; retain all windows only with a session-block/bootstrap or cluster-robust uncertainty procedure clustered at animal, with session nested within animal, and use group-held-out prediction as the decision statistic.  The number of held-out animals/sessions, not the number of windows, determines confirmatory degrees of freedom.

### D. H2 is a predictive comparison, not a nested likelihood-ratio test

The stated linear model and $\alpha+A/[1+\exp(k(B-B^*))]$ are generally non-nested; no ordinary nested-model $\chi^2$ test is valid.  $A,k,B^*$ must be selected/fitted entirely inside each training fold, with $k>0$, a prespecified bounded plausible range for $B^*$, and a constant baseline included.  Compare per-animal held-out log predictive density (or a single prespecified proper score) through an outer animal/session group split.  The sigmoid wins H2 only when its paired held-out score exceeds the linear score under a prespecified one-sided, cluster-level uncertainty interval and its $B^*$ is not at a bound or materially unstable across training resamples.  Otherwise H2 is not supported, even if in-sample fit improves.

## Multiplicity and degrees of freedom

The confirmatory family is: H1 primary exposure (one test), H1 secondary exposure (one test), H2 (one test), H3 (one test), and H4's two named endpoints (two tests): six tests total.  Use Holm adjustment across all six unless the contract is amended before data access.  If both $B$ and $H$ are called primary, or more bin widths, windows, state maps, endpoints, covariate sets, datasets, or route choices are inspected and selected by result, each is an added multiplicity dimension; such analyses are exploratory and cannot be silently folded into the six-test family.

Hyperparameters selected by cross-validation consume no nominal degrees of freedom only when all selection is nested inside the training partition.  The effective confirmation sample size remains the number of held-out groups.  With few animals, report exact group count and intervals; do not make a threshold-based confirmation claim from window-level $p$ values.

## Findings

- P0: the contract's phrase “nested training selection” for linear versus sigmoid is mathematically incorrect.  The models are generally non-nested; a nested likelihood-ratio conclusion would be invalid.  The corrective predictive protocol above is required for RR-H2.
- P0: window-level inference would be pseudoreplication.  Any H1/H2 result using window count as independent $n$ is invalid for the registered confirmation claim.
- P1: raw branching and entropy estimators are not comparable across variable unit yield, firing rate, state maps, or nonstationary windows without the listed controls/sensitivities.
- P1: an REM/SWS ratio alone cannot identify composition separately from total duration and is unstable at a small denominator.
- P2: label shuffles, alternative bins, and source-data reproductions are useful diagnostics only when their selection and multiplicity status are recorded.
