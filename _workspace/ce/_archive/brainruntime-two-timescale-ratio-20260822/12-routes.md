# 12-routes — BA-TS1 우회 경로 탐색

Status: COMPLETE

Date: 2026-08-22

실행 조건: `11-math.md`가 P0 3건(C1·C2·C3)을 확정했으므로 routes를 실행한다.
본 문서는 **후보의 지위·자유도·반증 시험만 기록**한다. 계약 §8이 식 개정(족
변경)을 이 run 안에서 금지하므로 어떤 후보도 여기서 구현·시뮬레이션하지
않았다 — 아래 수치는 전부 해석적 귀결이다. 승격·닫힘 언어는 쓰지 않는다.

## 1. 목표량 (한 문장)

성체 판정 구간(§6, $\Delta t\ge500$일)에서 **총 강도가 순환정상**이면서
야간 총 강도 하강분율 $R3a\in[0.10,0.25]$, 월 turnover $R1\in[0.02,0.08]$,
상위 $\ge15\%$ 보존을 **동시에** 만족하는 무차원 간선 동역학을, 새 공리
1개 이하로 얻을 수 있는가.

## 2. 정본이 강제하는 부분 / 자유 부분

- **강제 (프레임 v2 F1–F5, 본 run에서 건드리지 않음)**: 기질 동결, 강도/존재
  2계층, 각성=쓰기·수면=선택적 하향, 기하는 파생, 잡음은 자원.
- **강제 (관측)**: R1·R2·R3a·R5의 근거 관측 자체 (10-sources.md).
- **자유**: 보존 규칙의 **형태**(순위 vs 준위 vs 손실 등급), 이득의
  **형태**(가법 vs 승법 vs 포화), 정규화 통로의 유무. 계약 §3은 이 셋을
  각각 하나로 고정했으나 프레임 F3는 "보존 분위수를 자유 파라미터로 격리"만
  요구할 뿐 규칙 형태를 강제하지 않는다.

## 3. 왜 구조적 후보가 정확히 3개인가

`11-math.md` 정리 1의 가정은 셋뿐이다:

- **H1** 면제 집합의 손실이 0 (순위 기반 $\mathbf 1[w<q_\theta]$),
- **H2** 각성 이득이 비음 가법 ($+\eta\xi$),
- **H3** $w$에 상한·전역 정규화가 없음.

세 가정 중 하나라도 유지되면서 나머지를 바꾸는 것은 재파라미터화에
불과하다(예: 분위수 $q_\theta$를 절대 준위 $w_c$로 바꾸는 "RT-A′"는 H1을
그대로 두므로 정리 1이 그대로 적용되어 **즉시 사망**한다 — 새 후보로 세지
않는다). 따라서 구조적으로 다른 경로는 H1/H2/H3를 각각 깨는 3개가 전부다.

## 5. 후보별 절

### RT-0 — 게이트 정의 고정 (선행 필수, 족 변경 아님)

P0-1은 족이 아니라 **게이트 집합**의 결함이다. R2를 개체군 8일 생존으로
읽으면 $R1\le0.08$인 모든 정상 birth–death 과정에서 $S_{\rm pop}(8)\ge0.96$
이므로 R2b 대역 [0.60,0.85]와 서로소다. 신생 코호트로 읽으면 서로소는 아니지만
R2a/R2b의 성숙 방향을 만들 기전이 족에 없다(C3). 따라서 어떤 후보 족을
고르든 **R2의 조작정의를 먼저 고정하지 않으면 실패의 귀속이 불가능하다**.
지위: [미완성] (계약 결함). 대역 수정 권한은 본 레인에 없다 — 지목만 한다.

### RT-A — 등급화된 보존 (H1 파괴)

$w\leftarrow w\bigl(1-\lambda_0 s(w)\bigr)$, $s=1$ if $w<q_\theta$, $s=\varepsilon$
otherwise. 정상성은 각 부분모집단이 하루 이득만큼 잃을 것을 요구하므로 상위
집단의 야간 분율 손실은 $p\eta/\bar w_{\rm top}=R3a\cdot\bar w/\bar w_{\rm top}$
이고, $\bar w_{\rm top}\le\bar w/(1-\theta)$에서

$$\text{상위 분위 야간 손실}\ \ge\ R3a\,(1-\theta)\ =\ 0.18\times0.15\ =\ 2.7\%.$$

이는 $\varepsilon,\eta,\lambda_0$에 무관한 하한이다. 교차 예측: 상위 분위가
"무변화"가 아니라 **정확히 $R3a(1-\theta)$ 이상 감소**해야 하며, 이 값은
de Vivo류 EM 측정의 분해능과 직접 대조 가능하다. 강점: dof +1로 R3a·R4·R1을
동시에 열 여지가 생긴다. 약점: R3b의 문면("무변화")을 정량 완화해야 하므로
계약 §5 재발행이 필요하다.

### RT-B — 보존 = 포화 (H2 파괴)

면제 집합은 감쇠도 이득도 받지 않는다($w\ge q_\theta$이면 각성 이득 차단).
그러면 $S_k$가 정확히 상수여서 정리 1의 발산이 사라지고, 질량수지는
$p\eta N_{\rm bot}=\lambda_0M_{\rm bot}$ → $\bar w=p\eta\theta/R3a$로 유한
정상 분포가 가능하다. R3b는 정확히 항등적으로 통과하고 R7은 여전히 0이므로,
두 게이트의 판별력 0 문제(P1-5)는 그대로 남는다. dof 순증 0(포화 상한을
보존 분위에 묶으면). 교차 예측: 강도 분포가 $q_\theta+\eta$ 부근에서 절단되어
상위 꼬리가 없다 — 관측된 spine 크기 분포의 두꺼운 꼬리와 정면 대조.
반증 시험: (i) 상위 분위 spine의 추가 potentiation, (ii) 로그정규 상위 꼬리.

### RT-C — 전역 정규화 / 승법 동역학 (H3 파괴)

승법 이득 $w\leftarrow w(1+\eta\xi)$ + 전 간선 균일 야간 하향 또는 총 강도
target 정규화. log-공간에서 음의 드리프트 + 반사 경계 → 정상 로그정규 분포로,
관측된 시냅스 강도 분포와 프레임 v3의 L2 목표(BA-V3-1)에 정합한다.
그러나 균일 하향이면 $R3a=\lambda_0$이고 상위 분위도 같은 비율로 줄어
**R3b를 정의상 위반**한다. 즉 RT-C는 SHY 대 상위 보존 논쟁에서 상위 보존을
포기하는 선택이며, 계약이 금지한 "어느 진영의 공리 승격"에 해당하는지
audit 판단이 필요하다.

## 6. 순위 (낮은 dof·강한 교차 예측 우선)

1. **RT-0** (dof 0, 선행 필수 — 정의 고정 없이는 어떤 족의 실패도 귀속 불가)
2. **RT-B** (순 dof 0, 발산을 정확히 제거, 반증 시험이 관측 분포 하나로 결정)
3. **RT-A** (dof +1, 파라미터 무관 교차 예측 2.7% — 가장 날카로운 정량 시험)
4. **RT-C** (dof +1, 관측 분포 정합은 최고이나 R3b를 정의상 잃음)
