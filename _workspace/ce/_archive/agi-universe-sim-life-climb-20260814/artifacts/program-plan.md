# Program plan (artifact)

This file is the long-form plan cited by `00-contract.md`. It is not a
canonical `docs/` page and does not promote any layer to a theorem.

## Spine

Universe kernel $U$ is the only step. Life is a subsystem. An internal
simulator $K$, if ever opened, must emit the same kind of variables as $U$.
Operators are added only when the previous state is not a sufficient
statistic of the niche.

V15--V18b, BrainRuntime, and SCC towers are a later parts drawer, not the
spine. Occupancy ratios are not copied into the kernel.

## Layers

L0 finite chemostat step. L1 flux and leak. L2 existing $(m,b,q)$ hybrid
map. L3 label-to-phenotype-to-descendant coupling. L4 weighted routing.
L5 role split. L6 activity closure. L7 region loop. L8 internal kernel $K$.

This run authorizes L0--L3 construction only.

## First increment

1. Host $F_0$ inside $U$ with identical trajectories.
2. Search one-parameter couplings $F_\kappa$ that restore a $q\to(m,b)$
   channel without deleting the extinction wedge.
3. Do not claim autonomy, first life, or AGI.

## Forbidden promotions

Do not identify $q_{\mathrm{label}}$ with a gene. Do not skip to
BrainRuntime. Do not treat a coupled map that still needs an external
`step` caller as experimenter-free lineage.
