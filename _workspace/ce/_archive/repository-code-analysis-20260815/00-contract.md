## Evidence rules

- 코드 주장은 파일과 1-based 줄 번호로 근거를 남긴다.
- 동적 주장은 실행 명령, 종료 코드와 요약 결과를 남긴다.
- 수치 일치와 테스트 통과를 수학적 증명으로 간주하지 않는다.
- 현재 작업트리의 기존 변경은 수정하거나 되돌리지 않는다.
- 외부 웹 자료는 사용하지 않는다. 의존성의 최신성이나 외부 사실이 필요한 항목은 이 run의 판정 범위 밖으로 명시한다.

## Tolerances

- 테스트: 기대 종료 코드 0. 실패·수집 오류·경고는 개수와 원인을 분리한다.
- 수치: 각 테스트/정본이 선언한 허용오차를 우선한다. 선언이 없으면 구현의 dtype과 문제 조건을 고려해 별도 판정하며 임의 허용오차를 도입하지 않는다.
- 정적 품질: 재현 가능한 결함 또는 구체적 실패 경로만 P0/P1로 올린다. 선호 수준의 설계 의견은 P2로 제한한다.
