## 3. 파생 결론의 지위

- **"튜플 = 출처 불명 동결 공리, 형식 지위 [공리]" — 타당.** 지위 7종 정의상 [공리] = 독립 전제·외부 입력이며, 튜플은 (a) 체인 산출 아님(A-2), (b) §5 기록 관측 아님(A-3), (c) 런타임이 실제 소비하는 독립 전제. [경험식]은 부적합 — 관측·수치 패턴에서의 선택을 입증할 근거가 기각됐다. 레지스트리 자체 표기(AXIOM)·선행 run R-U1-LEGACY [공리]와 3중 정합.
- **우주론적 명명($\Omega$ 해석) 유지 — 부당.** 튜플은 CE 유도값도 관측값도 아님이 확정됐으므로 $\Omega_\Lambda/\Omega_{DM}/\Omega_b$ 표기는 존재하지 않는 우주론적 계보를 암시한다. 무우주론적 명명(ACTIVE/STRUCT/BACKGROUND) 유지 + 출처 불명 명기가 유일하게 정직한 표기다. 계약은 무우주론적 명명 유지를 (H-a) 분기에만 걸었으나, UNRESOLVED 하에서는 더 강한 이유(양쪽 계보 모두 기각)로 같은 결론이 성립한다. `bootstrap_solver.py`의 `*_OBS` 접미는 P2-1로 후속 정리 대상.
