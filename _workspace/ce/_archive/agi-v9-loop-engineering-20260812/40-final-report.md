# V9 first loop-engineering closure

Status: COMPLETE

## Verdict

The mathematical infinite-tail theorem survives, but the first task architecture is stopped.
It gave every V9 shell the same weak local recurrence and then compared it with an explicit
bank of slow modes. The experiment correctly rejected that architecture.

The only empirical statement retained is narrow: cross-level state changed behavior relative
to reset/cut controls. It did not outperform the registered monolithic comparator, so no task
utility, AGI, or confirmation claim survives.

## Required redesign

The successor must inherit the CloudCell audit boundary:

1. local temporal state is the base object;
2. the monadic object is the typed transition kernel, not a neuron or shell;
3. cross-level/cloud state is admitted only if full beats local-only and cloud-only under equal
   optimization and compute budgets;
4. level-specific timescales must be part of both candidate and matched controls;
5. readout must expose local and shared increments separately rather than averaging all levels;
6. the stopped seed block and confirmation block are not reused.

The new architecture is a separate model and requires a fresh contract and fresh seed roles.
