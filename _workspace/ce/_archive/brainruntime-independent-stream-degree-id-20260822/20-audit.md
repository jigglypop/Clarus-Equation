## 감사 항목별 소견

### 1. 형식 지위·기계 문자열

- 선행 상태 문자열(`CONDITIONAL_..._PASS` 등)은 §2 표에서 원장 상태로 인용 격리 — 이론 지위 승격 없음.
- `CLASS_EXTERNAL_ABSTAIN`, `CUE_DEGENERATE`는 fail-closed 프로토콜 라벨 — 적법.
- 11-math의 "수치 일치는 증명이 아니다 … a1·a3·b만이 정리" 자체 강등 명시 — 정합.
- P2-a: 계약 endpoint(§4.3)가 예측 지위 요건을 실질 충족하나 7종 어휘 태그가 없음. 1문 표기 권장.

### 2. 숨은 공리

### 3. 반례 처리 (P0-1 → R1)

- 수리 경로가 반례 기전을 직접 죽인다: 반례의 원인은 레버리지 꼬리 $1/(1-h)$이고, studentized PRESS는 성분 표준편차를 정확히 $\eta$로 만들어 꼬리를 제거, $N\,14\to24$는 $p/N$ 자체를 낮춘다. 6000-draw에서 false abstain 0 — 반례 재현 불가. 해소 인정 (calibration 신선 통과 조건부).
- 미해소 잔존 P1-3: 계약 §5.1이 "2.24배 최박, 게이트 완화하지 않음"으로 명시 기록 — 정직성 요건 충족. 잔존 리스크는 development 실패 시 §4.7-5 STOP으로 처리되는 구조라 계약 정합.

### 4. look-elsewhere 규율

- §5.1 마지막 항목과 12-routes look-elsewhere가 "설계 근거 ≠ 통과 증거"를 명시하고 calibration 117001 신선 통과 + 통과 후 재변경 불가(§4.7-3)를 요구 — 충족.
- P2-d: R1 채택 시점이 "development 개봉 전"으로만 기재. §5 교정 레지스터의 calibration 단계 허용 범위를 §4.2 통계·N 변경이 문면상 초과한다(12-routes가 자체 지적). run 내 실행 산출물 부재로 seed 일체 미개봉 상태의 계약 개정으로 읽히며 그 경우 정합 — "R1은 seed 일체 미개봉 상태에서 채택됨" 1문 명시로 닫을 것.

### 5. 선행 재시도 금지 조건

| 선행 | 금지 조건 | 본 계약 | 판정 |
|---|---|---|---|
| TR28 | threshold·seed·split·control 재조정, STOP 뒤집기 | random 3-packet endpoint 미재사용, δ-완성 no-go §6 보존, 신규 기전(차수 선택+기권+독립 은행) | 비침해 |
| TR29 | 예측·기준선 유도 decoy, 은행 중심화 | §4.4가 두 경로를 명시 금지 | 비침해 (원장 admission 일치) |

R1은 본 run 자체 설계의 pre-data 개정이며 선행 run endpoint 재조정이 아님 — "endpoint·threshold·seed만 바꾼 재시도" 퇴역 규정에 해당하지 않음.

### 6. 부 endpoint 독립성 영수증 (P1-B)

§4.4는 금지 선언(정의)만 있고 검증 가능 산출물이 없다. §4.1의 packet 영수증은 runtime 층이지 후보 은행 층이 아니다. 필요 규격: (i) 은행 $\{c_k\}$ 생성·직렬화 해시가 $\hat y_q$ 계산 이전에 기록되는 순서 영수증, (ii) matched-norm 기준 = 비query 셀 content 통계 명시 (진리 norm 기준이면 §4.4 자기 위반), (iii) carve-out 자구("전원이 (seed, 생성기, 비query 셀)만의 함수" 대 진리 원소) 정리. run 제목 주장("독립 후보 스트림")의 핵심이므로 방치 불가 — P1.
