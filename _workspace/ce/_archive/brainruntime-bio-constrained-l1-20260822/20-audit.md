## 2. 쟁점 판정

### 2.1 [A-1] λ(w) 발산 반례의 등급 — P1이 옳다

- 현재 지위: 11-math §11 P1-1 (기전 귀속 오류). snapshot은 P0.
- 기준 적용: P0는 "주장을 무너뜨리는 결함"이다. 계약의 활성 주장은 §1 "허용 원시연산 조합이 게이트를 동시 만족하는지 **시험**한다"(실패도 산출)이지 "λ(w)가 안정화한다"가 아니다. "λ(w)>0가 TS1 정리 1을 흡수한다"는 §2 승계 처방 표의 기전 귀속 문장이고, 동결 모델 전체(§3.1–3.4)는 정리 1(iv)에 의해 항상성 수축 $\bar c<1$ 하에서 순환정상상태를 가진다. 반례는 $c\equiv1$(§3.4 차단, $\beta=0$) 부분모형에서만 성립하며 이는 동결 모델이 아니다. 적합 결론이 아직 없으므로 뒤집힐 결론도 없다. 두 판본의 수치 witness는 합치(독립 재현) — 이견은 등급뿐이고, snapshot의 P0는 §3.4를 제외한 부분모형을 계약 전체로 오독한 결과다.
- 잔여 위험(P1인 이유): 유일한 안정화 기전 §3.4가 이득 $\beta$·locus를 미선언([미완성], A-5) — impl이 항상성을 약하게 잡으면 TS1 no-go가 재발한다. 수정 범위: BA-V3-2 §2 승계 처방을 "$\lambda>0$ + 항상성 수축 $c<1$ ($\beta>0$·locus 선언)"으로 정정. 본 run 계약은 동결 유지(재발행 사안).

### 2.2 [A-2] source lock 실패 — 처분 (a), 새 계약 필수 — **P0 (열림)**

- 10-sources 재감사: R1′ `UNVERIFIED_AS_GATE`, R3b′ 게이트 미검증(CI 없는 $(0,0.05]$ 정밀 대역 제거), R4′·R5′ 원자료 부재로 제거, R6′ formation contrast로 재정의, "전 gate 동시 적합은 source lock 불통과 — 구현 불가".
- (i)/(ii) 구분: 재감사 근거는 전부 **출처 검증 유래(B-class) 문면**이다 (subgroup CI/SE 부재, longitudinal dataset·estimator 부재, 1.5 비의 출처 부재, Yang 2014는 8시간 형성 대조). 결과값 참조 흔적 없음. **그러나** 재감사(08-23)는 대리 모형 7,167점 탐색보다 뒤이고, 영향 게이트 중 R5′·R1′는 대리 최선점이 놓친 게이트에 속한다. outcome-blind임을 감사가 **증명할 수 없으므로**, 새 하네스 §4("필요한 변경은 새 계약")와 TS1 선례의 엄격한 쪽을 적용한다.
- 처분: **(a)** — `SOURCE_LOCK_FAIL / CONTRACT_SUPERSEDED`로 STOP-완결 (부정 결과도 산출). (b) run 내 §5 재정의는 하네스 §4 위반이라 기각. 30/31 구현·채점은 열지 않는다 (하네스 §3-1).
- 등급: **P0 (A-2)** — 계약 §5 게이트 배터리가 채점 도구로서 무효. revise로 해소 불가(§5 재발행 = 필수 필드 12종의 새 계약) → Gate BLOCKED의 직접 근거.
- 오염 방지 조항: BA-V3-2의 게이트 대역·정의는 **출처 수치만** 입력으로 한다. 대리 탐색 결과(어느 게이트가 어렵고 쉬운지)를 대역 설계 입력으로 쓰는 것을 명시 금지한다.
