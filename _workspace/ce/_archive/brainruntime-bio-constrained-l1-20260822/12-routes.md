## 3. 왜 구조적 후보가 이 다섯인가

`11-math.md` 정리 2의 가능 조건은 세 양 $(f_{\rm top},\theta_G,\lambda\text{의 형상})$과
제거 규칙, 그리고 게이트 정의에만 의존한다. 막힘의 원인은 다음 넷 중 하나다.

- **G1** 각성 이득이 가법·$w$-무관·i.i.d. ⇒ $\theta_G$가 창발이 아니라 고정
  (대리 모형 실측 중앙값 0.353).
- **G2** 수면 법칙의 무릎 형상이 $(\lambda_0,\kappa)$ 2개 + 지수 2로 고정
  ⇒ $s_{\rm bot}/s_{\rm top}$ 달성 가능 대비가 제한.
- **G3** 제거가 경성 임계 + 고정 $(w_0,\tau_e)$ ⇒ "성체 풀 4%/월"과 "신생
  27–40%가 8일 내 사망"이 같은 한 규칙에서 나와야 함.
- **G4** 게이트 정의 분기(R2' 하위 정의, R1' 분자)가 열려 있어 목표 자체가 2값.

G1–G4를 각각 여는 후보와, 어느 것도 열리지 않을 때의 범위 축소 salvage —
합쳐 다섯이 전부다. 이들 중 하나를 유지한 채 다른 표기를 바꾸는 것
(예: $\kappa$를 분위수로 재파라미터화, seed·창 끝점 변경)은 재파라미터화이며
후보로 세지 않는다.

## 5. 후보별 절

### VR-4 — 게이트 정의 분기 고정 (선행 필수, 족 변경 아님)

R2'(N)의 하위 정의와 R1' 분자는 게이트 값을 대역폭보다 크게 움직인다
(0.36 vs 0.25; 0.040↔0.110 vs 폭 0.06). 더 중요한 것은 **연쇄**다:
(N-a)를 택하면 $R6'\le1/R2'_{\rm ad}$ 천장이 걸려 $R2'_{\rm ad}\in(0.769,0.85]$가
R6'와 서로소가 되고, (N-b)를 택하면 §6 창 길이가 게이트 값을 0.63↔0.94로
움직이는 사실상의 적합 파라미터가 된다. dof 0, 비용 최저, 다른 두 게이트의
성패를 결정 → **1순위**. 반증: 원문 분모가 (P)로 확정되면 TS1 P0-1 복귀.

### VR-1 — 실 모형에서 $\theta_G$·eligibility 형상을 창발시킴

대리 모형의 S1이 지운 두 자유도(간선별 quenched 이질성, $w$–$\Delta$ 상관)를
실 스파이크 회로가 복원한다. 새 공리 0. **사전 등록 가능한 단일 수치 시험**:
적합점에서 $R3a'$를 대역 안에 두고 $(f_{\rm top},\theta_G)$를 측정해
$1.159<f_{\rm top}/\theta_G<4.171$ (일반형 $\frac{1-R3b'}{1-R3a'}<\frac{f_{\rm top}}{\theta_G}<\frac{R3a'(1-R3b')}{R3b'(1-R3a')}$)
를 확인. 대리 모형은 1.116으로 하한 바로 아래에 있었고, $w$–$\Delta$ 양의
상관은 $\theta_G$를 키워 창을 더 좁히므로 **이 시험은 실패 쪽으로 기울 수 있다**.
이 경로가 죽으면 "허용 원시연산 조합의 L1 STOP"이 해석적으로 확정된다.
부수 예측: $\gamma\ge0.2195$ (각성 순 증가 ≥22%/일), $\lambda_0>0.219$,
$\sigma_{\log w}\in(0.108,1.812)$.

### VR-3 — 제거를 강도 의존 hazard로 (새 공리 1, 본 run 밖)

경성 임계는 성체 풀의 4%/월과 신생의 27–40%/8일을 **하나의 임계와 하나의
$\tau_e$**로 동시에 내야 한다. 민감도(§6, 11-math)에서 $\tau_e$ 단독이
R2'-adult를 0.403↔0.931로 옮긴다는 사실은 이 규칙이 두 스케일을 분리하지
못하고 하나로 묶고 있다는 신호다. hazard $h(w)$는 두 스케일을 형상으로
분리한다. 단 §3.3 식 개정이므로 본 run 밖이며, 반증 시험은 성숙 통로
($q_p^{ad}/q_p^{dev}\ge1.33$) 확보 여부다 — 항상성 대비 $c_{dev}/c_{ad}$가
$\gamma\to\infty$에서 2/3로 포화하므로, hazard 없이도 통로는 있으나 대비 상한이
존재한다는 점이 이 후보의 근거다.

### VR-2 — 수면 무릎 지수 자유화 (새 공리 1, target-aware, 본 run 밖)

$s_{\rm top}\le0.05$와 $s_{\rm bot}\approx0.31$을 동시에 내려면 두 군이 $\kappa$를
사이에 두고 충분히 분리돼야 한다 ($\lambda_0{=}0.3,f_{\rm top}{=}0.4$에서 요구비
6.32 > 로그정규 실제비 2.67 → 불가; $\lambda_0{=}0.5,f_{\rm top}{=}0.5$에서
3.83 vs 4.00 → 가능). 지수 $n$은 이 대비를 직접 조절한다. **target-aware**로
표시한다 — 막힌 게이트를 본 뒤 고안됐다. 위험: $n$이 커질수록 $\lambda$는
계약 §2가 금지한 절대 면제 지시함수에 수렴하므로, $n\gtrsim4$를 요구하는
적합은 **퇴역 경로 재도입**으로 즉시 기각한다. 이전 실패(TS1 RT-A/절대 면제)와
독립적인 기전이라 볼 수 있는 구간은 $n\in(1,4)$뿐이다.

### VR-5 — 범위 축소 salvage (dof 0)

동시점 유무와 무관하게 이 run이 이미 확보한 것:
(i) **정리 1(iv)** — $\bar c<1$ 하 순환정상상태 존재 충분조건과, $\lambda>0$
단독으로는 불충분하다는 반례(정리 1(iii), $\beta{=}0$에서 $\bar w=2166.9$);
(ii) **정리 2** — R3a'×R3b'×R4'의 닫힌 정합 창과 그것이 함의하는 L2 E1 폭
구속 $\sigma_{\log w}\in(0.108,1.812)$;
(iii) R1'×R2'(N)의 2-혼합 동시 가능 창 (TS1 P0-1의 해석적 해소).
이 셋은 사전 등록 가능한 교차 예측이며, "8게이트 동시 만족"을 주장하지 않는
좁은 산출로 남는다.

## 6. 순위와 근거

1. **VR-4** (dof 0, 두 게이트의 성패를 결정, 즉시 실행 가능)
2. **VR-1** (dof 0, 단일 수치 시험으로 조합의 생사를 가름, 교차 예측 최다)
3. **VR-3** (새 공리 1, 기전이 명확하고 이전 실패와 독립)
4. **VR-2** (새 공리 1, target-aware, 퇴역 경로 경계에 인접)
5. **VR-5** (salvage — 1–4가 모두 죽어도 남는 산출)

낮은 dof·강한 교차 예측 우선 규칙에 따랐다. 결과 수치가 좋아 보이는 순서로
정렬하지 않았다 (VR-2가 가장 쉽게 게이트를 통과시킬 수 있으나 4순위다).

## 8. 경로로 해소되지 않는 잔여 결함

- **R3b' 하한의 판별력 0**: §3.2가 $\lambda>0$을 구조로 강제하는 한 어떤
  후보에서도 자동 해소되지 않는다 (VR-2에서는 오히려 고착).
- **R4'의 낮은 판별력**: 항상성이 총 질량을 직접 고정하므로 무작위 상자의
  90.7%가 통과한다. 판별력 있는 형태(개수 표류 또는 분포 형상 표류)로 다시
  쓰는 것은 §5 재발행 사안이다.
- **숨은 설계 상수 4개**($w_0,\tau_e$, eligibility 형상, $\beta$)는 다섯 후보
  전부에 그대로 남는다. VR-3만 $\tau_e$를 흡수한다.
- **E2의 실 모형 전용성**: 대리 모형으로는 판정할 수 없고, 뉴런별 항상성이
  구조적으로 억누른다는 우려는 §3.4의 locus 선언 없이는 어느 후보로도 풀리지 않는다.
