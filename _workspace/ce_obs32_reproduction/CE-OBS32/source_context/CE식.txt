**암흑부문에서 한 단계 더 나아가, 같은 스펙트럼 함수가 중력의 곡률 반응·세 힘의 결합 보정·뮤온의 전자기 반응을 함께 정하는 식까지 연결했습니다.** 각각에 다른 보정함수를 붙이는 대신, **한 함수의 질량제곱 미분으로 여러 효과가 따라 나오도록** 구성했습니다.

**계산과 재현 문서는 마감했지만, Git 푸시는 완료하지 못했습니다.** 현재 연결에는 쓰기 기능이 없고 직접 Git 접속도 실패했습니다. 원격 기록을 덮어쓰지 않는 **14개 파일 추가 패치**를 만들어 적용 검증까지 끝냈습니다.

먼저 이번에 얻은 통일 관계부터 설명하겠습니다. **완성된 것은 명시한 유효장론의 공통 반응식이며, 모든 힘의 절대 세기와 질량까지 결정하는 최종 통일장이론은 아직 아닙니다.**

## 1. 이번의 핵심 통일식

지난번에는 공통 스펙트럼에서 암흑입자의 질량·위상 퍼텐셜·에너지 교환을 연결했습니다. 이번에는 같은 순환위상에 반응하는 **하전 매개장**을 추가해, 그 스펙트럼이 가시적인 세 힘에도 어떻게 나타나는지 계산했습니다.

공통 함수 \(\mathcal U\)를 정의하면 결과는 다음처럼 묶입니다.

\[
\boxed{
\begin{aligned}
U_R
&=d_R\,\mathcal U,\\[1mm]
\Delta C_{\mathrm{grav},R}^{E}
&=d_R\left(\xi_R-\frac16\right)
\frac{\partial\mathcal U}{\partial s_R},\\[1mm]
\Delta\!\left(\frac1{g_a^2}\right)
&=-\frac{T_a(R)}3
\frac{\partial^2\mathcal U}{\partial s_R^2},\\[1mm]
\Delta_\pi a_\mu^{R,\mathrm{EM}}
&=
\frac{2\alpha^2m_\mu^2\mathcal Q_2(R)}{45}
\frac{\partial^3\mathcal U}{\partial s_R^3}
+\text{고차 보정}.
\end{aligned}
}
\tag{1}
\]

여기서 \(s_R\)은 공통 대각 질량제곱, \(d_R\)은 해당 표현의 성분수, \(T_a(R)\)는 각 게이지 힘에 대한 표현 계수, \(\mathcal Q_2(R)\)는 전기전하 제곱의 합입니다. \(C_{\mathrm{grav}}^E\)는 유클리드 유효작용에서 곡률 \(R\) 앞에 생기는 계수입니다.

**같은 입자 스펙트럼이 만드는 퍼텐셜과 중력 반응, 게이지 보정, 뮤온 반응을 서로 독립적으로 고를 수 없다는 결과입니다.**

다만 세 번째 줄은 **게이지 결합의 보정**, 네 번째 줄은 **뮤온 자기모멘트의 특정 전자기 구성항**입니다. 전체 중력·전체 표준모형·전체 \(g-2\)를 모두 계산했다는 뜻은 아닙니다. 열핵 전개와 질량행렬식에 대한 저에너지 정리는 기존 QFT 도구이며, 이번에는 이를 우리가 만든 순환 스펙트럼에 적용해 연결했습니다. citeturn641711view0turn641711view2

또 **미분 차수 1·2·3을 공간 차원이나 힘의 발생 순서로 해석하지 않았습니다.** 같은 질량 원천을 바꿨을 때 각 물리적 반응이 어떻게 연결되는지를 나타냅니다.

## 2. 그 공통 함수는 임의로 맞춘 함수가 아닙니다

세 관계를 순환시키는 행렬을 \(S\), 순환위상을 \(\theta\)라고 하고,

\[
S^3=I
\]

를 유지했습니다. 각 물질표현 \(R\)의 질량제곱 행렬은

\[
\boxed{
\mathcal M_R^2(\theta)
=
s_RI_3+
\epsilon\left(
e^{i\theta/3}S+e^{-i\theta/3}S^\dagger
\right)
}
\tag{2}
\]

입니다.

\(\epsilon\)도 질량제곱 차원이며, 안정한 영역은 \(s_R>2|\epsilon|\)입니다. 고유질량은

\[
\boxed{
M_{Rj}^2
=
s_R+2\epsilon
\cos\frac{\theta+2\pi j}{3}.
}
\tag{3}
\]

**세 질량을 따로 넣지 않고, 하나의 대각 척도와 관계 결합으로 함께 정합니다.**

이 스펙트럼으로 세 복소 스칼라장을 적분하면, 위상 \(\pi\)에 대한 퍼텐셜 차이는

\[
\boxed{
\mathcal U(s,\epsilon,\theta)
=
\frac1{32\pi^2}
\Delta_\pi
\sum_{j=0}^{2}
x_j^2
\left[
\ln\frac{x_j}{\mu^2}-\frac32
\right],
\qquad x_j=M_j^2.
}
\tag{4}
\]

입니다.

여기서 새로운 가정은 분명히 남깁니다. **암흑장은 게이지 중성으로 유지하고, 세 힘과 연결하기 위한 하전 매개장에는 더 큰 질량척도 \(s_H\)를 허용했습니다.** 두 부문이 같은 \(\theta,\epsilon\)을 공유한다는 것이 이번 합성의 추가 가정입니다. 암흑물질을 곧바로 전기적으로 충전된 입자로 바꾼 것이 아닙니다.

### 왜 이 함수의 위상 의존 부분이 닫히는가

식 (3)에서는

\[
\sum_jx_j=3s,
\qquad
\sum_jx_j^2=3s^2+6\epsilon^2
\]

가 위상에 무관합니다.

따라서 위상에 따른 차이에서는 한 루프 발산과 재규격화 척도 \(\mu\)의 의존성이 상쇄됩니다. 이어서 **\(\epsilon\)을 고정하고 \(s\)를 미분**하면,

\[
\boxed{
\mathcal U_{ss}
=
\frac1{16\pi^2}
\ln\frac{D(s,\theta)}{D(s,\pi)}
}
\]

\[
\boxed{
\mathcal U_{sss}
=
\frac1{16\pi^2}
\Delta_\pi\sum_j\frac1{x_j}
}
\]

를 얻습니다. 여기서

\[
\boxed{
D(s,\theta)
=
s^3-3s\epsilon^2+2\epsilon^3\cos\theta
}
\tag{5}
\]

는 질량제곱 행렬의 행렬식입니다.

**퍼텐셜의 형상과 힘의 반응을 다른 함수로 적합한 것이 아니라, 같은 행렬식을 미분해 얻었습니다.** 유도와 독립적인 행렬·적분 대조는 [상세 보고서](sandbox:/mnt/data/CE_unified_spectral_response_report_2026-09-08.md)에 있습니다.

물론 **위상에 무관한 진공상수까지 사라지는 것은 아닙니다.** 이번에 계산한 것은 위상 의존 양자 보정입니다.

## 3. 세 힘 사이에서도 하나의 보정 비율이 강제됩니다

앞서 검토했던 16성분 표현을 이번에는 **하전 복소 스칼라 매개장의 한 선택**으로 사용했습니다.

\[
(3,2)_{1/6}
\oplus(\bar3,1)_{-2/3}
\oplus(\bar3,1)_{1/3}
\oplus(1,2)_{-1/2}
\oplus(1,1)_1
\oplus(1,1)_0.
\]

색과 약한 이중항의 다중도를 모두 포함하면

\[
T_Y=\frac{10}{3},
\qquad
T_2=T_3=2,
\qquad
\mathcal Q_2=\frac{16}{3}.
\]

같은 질량척도와 순환구조를 사용하는 경우 식 (1)은

\[
\boxed{
\frac35\,\Delta\!\left(\frac1{g_Y^2}\right)
=
\Delta\!\left(\frac1{g_2^2}\right)
=
\Delta\!\left(\frac1{g_3^2}\right)
}
\tag{6}
\]

을 줍니다.

**한 부문의 보정을 바꾸면 나머지 두 부문의 보정도 정해진 비율로 따라옵니다.** 전자기력에 해당하는 저에너지 조합은 전약 혼합을 거쳐 읽습니다.

여기서 \(5/3\) 자체는 이전에도 등장한 표현의 정규화 계수입니다. 이번에 새로 연결한 것은 **그 비율이 같은 위상 퍼텐셜의 두 번째 질량미분에 붙는다는 점**입니다.

하지만 중요한 구분이 있습니다.

\[
\boxed{
\text{세 힘의 보정이 통합됨}
\;\neq\;
\text{세 힘의 절대 결합상수가 모두 도출됨}.
}
\]

현재의 \(g_Y,g_2,g_3\) 값과 높은 에너지에서의 흐름을 완전히 설명한 것은 아닙니다. 또한 이 공통 질량구조는 한 matching 척도에서의 가정이며, 서로 다른 게이지 상호작용이 이후에 만드는 질량분리와 고차 보정도 남습니다.

## 4. 중력까지 연결하자, 이전 암흑부문 식에 필요한 수정이 나왔습니다

같은 양자 스펙트럼은 곡률 앞의 계수도 바꿉니다. 따라서 유효작용은

\[
\boxed{
\Gamma=
\int d^4x\sqrt{-g_J}
\left[
\frac{F(\theta)}2R_J
-\frac{Z_J(\theta)}2(\partial\theta)^2
-V(\theta)
-\frac14\sum_a k_a(\theta)F_a^2
\right]
+S_{\mathrm{물질}}
}
\tag{7}
\]

로 정리됩니다.

여기서 \(k_a=1/g_a^2\)이며,

\[
F=F_0-2\sum_R\Delta C_{\mathrm{grav},R}^{E}
\]

입니다.

**이제 중력계수도 위상에 따라 변하므로, 원래의 입자 질량 변화만으로 힘을 계산하면 항 하나가 빠집니다.**

중력 운동항을 일정하게 만드는 Einstein 틀로 옮기면

\[
M_{j,E}=\frac{M_{\mathrm{Pl}}M_{j,J}}{\sqrt F}
\]

이고, 물리적인 집단장 \(\phi\)에 대한 질량 반응은

\[
\boxed{
\beta_{j,E}
=
\frac{M_{\mathrm{Pl}}}{\sqrt{Z_E}}
\left[
\frac{\partial_\theta x_j}{2x_j}
-\frac{F_\theta}{2F}
\right].
}
\tag{8}
\]

첫 항은 이전에 계산한 스펙트럼의 반응이고, 두 번째는 **중력계수의 변화 때문에 모든 물질에 공통으로 생기는 반응**입니다. 스칼라와 실제 원자·핵의 결합을 계산할 때도 이런 보편 성분과 전기적·강한 결합에너지의 성분을 구분해야 합니다. citeturn641711view1

그래서 이전의 “세 성분의 반응이 합쳐져 상쇄된다”는 관계도 정확히 고쳤습니다. 공통항을 \(\beta_F\)라고 하면,

\[
\boxed{
\sum_jM_{j,E}^2(\beta_{j,E}-\beta_F)=0,
\qquad
\sum_jM_{j,E}^4(\beta_{j,E}-\beta_F)=0.
}
\tag{9}
\]

**세 암흑종의 상대적인 힘이 상쇄돼도, 중력계수에서 오는 공통 반응까지 자동으로 사라지는 것은 아닙니다.** 이 항을 남겨야 같은 작용에서 서로 다른 방식으로 계산한 결과가 일치합니다.

같은 Einstein 틀에서 집단장의 방정식은

\[
\boxed{
\ddot\phi+3H\dot\phi
+V_{E,\phi}
+\sum_j\frac{\beta_{j,E}\rho_j}{M_{\mathrm{Pl}}}
+\frac14\sum_a k_{a,\phi}\langle F_a^2\rangle
=0
}
\tag{10}
\]

입니다.

**암흑물질·위상 퍼텐셜·게이지장·중력 반응이 한 방정식에 함께 들어가며, 물질과 게이지장에 전달되는 반대쪽 에너지까지 포함하면 총응력이 보존됩니다.** 이 보존식도 기호적으로 확인했습니다.

## 5. 뮤온에는 별도의 임의 결합을 붙이지 않고 한 반응항을 계산했습니다

새 하전 매개장은 광자의 진공편극을 바꾸므로, 직접적인 뮤온 Yukawa를 추가하지 않아도 뮤온 자기모멘트에 영향을 줍니다.

무거운 매개장 영역에서 그 전자기 기여는

\[
\boxed{
a_\mu^{\chi,\mathrm{EM}}
=
\left(\frac{\alpha}{\pi}\right)^2
\frac{m_\mu^2\mathcal Q_2}{360}
\sum_j\frac1{M_j^2}
+\text{고차 보정}
}
\tag{11}
\]

입니다.

앞서의 \(\mathcal U_{sss}\)와 같은 역질량제곱 합이므로, 위상에 따른 변화가 식 (1)의 마지막 줄로 연결됩니다.

**입자의 질량을 한 곳에서 고르고, 뮤온 보정은 다른 자유계수로 맞추는 방식을 피했습니다.** 다만 계산한 것은 이 새 부문의 **전자기 진공편극 구성항**이지, 전체 전약 보정이나 뮤온의 완전한 자기모멘트는 아닙니다.

검산용으로

\[
\sqrt{s_H}=1\,\mathrm{TeV},
\qquad
\epsilon/s_H=0.025,
\qquad
\theta=1.2
\]

를 공급했습니다. 미세구조상수와 뮤온 질량은 독립적인 기존 측정값을 입력했습니다. 이 값들을 CE가 유도했다고 하지 않습니다. citeturn236619view0turn815781search0

| 계산 방식 | 해당 뮤온 기여 |
|---|---:|
| 전체 전자기 진공편극 적분 | \(2.6803707082\times10^{-15}\) |
| 식 (11)의 무거운 질량 근사 | \(2.6803707727\times10^{-15}\) |

상대차는 약 \(2.41\times10^{-8}\)입니다.

이 값은 **관측된 뮤온 잔차를 설명한 결과가 아닙니다.** 공급한 무거운 매개장 예에서 그 기여가 얼마나 작고, 같은 스펙트럼으로 얼마나 정확히 계산되는지를 확인했습니다. 이 검산점과 우주론 조건들을 모두 동시에 맞춘 완성 모형도 아닙니다.

## 6. 암흑에너지의 움직임과 정밀 원자실험도 연결됩니다

가시부문과 연결되면 암흑 집단장이 움직이는 동안 전자기 결합도 변할 수 있습니다. 같은 행렬식으로부터

\[
\boxed{
\frac{d\ln\alpha}{d\theta}
=
-\frac{\alpha\mathcal Q_2}{6\pi}
\frac{\epsilon^3\sin\theta}
{s_H^3-3s_H\epsilon^2+2\epsilon^3\cos\theta}
}
\tag{12}
\]

를 얻었습니다.

집단장이 canonical 암흑에너지 성분일 때는

\[
\boxed{
\left(\frac{d\ln\alpha}{d\ln a}\right)^2
=
3\Omega_\phi(1+w_\phi)
\left(
M_{\mathrm{Pl}}\frac{d\ln\alpha}{d\phi}
\right)^2.
}
\tag{13}
\]

**암흑에너지의 운동과 원자에서 읽는 전자기 반응을 별개로 조절할 수 없게 됩니다.**

이를 검사하는 데 새 가속기가 반드시 필요한 것도 아닙니다. 예를 들어 기존 원자시계 연구는

\[
\frac{\dot\alpha}{\alpha}
=
(1.0\pm1.1)\times10^{-18}\ \mathrm{yr}^{-1}
\]

라는 결과를 발표했습니다. 이것은 이번 비교에 고정한 **2021년 발표값**이며, 최신 모든 측정의 세계한계라고 부르지 않았습니다. citeturn787272search0

다만 우주론적 \(\phi\)와 실험실의 \(\phi\)가 같은 이력을 따른다는 조건, 차폐 여부, 실제 물질의 결합을 함께 계산해야 합니다. **작은 매개변수를 골라 제한 아래에 들어갔다고 이론이 실험으로 입증됐다고 하지 않았습니다.**

이번의 의미는 **어디를 조절하면 어떤 다른 관측이 함께 바뀌는지를 이론에서 묶었다는 것**입니다.

### 가시부문을 무겁게 할 때의 영향도 계산했습니다

\(\epsilon\)을 고정한 채 하전 매개장의 \(s_H\)를 크게 하면,

\[
\mathcal U
\sim
\frac{\epsilon^3(1+\cos\theta)}{16\pi^2s_H},
\]

\[
\mathcal U_{ss}
\sim
\frac{\epsilon^3(1+\cos\theta)}{8\pi^2s_H^3}.
\]

따라서 **하전 매개장을 무겁게 하면 위상에 대한 퍼텐셜 보정과 가시 게이지 반응이 서로 다른 정해진 속도로 감소**합니다.

이것이 전체 진공상수 문제를 해결한다는 뜻은 아닙니다. 위상에 무관한 큰 진공·질량 보정은 따로 남습니다. 공통 \(\epsilon\)을 보호하는 미시 대칭도 아직 필요합니다.

## 7. 이번에 마무리한 범위와 최종 통일 사이의 경계

이번 결과는 다음 구조로 요약할 수 있습니다.

\[
\boxed{
\mathcal M^2(\theta)
\;\longrightarrow\;
\mathcal U
\;\longrightarrow\;
\left\{
\begin{array}{l}
\text{암흑입자 질량과 관계 퍼텐셜}\\
\text{중력의 곡률 반응}\\
\text{세 게이지 결합의 보정}\\
\text{뮤온의 전자기 구성항}\\
\text{물질·게이지장과의 보존적 교환}
\end{array}
\right.
}
\]

**공통 유효작용과 그 반응 관계까지는 이번 단계의 완결된 결과로 정리했습니다.** 이전보다 연결되는 관측량은 늘었지만, 각각을 설명하는 임의의 새 함수는 넣지 않았습니다.

반면 다음 입력은 여전히 이론 밖에서 주었습니다.

| 항목 | 이번에 정해진 것 | 아직 독립 입력인 것 |
|---|---|---|
| 세 힘 | 위상에 따른 보정의 공통 형태와 비율 | 게이지군의 기원, 절대 결합상수 |
| 중력 | 같은 스펙트럼의 곡률 반응과 보존식 | Newton 상수의 기원, metric 양자화 |
| 암흑부문 | 질량·퍼텐셜·교환·추가 힘의 연결 | 절대 밀도, 초기 점유, 남는 국소항 |
| 뮤온 | 동일 하전 스펙트럼의 전자기 구성항 | 완전한 새부문 보정과 매개장 질량 |
| 허블상수 | 같은 총응력으로 풀어야 할 방정식 | 초기 음향 눈금과 절대 팽창척도 |

따라서 **“통일식의 공통 구조를 만들었다”는 것과 “자연의 모든 숫자가 결정됐다”는 것을 구분해야 합니다.** 이번에는 전자기·약력·강력·중력의 *계산 가능한 보정*을 하나의 스펙트럼에 묶었지만, 네 힘의 미시적 기원과 모든 자유상수를 없애는 최종 통일은 남아 있습니다.
