## 사전등록 (결과 보기 전 고정, 2026-09-02)

기준 배경: 평탄 ΛCDM, Ω_b=0.0493, Ω_c=0.2645, Ω_Λ=0.6847, Ω_r=9.1e-5 (Planck 2018 h=0.674 근사). 단위 ρ_crit0=1, H0=1.

규칙 공간 (모두 돌린다):
- 틱 속도 Γ: R1 γH · R2 γH0 · R3 γH0 a^-3 · R4 γH0 a^-4 · R5 절대 생성률 γH0(원천 밀도 무관) · R6 한 번 접힘(a_*, 분율 f)
- 원천: S1 바리온 · S3 바리온+복사 · (R5는 원천 상수)
- 싱크 w_D ∈ {−1, −2/3, −1/3, 0, +1/3}
- 보존: transfer(원천에서 뺌) / copy(원천 유지, 총에너지 비보존)
- γ ∈ logspace(−8, 2, 41), a_* ∈ logspace(−8, −0.3, 16), f ∈ {0.5, 0.84, 0.95, 5.4/6.4, 19}

세 가설과 통과 기준:
- H_single: D 하나가 DM+DE 전부. 오늘 ρ_D=Ω_c+Ω_Λ로 두고 뒤로 적분. z∈{0.25,0.5,1,2,5,10,100,1100}에서 |ρ_D/ρ_dark^ΛCDM − 1| 최대 < 0.05 이고 |E(z)/E_ΛCDM − 1| 최대 < 0.02.
- H_DM: D는 DM만, Λ 별도. z=1100→0 사이 ρ_D/ρ_b 상대 변동 < 0.05, z=1100 이후 생성분이 오늘 DM의 < 0.05.
- H_DE: D는 DE만, CDM 별도. z<1에서 |w_eff+1| < 0.1, z=1100에서 ρ_D/ρ_tot < 0.02, |E(z)/E_ΛCDM − 1| < 0.02.
- 성장 검사(H_single 생존자만): 균질 생성·정지 생성 ansatz의 선형 성장. D(z=0)/D(z=1000)와 f(z=0.5)·D(0.5)가 ΛCDM 대비 ±0.10 안.
- 음의 밀도·발산은 그 규칙의 실패로 기록. 허용치는 결과 뒤 바꾸지 않는다.

코드: `examples/physics/tick_fold_rule_scan.py`, 검사: `tests/test_tick_fold_rule_scan.py`.

**잠정 판정(원장 아님).** "틱마다 분율이 복제되어 남는다"는 배경 우주론 수준에서 (i) 원천 비례 틱 속도(R1–R4)는 DM+DE를 재현 못 함, (ii) 유일한 배경 축퇴 규칙은 ln a당 상수 절대 생성률(CCDM 동형)이며 관측 Λ에 ±1% 미세조정이 필요하고 선형 성장에서 기각, (iii) DM만·DE만은 규칙이 아닌 초기조건이 설명. 남는 좁은 명제: 재결합 전 한 번 접힘은 배경·비율 검사와 양립하지만 f=5.36의 미시 기원과 DE는 별도. sourcer: CCDM 축퇴 문헌 Lima–Jesus–Oliveira JCAP 1011:027(2010), arXiv:1508.07263; 섭동 제약 σ 수준 미확인(JCAP 2014/07/040, PRD 84 063511 존재).
