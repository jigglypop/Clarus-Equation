# _workspace: 시행착오 노트 (비대화 금지)

`paper/`에는 결과만 남긴다. 실패 확률이 높은 시도, 중간 계산, 후보 아이디어,
정렬 감사 기록은 여기에 둔다. 이 폴더는 **작고 짧게** 유지하며, harness가
아래 상한을 기계적으로 강제한다(`python.cmd harness`가 초과 시 FAIL).

## 상한 (repository_harness.py가 검사)

| 항목 | 상한 |
|---|---|
| 파일 수 | README 제외 20개 |
| 파일당 크기 | 48 KB |
| 폴더 전체 | 640 KB |
| 파일 형식 | `.md`만. 하위 폴더 금지. 데이터·binary는 `check-large-data`가 차단 |
| 무활동 보존 | 21일. 넘기면 harness가 파일명을 나열하며 FAIL — 흡수 또는 삭제로만 해소 |

## 노트 규칙

- 파일 이름은 `<YYYYMMDD>-<트랙>-<주제>.md`. 주제 하나에 파일 하나. 같은
  주제의 v2·final 사본 금지.
- 머리 표에 표적 고리(진전 원장 §2 또는 §6의 "다음 하나"), 시작일, 상태
  (진행 / 흡수됨 / 폐기)를 적는다. 표적 연결이 없는 노트는 만들지 않는다.
- 본문은 세 표뿐이다. **시도 로그**(날짜 | 시도 | 결과 | 다음), **주차장**
  (아이디어 | 표적 연결 | 예상 비용 | 죽이는 시험), **흡수 판정**(무엇을 |
  어느 정본 어디에 | 날짜). 산문 서사, 유도 전문, 로그 덤프는 넣지 않는다.
  긴 계산은 `examples/`나 `tests/`의 코드로 옮기고 경로만 적는다.
- 흡수가 끝나면(정본에 결과와 반례가 반영되면) 노트를 **삭제**한다. 이력은
  git이 갖는다. 폐기도 삭제다. 진전 원장 §7 세션 로그에 한 행이 남는다.
- 노트 안의 지위 태그는 잠정이며 원장을 대체하지 않는다. "유도됨·닫힘"을
  여기서 선언하지 않는다.

## 템플릿

```markdown
# <주제>

| 표적 고리 | 시작일 | 상태 |
|---|---|---|
| 진전 원장 §2 <고리> | 2026-09-02 | 진행 |

## 시도 로그
| 날짜 | 시도 | 결과 | 다음 |
|---|---|---|---|

## 주차장
| 아이디어 | 표적 연결 | 예상 비용 | 죽이는 시험 |
|---|---|---|---|

## 흡수 판정
| 무엇을 | 어느 정본 어디에 | 날짜 |
|---|---|---|
```
