# 부록 C 재현 코드 안내

이 책의 모든 수치는 저장소의 파이썬 모듈로 다시 계산할 수 있다. 절 끝의 "이 절의 수치와 재현" 표가 수치마다 함수를 가리킨다. 이 부록은 모듈의 위치, 실행 방법, 책 전용 검사 도구, 사전 등록 파일의 해시 검산, 웹 페이지 만들기를 설명한다. (본문은 과거 문서를 인용하지 않지만, 이 부록은 코드 경로를 적는다.)

## C.1 저장소 구조

| 경로 | 내용 |
|---|---|
| `examples/physics/rendering/` | 렌더링 이론의 계산 모듈(`ce_rendering_*.py`) |
| `experiments/preregistration/` | 사전 등록 파일 `rendering_predictions_v1.json` … `v24.json` |
| `book/` | 이 책의 마크다운 원본 |
| `book/tools/check_numbers.py` | 본문 핵심 수치 검사 |
| `book/tools/run_snippets.py` | 본문과 답안의 코드 조각 실행 검사 |

필요한 것은 파이썬 3.10 이상과 numpy, scipy다.

## C.2 실행

모든 명령은 저장소 루트에서 실행한다.

```
python -B -m examples.physics.rendering.ce_rendering_registry      # 코어와 채점
python -B -m examples.physics.rendering.ce_rendering_ledger        # 장부와 기준 모형 비교
python -B -m examples.physics.rendering.ce_rendering_horizon_pixel # 지평선 화소
```

모듈을 직접 불러 쓸 수도 있다.

```
from examples.physics.rendering import ce_rendering_registry as R
c = R.core(R.calibrated_alpha_s()[0])      # 코어 사슬 전체
print(c["a"], c["D"], c["q"], c["F"], c["Om"])
# 0.117916 3.177795 0.048645 1.374713 0.30796  (키 "a"는 밑 a가 아니라 α_s다)
```

`-B`는 `.pyc` 파일을 만들지 않게 한다. 사전 등록은 모듈의 해시도 잠그므로, 모듈 파일은 고치지 않는다.

## C.4 책 전용 검사 도구

**수치 검사.**

```
python -B book/tools/check_numbers.py
```

본문에 적은 핵심 수치(문자열)를 모듈과 사전 등록 v24에서 다시 계산해 대조한다. 계산값이 적힌 문자열의 마지막 자리 반올림 범위(±½ 단위) 안에 있어야 통과다. 항목마다 그 수치가 처음 나오는 장.절이 적혀 있다.

**코드 조각 검사.**

```
python -B book/tools/run_snippets.py            # 책 전체
python -B book/tools/run_snippets.py 15_ 16_    # 폴더 이름으로 거르기
```

본문과 답안의 파이썬 코드 블록을 모두 뽑아 새 이름공간에서 하나씩 실행한다. 연습문제의 코드 조각은 표준 파이썬과 numpy, scipy만 쓰며 저장소 없이 돌아간다. 저장소 파일을 읽는 조각(사전 등록 해시 검산)은 예외로 표시되어 있다.

## C.5 사전 등록 파일의 해시 검산

사전 등록 파일은 자기 해시를 담는다. 해시는 파일에서 `manifest_sha256` 필드를 뺀 JSON을 정규형(키 정렬, 구분자 `,`와 `:`, 공백 없음, 유니코드 그대로)으로 직렬화한 UTF-8 바이트의 SHA-256이다. (저장소 파일을 읽는 예외 조각이다.)

```python
import hashlib
import json

path = "experiments/preregistration/rendering_predictions_v24.json"
data = json.load(open(path, encoding="utf-8"))
stored = data.pop("manifest_sha256")
canon = json.dumps(data, sort_keys=True, separators=(",", ":"), ensure_ascii=False)
digest = hashlib.sha256(canon.encode("utf-8")).hexdigest()
print(digest[:16], digest == stored)     # 90d3905862e3a0f5 True
```

값이 일치하면 파일이 동결 뒤 바뀌지 않았다는 뜻이다. 동결 파일은 고치지 않는다. 바뀐 것은 다음 판본의 변경 내역(`deltas`)에 적는다.

## C.6 웹 페이지

같은 마크다운 원본을 MkDocs(Material 테마)로 정적 웹 사이트로 만든다. 수식은 `pymdownx.arithmatex`와 MathJax로 렌더링한다. 설정은 `book/web/mkdocs.yml`이다(MkDocs는 설정 파일이 있는 폴더 자체를 원본 폴더로 쓰지 못하므로 한 단계 아래에 두고 `docs_dir: ..`로 `book/`을 가리킨다). `book/web/`에서

```
pip install mkdocs-material
mkdocs serve                   # 로컬 미리 보기(http://127.0.0.1:8000)
mkdocs build -d ../../site_book  # 정적 사이트 생성
```

을 실행한다. 사이트에서는 `PRD.md`와 `tools/`를 뺀다. 출력 폴더는 원본 폴더 밖이어야 한다. 마크다운 원본에서 목록과 `$$` 수식 블록 앞뒤에 빈 줄을 두는 것은 이 변환기가 요구하는 규칙이다. 공개(게시)는 따로 결정한다.
