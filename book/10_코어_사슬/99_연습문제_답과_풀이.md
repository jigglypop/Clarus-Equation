## 10.1절

**10.1.1.** $\delta=\tfrac14\cdot\tfrac34=\tfrac3{16}$, $D=3.1875$.

**10.1.2.** $d\delta/d\hat s^2=1-2\hat s^2$. $\hat s^2=\tfrac12$에서 0(최대점).

**10.1.3.** $d\hat s^2/d\alpha_s=\tfrac{16}3\alpha_s^{1/3}=2.6153$이므로 $\sigma_{\hat s^2}=2.6153\times1.53\times10^{-5}=4.0\times10^{-5}$. $\sigma_D=(1-2\hat s^2)\sigma_{\hat s^2}=0.5374\times4.0\times10^{-5}=2.2\times10^{-5}$.

**10.1.4.** $q=e^{-3(1-q)}$의 작은 근은 0.05952. $\omega_b=0.05952\times0.67772^2=0.02734$로 Planck $0.02237\pm0.00015$와 $+33\sigma$(약)다. 분별의 몫 $\delta$가 없으면 보이는 물질이 너무 많다. (실제로 $h$도 $D$에 따라 바뀌지만 여기서는 고정했다.)

**10.1.5.** $e^{-12D}=e^{-38.1335}=2.7462\times10^{-17}$, $/F=1.9977\times10^{-17}$, $\times(1+\alpha_s/4\pi)=\times1.009383$에서 $2.0168\times10^{-17}$. $\ln(M_{\rm Pl}/v)=38.442$(관측 38.4425).

## 10.2절

**10.2.1.** 수치로 풀면 $D=2$: 0.2032, $D=3$: 0.0595, $D=4$: 0.0198.

**10.2.2.** $0.048645\times0.67772^2=0.022343$.

**10.2.3.** $\phi(q)=e^{-D(1-q)}-q$는 $\phi(0)=e^{-D}>0$, $\phi(1)=0$, $\phi''=D^2e^{-D(1-q)}>0$(볼록)이다. $\phi'(1)=D-1>0$이므로 1 바로 아래에서 $\phi<0$이다. 볼록 함수가 $\phi(0)>0$에서 1 근처의 음수로 가므로 $(0,1)$에서 0을 정확히 한 번 지난다(볼록 함수는 직선과 많아야 두 번 만나고, 한 번은 $q=1$이다). ∎

**10.2.4.** 칸마다 독립으로 확률 $p=D/n$의 후손이 있으면 $G(s)=(1-p+ps)^n=(1+D(s-1)/n)^n$. $n\to\infty$에서 $e^{D(s-1)}$로 간다. 칸이 유한하면 $q$가 달라지고, $n=64$에서 이미 $\omega_b$가 $-12.6\sigma$다.

**10.2.5.** $s=1/(1+D(1-s))$에서 $s(1+D-Ds)=1$, 곧 $Ds^2-(1+D)s+1=0$, $(Ds-1)(s-1)=0$. 작은 근은 $s=1/D$. $D=3.1778$이면 $q=0.3147$로 너무 크다($+814\sigma$).

**10.2.6.**
```python
import numpy as np
rng = np.random.default_rng(4)
D, n_lin, cap = 3.1777949, 100_000, 1000
died, sizes = 0, []
for _ in range(n_lin):
    alive, total = 1, 1
    while 0 < alive <= cap:
        kids = rng.poisson(D, alive).sum()
        alive, total = kids, total + kids
    if alive == 0:
        died += 1; sizes.append(total)
sizes = np.array(sizes)
p = died/n_lin
print(p, np.sqrt(p*(1-p)/n_lin))                 # 약 0.0486 ± 0.0007
print(np.mean(sizes == 1), sizes.mean())         # 약 0.857, 약 1.18
```
끊긴 비율은 $q=0.0486$과, 크기 1의 비율과 평균 크기는 Borel의 0.857, 1.183과 통계 오차 안에서 맞는다.

## 10.3절

**10.3.1.** $X=m/(1-m)=0.59927$. $\Omega_{\rm DM}=(1-q)X/(1+X)=0.951355\times0.37471=0.35648$. $\Omega_m=0.04864+0.35648=0.4051$.

**10.3.2.** $\Omega_m=\Omega_b+\Omega_{\rm DM}=q+(1-q)\alpha_sD/F$이고 $\alpha_sD=F-1$이므로 $q+(1-q)(F-1)/F$. ∎

**10.3.3.** $M_H/M_Z-1=0.37299$. 이것이 (10.3.4)에서 $\Omega_{\rm DM}/\Omega_\Lambda$가 된다. 13장에서 이 값으로 $\Omega_m=0.3071$을 예측한다.

**10.3.4.** 붙잡힘 빠르기가 $\alpha_sD/2=0.18736$이면 $\Omega_{\rm DM}=(1-q)\times0.18736/1.18736=0.15012$, $\Omega_m=0.1988$. Planck 0.3153과 $-16\sigma$다. 통로마다 $\alpha_s$(= 색 진공 세계의 확률)라는 식별이 자료로 강하게 고정된다.

**10.3.5.** 경주 규칙은 "먼저 온 사건이 운명을 정하고 그 뒤는 바뀌지 않는다"는 것이다. 기록이 되돌릴 수 없어야(RL) 첫 사건의 결과가 고정된다. 기록을 되돌릴 수 있다면 붙잡힌 계보가 다시 풀리고 또 붙잡히는 과정이 반복되어, 운명은 두 상태 사이의 평형(빠르기의 비로 정해지는 정상 분포)이 된다. 그 경우 결과는 경주와 다른 꼴(예: 재귀나 평형 비)이 될 수 있다.

**10.3.6.**
```python
import numpy as np
rng = np.random.default_rng(11)
n, a_s, D = 400_000, 0.117916, 3.1777949
t_self = rng.exponential(1.0, n)
t_cap = rng.exponential(1/(a_s*D), n)                                  # 합친 빠르기
print(np.mean(t_cap < t_self), a_s*D/(1 + a_s*D))                       # 약 0.2726, 0.27258
k = 4                                                                   # 통로를 4개로 쪼갠 판본(각 빠르기 a_s*D/4)
t_cap4 = rng.exponential(k/(a_s*D), (n, k)).min(axis=1)
print(np.mean(t_cap4 < t_self))                                         # 같은 값
```
독립 지수 시계 여러 개의 최솟값은 빠르기의 합을 가진 지수 시계이므로(정리 2.2.4), 통로를 어떻게 쪼개도 결과가 같다.

## 10.4절

**10.4.1.** $r_0=\tfrac12$에서 $\lambda(\tfrac12)=\frac{1/8}{2\pi}(1+\frac{3/16}{2\pi})=0.019894\times1.029842=0.020488$. $r_1=\tfrac12(1-0.020488)=0.489756$, $\alpha_s=0.117473$. 한 번만 보정하면 $\hat s^2$가 $-28.9\sigma$로 크게 틀린다.

**10.4.2.** $1/(137\times2\pi)=0.001162$.

**10.4.3.** $r=\tfrac12e^{-\lambda(r)}$를 반복하면 $\alpha_s=0.117966$, $\hat s^2=0.231420$으로 측정과 $+3.3\sigma$. 기각된다.

**10.4.4.** 증거 $-\log_20.06=4.06$ bit, 선택 비용 4.58 bit. 순증거는 약 $-0.5$ bit, 곧 거의 없다.

**10.4.5.** 세대 동전을 기울이면 $P(V)=r^3$(세 세대 명제가 모두 거짓), $r=0.490352$에서 $0.117903$. $\beta=180^\circ\times0.117903=21.22^\circ$.

**10.4.6.**
```python
import math
from scipy.optimize import brentq
L = {"a/2pi": lambda a, d: a/(2*math.pi), "a/4pi": lambda a, d: a/(4*math.pi), "a/pi": lambda a, d: a/math.pi,
     "a/16pi": lambda a, d: a/(16*math.pi), "d/2pi": lambda a, d: d/(2*math.pi), "d/8": lambda a, d: d/8}
C = {"1": lambda a, d: 1.0, "1+d/2pi": lambda a, d: 1 + d/(2*math.pi),
     "1-d/2pi": lambda a, d: 1 - d/(2*math.pi), "1+a/2pi": lambda a, d: 1 + a/(2*math.pi)}
hits = []
for ln, lf in L.items():
    for cn, cf in C.items():
        def f(r, lf=lf, cf=cf):
            a, s2 = r**3, 4*r**4; d = s2*(1 - s2)
            return r - 0.5*(1 - lf(a, d)*cf(a, d))
        r = brentq(f, 0.3, 0.5)
        pull = (4*r**4 - 0.23129)/0.00004
        if abs(pull) <= 1: hits.append((ln, cn, round(pull, 2)))
print(hits)   # [('a/2pi', '1+d/2pi', -0.86)]
```
24개 가운데 $1\sigma$ 적중은 채택한 조합 하나다.

## 10.5절

**10.5.1.** $0.019296\times0.048645^2=4.57\times10^{-5}$.

**10.5.2.** $x=-\ln0.048645=3.023$. 그래서 $q^2\approx e^{-6}$이고 $\lambda q^2\approx\lambda e^{-6}$이다.

**10.5.3.** $r=\tfrac12(1-\lambda+\lambda^2/2)$이므로 $\varepsilon=-\lambda^2/2\approx-1.86\times10^{-4}$. 필요한 $-4.94\times10^{-5}$의 약 3.8배라 렙톤 규칙 대비 $+10.4\sigma$로 떨어진다. 급수를 더 이어 가도 $e^{-\lambda}$ 쪽으로 수렴할 뿐이라($\varepsilon\to-1.85\times10^{-4}$), 전체가 기각된다.

**10.5.4.** FP가 렙톤 규칙과 $3.75\sigma$ 어긋난다는 것을 이미 알므로, 실제 과녁은 0에서 적어도 $3\sigma_\varepsilon$ 떨어져 있다. 하한을 $10^{-6}$으로 잡으면 0 근처의 작은 과녁이 많이 섞인다. $\lambda^2e^{-n}$ 같은 작은 항들은 그런 과녁에 쉽게 맞으므로(창이 절대 폭 $\sigma_\varepsilon$이라 작은 값끼리는 모두 창 안에 든다) 우연 적중이 부풀어 오른다(27%가 65%로). 알고 있는 사실을 기준선에 반영해야 한다.

**10.5.5.** SS("자기는 한 번 센다")는 자기를 두 번 세는 꼴($\lambda^2$류: $\lambda^2/8$, $\lambda^2e^{-2}$)을 불리하게 만들고, 두 계보(나와 아닌 나)를 세는 $\lambda q^2$와도 긴장한다. 남는 것은 $\lambda e^{-6}$이다. 그러나 이 좁힘은 네 후보를 이미 본 뒤에 SS를 적용한 것(목격 후)이고, SS 자체도 이미 나온 수치의 재해석이다. 새 자료가 아니므로 증거로 세지 않는다.

**10.5.6.**
```python
import math
import numpy as np
lam, sig = 0.0193, 1.317e-5
fam = np.array([s*lam**k*math.exp(-n) for k in (1, 2) for n in range(9) for s in (1, -1)])
rng = np.random.default_rng(7)
for lo in (math.log10(3*sig), -6):
    draws = rng.choice([-1, 1], 200_000) * 10**rng.uniform(lo, -3, 200_000)
    print(lo, (np.abs(draws[:, None] - fam[None, :]) <= sig).any(axis=1).mean())
# 약 0.27(하한 3σ), 약 0.65(하한 1e-6)
```
