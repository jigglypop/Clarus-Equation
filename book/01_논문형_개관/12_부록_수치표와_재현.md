# 1.12 부록: 수치표와 재현

## 1.12.1 재현 방법

모든 수치는 저장소의 `examples/physics/rendering/` 모듈로 계산한다. 저장소 루트에서 다음을 실행한다.

```powershell
# 이 책의 핵심 수치 대조(수치마다 ok/FAIL)
python -B book/tools/check_numbers.py

# 레지스트리 판본 I·II의 점수
python -B -m examples.physics.rendering.ce_rendering_registry

# 저장소의 고정 검사
python -B -m pytest tests/test_rendering_registry.py -q
```

사전 등록 파일은 `experiments/preregistration/rendering_predictions_v1.json`부터 `…_v24.json`까지이고, 각 파일의 `manifest_sha256`은 키를 정렬한 정규 JSON(구분자 `,` `:`, 한글 그대로, 자기 해시 칸 제외)의 SHA-256이다.
