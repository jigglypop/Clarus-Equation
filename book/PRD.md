## 1. 목적

CE의 살아 있는 이론인 **렌더링 이론**을 책 한 권(이하 book)으로 정리한다. book은 두 역할을 함께 한다.

1. **처음 보는 독자를 위한 논문.** 01장은 혼자 완결된 논문이다. 저장소의 다른 문서를 한 번도 본 적 없는 연구자가 01장만 읽고 이론의 주장, 근거, 예측, 한계를 알 수 있어야 한다.
2. **학부 2학년을 위한 교과서.** 02장부터는 수학과·물리학과 2학년이 혼자 공부할 수 있는 교과서다. 장, 절, 예제, 연습문제, 답과 풀이를 자세히 갖춘다.

저장소의 과거 문서(`paper/참조/`, 통합 논문, 43장 작업 원장)는 **집필 자료**로만 쓴다. book 본문은 그것들을 인용하지 않는다. 필요한 내용은 본문에서 다시 쓴다.

## 2. 범위

**포함**
- 렌더링 이론 전체: 공리, 정리, 조건부 정리, 읽기, 가설 규칙, 경험식, 예측, 기각, 열린 문제
- 2026-09-24 판정 기준의 수치(v24 동결값과 저장소 모듈의 계산값)
- 사전 등록 예측 41개(P01–P41, 기각 1개 P17)와 등록 후보 P42
- 모든 수치의 재현 경로
- 기각된 판본과 잘못 든 길. 틀린 길도 배울 거리다

**제외**
- 공통 스펙트럼 이론(퇴역 중)
- 작업 순서의 이야기(어느 날 무엇을 했는지). book은 논리 순서를 따른다
- 과거 문서의 인용이나 링크(본문 기준. 부록 C의 코드 경로는 예외)

## 3. 독자와 수준

**독자:** 수학과·물리학과 학부 2학년.

**가정하는 선수 지식(book에서 다시 가르치지 않음)**
- 일변수·다변수 미적분, 테일러 전개, 상미분방정식 기초
- 선형대수: 행렬, 행렬식, 고유값, 내적 공간
- 복소수와 오일러 공식
- 확률 기초: 확률변수, 기댓값, 분산, 정규분포
- 일반물리(역학, 전자기), 현대물리 입문(특수상대론, 슈뢰딩거 방정식의 뜻, 원자와 원자핵의 기초)

**book이 준비 장에서 가르치는 것(2학년이 아직 배우지 않았을 것)**
- 정보 엔트로피(nat과 bit), 지수 시계와 경주, 최대 엔트로피
- 판정 통계: pull, $\chi^2$, 공분산, RMSE, look-elsewhere, 설명 길이(bit 장부), 사전 등록
- 외대수: 쐐기곱, $\Lambda^k$, 단일항, 야코비 공식
- 양자 측정: 밀도행렬, 보른 규칙, 결어긋남과 기록
- 표준 모형: 게이지군, 초전하 배정, 결합 상수의 흐름(1고리), 약전자기 섞임각, Z 극, Higgs, CKM, PMNS
- 일반상대론과 우주론: 아인슈타인 방정식, FLRW 우주, 밀도 모수, CMB 음향 척도 $\theta^*$, BAO, 허블 긴장
- 블랙홀 열역학: 호킹 온도, 베켄슈타인 엔트로피, 운루 온도, Jacobson 논증

**문체 규칙**
- 한국어, 짧은 문장. 전문 용어는 처음 쓸 때 정의하고 영문을 한 번 병기한다.
- 식마다 "이 식이 무슨 뜻인가"를 한 줄로 쓴다.
- 비유는 쓰되, 비유와 식의 경계를 분명히 한다. 비유 문단은 인용 블록(`>`)으로 구분한다.
- 용어는 `paper/용어사전.md`와 최신 원장의 용어를 따른다(예: "영감" 대신 "가설").

## 4. 정직성 규칙

1. **지위 표기 필수.** 모든 주장 앞에 다음 가운데 하나를 굵게 붙인다.

   | 표기 | 뜻 |
   |---|---|
   | **[정의]** | 이름을 붙이는 약속 |
   | **[공리]** | 증명 없이 받아들이는 출발점 |
   | **[정리]** | 공리와 정의에서 유도된 명제 |
   | **[조건부 정리]** | 명시된 추가 조건(읽기나 사전) 아래서 유도된 명제 |
   | **[읽기]** | 식을 물리량으로 번역하는 규칙. 유도가 아니다 |
   | **[가설]** | 자료를 보고 고른 규칙. bit 비용을 적는다 |
   | **[경험식]** | 자료에 맞췄으나 아직 유도가 없는 식 |
   | **[산출]** | 위의 것들로 계산한 수치 |
   | **[예측]** | 사전 등록된 산출(P번호) |
   | **[기각]** | 관측이나 반례로 죽은 판본 |
   | **[열림]** | 아직 답이 없는 문제 |

2. **자료를 보고 고른 규칙**은 [가설]로 쓰고 bit 비용을 적는다. 계산 전에 자료를 먼저 본 경우(목격 후)는 그렇다고 적는다.
3. **테스트 통과와 수치 일치는 구현의 증거이지 자연에 대한 증명이 아니다.** 이 구분 자체를 02장에서 가르친다.
4. **예측**은 P번호, 예측값, 기각 조건, 판정 실험과 함께 적는다.
5. **기각과 긴장도 가르친다.** 예: P17 기각, 저장소 암흑에너지 식 W1 기각, 가지 무게 중력 기각, 외부 요동 모형을 공리 확인 없이 대입했다가 철회한 일.
6. **수치는 v24 동결값과 저장소 모듈의 계산값만 쓴다.** 관측값에는 실험 이름과 연도를 붙이고 부록 B에 모은다.

## 5. 폴더와 파일 규칙

```
book/
├── PRD.md                          ← 이 문서
├── README.md                       ← book 첫 화면(목차, 읽는 법). 웹 페이지의 index가 된다
├── mkdocs.yml                      ← 웹 페이지 설정(M9)
├── 00_머리말/
├── 01_논문형_개관/                  ← 처음 보는 독자용 논문
├── 02_확률_정보_판정/ … 06_중력과_우주/ ← 제1부 준비
├── 07_분별과_기록/ … 10_코어_사슬/      ← 제2부 뼈대
├── 11_세대와_섞임/ … 12_질량과_경주/    ← 제3부 입자
├── 13_우주의_성분/ … 15_우주론_채점/    ← 제4부 우주
├── 16_확률_무게_중력/ … 18_양자_중력의_흔적/ ← 제5부 중력
├── 19_채점과_장부/ … 21_열린_문제/      ← 제6부 판정
├── 부록_A_기호와_단위/ … 부록_E_용어집/
└── tools/check_numbers.py          ← 본문 수치 검사(M1부터)
```

**이름 규칙**
- 장 폴더: `NN_장이름/`(두 자리 번호, 밑줄로 띄어쓰기)
- 절 파일: `NN_절이름.md`. 장마다 `00_장_개요.md`와 `99_연습문제_답과_풀이.md`를 둔다.
- 절 번호: 본문에서 "3.2절"처럼 장.절로 부른다. 식 번호는 (3.2.1)처럼 장.절.순번이다.
- 정의, 정리, 예제, 연습문제에도 번호를 붙인다: 정의 3.2.1, 정리 3.2.2, 예제 3.2.3, 연습 3.2.4.

**절 파일 틀(모든 절 공통)**
1. 제목과 한 줄 요지
2. 학습 목표(3–5개)
3. 선수 지식(앞 절 링크)
4. 본문: 정의 → 식 → 뜻 → 표. 증명은 "증명." 으로 시작해 "∎"로 끝낸다
5. 예제 2–3개. 풀이를 본문에 바로 쓴다
6. 연습문제 4–8개. 난이도 표시:
   - ★ 기본 계산(5–10분)
   - ★★ 개념과 짧은 증명(20–30분)
   - ★★★ 긴 유도나 수치 탐구, 파이썬 코드(1시간 이상)
7. 요약(3–5줄)
8. 이 절의 수치와 재현: 수치마다 재현 함수 경로

**장 개요 파일 `00_장_개요.md`:** 이 장이 답하는 질문, 절 목록과 한 줄 요지, 장의 지도(어떤 결과가 어떤 결과에 쓰이는가), 선수 장.

**장 끝 파일 `99_연습문제_답과_풀이.md`:** 모든 연습문제의 최종 답을 먼저 한 표로 모으고, 그 아래에 단계별 풀이를 쓴다. 수치 답은 유효숫자 4자리이고 단위를 붙인다. 코드 문제는 표준 파이썬과 numpy, scipy만 쓰는, 저장소 없이 돌아가는 조각을 넣는다(2.6절의 해시 검산처럼 저장소 파일을 읽는 조각은 예외로 표시한다).

**마크다운 규칙(웹 페이지 호환)**
- 수식은 `$…$`와 `$$…$$`만 쓴다. `\begin{align}`은 `$$` 안에서만 쓴다.
- 표는 GitHub 표 문법만 쓴다. HTML 태그는 쓰지 않는다.
- 파일 사이 링크는 상대 경로(`../03_외대수와_행렬식/02_쐐기곱.md`)로 쓴다.
- 그림은 텍스트 도해(코드 블록)나 표로 대신한다. 필요하면 M9에서 SVG로 바꾼다.
- 풀이는 99 파일로 분리해 숨기기 효과를 낸다. 웹 페이지에서도 접는 블록은 쓰지 않는다(§12).
- 목록과 `$$` 수식 블록 앞뒤에는 빈 줄을 둔다(Python-Markdown 호환). 목록 항목 안의 블록 수식은 4칸 들여쓴다.

### 제1부 준비 — 2학년이 아직 배우지 않은 도구

**02 확률, 정보, 판정** (원장 §43.44, §43.47, §43.64, §43.71)
- 01 정보 엔트로피: nat과 bit, 최대 엔트로피 분포
- 02 지수 시계와 경주: 먼저 울리는 시계의 확률, 분기비
- 03 측정과 오차: pull, $\chi^2$, 공분산, RMSE
- 04 우연과 사후 탐색: look-elsewhere, 우연 확률 기준선
- 05 설명 길이와 bit 장부: 규칙 하나의 값
- 06 사전 등록: 해시로 잠그는 약속, 구현 증거와 물리 증거
- 대표 예제: 평균 1인 지수분포의 미분 엔트로피가 정확히 1 nat임을 보인다.
- 대표 연습(★★): 빠르기 1과 $\lambda$인 두 지수 시계 중 첫째가 먼저 울릴 확률을 구하라. **답:** $1/(1+\lambda)$.

**03 외대수와 행렬식** (§43.5, §43.78, §43.83)
- 01 쐐기곱과 $\Lambda^k V$, 차원 $\binom{n}{k}$와 $2^n$
- 02 행렬식은 최고차 쐐기곱이다
- 03 단일항: 모든 성분을 한 번씩 담은 상태
- 04 야코비 공식: $\partial\ln\det M=\mathrm{tr}(M^{-1}\partial M)$
- 05 대각합과 사영, 부분공간의 무게
- 대표 예제: $\dim\Lambda^\bullet(\mathbb{R}^3)=8$과 등급별 차원 $1,3,3,1$.
- 대표 연습(★★): $A(a)=\mathrm{diag}(a,a,a)$일 때 $a\,\partial_a\ln\det A$를 구하라. **답:** 3.

**04 양자 측정과 기록** (§43.29–43.31, §43.43–43.44)
- 01 상태공간, 진폭, 보른 규칙
- 02 밀도행렬과 부분 대각합
- 03 결어긋남: 기록이 남으면 간섭이 사라진다
- 04 켤레와 확률: $|A|^2=AA^*$
- 05 관측 기록의 정의: 복제 가능하고 되돌릴 수 없는 흔적
- 대표 예제: 두 경로 간섭에서 경로 기록이 생기면 간섭항이 사라짐을 밀도행렬로 계산한다.
- 대표 연습(★): 상태 $(|0\rangle+|1\rangle)/\sqrt2$가 경로 기록을 남긴 뒤 밀도행렬의 비대각 성분을 구하라. **답:** 0(대각 성분은 ½, ½).

**05 표준 모형 요약** (§43.20–43.22, §43.60, §43.62)
- 01 게이지군 $SU(3)\times SU(2)\times U(1)$과 한 세대의 입자표
- 02 초전하와 전하: $Q=T_3+Y$, 이상 상쇄
- 03 결합 상수의 흐름: 1고리 베타 함수
- 04 약전자기 섞임: $\sin^2\theta_W$, Z와 W, Z 극 관측
- 05 Higgs와 질량
- 06 섞임 행렬: CKM과 PMNS, 표준 매개화
- 대표 예제: 한 세대 렙톤(전자, 전자 중성미자)에서 $\mathrm{Tr}\,T_3^2/\mathrm{Tr}\,Q^2$를 계산한다.
- 대표 연습(★): $\alpha_s(M_Z)=0.118$에서 1고리($n_f=5$, $b_0=23/3$) 흐름으로 $\alpha_s(2M_Z)$를 구하라. **답:** 0.1073.

**06 중력과 우주** (§43.30, §43.48–43.53, §43.71–43.72)
- 01 일반상대론 요약: 계량, 곡률, 아인슈타인 방정식
- 02 블랙홀 열역학: 호킹 온도, $S=A/4$, 운루 온도
- 03 Jacobson 논증: 열역학에서 아인슈타인 방정식으로
- 04 FLRW 우주: 프리드만 방정식, 밀도 모수, 평탄성

### 제2부 뼈대 — 렌더링 이론의 공리와 핵심 정리

**07 분별과 기록** (§43.43–43.44, §43.60, §43.63, §43.66)
- 01 렌더링: 참과 거짓의 기록(Bool)
- 02 기록 전의 공평한 동전(무차별, Ind)
- 03 나와 바깥: 분별의 동전, 여집합 = 반입자
- 04 분별 = 무분별: 극에서 기록만 남는다
- 05 자기는 하나: 자기참조 고정점의 유일성
- 대표 예제: 공평한 동전 $n$개가 모두 같은 면일 확률과 그 정보량(bit).
- 대표 연습(★★): 함수 $g(r)=\tfrac12[1-\lambda(r)]$가 축약이면 고정점이 하나뿐임을 보여라(바나흐 고정점 정리).

**08 렌더링 연산과 사전** (§43.5, §43.70, §43.83)
- 01 렌더링 진폭 $A_m=m\,a^m$
- 02 세 힘과 세 차원: $A_1$, $A_2$, $A_3$
- 03 기록은 곱하고 진폭은 더한다
- 04 사전 D: 결합 = 기록의 확률, 섞임 = 그 척도 미분
- 대표 예제: $a=0.49037$에서 $A_1$, $A_2$, $A_3$를 계산한다. **답:** 0.4904, 0.4809, 0.3537.
- 대표 연습(★★): 사전 D에서 $\ln\det$의 척도 미분이 대각합이 됨을 야코비 공식으로 보여라.

**09 주춧돌 E4** (§43.55, §43.60, §43.62, §43.78–43.82)
- 01 닻: 공평한 동전 점 $(\alpha_s,\hat s)=(1/8,\,1/2)$
- 02 한 동전, 한 사건: 흐름은 E4 곡선을 한 번만 가로지른다($\mu^*\approx M_Z$)
- 03 가둠 ⇔ 붙잡힘: 외대수 단일항과 $\alpha_s=a^3$
- 04 렙톤 영역의 대각합 ¼
- 05 보른 배가: 지수 $m=2$, 곧 $\hat s^2=4\alpha_s^{4/3}$
- 06 E4는 조건부 정리다: 무엇이 증명되었고 무엇이 조건인가
- 대표 예제: $a=\tfrac12$에서 $\alpha_s=1/8$, $\hat s=\tfrac12$, $\hat s^2=\tfrac14$를 확인한다.
- 대표 연습(★★): $A_m=m\,a^m$이 모든 $a$에서 $A_m^2=A_{2m}$을 만족하는 $m\ge1$을 구하라. **답:** $m=2$(보른 배가).
- 대표 연습(★): $\alpha_s=0.117916$에서 $\hat s^2=4\alpha_s^{4/3}$를 구하라. **답:** 0.2313.

**10 코어 사슬** (§43.2, §43.54, §43.57–43.58, §43.64, §43.66)
- 01 $\delta=\hat s^2(1-\hat s^2)$, $D=3+\delta$
- 02 가지치기 고정점 $q=e^{-D(1-q)}$
- 03 경주 인자 $F=1+\alpha_s D$와 $\Omega_m$
- 04 기운 동전과 자기일관 고정점 FP
- 05 고정점의 빠진 보정: 있지만 가려낼 수 없다
- 대표 예제: $\alpha_s=0.117916$에서 코어 사슬 전체를 손으로 계산한다. **답:** $\delta=0.1778$, $D=3.178$, $q=0.04864$, $F=1.375$, $\Omega_m=0.3080$.
- 대표 연습(★★★): $q=e^{-D(1-q)}$의 작은 근을 뉴턴법으로 구하는 코드를 짜고, $D$에 대한 $q$의 민감도 $dq/dD$를 구하라.

## 8. 수치와 재현 정책

1. 본문의 모든 수치에는 절 끝 "수치와 재현"에 재현 함수 경로를 적는다.
