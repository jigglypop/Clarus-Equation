## 19.1절

**19.1.1.** $0.03^2+0.16^2+0.58^2+0.56^2+0.18^2+1.26^2+0.45^2+1.53^2+0.22^2=4.888$. $\sqrt{4.888/9}=0.737$. 거시 블록 RMSE 0.849를 올리는 것은 BAO 13성분이다($\chi^2=10.99$, 성분당 0.85).

**19.1.2.** $-1.06$, $+1.42$, $+1.22$, $-1.11$, $+1.80$의 5개, 29%다. 가우스라면 $|p|>1$의 확률은 31.7%이므로 17행에서 약 5.4개를 기대한다. 잘 맞는다.

**19.1.3.** 전체 RMSE > 1은 $\chi^2>39$다. $\chi^2_Q=17\times0.815^2=11.29$이므로 $\chi^2_M>27.71$, $\text{RMSE}_M>\sqrt{27.71/22}=1.122$.

**19.1.4.** $\lvert V_{ub}\rvert$: 이론(0.0036759)이 관측(0.003732)보다 작으므로 규칙은 아래쪽 $\sigma=0.000085$를 써서 $-0.66$. 반대로 쓰면 위쪽 $0.000090$으로 $-0.62$. $S_8$ KiDS: 이론이 크므로 위쪽 $0.016$으로 $+0.069$, 반대면 $0.021$로 $+0.052$. 규칙은 이론과 관측 사이에 놓인 쪽의 오차를 쓰는 것이라 자연스럽고, 반대로 쓰면 pull이 작아져 이론에 유리해진다.

**19.1.5.** $P(\chi^2_{39}\le27.14)=0.076$, $P(\chi^2_{43}\le33.18)=0.14$. 아래 꼬리 확률이 몇 %보다 작지 않으므로 오차 과대평가나 과적합을 강하게 의심할 수준은 아니다. 다만 7.6%는 아주 큰 값도 아니다. 행 대부분이 본 자료라는 사실과 함께 읽어야 한다.

**19.1.6.**
```python
import math
from scipy import stats

Q = [-0.09, -1.06, 1.42, -0.12, -0.28, -0.66, 1.22, -0.19, -0.23,
     0.11, -0.60, 0.10, 0.13, 0.88, -1.11, 1.80, -0.60]
M = [0.03, 0.16, 0.58, 0.56, -0.18, -1.26, 0.45, 1.53, 0.22]
bao = 10.99
q = sum(p*p for p in Q); m = sum(p*p for p in M) + bao
for label, cq, nq, cm, nm in (("39", q, 17, m, 22),
                              ("43", q + 0.46**2 + 0.54**2, 19, m + 0.07**2 + 2.35**2, 24)):
    tot, n = cq + cm, nq + nm
    print(label, round(math.sqrt(cq/nq), 3), round(math.sqrt(cm/nm), 3),
          round(math.sqrt(tot/n), 3), round(stats.chi2.sf(tot, n), 3))
```
출력: 39행 0.814, 0.850, 0.834, p값 0.924. 43행 0.787, 0.944, 0.878, p값 0.860.

## 19.2절

**19.2.1.** V: $27.14+2\times1=29.14$. IV: $\chi^2=0.839^2\times39=27.45$, $+2\times2=31.45$. V가 2.3 낮아 낫다. 매개변수 하나를 줄이고도 $\chi^2$가 거의 같기 때문이다.

**19.2.2.** $0.876^2\times39=29.93$, 이전보다 2.79 늘었다. 늘어난 몫은 $n_s$(2.37)와 $s_{12}^2$(0.37)다.

**19.2.3.** 대기 중성미자 자료(SK)는 θ₂₃ 옥탄트에 대한 추가 정보를 준다. NuFIT 6.0에서 SK를 넣으면 $s_{23}^2$의 최적값이 0.470(아래 쪽)이고, 빼면 위 옥탄트(약 0.56)로 옮긴다. 이론은 옥탄트 부호를 공리 SA로 아래쪽($s_{23}^2=0.4556$)에 고정하므로, 위 옥탄트 자료에서는 $-7\sigma$가 된다. 이론은 옥탄트를 자료에 맞춰 바꿀 수 없다. 그래서 옥탄트 측정(P01)이 가장 결정적인 시험이다.

**19.2.4.** 현재 자료로는 두 판본을 가를 수 없다는 뜻이다. 순위가 한 행의 포함 여부로 바뀌고 차이가 0.015 이하다. 둘을 가르는 관측은 $S_8$(W2 0.8161, W3 0.8119, 차이 0.004)의 정밀 측정(Euclid, Rubin LSST)과 늦은 우주의 물질 증가($\Omega_{d0}=0.0046$ 수준의 추가 먼지)다.

**19.2.5.** P-ACT에 BAO를 더한 $n_s$는 BAO 자료를 이미 품고 있다. 그 BAO 자료는 채점의 BAO 13성분과 같으므로, 두 행을 독립으로 채점하면 같은 정보를 두 번 센다. 이것이 "불리한 자료를 뺀 것"이 아니려면 (1) 겹침 규칙이 결과와 무관하게 미리 정해져 있고, (2) 같은 규칙이 이론에 유리한 경우에도 적용되며, (3) 뺀 값($-2.7\sigma$)을 숨기지 않고 보고해야 한다. 이 책은 (3)을 지키고, (1)과 (2)는 채점 규칙 6(자료 판본)에 따른다.

## 19.3절

**19.3.1.** $\chi^2=33.18$, 벌점 $2\times1=2$, 가설 $2\ln2\times34.6=47.96$. 합 83.14.

**19.3.2.** $64.9-19.9=45.0$ bit.

**19.3.3.** 20자릿수: $\log_2(0.118\times46.05/0.0009)=\log_2(6038)=12.56$ bit. 가장 좁은 사전: $\log_2(0.118/0.0009)=\log_2(131.1)=7.03$ bit.

**19.3.4.** AIC는 매개변수의 값을 적는 비용을 모형 크기와 무관한 상수(1.4 bit)로 둔다. 예측 성능(교차 검증)을 근사하려는 관례라, 매개변수가 정밀하게 정해져 있어도 싸게 매긴다. 설명 길이는 매개변수를 측정 정밀도까지 적는 실제 비용을 세며, 사전 범위 $W$의 선택에 기댄다. "같은 자료를 가장 짧게 설명하는 이론"을 묻는다면 설명 길이가 맞는 화폐이고, "새 자료에서 잘 예측하는 모형"을 묻는다면 AIC의 동기가 가깝다. 이 책은 두 결과를 모두 보고하고, 양자 블록의 판정이 화폐에 달려 있음을 밝힌다.

**19.3.5.** 어림의 예: 가지치기 방정식은 몇 가지 함수 꼴 가운데 하나(2–3 bit), $F=1+\alpha_sD$는 경주 인자의 몇 가지 꼴 가운데 하나(약 3 bit), $N_e=18D$의 계수 $\tfrac32$는 작은 분수 몇 개 가운데 하나(3–4 bit), $A_s$ 식은 여러 인자를 조합한 꼴이라 비싸다(약 10 bit), 합규칙의 $1/2\pi$는 3 bit 안팎이다. 합계 20–25 bit 정도로, 44 bit 여유 안에 든다. 다만 이 어림 자체가 사후 판단이므로 감사를 대신하지 못한다. 감사하지 않은 식이 장부 밖에 있다는 사실은 이론의 약점으로 남는다(21장).

**19.3.6.**
```python
import math

def param_bits(x, sigma, decades=20):
    return math.log2(abs(x)*decades*math.log(10)/sigma)

nat_per_bit = 2*math.log(2)
L_theory = param_bits(0.1180, 0.0009) + 17.9 + 11.26/nat_per_bit
L_base = 167.0 + 1.53/nat_per_bit
print(round(L_theory, 2), round(L_base, 2))   # 38.58 168.1
```
표의 38.6, 168.1과 같다.

## 19.4절

**19.4.1.** $\Delta\chi^2>9$는 $|\Omega_m-0.296|>3\times0.0215=0.0645$, 곧 $\Omega_m<0.2315$ 또는 $\Omega_m>0.3605$.

**19.4.2.** (가) 본 자료: G1m의 무게 시점은 BAO 점수를 보고 골랐다. (나) 보류 자료. (다) 보류 자료(약): 규칙을 세울 때 쓰지 않았지만 이미 공개되어 있었다. (라) 사전 등록 예측(P01)의 판정 자료.

**19.4.3.** (1) 규칙과 채점 코드를 해시로 동결하고, (2) 동결 시각이 자료 공개 시각보다 앞서며, (3) 채점 절차(어느 행을 어느 자료로 바꾸는지, 겹침 처리)를 미리 적고, (4) 결과를 그대로 보고해야 한다. 2026 점검은 (2)를 만족하지 못한다.

**19.4.4.** 예: 차기 LHCb·Belle II의 CKM 각 $\gamma$와 $\lvert V_{ub}\rvert$ 측정을 보류한다. 예측값(직각 단위 삼각형의 $\gamma=67.5^\circ$, $\lvert V_{ub}\rvert=0.003676$)과 기각 기준($3\sigma$ 배제)은 이미 P05, P06으로 동결되어 있다. 새 발표가 나오면 동결된 값으로만 채점하고, 행을 추가한 공동 RMSE도 미리 정한 방식으로 계산한다.

**19.4.5.** 기각은 그 예측이 기대는 부분에 가장 강하게 작용한다. P17은 중성미자 질량식(경험식, 13.7 bit)과 표준 ΛCDM 분석이라는 해석에 기댄다. 코어 사슬이나 섞임 규칙은 P17에 기대지 않으므로, 기각이 그 부분의 신뢰도를 직접 깎지는 않는다. 그러나 "경험식이 우주론 자료와 맞는다"는 형태의 주장 전체에 대한 신뢰는 줄어야 하고, 같은 식에 기대는 P18, P19도 더 조심스럽게 봐야 한다. 이론 전체로는, 독립 예측 38개 가운데 판정에 이른 소수 중 하나가 기각되었다는 사실이 남는다. 앞으로의 판정 결과를 함께 세어야 한다.

**19.4.6.**
```python
best, width = 0.296, 0.0215
for om in (0.22, 0.2315, 0.253, 0.296, 0.308, 0.339, 0.3605, 0.38):
    print(om, round(((om - best)/width)**2, 2))
print("통과:", round(best - 2*width, 4), "~", round(best + 2*width, 4))
print("기각 밖:", round(best - 3*width, 4), "~", round(best + 3*width, 4))
```
통과($\Delta\chi^2\le4$)는 $0.253\le\Omega_m\le0.339$, 기각($>9$)은 $0.2315$–$0.3605$ 밖이다. 코어 $\Omega_m=0.308$은 통과 구간 한가운데에 가깝다.
