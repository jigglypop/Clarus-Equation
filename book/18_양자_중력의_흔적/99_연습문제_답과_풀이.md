## 18.1절

**18.1.1.** $p=\tfrac12e^{-t/2}$, $K=\ln2+t/2$. $S=\ln2+1=1.693$, $C=\mathrm{Var}(t)/4=4/4=1$. $C/S=0.5906$. 평균이 1일 때만 $C=S$다.

**18.1.2.** 균등 분포에서는 모든 결과의 확률이 같아 놀람 $K=-\ln p$가 어디서나 $\ln2$로 같다. 놀람의 스펙트럼(얽힘 스펙트럼)이 평평하면 분산이 없으므로 $C=0$이다.

**18.1.3.** $K=\text{상수}+t^2/2\sigma^2$이므로 $C=\mathrm{Var}(t^2)/4\sigma^4=(\langle t^4\rangle-\langle t^2\rangle^2)/4\sigma^4=(3\sigma^4-\sigma^4)/4\sigma^4=\tfrac12$.

**18.1.4.** 독립이면 $p=p_1p_2$이므로 $K=K_1+K_2$. 평균은 선형이라 $S=S_1+S_2$. $K_1$과 $K_2$는 독립이라 공분산이 0이고 $C=C_1+C_2$.

**18.1.5.** 합을 고정하면 조건부 분포는 단체 위 균등이고 $K=\ln V_N$(상수)이므로 전체 $C=0$이다. 화소 하나의 주변 분포는 $t_1/N\sim\text{Beta}(1,N-1)$, 밀도 $\tfrac{N-1}N(1-t/N)^{N-2}$다. $v=1-t/N\sim\text{Beta}(N-1,1)$로 두면 $K=\text{상수}-(N-2)\ln v$이고, $\mathrm{Var}(\ln v)=1/(N-1)^2$이므로

$$C_1=\Big(\frac{N-2}{N-1}\Big)^2 .$$

$N=2$에서 0(주변 분포가 균등), $N=3$에서 $\tfrac14$, $N\to\infty$에서 1이다. 큰 계의 일부는 나머지와 에너지를 주고받아 독립 지수 시계(바른틀)처럼 요동한다.

**18.1.6.**
```python
import math
import numpy as np
from scipy import integrate

rng = np.random.default_rng(2)
for N in (10, 1000, 100000):
    trials = 4000 if N < 100000 else 400
    K = np.array([rng.exponential(1.0, N).sum() for _ in range(trials)])   # K = Σ t_i
    print(N, round(K.var()/K.mean(), 3))                                   # C/S ≈ 1

f = lambda t: 4*t*math.exp(-2*t)                                          # 감마(2), 평균 1
K = lambda t: -math.log(f(t))
S = integrate.quad(lambda t: f(t)*K(t), 0, 60)[0]
C = integrate.quad(lambda t: f(t)*K(t)**2, 0, 60)[0] - S*S
print(round(S, 4), round(C, 4), round(math.pi**2/6 - 1, 4))                # 0.8841 0.6449 0.6449
```
출력은 1.015, 0.991, 1.06 정도다. 표본 분산의 상대 잡음은 약 $\sqrt{2/\text{시행 수}}$(4000번에서 2%, 400번에서 7%)이므로 모두 잡음 안에서 1이다. 감마(2)는 $S=0.8841$, $C=\pi^2/6-1=0.6449$.

## 18.2절

**18.2.1.** $(\delta,\delta,\delta)$: $x$와 $y$ 팔의 차 $\delta-\delta=0$. $(\delta,-\delta,0)$: $\delta-(-\delta)=2\delta$.

**18.2.2.** 정리 15.4.1에서 중력은 $|A|$만 보고 회전 $\varphi$는 원천을 만들지 않으며, 같은 틀에서 새긴 길이의 비는 회전과 무관하므로, 실험실의 모든 자와 시계가 함께 도는 공통 회전은 국소 비교에 나타나지 않는다.

**18.2.3.** 정리 A의 (1)단계는 "원천이 가지(분해의 원소)에 의존하면 신호가 생긴다"였다. 정리 18.2.1은 "계량이 화소 시계의 한 실현에 반응하면 원천이 한 가지에 의존하는 것과 같다"이다. 둘 다 원천이 확률 분포의 평균이 아닌 한 실현에 의존하는 것을 금지하는 같은 구조다.

**18.2.4.** 축마다 시계가 따로 있으면 요동이 서로 독립($\rho=0$)이 되어 차등 간섭계에 $\alpha\sim1$의 신호가 생기고, Holometer가 이를 배제한다(18.3절). 이론 안에서는 9.4절과 부딪친다. 가둠 ⇔ 붙잡힘에서 강한 결합 $\alpha_s=a^3$은 세 축을 한꺼번에 기록한 단일항, 곧 사건 하나였다. 축마다 따로 기록되는 판본은 이 구조와 맞지 않는다.

**18.2.5.** 기울기 $\pi/8$은 14장에서 인과 절반 잠금(CL)으로 유도되었다. 화소 요동이 쌓여 그 기울기가 된다는 연결은 크기를 계산하지 않았다. 요동의 크기에서 $\pi/8$을 다시 얻는 계산이 없으므로, 둘을 잇는 말은 증거가 아니라 읽기다.

## 18.3절

**18.3.1.** $\alpha_{\rm diff}=0.05$. GQuEST의 $3\sigma$ 도달 범위 0.1보다 작아 0과 가를 수 없다.

**18.3.2.** $1-\rho\le0.1$에서 $\rho\ge0.9$.

**18.3.3.** $J$의 고윳값은 3(한 번)과 0(두 번)이므로 $\Sigma$의 고윳값은 $1+2\rho$와 $1-\rho$(두 번)다. 양의 준정부호 조건은 $-\tfrac12\le\rho\le1$. $\rho<0$이면 $\alpha_{\rm diff}=1-\rho>1$이고 최대 $\rho=-\tfrac12$에서 1.5다.

**18.3.4.** $\mathrm{Var}((1+\varepsilon)d_x-d_y)=(1+\varepsilon)^2+1-2\rho(1+\varepsilon)=2(1-\rho)(1+\varepsilon)+\varepsilon^2$. 정규화하면 $\alpha_{\rm diff}=(1-\rho)(1+\varepsilon)+\varepsilon^2/2$. $\rho=1$이면 $\varepsilon^2/2$, $\varepsilon=0$이면 $1-\rho$.

**18.3.5.** $0.30\pm0.05$: 0에서 $6\sigma$ 떨어진 검출이고 값이 0.1 이상이므로 기각. $0.12\pm0.05$: 0에서 $2.4\sigma$라 $5\sigma$ 검출이 아니므로 기각되지 않는다. 다만 다음 측정에서 주목할 값이다.

**18.3.6.**
```python
import numpy as np

def alpha_diff(rho, eps=0.0, n=400000, seed=4):
    rng = np.random.default_rng(seed)
    cov = np.full((3, 3), rho) + (1 - rho)*np.eye(3)
    d = rng.multivariate_normal(np.zeros(3), cov, n)
    return float(((1 + eps)*d[:, 0] - d[:, 1]).var()/2)

for rho in (0.0, 0.5, 0.9, 0.99, 1.0):
    print(rho, round(alpha_diff(rho), 5))                 # 1.0, 0.5, 0.1, 0.01, 0
for eps in (1e-2, 1e-3):
    print(eps, f"{alpha_diff(1.0, eps):.2e}")            # 5.0e-05, 5.0e-07
```

## 18.4절

**18.4.1.** (1) 가정: 응답 모형은 요동이 방향마다 독립으로 계량을 흔든다고 가정한다. (2) 대조: QG1(중력은 확률 무게의 평균에 반응)과 어긋난다. (3) 대입하지 않는다: 긴장을 이론의 위험으로 적지 않는다. (4) 다시 계산: 18.2절(공통 회전), 18.3절($\alpha_{\rm diff}=1-\rho=0$). (5) 지위: Holometer·LIGO와의 일치는 일관성, GQuEST(P42)가 시험.

**18.4.2.** (가) 목격 후 가설의 일치(증거 아님). (나) 독립적 일관성. (다) 기존 원리의 적용(기존 자료와의 일치는 일관성). (라) 사전 등록 예측.

**18.4.3.** 예를 들어 "고친 원리가 자료보다 먼저 있었는가"와 "새로 반증 가능한 예측을 내놓았는가". 앞의 것은 결론이 자료에 맞춰 만들어지지 않았음을 보이고, 뒤의 것은 이론이 계속 틀릴 위험을 진다는 것을 보인다. "기존 자료와의 일치를 증거로 세지 않는다"를 고르는 것도 좋은 답이다.

**18.4.4.** 예 1(15.4절 성장): 표준 성장 방정식과 전달함수는 중력이 척도인자의 크기 $|A|$와 평균 밀도에 반응한다고 가정한다. 이는 정리 15.4.1과 QG1(평균장)과 맞는다. 예 2(17.5절 링다운): 분석 모형은 "기본 모드가 넓이 양자화의 선 가운데 하나에 있어야 한다"고 가정한다. 이 가정은 HP 자체에서 따라 나온 것이 아니라 분석 모형의 가정이다. 그래서 P40의 판정은 그 모형에 기대며, 약한 시험이라는 단서가 붙는다.

**18.4.5.** 결과를 본 뒤 탈출구(모형 세부, 적용 범위 축소)를 골라 쓸 수 있다면, 어떤 결과가 나와도 이론을 살릴 방법이 생긴다. 그러면 이론은 아무것도 금지하지 않게 되어 반증할 수 없다. 탈출구를 미리 "쓰지 않음"으로 적어 두는 것은 이론이 틀릴 수 있는 길을 열어 두는 일이다.
