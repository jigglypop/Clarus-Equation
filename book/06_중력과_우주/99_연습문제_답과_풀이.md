## 6.1절

**6.1.1.** $r_s=2GM/c^2=2\times6.674\times10^{-11}\times5.97\times10^{24}/(2.998\times10^8)^2=8.87\times10^{-3}$ m.

**6.1.2.** $ds^2=-(3.0\times10^8)^2+(2\times10^8)^2=-5\times10^{16}$ m² $<0$이므로 시간꼴이다. 첫 사건이 둘째 사건에 영향을 줄 수 있다.

**6.1.3.** 먼지의 정지 틀 4-속도 $u_d$와 관측자 4-속도 $u$의 내적은 $u_d\cdot u=-\gamma$다($c=1$). $T_{\mu\nu}u^\mu u^\nu=\rho(u_d\cdot u)^2=\gamma^2\rho$. 한 번의 $\gamma$는 길이 수축으로 늘어난 밀도, 또 한 번은 운동 에너지다. 진공은 $T_{\mu\nu}=-\rho g_{\mu\nu}$라 모든 관측자에게 $\rho$다. 먼지는 틀에 따라 달라 보이고 진공은 그렇지 않다.

**6.1.4.** 느린 입자는 $dx^0/d\tau\approx1$이고 공간 속도가 작아 측지선 방정식에서 $\Gamma^i_{00}$만 남는다: $\ddot x^i=-\Gamma^i_{00}$. 정적 계량에서 $\Gamma^i_{00}=-\tfrac12\partial_ig_{00}=\partial_i\Phi$이므로 $\ddot x^i=-\partial_i\Phi$. ∎

**6.1.5.** 정지한 시계는 $dr=d\Omega=0$이므로 $c^2d\tau^2=-ds^2=(1-r_s/r)c^2dt^2$, 곧 $d\tau=\sqrt{1-r_s/r}\,dt$다.

**6.1.6.** 반지름 방향 빛은 $ds^2=0$에서 $dr/dt=\pm c(1-r_s/r)$다. $r_0$에서 $r_s$까지의 좌표 시간은 $\frac1c\int_{r_s}^{r_0}\frac{dr}{1-r_s/r}=\frac1c\big[r+r_s\ln(r-r_s)\big]_{r_s}^{r_0}$로, $r\to r_s$에서 로그 발산한다.
```python
import numpy as np
from scipy import integrate
rs, c = 1.0, 1.0
for eps in (1e-2, 1e-4, 1e-6):
    t = integrate.quad(lambda r: 1/(c*(1 - rs/r)), rs + eps, 10*rs)[0]
    print(eps, t)   # eps를 줄일 때마다 약 rs*ln(100)=4.6씩 는다
```

## 6.2절

**6.2.1.** $T_H=\hbar c^3/(8\pi GMk_B)=1.23\times10^{11}$ K. 작은 블랙홀은 뜨겁다.

**6.2.2.** $M=\hbar c^3/(8\pi Gk_BT)=4.50\times10^{22}$ kg, 달 질량의 0.61배. 이보다 무거운 블랙홀은 오늘의 우주배경복사보다 차가워 증발보다 흡수가 많다.

**6.2.3.** $a=2\pi ck_BT/\hbar=2.47\times10^{20}$ m/s². 운루 효과를 실험실에서 보기 어려운 이유다.

**6.2.4.** $dMc^2=T_HdS$에서 $dS=\frac{8\pi GMk_B}{\hbar c^3}c^2dM=\frac{8\pi Gk_B}{\hbar c}M\,dM$. 적분하면 $S=\frac{4\pi Gk_B}{\hbar c}M^2$. $A=4\pi r_s^2=\frac{16\pi G^2M^2}{c^4}$이므로 $S=\frac{k_Bc^3A}{4\hbar G}=\frac{k_BA}{4\ell_P^2}$. ∎

**6.2.5.** $N=A/a\ell_P^2$개의 칸에 칸마다 $d$개 상태이면 $S=N\ln d$다. $S=A/4\ell_P^2$이려면 $\ln d/a=\tfrac14$. $a=1$: $d=e^{1/4}=1.284$. $a=4$: $d=e=2.718$. $a=4\ln2=2.77$: $d=2$(칸마다 1 bit). 정수 $d$를 주는 칸 넓이는 자연스러운 값이 아니다.

**6.2.6.** $c/H_\Lambda=5317$ Mpc $=1.641\times10^{26}$ m, $\ell_P=1.616\times10^{-35}$ m. $\pi(1.641\times10^{26}/1.616\times10^{-35})^2=3.24\times10^{122}$.

**6.2.7.**
```python
import math
def kerr(M, J):
    a = J/M; rp = M + math.sqrt(M*M - a*a)
    S = math.pi*(rp*rp + a*a)                        # A/4
    T = (rp - M)/(2*math.pi*(rp*rp + a*a))
    Om = a/(rp*rp + a*a)
    return S, T, Om
worst, h = 0.0, 1e-6
for chi in (0.0, 0.3, 0.6, 0.9, 0.99):
    S, T, Om = kerr(1.0, chi)
    dSdM = (kerr(1+h, chi)[0] - kerr(1-h, chi)[0])/(2*h)
    worst = max(worst, abs(T*dSdM - 1))                      # dM = T dS (J 고정)
    if chi > 0:
        dSdJ = (kerr(1, chi+h)[0] - kerr(1, chi-h)[0])/(2*h)
        worst = max(worst, abs(T*dSdJ + Om))                 # 0 = T dS + Om dJ (M 고정)
print(worst)   # 약 4e-9
```
유한차분 잔차는 $4\times10^{-9}$로, 첫째 법칙이 성립한다.

## 6.3절

**6.3.1.** $\eta=1/\ell_P^2=1/\hbar G$이므로 $G_{\rm eff}=1/(4\hbar\eta)=G/4$. 비 0.25.

**6.3.2.** 클라우지우스 관계 $\delta Q=T\eta\,dA$에서 $T$와 $\eta$는 곱으로만 들어간다. $T$를 두 배로 잡으면 $\eta$를 두 배로 잡은 것과 같아 $G_{\rm eff}$가 절반이 된다. 온도의 규격화와 엔트로피의 규격화가 함께 뉴턴 상수를 정한다.

**6.3.3.** 2차원에서 널 벡터는 $k=(1,\pm1)$이다. $A_{00}\pm2A_{01}+A_{11}=0$에서 $A_{01}=0$, $A_{11}=-A_{00}$. $g=\mathrm{diag}(-1,1)$이므로 $A=-A_{00}\,g$, 곧 $g$에 비례한다. ∎

**6.3.4.** $d\theta/d\lambda=-\tfrac12\theta^2-\sigma^2-R_{\mu\nu}k^\mu k^\nu$에서 $\lambda=0$에서 $\theta=\sigma=0$이면 $d\theta/d\lambda|_0=-R_{\mu\nu}k^\mu k^\nu$이다. 1차에서 $\theta(\lambda)=-\lambda R_{\mu\nu}k^\mu k^\nu$(θ²와 σ²는 2차). ∎

**6.3.5.** 직접 지지하거나 반대하지 않는다. 논증은 아인슈타인 방정식이 거시적 상태방정식으로 나올 수 있음을 보일 뿐, 미시 자유도가 무엇인지(양자 얽힘을 나르는 중력자인지)는 말하지 않는다. 다만 "중력은 열역학적 상태방정식"이라는 그림은, 중력장 자체를 기본 양자 자유도로 볼 필요가 없다는 쪽으로 기운다. 렌더링 이론은 이 그림을 확률 무게 중력(16장)과 함께 써서, 중력이 얽힘을 만들지 않는다고 예측한다(P23). 이것은 읽기이지 논증의 귀결이 아니다.

## 6.4절

**6.4.1.** $a=1/(1+z)=\tfrac12$.

**6.4.2.** $\rho\propto a^{-3(1+w)}=a^{-3\cdot\frac13}=a^{-1}$.

**6.4.3.** $\sqrt{0.6847/0.3153}=1.4736$, $\mathrm{arsinh}=1.1674$, $1/H_0=14.516$ Gyr, $t_0=\frac{2}{3\times0.82747}\times14.516\times1.1674=13.80$ Gyr.

**6.4.4.** 평탄하고 먼지와 진공만 있으면 $\dot a^2=H_0^2(\Omega_ma^{-1}+\Omega_\Lambda a^2)$다. $t_0=\int_0^1\frac{da}{H_0\sqrt{\Omega_ma^{-1}+\Omega_\Lambda a^2}}=\frac1{H_0}\int_0^1\frac{\sqrt a\,da}{\sqrt{\Omega_m+\Omega_\Lambda a^3}}$. $x=a^{3/2}$로 두면 $dx=\tfrac32\sqrt a\,da$이고 $t_0=\frac2{3H_0}\int_0^1\frac{dx}{\sqrt{\Omega_m+\Omega_\Lambda x^2}}=\frac{2}{3H_0\sqrt{\Omega_\Lambda}}\mathrm{arsinh}\sqrt{\Omega_\Lambda/\Omega_m}$. ∎

**6.4.5.** $\tfrac23\mathrm{arsinh}\,x=\pi/4$에서 $x=\sinh(3\pi/8)=1.4700$, $\Omega_\Lambda/\Omega_m=2.1609$, $\Omega_m=1/3.1609=0.3163$.

**6.4.6.** $\dot\rho=-3H(1+w)\rho$이고 $H=\dot a/a$이므로 $d\ln\rho/d\ln a=-3(1+w)$, 곧 $\rho\propto a^{-3(1+w)}$. ∎

**6.4.7.**
```python
import math
from scipy import integrate
h, Om = 0.67772, 0.30796
E = lambda z: math.sqrt(Om*(1+z)**3 + 1 - Om)
DM = 299792.458/(100*h) * integrate.quad(lambda z: 1/E(z), 0, 1)[0]
print(DM)   # 약 3396 Mpc
```

## 6.5절

**6.5.1.** $\theta^*=0.01041$ rad $=0.596^\circ$. 보름달 지름(약 0.5°)과 비슷하다.

**6.5.2.** $c_s=c/\sqrt3=0.577c$. 복사가 지배하는 유체의 소리 속도다.

**6.5.3.** $r_d=99.99/0.6777=147.5$ Mpc.

**6.5.4.** $\theta^*$는 같은 시기(재결합)에 같은 물리로 새겨진 길이 $r_s$와 거리 $D_M$의 비, 곧 무차원 각이다. 관측자의 운동은 하늘 전체를 쌍극자 모양으로 조금 일그러뜨릴 뿐 음향 무늬의 평균 각 척도를 바꾸지 않는다. 시계나 막대의 단위를 바꾸어도 비는 그대로다.

**6.5.5.** $\Omega_m$을 고정하면 $E(z)$가 그대로이고 $D_M=\frac c{H_0}\int\frac{dz}E$이므로 $D_M$은 $-1\%$, $\theta^*=r_s/D_M$은 $+1\%$다. 실제로는 $r_s$ 자체가 $\omega_b$와 $\omega_m=\Omega_mh^2$(물리적 밀도)에 의존한다. 초기 물리를 고정하려면 $\omega_m$을 고정해야 하고, 그러면 $h$를 바꿀 때 $\Omega_m$이 따라 바뀐다. 그래서 $\theta^*$의 정밀 측정은 $h$와 $\Omega_m$의 특정 조합을 강하게 묶는다.

**6.5.6.**
```python
import math
from scipy import integrate
h, Om, Or = 0.67772, 0.30796, 9.1e-5
E = lambda z: math.sqrt(Om*(1+z)**3 + Or*(1+z)**4 + 1 - Om - Or)
DM = 299792.458/(100*h) * integrate.quad(lambda z: 1/E(z), 0, 1090, limit=200)[0]
print(DM, 100*144.4/DM)   # 약 13914 Mpc, 약 1.038
```
어림값 1.038은 Planck의 1.0411과 0.3% 다르다. $r_s$를 고정한 어림이고 복사 밀도를 단순화했기 때문이다. 정밀 비교에는 같은 코드로 CE와 Planck 기준을 모두 계산해 상대 차이만 쓴다(15장).

## 6.6절

**6.6.1.** $(73.17-70.39)/\sqrt{0.86^2+1.94^2}=2.78/2.122=1.31\sigma$.

**6.6.2.** $(68.51-67.36)/\sqrt{0.58^2+0.54^2}=1.15/0.793=1.45\sigma$.

**6.6.3.** $1/\cos(\pi/8)=1.0824$, $73.17/67.36=1.0863$. 차이는 0.36%로, 두 측정의 비 오차(약 1.5%) 안이다.

**6.6.4.** 사다리는 기준점에서 주기–광도 관계(또는 다른 표준 촉광의 밝기)를 교정하고, 같은 관계를 먼 은하에 쓴다. 모든 시계가 인자 $k$로 느려지면 주기가 모두 $k$배가 되어 $\log k$가 교정의 절편에 흡수된다. 적색편이는 같은 시계로 잰 진동수의 비라 불변이다. 그래서 $H_0$는 바뀌지 않는다. 시계 여부가 아니라 "초기 기록으로 교정했는가, 현재의 막대로 교정했는가"가 판독을 가른다.

**6.6.5.** BAO는 $hr_d$를 재므로 $r_d$를 $\cos(\pi/8)$배 줄이면 추론한 $h$는 $1/\cos(\pi/8)=1.0824$배가 된다. $147.5\cos(\pi/8)=136.3$ Mpc. 허블 긴장을 풀려면 $r_d\approx137$ Mpc가 필요하다는 알려진 요구와 같은 크기다.

**6.6.6.** 초기 무리(Planck, DESI+BBN): 가중 평균 $67.89\pm0.40$. 현재 무리(SH0ES, CCHP, TDCOSMO(대칭화 ±3.6), H0DN): $73.06\pm0.56$. 다만 H0DN과 SH0ES는 자료를 일부 공유하므로 독립 가정은 오차를 과소평가한다.
