# 렌더링 이론 — 입력 하나로 입자와 우주를 함께 채점하는 이론

이 책은 **렌더링 이론**을 처음 보는 사람을 위해 쓴 책입니다. 렌더링 이론은 "현실은 참과 거짓이 하나씩 기록되며 확정된다"는 생각에서 출발합니다. 이 생각을 수식으로 옮겨, 강한 힘의 세기 $\alpha_s$ 하나만으로 입자물리와 우주론의 관측 43개를 함께 채점합니다.

- **결과:** 표준화 잔차의 공동 RMSE는 0.834(39행)와 0.878(43행)입니다. 같은 행에서 표준 모형과 ΛCDM(SM+ΛCDM)은 1.442와 1.471입니다.
- **예측:** 사전 등록한 예측은 41개입니다. 그중 1개(P17, 중성미자 질량 합)는 이미 기각되었습니다.
- **한계:** 이 책의 판정은 **2026-09-24 기준**입니다. 수치 일치와 테스트 통과는 구현의 증거일 뿐, 자연에 대한 증명이 아닙니다. 이론의 성패는 앞으로 나올 관측이 가립니다.

## 읽는 두 갈래

| 목적 | 경로 |
|---|---|
| 이론의 주장, 근거, 예측, 한계를 빨리 알고 싶다 | [01장 논문형 개관](01_논문형_개관/00_장_개요.md)만 읽는다 |
| 식을 하나씩 유도하며 배우고 싶다(학부 2학년 이상) | [00장 머리말](00_머리말/00_장_개요.md) → 02장부터 차례로 |

## 지위 표기

모든 주장 앞에 지위를 굵게 붙입니다. 자세한 규칙은 [00장 3절](00_머리말/03_지위_표기와_정직성.md)에 있습니다.

| 표기 | 뜻 |
|---|---|
| **[정의]** | 이름을 붙이는 약속 |
| **[공리]** | 증명 없이 받아들이는 출발점 |
| **[정리]** | 공리와 정의에서 유도된 명제 |
| **[조건부 정리]** | 명시된 추가 조건 아래서 유도된 명제 |
| **[읽기]** | 식을 물리량으로 번역하는 규칙(유도가 아님) |
| **[가설]** | 자료를 보고 고른 규칙. bit 비용을 적는다 |
| **[경험식]** | 자료에 맞췄으나 아직 유도가 없는 식 |
| **[산출]** | 위의 것들로 계산한 수치 |
| **[예측]** | 사전 등록된 산출(P번호) |
| **[기각]** | 관측이나 반례로 죽은 판본 |
| **[열림]** | 아직 답이 없는 문제 |
