## 11.1절

**11.1.1.** $S=\begin{pmatrix}0&0&1\\1&0&0\\0&1&0\end{pmatrix}$($e_1\to e_2\to e_3\to e_1$). 세 번 밀면 제자리이므로 $S^3=I$.

**11.1.2.** 위의 $S$에서 $(Sv)_1=v_3$, $(Sv)_2=v_1$, $(Sv)_3=v_2$다. $v_1=(1,\omega,\omega^2)/\sqrt3$이면 $Sv_1=(\omega^2,1,\omega)/\sqrt3=\omega^2(1,\omega,\omega^2)/\sqrt3=\bar\omega v_1$. 곧 고윳값은 $\bar\omega$다. $S$의 방향을 반대로 잡으면 $\omega$가 된다. 어느 쪽이든 $v_1$은 고유벡터다.

**11.1.3.** $(S^jn)_x$는 $n$의 성분 가운데 하나이고, $j=0,1,2$에서 세 성분이 한 번씩 나온다. 따라서 $\tfrac13\sum_j|(S^jn)_x|^2=\tfrac13(|n_x|^2+|n_y|^2+|n_z|^2)=\tfrac13$. ∎

**11.1.4.** 두 부문의 고유벡터 집합은 같고, 어느 고유벡터를 몇 세대라 부를지(질량 순서)만 다르다. 순서가 다르면 CKM $=U_u^\dagger U_d$는 순서를 맞바꾸는 순열 행렬이 된다. 예를 들어 위 쿼크에서 2세대와 3세대의 고유벡터가 뒤바뀌면 CKM은 2↔3을 맞바꾸는 순열이다. 관측된 CKM은 단위행렬에 가까우므로 순서가 같은 경우다.

**11.1.5.**
```python
import numpy as np
w = np.exp(2j*np.pi/3)
F = np.array([[1, 1, 1], [1, w, w**2], [1, w**2, w]]) / np.sqrt(3)   # 이산 푸리에 행렬
c, s = np.cos(np.pi/4), np.sin(np.pi/4)
R13 = np.array([[c, 0, s], [0, 1, 0], [-s, 0, c]])
U = F @ R13
P = np.abs(U)**2
print(np.round(P, 6))
# 열의 순서를 (1열, 0열, 2열)처럼 맞바꾸면 [[2/3,1/3,0],[1/6,1/3,1/2],[1/6,1/3,1/2]]의 행 순서가 된다
TBM = np.array([[2/3, 1/3, 0], [1/6, 1/3, 1/2], [1/6, 1/3, 1/2]])
import itertools
best = min(np.abs(P[np.ix_(r, c)] - TBM).max()
           for r in itertools.permutations(range(3)) for c in itertools.permutations(range(3)))
print(best)   # 1e-16 수준
```
행과 열의 순서(세대와 질량 상태의 이름 붙이기)를 맞추면 TBM과 기계 정밀도로 같다.

## 11.2절

**11.2.1.** G1에서 1세대와 3세대는 가중치가 모두 1이라 $w_1/w_3=1$이다. 1↔3 전이는 경계 인자를 받지 않는다.

**11.2.2.** $4u=\hat s^2$이므로 $|V_{us}|=\hat s^2/w$.

**11.2.3.** 이론 $0.041637/0.22493=0.18511$, 관측 $0.04183/0.22501=0.18590$. 0.4% 차이다.

**11.2.4.** 조건 $n_1-n_2=-1$, $n_2-n_3=1$, $n_1-n_3=0$에서 $n_2=n_1+1$, $n_3=n_1$. 범위 $\{-1,0,1\}$에서 가능한 해는 $(-1,0,-1)$, $(0,1,0)$ 둘이고, 둘은 공통 이동으로 같다. 범위를 넓혀도 해는 공통 이동한 것들뿐이다. 공통 이동은 모든 전이 인자 $w_i/w_j$를 바꾸지 않으므로 물리적으로 같은 해다.

**11.2.5.** $|V_{cb}|=uw=0.059459$, pull $(0.059459-0.04183)/0.00069=+25.5\sigma$. 시간 통로 $\varepsilon$ 없이는 크게 틀린다.

**11.2.6.** 지수 $(8,9,16)$은 자료에서 역산한 뒤에 알려졌고, "통로 수"라는 읽기는 그 뒤에 붙였다. 작은 정수를 설명할 방법은 많아서(목격 후 가족은 크다), 이런 읽기가 맞는 것은 우연 확률이 높다. 또 이 읽기에서 새 예측이 나오지 않는다. 그래서 유도가 아니라 읽기다.

## 11.3절

**11.3.1.** $22.5+67.5+90=180$.

**11.3.2.** $J_{\rm max}=1/(6\sqrt3)=0.0962$이므로 $3.097\times10^{-5}/0.0962=3.2\times10^{-4}$, 곧 0.032%. CKM의 CP 위반은 가능한 최대의 3천분의 1이다.

**11.3.3.** {V, EXACT$_1\cup$EXACT$_2$, A}의 확률은 $(\tfrac18,\tfrac68,\tfrac18)$이고 각은 $(22.5^\circ,135^\circ,22.5^\circ)$다. 합은 $180^\circ$이지만 직각이 없다. 여집합이 V↔A를 맞바꾸므로 이 분할은 대칭이지만, ½을 갖는 사건이 없다.

**11.3.4.** 세 각이 같아도 삼각형은 복소평면에서 위쪽을 향할 수도, 아래쪽을 향할 수도 있다. 이 방향은 $J$(삼각형 넓이의 두 배)의 부호, 곧 CP 위반의 방향이다. 분할은 크기만 정하고 방향은 정하지 않으므로 1 bit의 선택이 남는다. 렌더링 이론은 이 bit를 "기록이 쌓이는 쪽이 미래"라는 시간 화살표로 읽고, 렙톤은 반대 방향이라고 둔다(M1).

**11.3.5.**
```python
import numpy as np
from scipy.optimize import fsolve
def ckm(s12, s23, s13, d):
    c12, c23, c13 = np.sqrt(1 - np.array([s12, s23, s13])**2); e = np.exp(1j*d)
    return np.array([[c12*c13, s12*c13, s13/e],
                     [-s12*c23 - c12*s23*s13*e, c12*c23 - s12*s23*s13*e, s23*c13],
                     [s12*s23 - c12*c23*s13*e, -c12*s23 - s12*c23*s13*e, c23*c13]])
def angles(V):
    beta = np.angle(-V[1, 0]*np.conj(V[1, 2]) / (V[2, 0]*np.conj(V[2, 2])))
    alpha = np.angle(-V[2, 0]*np.conj(V[2, 2]) / (V[0, 0]*np.conj(V[0, 2])))
    return alpha, beta
vus, vcb = 0.22493, 0.041637
def eqs(x):
    s13, d = x; n = np.sqrt(1 - s13**2)
    a, b = angles(ckm(vus/n, vcb/n, s13, d))
    return [a - np.pi/2, b - np.pi/8]
s13, d = fsolve(eqs, [0.0037, 1.2])
V = ckm(vus/np.sqrt(1 - s13**2), vcb/np.sqrt(1 - s13**2), s13, d)
J = np.imag(V[0, 0]*V[1, 1]*np.conj(V[0, 1])*np.conj(V[1, 0]))
print(s13, d, J)   # 약 0.003676, 약 1.1787, 약 3.10e-5
```

## 11.4절

**11.4.1.** $\delta=\tfrac3{16}$, $(1+0.1875/2\pi)/4=0.257460$.

**11.4.2.** $105.6584/1776.93=0.0594612$.

**11.4.3.** 예측 0.2570742, 측정 $0.0594612/0.23129=0.2570850$. 오차는 $0.257085\sqrt{(5.1\times10^{-5})^2+(0.00004/0.23129)^2}=0.257085\times1.80\times10^{-4}=4.64\times10^{-5}$. pull $=(0.2570742-0.2570850)/4.64\times10^{-5}=-0.23$.

**11.4.4.**
```python
import math
from scipy.optimize import brentq
def f(a, target=0.0594612):
    u = a**(4/3); s2 = 4*u; d = s2*(1 - s2)
    return u*(1 + d/(2*math.pi)) - target
a0 = brentq(f, 0.10, 0.13)
a1 = brentq(lambda a: f(a, 0.0594612*(1 + 5.1e-5)), 0.10, 0.13)
print(a0, a1 - a0)   # 0.1179196, 4.4e-6
```
오차는 $m_\mu/m_\tau$의 상대 오차 $5.1\times10^{-5}$에서 온다. 그 대부분은 $m_\tau$(상대 $5\times10^{-5}$)이고 $m_\mu$는 훨씬 정밀하다. $\alpha_s\propto(m_\mu/m_\tau)^{3/4}$ 근처라 상대 오차는 약 $3.8\times10^{-5}$가 된다.

**11.4.5.** $x=\sqrt{m_e}$, $S=\sqrt{m_\mu}+\sqrt{m_\tau}$, $M=m_\mu+m_\tau$로 두면 $x^2+M=\tfrac23(x+S)^2$, 곧 $x^2-4Sx-2S^2+3M=0$이다. 작은 근 $x=2S-\sqrt{6S^2-3M}$. 측정 $m_\mu=105.6584$, $m_\tau=1776.93$ MeV에서 $m_e=0.51087$ MeV(측정 0.51100, 0.03% 차이).

**11.4.6.**
```python
import math
s2, r_obs = 0.23129, 0.0594612
x = s2*(1 - s2)/(2*math.pi)
sig = r_obs*math.hypot(5.1e-5, 0.00004/s2)
for name, w in (("선형", 1 + x), ("복리", math.exp(x)), ("기하", 1/(1 - x))):
    print(name, round((s2/4*w - r_obs)/sig, 2))   # -0.23, +1.95, +4.21
```

## 11.5절

**11.5.1.** $\tfrac12(1+\tfrac78\times0.177795)=0.5778$로 위 옥탄트다. S1의 높이 $(1,3,7)$은 $h_2=3\ne2h_1=2$라 공리 B(TM1)와 맞지 않는다. 또 SK 포함 자료와 $+6.3\sigma$다. 계단 공리(Bool)의 $(1,2,4)$로 대체되었다.

**11.5.2.** $\tfrac12(1+\tfrac12\times0.177795)=0.544449$.

**11.5.3.** TM1: $(1-3s_{13}^2)/[3(1-s_{13}^2)]=0.933327/2.933327=0.31818$. TM2: $1/[3(1-s_{13}^2)]=0.34091$.

**11.5.4.** $s_{23}^2=\tfrac12\pm\tfrac\delta4$이면 $s_{23}^2(1-s_{23}^2)=\tfrac14-\tfrac{\delta^2}{16}$이고 $\sin^22\theta_{23}=4s_{23}^2c_{23}^2=1-\tfrac{\delta^2}4$. 부호(옥탄트)와 무관하다. ∎

**11.5.5.** 선형 계단의 셋째 높이 $h_3=3$은 세계 8개 가운데 3개에서 "나"가 참이라는 뜻, 곧 $P(\text{나}=\text{참})=\tfrac38$이다. 무차별(Ind)에서는 모든 세계의 무게가 같아 이 확률이 $\tfrac48=\tfrac12$이어야 한다. $\tfrac38$은 거짓 쪽으로 치우친 무게다.

**11.5.6.** 두 계단의 $s_{23}^2$ 차이는 $\delta/16=0.01111$이다. 오차 0.004이면 $0.01111/0.004=2.8\sigma$다. $3\sigma$에는 조금 모자란다.

**11.5.7.**
```python
import numpy as np
from scipy.optimize import brentq
d = 0.1777949
s13, s12 = d/8, (1 - 2*d/8)/3
def U(s12, s23, s13, dl):
    a = np.sqrt([s12, s23, s13]); c = np.sqrt(1 - np.array([s12, s23, s13])); e = np.exp(1j*dl)
    return np.array([[c[0]*c[2], a[0]*c[2], a[2]/e],
                     [-a[0]*c[1] - c[0]*a[1]*a[2]*e, c[0]*c[1] - a[0]*a[1]*a[2]*e, a[1]*c[2]],
                     [a[0]*a[1] - c[0]*c[1]*a[2]*e, -c[0]*a[1] - a[0]*c[1]*a[2]*e, c[1]*c[2]]])
for s23 in (0.43, (1 - 4*d/8)/2, 0.47, 0.5, (1 + 4*d/8)/2, 0.561, 0.57):
    f = lambda deg: abs(U(s12, s23, s13, np.radians(deg))[1, 0])**2 - abs(U(s12, s23, s13, np.radians(deg))[2, 0])**2
    print(round(s23, 4), round(brentq(f, 181, 359), 2))
# 0.43 252.01 / 0.4556 258.76 / 0.47 262.46 / 0.5 270.0 / 0.5444 281.24 / 0.561 285.57 / 0.57 287.99
```

## 11.6절
