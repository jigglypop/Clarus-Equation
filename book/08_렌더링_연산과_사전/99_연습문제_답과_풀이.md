## 8.1절

**8.1.1.** $a=0.490370$. $A_1=0.4904$, $A_2=2a^2=0.4809$, $A_3=3a^3=0.3537$.

**8.1.2.** $A(m)=m\,a^m$을 $m$으로 미분하면 $a^m(1+m\ln a)$이다. 0이 되는 곳은 $m=-1/\ln a=1/0.71259=1.403$이다. 정수 가운데는 $m=1$(0.4904)이 $m=2$(0.4809)보다 조금 크다. 공평점($a=\tfrac12$)에서는 $m=-1/\ln\tfrac12=1.443$이고 $m=1,2$가 동률(½)이다.

**8.1.3.** $a=0.117916^{1/3}=0.49037$.

**8.1.4.** $R=\mathrm{diag}(a,a,b)$에서 $W_1=\mathrm{span}(e_1,e_2)$이면 $\det(B^\dagger RB)=a^2$, $W_2=\mathrm{span}(e_1,e_3)$이면 $ab$다. $a\ne b$이면 $A_2(W_1)=2a^2\ne2ab=A_2(W_2)$. 방향 무관성은 $R$이 스칼라일 때만 성립한다.

**8.1.5.** $R=aI_5$이면 상태 $e_S$의 무게는 $a^{k+j}$다. 단일항 넷의 무게는 $(0,0)$ 1, $(0,2)$ $a^2$, $(3,0)$ $a^3$, $(3,2)$ $a^5$로, 1이 아닌 무게가 $a^2,a^3,a^5$ 셋이다. 그러면 "가둔 기록의 무게"가 하나로 정해지지 않아 $\alpha_s=a^3$을 고를 여지가 생긴다. E1(색 축에만 작용)이 $\alpha_s=a^3$을 강제하는 조건이다.

**8.1.6.**
```python
import numpy as np
rng = np.random.default_rng(0)
a = 0.49037
R = a*np.eye(3)
for m in (1, 2, 3):
    worst = 0.0
    for _ in range(1000):
        B, _ = np.linalg.qr(rng.normal(size=(3, m)) + 1j*rng.normal(size=(3, m)))
        A = np.trace(B @ B.conj().T).real * np.linalg.det(B.conj().T @ R @ B).real
        worst = max(worst, abs(A - m*a**m))
    print(m, worst)   # 모두 1e-15 수준
```

## 8.2절

**8.2.1.** $\varepsilon=\alpha_s^{1/6}$이므로 $\varepsilon^8=\alpha_s^{4/3}$, $\varepsilon^9=\alpha_s^{3/2}$, $\varepsilon^{16}=\alpha_s^{8/3}$.

**8.2.2.** E4에서 $\hat s^2=4\alpha_s^{4/3}$이므로 $\alpha_s^{4/3}=\hat s^2/4$. 또 $A_2/\mathrm{tr}P_2=2a^2/2=a^2$이고 $u=a^4=\alpha_s^{4/3}$.

**8.2.3.** $u=0.0578225$, $w=1.028297$, $\varepsilon=0.700264$. $4u/w=0.231290/1.028297=0.22493$. $u\varepsilon w=0.0578225\times0.700264\times1.028297=0.041637$. $uw=0.059459$.

**8.2.4.** $|V_{cb}|/(m_\mu/m_\tau)=(u\varepsilon w)/(uw)=\varepsilon=0.70026$. 관측은 $0.04183/0.059461=0.70348$로 0.46% 크다. $|V_{cb}|$의 오차(1.6%) 안이다.

**8.2.5.** $\dim\mathfrak{su}(3)=8$, $\dim\mathfrak{su}(2)=3$, $\dim\mathfrak u(1)=1$, 합 12. 이 12는 단계 분해를 보존하는 대칭의 차원으로 계산되는 정리다. 반면 "e-fold 수 = $\tfrac32\cdot D\cdot12$"라는 배분 규칙(생성자마다 $\tfrac32D$ e-fold)은 자료에 맞춰 쓴 경험식이고 유도가 없다. 정리인 부분(12)과 경험식인 부분($\tfrac32D$)을 구분해야 한다.

## 8.3절

**8.3.1.** $2a^2=0.48093$에서 $a^2=0.240465$, $a=0.490373$, $\alpha_s=a^3=0.117917$. pull $=(0.117917-0.1180)/0.0009=-0.09$.

**8.3.2.** 같은 $a$에서 $\alpha_s=3a^3=0.35375$, pull $=(0.35375-0.1180)/0.0009=+262$. 강한 쪽에 합(축 수)을 붙이면 완전히 틀린다.

**8.3.3.** $\hat s^2=4a^4=(2a^2)^2=\sin^2\theta_W$. 곧 대조군 3의 $(3,4)$는 E4의 두 식 $\alpha_s=a^3$, $\sin\theta_W=2a^2$과 같다.

**8.3.4.** $\alpha_{\rm em}=1/127.951=0.0078155$, $\alpha_2=\alpha_{\rm em}/\hat s^2=0.033791$. $a^2=0.24047$이므로 비 $7.12$.

**8.3.5.** AP는 E4를 보고 세웠으므로 AP 가족에서 E4가 적중한 것은 구성상 당연하다(목격 후). 증거의 성격을 갖는 부분은 **대조군이 모두 떨어진다는 사실**이다. 강한 쪽에 합을 붙이거나, 약한 쪽에서 합을 빼면 각 25개 가운데 하나도 맞지 않는다. 이것은 "비대칭이 필요하다"는 제약이다. 그러나 대조군도 계산 전에 적었을 뿐 E4를 알고 설계했으므로, 이 결과는 "AP 모양이 자료와 일관된다"는 정도로만 센다. 새 예측은 아니다.

**8.3.6.**
```python
import numpy as np
from scipy.optimize import brentq
sw, s2, A0, S0 = 0.48093, 0.23129, 0.1180, 0.0009
def solve(f, target):
    xs = np.linspace(1e-6, 1 - 1e-6, 20001); g = f(xs) - target
    return [brentq(lambda a: f(a) - target, xs[i], xs[i+1]) for i in range(len(xs)-1) if g[i]*g[i+1] < 0]
families = {
    "AP":       (lambda m: (lambda a: a**m),     lambda k: (lambda a: k*a**k), sw),
    "기록에 합": (lambda m: (lambda a: m*a**m),   lambda k: (lambda a: k*a**k), sw),
    "합 제거":   (lambda m: (lambda a: a**m),     lambda k: (lambda a: a**k),   sw),
    "확률":      (lambda m: (lambda a: a**m),     lambda k: (lambda a: k*a**k), s2),
}
for name, (alpha, mix, target) in families.items():
    best = min(((abs((alpha(m)(a) - A0)/S0), (m, k), (alpha(m)(a) - A0)/S0)
                for m in range(1, 6) for k in range(1, 6) for a in solve(mix(k), target)), default=None)
    hits = [(m, k) for m in range(1, 6) for k in range(1, 6)
            for a in solve(mix(k), target) if abs((alpha(m)(a) - A0)/S0) <= 1]
    print(name, "적중", hits, "최선", best[1], round(best[2], 2))
```
출력: AP 적중 [(3, 2)], 기록에 합 적중 없음(최선 $+11.8$), 합 제거 적중 없음(최선 $-7.5$), 확률 적중 [(3, 4)].

## 8.4절

**8.4.1.** $\ln\det(aI_m)=m\ln a$이므로 $a\partial_a(m\ln a)=m$.

**8.4.2.** $a\partial_aa=a=0.48093$, $\alpha_s=a^3=0.11124$, pull $-7.5$.

**8.4.3.** $f_m(a)=m\,a^m(1-a)$의 최댓값은 $m=1$: $a=\tfrac12$에서 0.25. $m=2$: $a=\tfrac23$에서 $\tfrac8{27}=0.296$. $m=3$: $a=\tfrac34$에서 $\tfrac{81}{256}=0.316$. 모두 0.48093보다 작아 해가 없다.

**8.4.4.** $a\partial_a\det(aI_2)=2a^2$이 $a=\tfrac12$에서 ½, 제곱은 ¼이다. 공평점에서 섞임각은 $\sin\theta_W=\tfrac12$, $\sin^2\theta_W=\tfrac14$이다. 이것이 09장의 닻이다.

**8.4.5.** 두 규칙 모두 수학적 대상(에르미트 연산자, 행렬식과 그 미분)을 물리적 개념(관측량, 결합과 섞임)에 대응시키는 약속이다. 수학 안에서 증명할 명제가 아니다. 둘 다 시험 가능하다. 양자역학의 규칙은 그것으로 계산한 측정 통계가 맞는지로, 사전 D는 그것으로 계산한 예측(P20, P34, P36, P38)이 맞는지로 시험된다.
