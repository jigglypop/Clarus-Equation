## 4.1절

**4.1.1.** $P(0)=9/25=0.36$, $P(1)=16/25=0.64$.

**4.1.2.** $\langle+|\psi\rangle=(\cos\theta+\sin\theta)/\sqrt2$이므로 $P(+)=\tfrac12(\cos\theta+\sin\theta)^2=\tfrac12(1+\sin2\theta)$.

**4.1.3.** $A_1+A_2=\tfrac12(1+e^{i\phi})$이고 $|1+e^{i\phi}|^2=2+2\cos\phi$이므로 $P=\tfrac12(1+\cos\phi)$.

**4.1.4.** $|A_1+A_2|^2=(A_1+A_2)(A_1^*+A_2^*)=|A_1|^2+|A_2|^2+A_1A_2^*+A_2A_1^*$이고, $A_2A_1^*=(A_1A_2^*)^*$이므로 마지막 두 항의 합은 $2\mathrm{Re}(A_1A_2^*)$다. ∎

**4.1.5.** 복소 $m$차원 벡터는 실수 $2m$개다. 규격화로 1개, 전체 위상으로 1개를 빼면 $2m-2$개다. $m=2$이면 2개이고, 그 공간은 구면 $S^2$(블로흐 구)다.

**4.1.6.**
```python
import numpy as np
rng = np.random.default_rng(0)
psi = rng.normal(size=3) + 1j*rng.normal(size=3); psi /= np.linalg.norm(psi)
U, _ = np.linalg.qr(rng.normal(size=(3, 3)) + 1j*rng.normal(size=(3, 3)))
print(np.sum(abs(psi)**2), np.sum(abs(U.conj().T @ psi)**2))   # 1.0 1.0
```
유니터리 기저 변환은 벡터의 길이를 보존하므로 확률의 합은 어느 기저에서나 1이다.

## 4.2절

**4.2.1.** $\rho^2=\tfrac14\begin{pmatrix}2&2\\2&2\end{pmatrix}=\rho$이므로 순수 상태 $|+\rangle\langle+|$다.

**4.2.2.** $|\Psi^-\rangle$의 계수는 $(|01\rangle-|10\rangle)/\sqrt2$이다. $(\rho_B)_{00}=|c_{10}|^2=\tfrac12$, $(\rho_B)_{11}=|c_{01}|^2=\tfrac12$, $(\rho_B)_{01}=\sum_ac_{a0}c_{a1}^*=c_{00}c_{01}^*+c_{10}c_{11}^*=0$. 곧 $I/2$.

**4.2.3.** 파울리 행렬의 대각합이 0이므로 $\mathrm{Tr}\rho=1$이다. $\vec r\cdot\vec\sigma$의 고윳값은 $\pm|\vec r|$이므로 $\rho$의 고윳값은 $(1\pm|\vec r|)/2$다. 양의 준정치이려면 $|\vec r|\le1$이다. 순수(고윳값 1, 0)이려면 $|\vec r|=1$, 곧 블로흐 구의 표면이다.

**4.2.4.** $\mathrm{Tr}[(I\otimes\hat O)\rho_{AB}]=\sum_{i,j,j'}(\rho_{AB})_{ij,ij'}\hat O_{j'j}=\sum_{j,j'}(\rho_B)_{jj'}\hat O_{j'j}=\mathrm{Tr}(\rho_B\hat O)$. ∎

**4.2.5.** 블로흐 구의 서로 반대인 두 점이면 된다. 예: $|{\pm i}\rangle=(|0\rangle\pm i|1\rangle)/\sqrt2$에서 $\tfrac12|{+i}\rangle\langle{+i}|+\tfrac12|{-i}\rangle\langle{-i}|=\tfrac12(\tfrac12(I+\sigma_y)+\tfrac12(I-\sigma_y))=I/2$.

**4.2.6.**
```python
import numpy as np
rng = np.random.default_rng(1)
psi = rng.normal(size=4) + 1j*rng.normal(size=4); psi /= np.linalg.norm(psi)
M = psi.reshape(2, 2)                 # M[a, b] = <ab|psi>
rhoB = M.T @ M.conj()                 # rho_B[b, b'] = sum_a M[a,b] M*[a,b']
V, _ = np.linalg.qr(rng.normal(size=(2, 2)) + 1j*rng.normal(size=(2, 2)))
avg = sum(np.outer(V[:, k].conj() @ M, (V[:, k].conj() @ M).conj()) for k in range(2))
print(np.abs(avg - rhoB).max())       # 약 1e-16
```

## 4.3절

**4.3.1.** $\langle+|\psi\rangle=\frac1{\sqrt2}\cdot\frac1{\sqrt2}(1+e^{i\phi})$이므로 $P=\tfrac14|1+e^{i\phi}|^2=\tfrac14(2+2\cos\phi)=\tfrac12(1+\cos\phi)$.

**4.3.2.** 가시성은 $|\gamma|=1/\sqrt2=0.707$.

**4.3.3.** $\cos0.1=0.99500$이므로 $N=10$: 0.951, $N=100$: 0.606, $N=1000$: 0.0067. 환경 입자 하나하나는 거의 흔들리지 않아도, 그 수가 많으면 겹침이 지수적으로 사라진다. 거시적인 물체의 간섭을 보기 어려운 이유다.

**4.3.4.** 편광을 $|D\rangle$로 재면 두 경로의 조건부 진폭이 $\langle D|H\rangle=\langle D|V\rangle=1/\sqrt2$로 같아, 입자 상태는 $(|L\rangle+e^{i\phi}|R\rangle)/\sqrt2$가 되고 $P(+|D)=\tfrac12(1+\cos\phi)$다. $|A\rangle$로 재면 $\langle A|V\rangle=-1/\sqrt2$라 $P(+|A)=\tfrac12(1-\cos\phi)$다. 두 결과는 각각 확률 ½이므로 합치면 $\tfrac12\cdot\tfrac12(1+\cos\phi)+\tfrac12\cdot\tfrac12(1-\cos\phi)=\tfrac12$, 곧 무늬가 없다. 간섭은 결과별로 나눌 때만 보인다.

**4.3.5.** $|\gamma|=\cos^N\epsilon\approx e^{-N\epsilon^2/2}$이므로 $1/e$가 되는 $N\approx2/\epsilon^2$이다. $\epsilon=0.1$에서 200이다.
```python
import numpy as np
eps = 0.1
N = np.arange(1, 2001); g = np.cos(eps)**N
print(N[np.argmin(abs(g - np.exp(-1)))], 2/eps**2)   # 200 200.0
```

## 4.4절

**4.4.1.** 블로흐 벡터 $(0,0,\tfrac12)$와 $(0,0,-\tfrac12)$이므로 4.4.2의 공식으로 $D=\tfrac12|\vec r-\vec s|=\tfrac12$.

**4.4.2.** $\rho-\sigma=\tfrac12(\vec r-\vec s)\cdot\vec\sigma$의 고윳값은 $\pm\tfrac12|\vec r-\vec s|$이므로 $D=\tfrac12(\tfrac12+\tfrac12)|\vec r-\vec s|=\tfrac12|\vec r-\vec s|$. ∎

**4.4.3.** $e^{\mp i\kappa t\sigma_x}$는 블로흐 벡터를 $x$축 둘레로 $\pm2\kappa t$ 돌린다. $Z$ 가지 $|0\rangle$($+\hat z$)은 $(0,-\sin2\kappa t,\cos2\kappa t)$로, $|1\rangle$($-\hat z$)은 반대 방향으로 돌아 $(0,-\sin2\kappa t,-\cos2\kappa t)$로 간다. 평균은 $(0,-\sin2\kappa t,0)$이다. $X$ 가지의 평균은 원점이다. 따라서 $D=\tfrac12\sin2\kappa t$이고, $\kappa t=\pi/8$에서 $\tfrac12\sin(\pi/4)=0.354$, $\kappa t=\pi/4$에서 ½이다.

**4.4.4.** 벨 상태에서 $\rho_B=I/2$이므로 $\mathrm{Tr}(\rho_B\sigma_z)=0$이고 $H=0$이다. 앨리스가 무엇을 하든 $\rho_B$는 $I/2$이므로(무신호), $H$는 늘 0이고 밥의 상태는 변하지 않는다. 일반적으로 $H$가 $\rho_B$에만 의존하면 앨리스의 선택과 무관하다.

**4.4.5.**
```python
import numpy as np
from scipy.linalg import expm
rng = np.random.default_rng(0)
sx, sz = np.array([[0, 1], [1, 0]]), np.diag([1, -1])
def tdist(a, b): return 0.5*np.sum(abs(np.linalg.eigvalsh(a - b)))
def steer(psi, V):                       # 앨리스 기저 V로 잰 뒤 밥의 가지들
    M = psi.reshape(2, 2); out = []
    for k in range(2):
        amp = V[:, k].conj() @ M; p = np.real(amp.conj() @ amp)
        out.append((p, amp/np.sqrt(p)))
    return out
def evolve(branches, kt, ez_of):
    out = np.zeros((2, 2), complex)
    for p, v in branches:
        U = expm(-1j*kt*ez_of(v)*sx); w = U @ v
        out += p*np.outer(w, w.conj())
    return out
worst_branch = worst_rho = 0.0
for _ in range(200):
    psi = rng.normal(size=4) + 1j*rng.normal(size=4); psi /= np.linalg.norm(psi)
    V1, _ = np.linalg.qr(rng.normal(size=(2, 2)) + 1j*rng.normal(size=(2, 2)))
    V2, _ = np.linalg.qr(rng.normal(size=(2, 2)) + 1j*rng.normal(size=(2, 2)))
    M = psi.reshape(2, 2); rhoB = M.T @ M.conj(); ez_rho = np.real(np.trace(rhoB @ sz))
    branch = lambda v: np.real(v.conj() @ sz @ v)     # 가지마다의 기댓값
    local = lambda v: ez_rho                          # 국소 밀도행렬의 기댓값
    worst_branch = max(worst_branch, tdist(evolve(steer(psi, V1), np.pi/4, branch), evolve(steer(psi, V2), np.pi/4, branch)))
    worst_rho = max(worst_rho, tdist(evolve(steer(psi, V1), np.pi/4, local), evolve(steer(psi, V2), np.pi/4, local)))
print(worst_branch, worst_rho)   # 약 0.48, 약 5e-16
```
가지 규칙은 앨리스의 기저 선택에 따라 밥의 상태가 크게 달라진다(이 시드에서 최대 0.48). 밀도행렬 규칙은 수치 오차 수준이다. 저장소 모듈의 검사(최대 0.62)는 결합 세기와 상태 분포가 조금 다른 설정이라 최댓값이 다르지만, 결론은 같다.

## 4.5절

**4.5.1.** $k_BT\ln2=1.381\times10^{-23}\times300\times0.6931=2.87\times10^{-21}$ J이므로 $10^9$ bit는 $2.87\times10^{-12}$ J.

**4.5.2.** GHZ 사례다. 복사 조각이 셋 이상이지만 열 저장고가 없고 결맞음이 유지된다. R2는 기록(결맞음 없음)을 예측해 어긋나고, RL은 기록이 아니라고 판정해 맞는다.

**4.5.3.** 한 큐비트에 결어긋남이 생기면 그 큐비트의 $|0\rangle\langle1|$ 성분이 $\gamma$배가 된다. GHZ의 $|0\cdots0\rangle\langle1\cdots1|$ 성분은 각 큐비트의 $|0\rangle\langle1|$의 곱이므로 $\gamma$배가 된다. $N$개 모두에 생기면 $\gamma^N$배로, 큐비트가 많을수록 빠르게 사라진다. 그러나 결어긋남이 없는 고립계에서는 $N$이 커도 유지된다. 복사의 수가 아니라 환경과의 비가역적 얽힘이 결맞음을 지운다.

**4.5.4.** $\hbar/M_Zc=\hbar c/M_Zc^2=197.3\ \text{MeV fm}/91187\ \text{MeV}=2.16\times10^{-3}$ fm $=2.16\times10^{-18}$ m.

**4.5.5.** "복사됨"은 정보가 여러 곳에 있다는 뜻이고, 그 곳들이 모두 결맞음을 유지하면 전체 상태는 여전히 순수하며 되돌릴 수 있다(GHZ). "되돌릴 수 없음"은 정보가 열 저장고의 수많은 자유도로 흩어져 다시 모을 수 없다는 뜻이다. 렌더링 이론의 기록은 후자다. 그래서 고립된 결맞음 계는 몇 입자에 퍼져 있어도 아직 "렌더링되지 않은" 상태로 남는다.
