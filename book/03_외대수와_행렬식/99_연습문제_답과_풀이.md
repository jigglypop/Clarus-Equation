## 3.1절

**3.1.1.** $\binom42=6$, $2^4=16$.

**3.1.2.** $e_2\wedge e_1\wedge e_3$은 앞 둘을 한 번 바꾸면 $e_1\wedge e_2\wedge e_3$이므로 $-e_{123}$이다. $e_3\wedge e_2\wedge e_1$은 순열 $(1\,3)$(호환 하나)이므로 역시 $-e_{123}$이다.

**3.1.3.** $(e_1+e_2)\wedge(e_1-e_2)=-e_1\wedge e_2+e_2\wedge e_1=-2\,e_1\wedge e_2$.

**3.1.4.** 대우를 보인다. $u,v$가 일차독립이면 기저 $u,v,e_3,\dots$로 늘릴 수 있고, $u\wedge v$는 $\Lambda^2V$의 기저 원소이므로 0이 아니다. 따라서 $u\wedge v=0$이면 일차종속이다. ∎

**3.1.5.** 이항정리로 $\sum_k(-1)^k\binom nk=(1-1)^n=0$($n\ge1$)이다. 곧 짝수 등급의 합과 홀수 등급의 합이 같고, 둘을 더하면 $2^n$이므로 각각 $2^{n-1}$이다. ∎

**3.1.6.** $|T|=k$인 부분집합 $T$마다, $n\times k$ 행렬 $[v_1\cdots v_k]$의 행 $T$로 된 $k\times k$ 소행렬식을 $\phi_T(v_1,\dots,v_k)$라 하자. $\phi_T$는 각 인자에 선형이고 두 인자를 바꾸면 부호가 바뀌므로, $\Lambda^kV$ 위의 선형 함수로 내려간다. $\phi_T(e_S)=\delta_{ST}$다. $\sum_Sc_Se_S=0$이면 $\phi_T$를 쓰면 $c_T=0$이다. 따라서 $e_S$들은 일차독립이다. ∎

**3.1.7.**
```python
from itertools import combinations
subsets = [frozenset(c) for k in range(6) for c in combinations(range(5), k)]
print([sum(1 for s in subsets if len(s) == k) for k in range(6)])   # [1, 5, 10, 10, 5, 1]
full = frozenset(range(5))
comp = {s: full - s for s in subsets}
print(all(len(comp[s]) == 5 - len(s) for s in subsets), len(set(comp.values())) == 32)   # True True
```

## 3.2절

**3.2.1.** 첫 행으로 전개하면 $2(3\cdot1-0\cdot1)-0+1(1\cdot1-3\cdot0)=6+1=7$.

**3.2.2.** $\Lambda^2T\,e_{ij}=t_ie_i\wedge t_je_j=t_it_j\,e_{ij}$이므로 $\mathrm{diag}(t_1t_2,t_1t_3,t_2t_3)$.

**3.2.3.** $\det(aI_5)=a^5$. $aI_3\oplus I_2$는 색 축 셋에만 $a$를 곱하므로 $\det=a^3$.

**3.2.4.** $\Lambda^n(ST)(e_1\wedge\cdots\wedge e_n)=STe_1\wedge\cdots\wedge STe_n=\Lambda^nS(Te_1\wedge\cdots\wedge Te_n)=\Lambda^nS\,\Lambda^nT(e_1\wedge\cdots\wedge e_n)$. 양변의 수를 비교하면 $\det(ST)=\det S\det T$. ∎

**3.2.5.** $|\det U|^2=\overline{\det U}\det U=\det U^\dagger\det U=\det(U^\dagger U)=1$. $\det U=1$인 유니터리의 모임은 특수 유니터리 군 $SU(n)$이다.

**3.2.6.** $T$가 대각화 가능하고 $Tv_i=\lambda_iv_i$이면 $\Lambda^kT(v_{i_1}\wedge\cdots\wedge v_{i_k})=\lambda_{i_1}\cdots\lambda_{i_k}\,v_{i_1}\wedge\cdots\wedge v_{i_k}$이고, 이 벡터들이 $\Lambda^kV$의 기저다. 대각화가 안 되면 슈어 삼각화로 같은 결론을 얻는다(삼각행렬의 유도 작용도 적절한 순서의 기저에서 삼각이고 대각 원소가 고윳값의 곱이다). ∎

**3.2.7.**
```python
import numpy as np
rng = np.random.default_rng(0)
a = 0.49037
R = a * np.eye(3)
vals = []
for _ in range(100):
    Z = rng.normal(size=(3, 2)) + 1j * rng.normal(size=(3, 2))
    B, _ = np.linalg.qr(Z)          # 정규직교 열 두 개
    vals.append(np.linalg.det(B.conj().T @ R @ B).real)
print(min(vals), max(vals), a**2)   # 모두 0.24046
```

## 3.3절

**3.3.1.** 블록 $(k,j)$의 차원 $\binom3k\binom2j$: $k=0$: 1, 2, 1. $k=1$: 3, 6, 3. $k=2$: 3, 6, 3. $k=3$: 1, 2, 1. 합은 $4+12+12+4=32$.

**3.3.2.** $(2,0)$: 색 축 둘, $Q=-\tfrac23$(세 상태). $(2,2)$: $-\tfrac23+1+0=+\tfrac13$(세 상태).

**3.3.3.** 상태의 전하는 든 축의 전하 합이고, 축의 전하는 $-\tfrac13,1,0$이다. 모두 $\tfrac13$의 정수배이므로 합도 그렇다. 따라서 $Q\in\{0,\pm\tfrac13,\pm\tfrac23,\pm1\}$이고 전자 전하는 아래 쿼크 전하의 정확히 $-3$배다.

**3.3.4.** 행렬 $X$가 $SU(3)\times SU(2)$의 모든 원소와 교환한다고 하자. $V_3$와 $V_2$는 서로 다른 기약표현이므로 슈어 보조정리로 $X=\mathrm{diag}(x,x,x,y,y)$다. 대각합이 0이면 $3x+2y=0$이고, $y=\tfrac12$로 규격화하면 $x=-\tfrac13$이다. ∎

**3.3.5.** 32상태 전체의 합은 $Y(\text{전체})=\tfrac22-\tfrac33=0$, $T_3(\text{전체})=0$이다. 값이 축마다 더해지므로 $Y(S^c)=Y(\text{전체})-Y(S)=-Y(S)$, 마찬가지로 $T_3\to-T_3$, $Q\to-Q$다. $|S^c|=5-|S|$이므로 짝수와 홀수가 바뀐다. ∎

**3.3.6.** 색 단일항은 $k\in\{0,3\}$이고 약 부분집합은 4개이므로 8상태다. 전하는 $k=0$에서 $0,1,0,1$, $k=3$에서 $-1,0,-1,0$이다.

**3.3.7.** 무게는 약 점유 $j$에 대해 $a^j$이므로 $(0,0)$ 1, $(0,2)$ $a^2$, $(3,0)$ 1, $(3,2)$ $a^2$다. 1이 아닌 무게는 $a^2$이다. 이 논리는 "가두는 힘의 결합 = 가둔 기록의 무게"라는 읽기에 기댄다. 약력은 가두지 않는다(약력을 받는 입자는 혼자 나타난다). 그래서 약력 결합은 가둔 기록의 무게가 아니고, $\alpha_2\ne a^2$은 모순이 아니다. 약력의 흔적은 붙잡힘이 아니라 섞임각(회전)으로 남는다(09장).

**3.3.8.**
```python
from itertools import combinations
from fractions import Fraction as Fr
colour, weak = {0, 1, 2}, {3, 4}
def charges(S):
    k = len(S & colour)
    t3 = (Fr(1, 2) if 3 in S else 0) + (Fr(-1, 2) if 4 in S else 0)
    Y = Fr(len(S & weak), 2) - Fr(k, 3)
    return Y, t3, t3 + Y
even = [set(c) for n in (0, 2, 4) for c in combinations(range(5), n)]
print(len(even), sum(charges(S)[0] for S in even), sum(charges(S)[0]**3 for S in even), sum(charges(S)[2] for S in even))
# 16 0 0 0
```

## 3.4절

**3.4.1.** $\det e^X=e^{\mathrm{tr}X}=e^4=54.60$.

**3.4.2.** $a\partial_aa^3=3a^3$, $a\partial_aa^{-1}=-a^{-1}$, $a\partial_a\ln a=1$.

**3.4.3.** $\ln\det(aI_3)=3\ln a$이므로 $a\partial_a(3\ln a)=3$.

**3.4.4.** $M=ODO^T$($O$ 직교, $D$ 양의 대각)이면 $\ln M=O(\ln D)O^T$이고 $\mathrm{tr}\ln M=\sum_i\ln d_i=\ln\prod_id_i=\ln\det M$. ∎

**3.4.5.** $b=\lambda a$로 두면 $\partial_b=\lambda^{-1}\partial_a$이므로 $b\,\partial_b=\lambda a\,\lambda^{-1}\partial_a=a\partial_a$. $\partial_b=\lambda^{-1}\partial_a\ne\partial_a$($\lambda\ne1$). ∎

**3.4.6.** $m=1$: $a=0.48093$, $\alpha_s=a^3=0.11124$, pull $(0.11124-0.1180)/0.0009=-7.5$. $m=3$: $3a^3=0.48093$이므로 $\alpha_s=a^3=0.16031$, pull $+47.0$.

**3.4.7.** $\partial_aa^m=m\,a^{m-1}$. $m=1$: 상수 1이므로 해 없음. $m=2$: $2a=0.48093$, $a=0.24047$, $\alpha_s=0.013905$, pull $-115.7$. $m=3$: $3a^2=0.48093$, $a=0.40039$, $\alpha_s=0.064186$, pull $-59.8$.

**3.4.8.**
```python
import numpy as np
from scipy.optimize import brentq
sw, A0, S0 = 0.48093, 0.1180, 0.0009
ops = {"d": lambda a, m: m*a**(m-1), "a d": lambda a, m: m*a**m,
       "(1-a)d": lambda a, m: (1-a)*m*a**(m-1), "a(1-a)d": lambda a, m: a*(1-a)*m*a**(m-1),
       "a^2 d": lambda a, m: a*a*m*a**(m-1)}
xs = np.linspace(1e-6, 1-1e-6, 20001)
for name, f in ops.items():
    for m in (1, 2, 3):
        g = f(xs, m) - sw
        roots = [brentq(lambda a: f(a, m) - sw, xs[i], xs[i+1]) for i in range(len(xs)-1) if g[i]*g[i+1] < 0]
        print(name, m, [round((r**3 - A0)/S0, 1) for r in roots] or "해 없음")
```
출력 요약: `a d, m=2`만 $-0.1\sigma$. 그다음은 `a d, m=1`의 $-7.5\sigma$. `(1-a)d`는 $+24.3$, $-58.7$과 $+106.1$, 해 없음. `a(1-a)d`는 모두 해 없음. `a^2 d`는 $+136\sigma$ 이상이다.

## 3.5절

**3.5.1.** $P^2=\tfrac14\begin{pmatrix}2&2\\2&2\end{pmatrix}=P$, $P^\dagger=P$. 대각합은 1(1차원 부분공간 $(1,1)/\sqrt2$로의 사영).

**3.5.2.** $A_1=\tfrac12$, $A_2=2\cdot\tfrac14=\tfrac12$, $A_3=3\cdot\tfrac18=\tfrac38$.

**3.5.3.** $\Lambda^2$ 10상태: 색–색 셋은 $T_3=0$, $Q=-\tfrac23$. 색–약1 셋은 $T_3=\tfrac12$, $Q=\tfrac23$. 색–약2 셋은 $T_3=-\tfrac12$, $Q=-\tfrac13$. 약–약 하나는 $T_3=0$, $Q=1$. $\sum T_3^2=6\cdot\tfrac14=\tfrac32$, $\sum Q^2=3\cdot\tfrac49+3\cdot\tfrac49+3\cdot\tfrac19+1=\tfrac43+\tfrac43+\tfrac13+1=4$. 비는 $\tfrac38$.

**3.5.4.** $k=1$: 색 셋 × 약 부분집합 넷. $Q$는 $-\tfrac13+\{0,1,0,1\}$이므로 $\sum Q^2=3(\tfrac19+\tfrac49+\tfrac19+\tfrac49)=\tfrac{10}3$, $\sum T_3^2=3\cdot\tfrac12=\tfrac32$. $k=2$: $Q=-\tfrac23+\{0,1,0,1\}$이므로 $\sum Q^2=3(\tfrac49+\tfrac19+\tfrac49+\tfrac19)=\tfrac{10}3$, $\sum T_3^2=\tfrac32$. 합치면 $3/\tfrac{20}3=\tfrac9{20}$.

**3.5.5.** $a=\tfrac12$에서 $A_m=m/2^m$은 $\tfrac12,\tfrac12,\tfrac38,\tfrac14,\dots$로, $m=1,2$에서 최대(동률)다. 09장에서 이 두 값이 "닻 조건" $A_m^2=\tfrac14$의 해 $m\in\{1,2\}$가 된다.

**3.5.6.** 비는 $\frac{w_\ell\cdot1+w_q\cdot3}{w_\ell\cdot4+w_q\cdot\frac{20}3}$이다. 분모의 두 부분 $u=4w_\ell$, $v=\tfrac{20}3w_q$로 쓰면 비 $=\frac{u}{u+v}\cdot\tfrac14+\frac{v}{u+v}\cdot\tfrac9{20}$, 곧 $\tfrac14$와 $\tfrac9{20}$의 가중 평균이다. 따라서 $[\tfrac14,\tfrac9{20}]$ 안에 있다. ∎

**3.5.7.**
```python
from itertools import combinations
a = 0.49037
colour = {0, 1, 2}
T = Q = Tw = Qw = 0.0
for n in range(6):
    for c in combinations(range(5), n):
        S = set(c); k = len(S & colour)
        t3 = (0.5 if 3 in S else 0) + (-0.5 if 4 in S else 0)
        q = t3 + 0.5*len(S - colour) - k/3
        T += t3*t3; Q += q*q; Tw += a**k*t3*t3; Qw += a**k*q*q
print(T/Q, Tw/Qw)   # 0.375 0.354
```
$a^k$ 무게는 색이 많은 상태를 덜 세므로 비가 $\tfrac38$에서 렙톤 쪽($\tfrac14$)으로 조금 내려가 0.354가 된다. 실제 $\hat s^2=0.2313$에는 닿지 않는다.
