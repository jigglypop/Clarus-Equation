## 15.1절

**15.1.1.** $1-2/60=0.96667$, $12/3600=0.00333$.

**15.1.2.** $N_e=2/(1-0.9709)=68.7$이고 $D=N_e/18=3.82$다. 분별량이 $\delta=0.82$여야 하는데 $\delta\le\tfrac14$이므로 불가능하다. P-ACT의 값이 옳다면 $N_e=18D$의 배분이나 (15.1.1)의 관계가 수정되어야 한다.

**15.1.3.** $P_3=\mathrm{diag}(1,1,1,0,0)$과 교환하는 행렬은 블록 대각 $\begin{pmatrix}A&0\\0&B\end{pmatrix}$($A$는 $3\times3$, $B$는 $2\times2$)이다. 반에르미트이면 $\mathfrak u(3)\oplus\mathfrak u(2)$로 차원 $9+4=13$이고, 대각합 0 조건 하나가 빠져 12다. $=8+3+1$($\mathfrak{su}(3)$, $\mathfrak{su}(2)$, 초전하).

**15.1.4.** $r=8/N_e=8/57.2=0.140$으로 관측 상한 0.036을 크게 넘어 기각된다. (15.1.1)의 $r=12/N_e^2$(Starobinsky형)는 0.0037로 상한 안이다. 이론이 쓰는 관계는 후자다.

**15.1.5.**
```python
import math
q, D = 0.0486447209, 3.1777949359
Ne = 18*D
Q = (2/math.pi)*(1 - q)**(D/(D + 1))*q*(1 - q)
print(Q*Q/(1 - q)**2 * q/(2*math.pi*Ne**2))   # 2.1035e-9
```

## 15.2절

**15.2.3.** 에너지 밀도는 4-속도에 대해 2차($T_{\mu\nu}u^\mu u^\nu$)라 기울어진 틀로 투영하면 $\cos^2\theta$가 곱해지고, 인자는 $1-\Omega_m(1-\cos^2\theta)$가 된다. BAO의 $D/r_d$는 길이의 비, 곧 1차 양이라 투영은 $\cos\theta$다. 2차를 쓰면 BAO $\chi^2$가 16.47로 나빠진다(1차 10.99).

**15.2.4.** $1-0.30796(1-\cos0.08)=0.99902$. $z=0.3$의 인자 0.98625와의 비 $0.99902/0.98625=1.013$. 등록값 P25(1.0126)와 같다(기울기 값의 어림 차이).

**15.2.5.** 1 bit $=2\ln2=1.39$($\chi^2$). 기록 시기 무게(15.56) 대비 오늘 무게(10.99)의 이득은 4.57이다. 비용을 빼도 순이득 3.2가 남는다. 다만 무게 시점을 고른 사실은 장부에 1 bit로 남는다.

## 15.3절

**15.3.1.** E4에서 $\sin\theta_W=2a^2=2\alpha_s^{2/3}$이므로 $\sin\theta_W/2=\alpha_s^{2/3}=\xi^2$. 교정의 항등식이며, 진폭이 왜 이 값인지의 유도는 아니다.

**15.3.2.** $w_a=-3(1+w_0)(1-\Omega_\Lambda)=-3\times0.232\times0.308=-0.214$.

**15.3.3.** (T)가 없으면 $f=a\cos\varphi+b\sin\varphi$까지 허용된다. $\sin$ 항은 탄생($\varphi=0$)에서 위상 이동을 준다. (S)가 없으면 평균 0인 임의의 짝함수($\cos k\varphi$의 조합)가 허용되어, 주파수를 고를 여지가 생긴다(실제로 $\nu=1,3$은 $\theta^*$에서 기각됨). (S)는 가장 매끄러운 변조, 곧 최저 조화를 고른다.

**15.3.4.** 식을 풀면 $1+w=-\dot\rho/(3H\rho)$다. 팽창하는 우주에서 $H>0$, $\rho>0$이므로 $\dot\rho<0$이면 $1+w>0$, 곧 $w>-1$이다. 같은 식을 $a$로 쓰면 $w=-1-\tfrac13\,d\ln\rho/d\ln a$다. W2에서 $\varphi\in(0,\pi)$ 동안 $\cos\varphi$가 줄므로 $w>-1$이다.

**15.3.5.** 사전 규칙은 "판본 V(39행)와 43행을 **모두** 낮출 때만 채택"이었다. W3는 43행을 낮췄지만(0.864 대 0.877) 판본 V에서는 0.0015 높았다(0.8341 대 0.8326). 그래서 탈락했다. 결과를 본 뒤 "43행만 보면 된다"로 규칙을 바꾸면, 어느 판본이든 유리한 점수 하나를 골라 채택할 수 있게 된다. 이것은 봉합이다. 규칙을 지키고 W3를 경쟁 판본으로 남긴 뒤, 두 판본이 다르게 예측하는 $S_8$로 가린다.

**15.3.6.**
```python
import math
Om, h, a_s = 0.30796, 0.67772, 0.117916
OL = 1 - Om
xi2 = a_s**(2/3)
def t_of_a(a):                                # ΛCDM 배경의 나이, 1/H0 단위
    return 2/(3*math.sqrt(OL))*math.asinh(math.sqrt(OL/Om)*a**1.5)
def w_of_z(z):
    a = 1/(1 + z)
    E = math.sqrt(Om*(1 + z)**3 + OL)         # H/H0
    phi = math.sqrt(OL)*t_of_a(a)/2           # H_Lambda t / 2
    rate = math.sqrt(OL)/2                    # (H_Lambda/2)/H0
    return -1 + xi2*math.sin(phi)*rate/(3*E*(1 + xi2*math.cos(phi)))
print(w_of_z(0), w_of_z(1))   # -0.9894, -0.9974
```
$d\ln\rho/d\ln a=\dot\rho/(H\rho)$이므로 $w=-1+\dfrac{\xi^2\sin\varphi\,(H_\Lambda/2)}{3H(1+\xi^2\cos\varphi)}$다. 배경을 ΛCDM으로 어림했지만 결과는 등록값 $-0.9894$, $-0.9974$와 소수 넷째 자리까지 같다. 진공의 변화가 작아 배경을 거의 바꾸지 않기 때문이다.

## 15.4절

**15.4.1.** 이론(0.8161)이 관측(0.815)보다 크므로 위쪽 오차 0.016을 쓴다. $(0.8161-0.815)/0.016=+0.07$.

**15.4.2.** KiDS 오차를 대칭화하면 약 0.0185. $(0.815-0.776)/\sqrt{0.017^2+0.0185^2}=0.039/0.0251=1.55\sigma$. 두 렌즈 측정도 서로 조금 긴장한다.

**15.4.3.** 약한 렌즈는 배경 은하 모양의 일그러짐, 곧 하늘에서의 각도의 비를 잰다. 관측 사상 M에서 같은 틀 안의 비는 불변이다. 렌즈를 만드는 물질과 빛의 경로는 같은 시기의 기록을 같은 틀에서 비교하므로 기울기의 투영을 받지 않는다. 그래서 $S_8$은 회전과 무관하게 표준 계산을 쓴다. (BAO가 투영을 받는 것은 탄생 틀의 자와 비교하기 때문이다.)

**15.4.4.** W3에서 진공에서 먼지로 가는 에너지 전달은 먼지의 정지 틀($\varphi$가 일정한 면)에서 균일하다. 새 먼지는 요동 없이 고르게 태어난다. 기존 물질의 밀도 대비 $\delta\rho/\rho$는 분모에 균일한 새 먼지가 더해져 희석된다. 그래서 성장이 조금 억제되고 $S_8$이 작아진다(0.8228 → 0.8119).

## 15.5절

**15.5.1.** $0.05916/93.14=0.000635$.

**15.5.2.** $(7.403-7.50)/0.12=-0.81\sigma$.

**15.5.3.** $(7.403-7.50)/0.0225=-4.3\sigma$. P19의 기각 조건($3\sigma$)에 걸린다.

**15.5.4.** (1) P41은 P17 기각 **뒤에** 따로 등록되었고, P17의 값이나 기각 조건을 바꾸지 않는다(P17은 기각 그대로다). (2) P41이 시험하는 것은 다른 관측량, 곧 CE 판독(G1m)을 넣은 분석의 사후분포다. (3) P41이 기대는 기제 G1m은 P17 기각 **전에** 세운 것이라, 기각을 피하려고 만든 규칙이 아니다. 게다가 P41 자체도 기각될 수 있다(CE 판독 분석이 55 meV 아래 상한을 주면).

**15.5.5.** 판정 규칙을 결과를 본 뒤 정하면, 이론에 유리한 쪽으로 정할 유혹이 있다. 그 사실을 기록하고 **불리한 쪽**을 택했다는 것을 밝히면, 판정이 이론을 보호하려고 조작되지 않았음을 독자가 확인할 수 있다. 정직성 규칙의 핵심은 "결과를 본 뒤의 선택"을 숨기지 않는 것이다.

**15.5.6.**
```python
import math
a_s = 0.1179159756
s2 = 4*a_s**(4/3); d = s2*(1 - s2); D = 3 + d
P = d**4*(1 - a_s/math.pi)/((16*math.pi**2)**2*32*math.pi**3*(1 + a_s*D))
me, mmu, mt = 0.51100e6, 105.658e6, 1776.93e6          # eV
m = [P*x**(5/8)*mt**(3/8)*1e3 for x in (me, mmu, mt)]  # meV
print([round(v, 3) for v in m], round(sum(m), 2))       # [0.307, 8.609, 50.244] 59.16
print((m[1]**2 - m[0]**2)*1e-6, (m[2]**2 - m[0]**2)*1e-6)   # 7.40e-5, 2.524e-3 eV^2
```
