## 17.1절

**17.1.1.** 화소 하나가 1 nat이므로 $S=N$ nat이다. $10M_\odot$에서 넓이는 태양 질량의 100배이므로 $N=1.049\times10^{79}$, $S=1.049\times10^{79}$ nat $=1.513\times10^{79}$ bit.

**17.1.2.** $d=e^{a/4}$: $e^{0.25}=1.284$, $e^{0.5}=1.649$, $e^1=2.718$.

**17.1.3.** 가장 짧은 파장 $2\ell_P=3.232\times10^{-35}$ m, 가장 높은 공간 진동수 $1/(2\ell_P)=3.094\times10^{34}$ m⁻¹.

**17.1.4.** 밀도 $\tfrac12$이므로 $h=-\int_0^2\tfrac12\ln\tfrac12\,dt=\ln2$. 평균 한 틱 단위로 길이 1인 구간의 균등 분포는 엔트로피 0이다. 길이 2의 구간에서는 "앞쪽 절반인가 뒤쪽 절반인가"라는 모름이 더해진다. 그 모름이 공평한 동전 하나, 1 bit $=\ln2$ nat이다.

**17.1.5.** 2.4절의 사후 탐색: 결과를 본 뒤 후보 목록과 판정 규칙을 정하면, 맞는 조합이 나오는 것은 당연해지고 우연 확률 계산이 뜻을 잃는다. HP는 $\tfrac14$이 나오는 것을 암산으로 먼저 본 뒤 목록을 적었다. 증거가 되려면 (나이퀴스트 화소와 1 nat 시계라는) 규칙을 $\tfrac14$을 모르는 상태에서 먼저 적고 동결했어야 했다. 지금 HP가 증거를 얻는 길은 목격 전에 적은 새 예측(로그 보정, P40)이 맞는 것뿐이다.

**17.1.6.** LHAASO가 기각한 것은 시공간 자체를 칸으로 나누어 빛의 전파가 에너지에 따라 달라지는 판본이다. 화소는 지평선 위의 상태 수를 세는 단위이고, 시공간은 연속이며 로렌츠 불변이다. 해상도가 넓이로만 나타나므로 광속의 에너지 의존을 만들지 않는다.

**17.1.7.**
```python
import math

D = 3.1777949359
def poisson_entropy(lam, kmax=200):
    h, p = 0.0, math.exp(-lam)
    for k in range(kmax):
        if k > 0:
            p *= lam/k
        if p > 0:
            h -= p*math.log(p)
    return h

cands = {"동전 ln2": math.log(2), "지수 시계 1": 1.0, "ln3": math.log(3),
         "Poisson(D)": poisson_entropy(D), "가우스 시계": 0.5*math.log(2*math.pi*math.e)}
for side in (1, 2):
    for name, h in cands.items():
        v = h/side**2
        print(side, name, round(v, 4), "<- 1/4" if abs(v - 0.25) < 1e-12 else "")
```
정확히 $\tfrac14$인 것은 한 변 2, 지수 시계 1 nat 하나다. $H(\text{Poisson}(D))=1.9629$.

## 17.2절

**17.2.1.** $S_{10}=9\ln10-\ln9!=20.723-12.802=7.921$. 점근식 $10-\tfrac12\ln10-\tfrac12\ln2\pi=7.930$. 차이 0.008은 스털링 공식의 다음 항 $1/(12N)=0.0083$과 같다.

**17.2.2.** $89.4/1.049\times10^{77}=8.5\times10^{-76}$.

**17.2.3.** $N=2$: $t_1+t_2=2$는 $t_1\in[0,2]$의 선분이고 $t_1$로 잰 길이는 $2=2^1/1!$. $N=3$: $t_1+t_2+t_3=3$은 삼각형이고, $(t_1,t_2)$ 평면에 내린 그림자는 두 변 3인 직각삼각형으로 넓이 $4.5=3^2/2!$. 부피는 참 넓이가 아니라 앞의 $N-1$개 좌표로 잰 넓이다(참 넓이는 $\sqrt3$배). 엔트로피 비교에서는 같은 좌표를 쓰므로 상수 차이만 난다.

**17.2.4.** 결합 밀도는 입방체 $[0,2]^N$ 위에서 상수 $2^{-N}$이므로, 합이 $N$인 조건부 분포는 여전히 균등이다. 그러나 영역은 단체 전체가 아니라 단체와 입방체의 교집합이다($t_i\le2$). 엔트로피는 그 교집합 부피의 로그다.

**17.2.5.** 독립 지수 시계 $N$개의 합은 감마$(N,1)$을 따른다(적률생성함수 $(1-s)^{-N}$). 평균 $N$, 분산 $N$이다. 합은 폭 $\sqrt N$으로 퍼지므로, 합을 한 값으로 고정하면 그 폭에 해당하는 모름, 곧 약 $\tfrac12\ln(2\pi eN)$이 사라진다. $N$에 의존하는 부분이 $\tfrac12\ln N$이다.

**17.2.6.**
```python
import math
import numpy as np

Ns = np.array([1e3, 1e4, 1e5, 1e6])
y = np.array([(N - 1)*math.log(N) - math.lgamma(N) - N for N in Ns])   # S_N - N
slope, icpt = np.polyfit(np.log(Ns), y, 1)
print(round(slope, 5), round(icpt, 4), round(-0.5*math.log(2*math.pi), 4))   # -0.49999 -0.9191 -0.9189
```
기울기는 $-\tfrac12$, 절편은 $-\tfrac12\ln2\pi=-0.9189$에 가깝다(작은 차이는 $1/(12N)$ 항).

## 17.3절

**17.3.1.** $T_H$는 질량에 반비례하므로 태양 질량 값의 1/10: $k_BT_H=5.317\times10^{-13}$ eV.

**17.3.2.** $\Delta M=M\big(\sqrt{1+1/(4\pi M^2)}-1\big)=\dfrac1{8\pi M}-\dfrac1{128\pi^2M^3}+\cdots$. $T_H=1/8\pi M$로 나누면 $1-\dfrac{8\pi M}{128\pi^2M^3}=1-\dfrac1{16\pi M^2}$. $M=10$에서 $1-0.000199=0.9998$.

**17.3.3.** $h=-\int_0^\infty\frac1Te^{-E/T}\ln\Big(\frac1Te^{-E/T}\Big)dE=\ln T+\frac{\langle E\rangle}T=1+\ln T$. $E'=E/T$로 재면 $T=1$이므로 $h=1$ nat.

**17.3.4.** 화소 하나의 질량은 $T\ln2$이다. $S=A/4$를 지키려면 화소 넓이가 $4\ln2\,\ell_P^2=2.77\ell_P^2$, 한 변 $1.665\ell_P$여야 한다. 나이퀴스트 화소(한 변 $2\ell_P$)와 맞지 않는다.

**17.3.5.**
```python
import math
from scipy.optimize import brentq

def kerr(M, J):
    a = J/M
    rp = M + math.sqrt(M*M - a*a)
    return 4*math.pi*(rp*rp + a*a), (rp - M)/(2*math.pi*(rp*rp + a*a))

for M in (10.0, 100.0):
    for chi in (0.0, 0.5, 0.9):
        J = chi*M*M
        A0, T = kerr(M, J)
        dM = brentq(lambda d: kerr(M + d, J)[0] - A0 - 4, 1e-9, 1.0)
        print(M, chi, round(dM/T, 6))
```
$M=10$: 0.999801, 0.999881, 1.000596. $M=100$: 0.999998, 0.999999, 1.000006. 비는 $M$이 커질수록 1로 간다.

## 17.4절

**17.4.1.** $\hbar/(2\pi ck_B)=4.055\times10^{-21}$ K s² m⁻¹이므로 $T=0.4055$ K.

**17.4.2.** 표준: Jacobson 정리 자체, 비소냐노–비흐만 정리(운루 온도), 클라우지우스 관계. 이론 고유: 엔트로피 밀도의 값(HP, 1 nat/$(2\ell_P)^2$), "기록 위상 = 모듈러 흐름"이라는 공리 TT와 그 국소 확장, "지평선을 넘는 에너지 = 기록"이라는 R1의 적용.

**17.4.3.** 온도가 $\hbar\kappa/4\pi$로 절반이 된다. 6.3절의 3단계에서 $T_{\mu\nu}k^\mu k^\nu=(\hbar\eta/4\pi)R_{\mu\nu}k^\mu k^\nu$가 되어 $8\pi G_{\rm eff}=4\pi/\hbar\eta$, 곧 $G_{\rm eff}=1/(2\hbar\eta)=2G$.

**17.4.4.** $R_{\mu\nu}+fg_{\mu\nu}=(2\pi/\hbar\eta)T_{\mu\nu}$에 $\nabla^\mu$를 취한다. 축약된 비앙키 항등식 $\nabla^\mu R_{\mu\nu}=\tfrac12\nabla_\nu R$과 에너지 보존 $\nabla^\mu T_{\mu\nu}=0$에서 $\nabla_\nu(\tfrac12R+f)=0$. 따라서 $f=-\tfrac12R+\Lambda$이고 $\Lambda$는 상수다. 식은 $G_{\mu\nu}+\Lambda g_{\mu\nu}=(2\pi/\hbar\eta)T_{\mu\nu}$가 된다. 방정식은 $\Lambda$의 값을 정하지 않는다.

**17.4.5.** 타당하지 않다. Jacobson 경로는 거친 수준의 방정식이 상태방정식처럼 나온다는 것만 보인다. 미시 자유도가 양자적이고 서로 얽힐 수 있어도 같은 거시 방정식이 나올 수 있다. 예: 섭동 양자 중력도 고전 극한에서 아인슈타인 방정식을 주면서 중력자 교환으로 얽힘을 만든다. 그래서 본문은 이 연결을 "읽기"로만 두고, 판정은 BMV(P23)에 맡긴다.

**17.4.6.**
```python
import numpy as np

rng = np.random.default_rng(0)
idx = [(m, n) for m in range(4) for n in range(m, 4)]      # 대칭 행렬의 10개 성분
rows = []
for _ in range(50):
    nhat = rng.normal(size=3); nhat /= np.linalg.norm(nhat)
    k = np.r_[1.0, nhat]                                    # 널 벡터 (1, n)
    rows.append([k[m]*k[n]*(1 if m == n else 2) for m, n in idx])
s, vt = np.linalg.svd(np.array(rows))[1:]
print(np.round(s, 6))                                       # 마지막 하나만 0
A = np.zeros((4, 4))
for v, (m, n) in zip(vt[-1], idx):
    A[m, n] = A[n, m] = v
print(np.round(A/A[1, 1], 6))                               # diag(-1, 1, 1, 1)
```
특잇값 가운데 하나만 0이고, 그 해는 $\mathrm{diag}(-1,1,1,1)=g$에 비례한다. 해 공간이 1차원이므로 $A\propto g$다.

## 17.5절

**17.5.1.** $M\omega_0=\alpha/32\pi$: $4\ln2\to0.02758$, $4\ln3\to0.04371$, $4\to0.03979$.

**17.5.2.** 넓이가 $\alpha$만큼 바뀌면 $\Delta M=\kappa\alpha/8\pi$이고, $\hbar=1$에서 진동수 $\omega_0=\Delta M$이다. $\kappa=1/4M$을 넣으면 $\omega_0=\alpha/32\pi M$.

**17.5.3.** $8\pi=25.13$은 $[2.3,\,36.1]$ 안이다. 현재 자료는 $\alpha=4$와 $\alpha=8\pi$를 모두 허용한다.

**17.5.4.** $(4-8)/1=-4.0\sigma$: $3\sigma$를 넘으므로 P40 기각. $(4-5)/1=-1.0\sigma$: 양립.

**17.5.5.** $t\ge0$에서 $e^{-\gamma t}e^{i\omega_Rt}$의 푸리에 변환은 $1/(\gamma-i(\omega-\omega_R))$이고, 파워는 $1/(\gamma^2+(\omega-\omega_R)^2)$로 반치폭이 $\gamma$인 로런츠 봉우리다(코사인은 $\pm\omega_R$의 두 봉우리). 선 간격이 $\gamma$보다 좁으면 이웃 선의 봉우리가 서로의 폭 안에 들어와 하나의 넓은 봉우리로 보인다. 슈바르츠실트에서 $\gamma=0.089$, 간격 0.0398이다.

**17.5.6.**
```python
import math

for chi in (0.0, 0.3, 0.67, 0.9, 0.99):
    wR = 1.5251 - 1.1568*(1 - chi)**0.1292
    Q = 0.7000 + 1.4187*(1 - chi)**(-0.4990)
    wI = wR/(2*Q)
    rp = 1 + math.sqrt(1 - chi*chi)                 # M = 1, a = chi
    kappa = (rp - 1)/(rp*rp + chi*chi)
    w0 = kappa*4/(8*math.pi)                        # alpha = 4
    print(chi, round(wR/w0, 2), round(wI/w0, 2))
```
출력: $\omega_R/\omega_0=9.26,\ 10.82,\ 15.42,\ 27.57,\ 90.17$, $\omega_I/\omega_0=2.18,\ 2.26,\ 2.43,\ 2.66,\ 3.04$. 모든 회전에서 감쇠율이 선 간격의 두 배를 넘는다. $\alpha=4$의 선은 어느 회전에서든 번진다. ($\chi=0$의 근사값 9.26은 정확한 슈바르츠실트 값 9.39와 근사식의 오차만큼 다르다.)
