# 00장 머리말 — 개요

**이 장이 답하는 질문:** 이 책은 무엇을 다루고, 어떻게 읽어야 하며, 책 속의 주장을 얼마나 믿어야 하는가?

## 절 목록

| 절 | 제목 | 한 줄 요지 |
|---|---|---|
| 0.1 | [이 책이 다루는 것](01_이_책이_다루는_것.md) | 입력 하나로 입자와 우주를 함께 채점하는 이론 |
| 0.2 | [읽는 법](02_읽는_법.md) | 논문만 읽는 길과 교과서로 배우는 길 |
| 0.3 | [지위 표기와 정직성](03_지위_표기와_정직성.md) | 모든 주장에 지위를 붙이고, 증거와 구현을 구분한다 |
| 0.4 | [사전 등록이란](04_사전_등록이란.md) | 결과를 보기 전에 예측과 기각 조건을 해시로 잠근다 |
| 0.5 | [기호와 수치의 기준](05_기호와_수치의_기준.md) | 자주 쓰는 기호와 기준 판본 v24 |
| — | [확인 질문의 답](99_연습문제_답과_풀이.md) | |

## 장의 지도

```
0.1 무엇을 ──► 0.2 어떻게 읽나
                 │
0.3 지위 표기 ◄──┘──► 0.4 사전 등록 ──► 0.5 기호와 기준
```

0.3과 0.4는 책 전체의 규칙입니다. 뒤의 모든 장이 이 두 절을 전제로 합니다.

**선수 장:** 없음.
