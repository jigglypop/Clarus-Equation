# 0.2 읽는 법

> **요지.** 01장만 읽으면 이론 전체를 알 수 있다. 식을 직접 유도하며 배우려면 02장부터 차례로 읽는다.

## 학습 목표

1. 자기 목적에 맞는 읽기 경로를 고를 수 있다.
2. 장, 절, 예제, 연습문제의 번호 규칙을 안다.
3. 연습문제의 난이도 표시(★)를 이해한다.

## 선수 지식

[0.1절](01_이_책이_다루는_것.md).

## 본문

### 두 갈래 경로

```
          ┌── 01장 논문형 개관 (이론 전체, 약 1시간)
00장 ─────┤
          └── 02–06 준비 ──► 07–10 뼈대 ──► 11–12 입자
                                          ├► 13–15 우주
                                          └► 16–18 중력 ──► 19–21 판정
```

**논문만 읽기.** 01장은 혼자 완결된 논문입니다. 다른 장을 읽지 않아도 이론의 주장, 근거, 예측, 한계를 알 수 있습니다. 연구자나 처음 보는 독자에게 권합니다.

**교과서로 배우기.** 02장부터 차례로 읽습니다. 제1부(02–06장)는 2학년이 아직 배우지 않았을 도구를 가르칩니다. 제2부(07–10장)가 이론의 뼈대이고, 제3–5부는 그 뼈대를 입자, 우주, 중력에 적용합니다. 제6부는 이론 전체를 채점하고 판정합니다.

**부분만 읽기.** 제3–5부는 서로 독립적입니다. 제2부를 읽은 뒤에는 관심 있는 부로 바로 가도 됩니다. 다만 15장(우주론 채점)은 14장을, 17장(지평선)은 16장을 전제로 합니다.

### 선수 지식

이 책은 수학과·물리학과 **학부 2학년**을 독자로 가정합니다. 다음은 안다고 보고 다시 가르치지 않습니다.

- 일변수·다변수 미적분, 테일러 전개, 상미분방정식 기초
- 선형대수: 행렬, 행렬식, 고유값, 내적 공간
- 복소수와 오일러 공식
- 확률 기초: 확률변수, 기댓값, 분산, 정규분포
- 일반물리(역학, 전자기), 현대물리 입문(특수상대론, 슈뢰딩거 방정식의 뜻)

### 번호 규칙

| 대상 | 예 | 뜻 |
|---|---|---|
| 절 | 3.2절 | 3장 2절 |
| 식 | (3.2.1) | 3장 2절의 첫 식 |
| 정의, 정리 | 정의 3.2.1, 정리 3.2.2 | 3장 2절 안에서 순서대로 |
| 예제 | 예제 3.2.1 | 3장 2절의 첫 예제 |
| 연습 | 연습 3.2.4 | 3장 2절의 넷째 연습 |

### 절의 틀

모든 절은 같은 틀을 따릅니다.

1. 요지(한 줄)
2. 학습 목표
3. 선수 지식
4. 본문
5. 예제(풀이 포함)
6. 연습문제
7. 요약
8. 이 절의 수치와 재현

### 연습문제의 난이도

| 표시 | 뜻 | 걸리는 시간 |
|---|---|---|
| ★ | 기본 계산 | 5–10분 |
| ★★ | 개념과 짧은 증명 | 20–30분 |
| ★★★ | 긴 유도, 수치 탐구, 파이썬 코드 | 1시간 이상 |

모든 연습문제의 답과 단계별 풀이는 장 끝의 `99_연습문제_답과_풀이.md`에 있습니다. 먼저 스스로 풀어 보고 확인하십시오.

### 비유와 식

이 책은 비유를 씁니다. 그러나 비유는 식을 대신하지 않습니다. 비유 문단은 다음처럼 인용 블록으로 구분하고, 바로 뒤에 식을 둡니다.

> 비유: 동전을 던지기 전에는 앞과 뒤의 무게가 같다.

$$P(\text{참})=P(\text{거짓})=\tfrac12 .$$

## 예제

**예제 0.2.1** 13장(우주의 성분)을 읽고 싶은 독자가 반드시 먼저 읽어야 할 장은 무엇인가?

*풀이.* 제4부는 제2부(07–10장)를 전제로 합니다. 제2부는 제1부의 도구를 씁니다. 13장은 특히 02장의 지수 시계와 경주(2.2절), 10장의 가지치기 고정점(10.2절)을 씁니다. 따라서 최소 경로는 02장 → 07–10장 → 13장입니다.

## 요약

- 비유는 인용 블록으로 구분하고, 바로 뒤에 식을 둔다.
