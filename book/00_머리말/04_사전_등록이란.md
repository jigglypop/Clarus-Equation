# 0.4 사전 등록이란

> **요지.** 사전 등록은 결과를 보기 전에 예측값, 판정 실험, 기각 조건을 파일에 적고 해시로 잠그는 일이다. 잠근 파일은 고치지 않고, 바꿀 것이 생기면 새 판본을 만든다.

## 학습 목표

1. 사전 등록이 왜 필요한지 설명할 수 있다.
2. 예측 하나가 갖춰야 할 네 요소를 말할 수 있다.
3. 해시로 파일을 잠그는 원리를 설명할 수 있다.
4. "독립 예측"과 "등록된 예측"의 차이를 안다.

## 선수 지식

[0.3절](03_지위_표기와_정직성.md).

## 본문

### 왜 필요한가

이론을 만든 사람은 자료를 이미 알고 있습니다. 그래서 이론이 자료와 맞는 것은 놀랍지 않습니다. 이론의 힘은 **아직 보지 못한 자료**를 맞출 때 드러납니다. 그러려면 "보기 전에 무엇을 예측했는가"를 나중에 확인할 수 있어야 합니다. 사전 등록이 그 장치입니다.

### 예측의 네 요소

**정의 0.4.1 (등록된 예측).** 등록된 예측은 다음 네 요소를 갖는다.

1. **번호:** P01, P02, …
2. **관측량과 값:** 예) $\sin^2\theta_{23}=0.455551$
3. **판정 실험:** 예) DUNE, Hyper-Kamiokande
4. **기각 조건(kill):** 예) "위 옥탄트($\sin^2\theta_{23}>0.5$)가 $3\sigma$ 이상으로 확정되면 기각"

기각 조건이 없는 예측은 예측이 아닙니다. 어떤 결과가 나와도 살아남기 때문입니다.

### 해시로 잠그기

예측 파일은 JSON으로 적습니다. 파일 내용 전체를 **SHA-256 해시**에 넣으면 64자리 16진수가 나옵니다. 내용이 한 글자만 바뀌어도 해시는 완전히 달라집니다. 파일 안에 자기 해시를 적어 두면, 나중에 누구든 다시 계산해서 파일이 바뀌지 않았는지 확인할 수 있습니다.

해시를 계산할 때는 JSON을 정해진 방식으로 직렬화합니다. 키를 정렬하고, 구분자를 `,`와 `:`로 두며, 한글을 그대로 둡니다. 자기 해시 칸은 빼고 계산합니다.

```python
import hashlib, json
def manifest_hash(d: dict) -> str:
    body = {k: v for k, v in d.items() if k != "manifest_sha256"}
    text = json.dumps(body, sort_keys=True, separators=(",", ":"), ensure_ascii=False)
    return hashlib.sha256(text.encode("utf-8")).hexdigest()
```

예측을 계산하는 코드 모듈도 해시로 잠급니다. 모듈을 고치려면 새 판본을 만들어야 합니다.

### 판본 규칙

- 잠근 파일은 **절대 고치지 않는다.**
- 새 예측을 더하거나 지위를 바꾸려면 새 판본(v2, v3, …)을 만든다. 새 판본은 이전 판본을 모두 보존한다.
- 이 책의 기준은 **v24**(자기 해시 `90d39058…`, 2026-09-24)다. 등록된 예측은 41개다.

### 독립 예측

등록된 예측 가운데 일부는 다른 예측과 같은 시험입니다. 예를 들어 P20("렌더링 사건의 척도는 $M_Z$")은 $\alpha_s$ 세계 평균 행과 같은 사실을 다른 말로 한 것입니다. 이런 예측은 **독립 예측**으로 세지 않습니다. v24의 41개 가운데 독립 예측은 37개입니다.

### 기각의 기록

P17(중성미자 질량 합 59.16 meV)은 기각 조건이 "95% 우주론 상한이 55 meV 아래"였습니다. 2026년 6월에 발표된 한 분석이 52 meV 상한을 주었으므로, 등록 문구 그대로 **기각**으로 기록했습니다. 그 분석이 특정 우주론 모형(ΛCDM)을 가정했다는 이유로 빠져나가지 않았습니다. 결과를 본 뒤 조건을 바꾸는 것은 봉합이기 때문입니다.

이 기각 뒤에 새 예측 P41을 **따로** 등록했습니다. P41은 P17의 구제가 아니라, 이론의 판독 방식을 넣은 분석에 대한 별개의 예측입니다(15장).

## 예제

**예제 0.4.1** 다음 예측의 약점을 지적하라. "암흑에너지의 상태방정식 $w$는 $-1$ 근처일 것이다."

*풀이.* 값이 정확하지 않고("근처"), 판정 실험과 기각 조건이 없습니다. 등록된 예측 P21은 "$w(z=0)=-0.9894$, $\sigma(w_0)\le0.02$인 CMB+BAO+SN 결합에서 $3\sigma$ 이상 배제되면 기각"처럼 네 요소를 모두 갖습니다.

**예제 0.4.2** 문자열 `abc`의 SHA-256 해시 앞 8자리를 파이썬으로 구하라.

*풀이.*
```python
import hashlib
print(hashlib.sha256(b"abc").hexdigest()[:8])   # ba7816bf
```

## 요약

- 사전 등록은 보기 전의 예측을 나중에 확인할 수 있게 한다.
- 예측은 번호, 값, 판정 실험, 기각 조건을 갖춰야 한다.
- 잠근 파일은 고치지 않고 새 판본을 만든다. 기준은 v24(등록 41, 독립 37, 기각 1)다.
