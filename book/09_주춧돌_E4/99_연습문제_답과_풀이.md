## 9.1절

**9.1.1.** $a=0.490370$, $\lambda=1-2a=0.019259$.

**9.1.2.** $4\alpha_s^{4/3}\le1\iff\alpha_s\le4^{-3/4}=2^{-3/2}=0.3536$.

**9.1.3.** $P(V_2)=r^2$, $P(V_3)=r^3$. $r=\tfrac12$에서 ¼과 ⅛.

**9.1.4.** $(1-\lambda)^4\approx1-4\lambda$이므로 $\hat s^2\approx\tfrac14-\lambda=0.25-0.019259=0.23074$. 정확한 값 0.23129보다 0.00055(0.24%) 작다. 2차 항 $6\lambda^2/4=0.00056$이 그 차이다.

**9.1.5.** $\sin\theta_W=a^2=0.48093$에서 $a=0.69349$, $\alpha_s=a^3=0.33352$. pull $=(0.33352-0.1180)/0.0009=+239$. 닻은 $a=\tfrac12$에서 $\sin\theta_W=\tfrac14$, $\hat s^2=\tfrac1{16}$로, 공평한 동전의 성질을 잃는다.

## 9.2절

**9.2.1.** 교차가 둘 이상이면 동전 $a$가 한 숫자로 정해지는 척도가 여럿이다. 그러면 규칙마다 다른 사건의 동전을 읽을 수 있어, "하나의 동전이 모든 규칙을 정한다"는 이론의 구조가 무너진다. 어느 사건을 쓸지 고르는 선택도 생겨 가설 비용이 늘어난다.

**9.2.2.** $(0.14143-0.1180)/0.0009=+26.0$.

**9.2.3.** E5의 관측 내용은 여전히 "$\alpha_s$ 세계 평균이 0.11792와 맞는다"(P20) 하나다. 조건부 정리가 된 것은 설명이 생긴 것이지, 자료를 보고 새로 고른 선택이 는 것이 아니다. 그래서 bit는 바뀌지 않는다.

**9.2.4.** 강한 힘의 척도 $\Lambda_{\rm QCD}$는 $\alpha_s$의 흐름(QCD)이 정하고, $M_Z$는 Higgs 진공 기댓값 $v$와 전약 결합이 정한다. 두 척도는 표준 모형에서 서로 독립이다. $\mu^*=M_Z$는 "Z 극에서 측정된 $\hat s^2$가 E4를 통해 $\alpha_s(M_Z)$, 따라서 $\Lambda_{\rm QCD}$를 정한다"는 방향이 있는 관계로 읽힌다.

**9.2.5.**
```python
import math
from scipy.optimize import brentq
MZ = 91.1876
a_s = lambda mu: 1/(1/0.1180 + (23/3)/(2*math.pi)*math.log(mu/MZ))
f = lambda mu: 0.23129 - 0.0007*math.log(mu/MZ) - 4*a_s(mu)**(4/3)
print(brentq(f, 30, 300))   # 약 91.65 GeV
```
한 고리 장난감 흐름에서도 교차는 91.65 GeV로 두 고리 결과(91.6)와 같다. $\hat s^2$의 기울기를 바꿔도(−0.0005, −0.001) 교차는 거의 움직이지 않는다. 교차를 정하는 것은 주로 $\alpha_s$의 빠른 흐름이다.

## 9.3절

**9.3.1.** 뮤온과 타우는 전자와 같은 양자수($T_3=-\tfrac12$, $Q=-1$)이므로 ¼.

**9.3.2.** W는 $SU(2)_L$ 게이지 보손이라 약 이중항에만 붙는다. 오른손 전자는 이중항이 아니라 단일항($e^c$의 켤레, $T_3=0$)이다.

**9.3.3.** 전자에서 $g_V=T_3-2Qs^2=-\tfrac12+2s^2$, $g_A=T_3=-\tfrac12$이므로 $g_V/g_A=1-4s^2$. $s^2=\tfrac14(1-\lambda)^4$이면 $1-(1-\lambda)^4$.

**9.3.4.** P36의 예측은 $\hat s^2$로 정해지는 $(1+\delta(\hat s^2)/2\pi)/4$이고, 측정 쪽은 $(m_\mu/m_\tau)/\hat s^2$다. $\hat s^2=0.23129$이면 예측 0.2570742, 측정 0.2570850으로 $-0.23\sigma$다. $\hat s^2=0.23147$이면 측정 쪽이 $0.0594612/0.23147=0.2568851$로 0.074% 작아지고, 예측은 거의 그대로(0.2570781)라 차이가 커진다. 두 측정의 상대 오차가 $5\times10^{-5}$와 $1.7\times10^{-4}$로 작아 $+4.17\sigma$가 된다.

**9.3.5.** 렙톤 규칙(P36)과 고정점(FP)은 MS-bar 값 0.23129를 보면서 찾았다(목격 후). 그러니 "MS-bar에서 가장 잘 맞는다"는 결과는 구성상 당연하고, 다른 정의가 떨어지는 것도 그 선택을 다시 확인한 것일 뿐이다. 순환을 피하려면 규칙을 만들 때 쓰지 않은 측정으로 시험해야 한다. 예를 들어 직접 측정한 유효각의 충돌기 평균(현재 $+1.5\sigma$로 가르지 못함)이나, FCC-ee의 Z 극 정밀 측정이다.

## 9.4절

**9.4.1.** $1,\ 1,\ a^3=0.117916,\ a^3=0.117916$.

**9.4.2.** $\alpha_2=\alpha_{\rm em}/\hat s^2=0.0078155/0.23129=0.033791$. $a^2=0.24046$, 비 7.12.

**9.4.3.** (1) E1을 빼면(렌더링이 5축 전부에 작용) 색 가득 후보가 $a^3$, $a^5$ 둘이 되고 약 단일항도 $a^2$을 가져, "1이 아닌 무게"가 여럿이다. (2) 가둠을 빼면 색을 가진 상태(무게 $a$, $a^2$)도 기록이 되어 후보가 늘어난다. (3) RC를 빼면 결합과 기록의 무게를 잇는 규칙이 없어 $\alpha_s$에 대해 아무것도 말하지 못한다.

**9.4.4.** "선|det|$\sin\theta_W$": $\det(aI_1)=a=0.48093$, $\alpha_s=0.11124$, $-7.5\sigma$. "부피|tr·det|$\sin\theta_W$": $3a^3=0.48093$, $\alpha_s=a^3=0.16031$, $+47\sigma$.

## 9.5절

**9.5.1.** $A_2^2=(2a^2)^2=4a^4=A_4$.

**9.5.2.** $(1-\lambda)^4=1-4\lambda+O(\lambda^2)$이므로 $\hat s^2=\tfrac14(1-4\lambda)=\tfrac14-\lambda$.

**9.5.3.** (가)만: $m\in\{0,2\}$. (나)만: $m\in\{1,2\}$. 어느 하나만으로는 $m=2$가 정해지지 않는다.

**9.5.4.** $\rho=1-0.01903$. $n=3$: $\hat s^2=0.23600$, $+2.6\sigma$. $n=4$: $0.23151$, $+0.12\sigma$. $n=5$: $0.22710$, 오차를 0.0018로 고정하면 $-2.3\sigma$다. 저장소 모듈은 $\alpha_s$ 전파 오차가 $n$에 비례해 커지는 것을 넣어($d\hat s^2/d\lambda\propto n$) $n=5$에서 $-1.45\sigma$를 준다. 어느 쪽이든 $1\sigma$ 안은 $n=4$뿐이지만, $n=5$와의 판별력은 약하다.

**9.5.5.** 보른 배가의 4차원은 "진폭 평면 + 그 켤레 평면"이다. 켤레는 진폭의 복소 켤레(아닌 나의 평면)로, 진폭과 켤레 진폭을 곱해 확률을 만드는 공간이다. 이것은 색 공간 $V_3$ 안의 4차원 부분공간이 아니다(3차원 공간에 4차원 부분공간은 없다). E1은 렌더링 연산이 색 공간에서 작용한다고 말할 뿐, 확률이 진폭 공간과 켤레 공간의 곱에서 나온다는 것과 충돌하지 않는다.

**9.5.6.**
```python
born = [m for m in range(0, 7) if m*m == 2*m]
anchor = [m for m in range(1, 7) if abs((m/2**m)**2 - 0.25) < 1e-12]
jump = [m for m in range(0, 7) if m + 2 == 2*m]
print(born, anchor, jump, sorted(set(born) & set(anchor) & set(jump)))
# [0, 2] [1, 2] [2] [2]
```

## 9.6절

**9.6.1.** 표준 물리: 가둠, 보른 규칙. 이론의 공리: E1. 이론의 정리: 켤레 = 아닌 나(7.3절), 렙톤 닻(9.5절). 읽기: 사전 D, RS(사건 척도의 조건). 사건 척도 자체는 조건부 정리.

**9.6.2.** $(0.23147/4)^{3/4}=0.117985$.

**9.6.3.** 렙톤 규칙은 $m_\mu/m_\tau=uw$이고 E4에서 $u=\alpha_s^{4/3}=\hat s^2/4$, $w=1+\delta/2\pi$, $\delta=\hat s^2(1-\hat s^2)$다. 따라서 $(m_\mu/m_\tau)/\hat s^2=(1+\delta(\hat s^2)/2\pi)/4$로 $\hat s^2$만의 함수다. $\alpha_s$가 식에서 사라진다.

**9.6.4.** $(0.11792-0.1185)/0.0001=-5.8\sigma$이므로 P38의 기각 조건($3\sigma$)이 충족된다. 기각되는 것은 RS 읽기(동전의 관계는 Z 극 기록의 척도에서 성립)이고, 따라서 E5의 조건부 유도가 무너진다. E4 식 자체와 $\hat s^2$로의 교정은 남지만, "왜 $M_Z$인가"의 설명이 틀린 것이 된다.

**9.6.5.** 모순이 아니다. "자료에서 찾은 식"은 증거의 문제다. 이미 본 자료와의 일치는 증거가 되지 않는다. "조건부 정리"는 논리 구조의 문제다. 그 식이 명시한 조건에서 유도된다는 것이다. 두 사실은 함께 성립한다. 유도가 생겼다고 옛 일치가 증거가 되지는 않는다. 증거는 E4에서 나온 새 예측(P20, P34, P36, P38)이 동결 뒤의 관측과 맞을 때 생긴다.
