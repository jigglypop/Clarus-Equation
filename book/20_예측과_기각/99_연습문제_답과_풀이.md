## 20.1절

**20.1.1.** P03($\sin^2\theta_{12}$), P04($\sin^2\theta_{13}$, Daya Bay와 함께), P19($\Delta m^2_{21}$).

**20.1.2.** P23: 얽힘 검출은 새 물리의 발견 주장이라 발견 문턱을 쓴다. P28: FCC-ee에서 매우 정밀해질 비라 계통 오차에 흔들리지 않도록. P31: 광속의 에너지 의존 검출도 발견 주장이다. P34의 $\hat s^2$: 오차가 $10^{-5}$ 수준으로 작아 이론 오차와 계통 오차의 여유를 둔다. P36: 두 측정의 상대 오차가 $10^{-4}$ 수준으로 매우 날카로운 시험이라 같은 이유다.

**20.1.3.** P20: "사건 척도는 $M_Z$"의 기각 조건이 $\alpha_s$ 세계 평균 행과 같은 시험이다. P33: BAO+BBN의 ΛCDM 판독 값은 P14($hr_d$)와 P25(G1m 기울기)에서 계산되는 파생값이다. P38: P20과 같은 값(0.11792)을 Z 극의 다른 기록으로 시험한다.

**20.1.4.** 창 $[0.002,\,0.006]$의 가운데는 0.004이고, 예측 0.00367은 가운데보다 약간 아래다. 창의 반폭 0.002가 약 $2\sigma$라면 $\sigma(r)\sim0.001$을 전제한다. LiteBIRD, CMB-S4, SO가 이 수준에 이른다(15.1절).

**20.1.5.** 두 예측의 차는 $1.08306-1.08239=0.00067$. $3\sigma$로 가르려면 비의 오차가 $0.00067/3=0.00022$, 곧 약 0.02% 이하여야 한다.

## 20.2절

**20.2.1.** $(0.965035-0.9700)/0.0015=-3.31$. $3\sigma$를 넘으므로 P10 기각. 같은 $N_e=18D$에 기대는 P09도 함께 의심받는다.

**20.2.2.** P09의 기각 조건 "$r<0.002$(95%)"가 충족되므로 기각이다.

**20.2.3.** P32: 순수 현재 교정 방법이 $\sigma=0.7\le0.8$로 $69.8\le70.0$에 모였으므로 기각. P07: $(73.356-69.8)/0.7=+5.08\sigma$로 기각. 의존 지도에서 O1, CL, 관측 사상 M이 흔들리고, 같은 규칙에 기대는 P11, P26, P37도 신뢰를 잃는다. 허블 긴장을 틀 기울기로 설명하는 이론의 거시 블록 우위(19.3절)가 무너진다.

**20.2.4.** 규칙 2가 없으면, 결과를 본 뒤 "그 분석은 등록 때 뜻한 분석이 아니다"라며 불리한 결과를 모두 피할 수 있다. P17에서 등록 문구는 모형과 사전분포를 지정하지 않았다. ΛCDM 상한(52 meV)은 걸리고, 위계 사전분포(92 meV)나 CPL 암흑에너지(111 meV) 분석은 걸리지 않았다. 규칙이 없으면 후자를 골라 기각을 피할 수 있었다. 그것은 봉합이다.

**20.2.5.** P01: 위 옥탄트가 $(0.56-0.5)/0.01=6\sigma$로 확정되어 기각. P02: $(258.76-285)/10=-2.62\sigma$로 기각 아님. P29: $\delta=285^\circ$는 창 $[250^\circ,290^\circ]$ 안이고, $s_{23}^2=0.56$에서 TM1 곡선의 값은 $285.3^\circ$라 곡선 위에 있다. 통과. P30: $\sin^22\theta_{23}=4\times0.56\times0.44=0.9856$, 오차 $|4(1-2s)|\times0.01=0.0048$. pull $(0.992097-0.9856)/0.0048=+1.35$로 통과. 이 가상 결과는 "계단 정렬 SA는 죽고 경계 B는 산다"는 경우다.

**20.2.6.**
```python
PRED = {                                    # 번호: (예측값, 문턱)
    "P03": (0.318517, 3), "P10": (0.965035, 3), "P19": (7.403e-5, 3),
    "P28": (1.37471, 5), "P36": (0.2570745, 5), "P39": (172.33, 3),
}

def judge(meas):
    out = {}
    for key, (obs, sig) in meas.items():
        val, thr = PRED[key]
        p = (val - obs)/sig
        state = "기각" if abs(p) >= thr else ("위험" if abs(p) >= 2 else "통과")
        out[key] = (round(p, 2), state)
    return out

print(judge({"P03": (0.3092, 0.0087), "P10": (0.9700, 0.0015),
             "P19": (7.50e-5, 0.0225e-5), "P28": (1.37299, 0.00121)}))
```
출력: P03 $+1.07$ 통과, P10 $-3.31$ 기각, P19 $-4.31$ 기각, P28 $+1.42$ 통과. 실제 판정에서는 비대칭 오차, 방향 조건, 정밀도 조건을 예측마다 따로 넣어야 한다.

## 20.3절

**20.3.1.** 가지 무게 중력(빛의 한계와 모순), 반례 C-0(증명의 오류), 실수 속도 분기(쌍극자는 관측이지만 핵심은 $\gamma$가 P11과 맞지 않는 내부 불일치도 함께), 지평선 정수 통로(정수 해가 없다는 수학), 선형 PMNS 계단(무차별 공리와 모순). 나머지는 관측으로 떨어졌다.

**20.3.2.** 예: W1. (1) 후보: 저장소 식 $w_0=-0.768$, $w_a=-0.214$, 연속 매개변수 없음. 조건: 공동 RMSE 감소, 새 $3\sigma$ 초과 행 없음, CMB–BAO 긴장 감소. (2) 결과: BAO 모양과 $S_8$은 좋아졌지만 고정된 $h$에서 $100\theta^*$가 $+56.7\sigma$, 판본 V가 6.76. (3) 근거: 관측(Planck $\theta^*$). (4) 살아남은 것: $-1$ 둘레를 오가는 변화만 가능하다는 조건에서 정리 B의 W2, 다음 시험 P21, P22.

**20.3.3.** P17은 이론이 동결해 걸었던 값이 자료에 져서 죽었다. 기록은 지우지 않고, 이론은 그만큼 신뢰를 잃는다. 18.4절의 간섭계 긴장은 이론의 공리와 어긋난 외부 모형을 대입해 적은 것이라, 이론이 걸었던 것이 아니다. 그래서 거둬들였고 이론의 신뢰를 깎지 않는다. 대신 철회의 사실과 이유를 적고, 새 시험(P42)을 내놓았다.

**20.3.4.** $p=41/299=0.1371$. 평균 41, 표준편차 $\sqrt{299\times0.1371\times0.8629}=5.95$. $P(X\ge29)\approx P(Z\ge(28.5-41)/5.95)=P(Z\ge-2.1)\approx0.98$. 정확한 값은 0.986이다. 29개 이상이 우연히 들 확률이 거의 1이므로 적중은 정보를 주지 않는다.

**20.3.5.** 진공 주파수 $\nu\in\{\tfrac12,1,3\}$은 모두 "$-1$ 둘레를 오가는" 올바른 꼴(방향)이었지만, $\nu=1,3$은 변화의 크기가 너무 커서 $\theta^*$를 $+6.2\sigma$, $+46\sigma$로 깨뜨렸다. 올바른 꼴 안에서도 크기(주파수)가 맞아야 했고, 그것을 정리 B의 최저 조화가 정했다.

**20.3.6.**
```python
from scipy import stats

N, expect, hits = 299, 41, 29
p = expect/N
print(round(p, 4), round(stats.binom.sf(hits - 1, N, p), 3), round(stats.binom.cdf(hits, N, p), 3))
```
출력: $p=0.1371$, $P(X\ge29)=0.986$, $P(X\le29)=0.023$. 적중 수가 우연 기대보다 작은 쪽으로 약 $2\sigma$ 벗어나 있다. 적어도 "우연보다 많이 맞았다"는 증거는 전혀 없으므로 인자 흡수는 수비학으로 기각된다.
