## 16.1절

**16.1.1.** $\hat T=\mathrm{diag}(4,2)$이므로 $s=0.25\times4+0.75\times2=2.5$.

**16.1.2.** 대각합은 선형이므로 $\mathrm{Tr}\big[(\sum_kp_k\rho_k)\hat T\big]=\sum_kp_k\mathrm{Tr}(\rho_k\hat T)$. 확률 가중치의 합이 1이므로 이것은 아핀 조합이다.

**16.1.3.** 혼합 $\tfrac12\rho_1+\tfrac12\rho_2=I/2$에서 $\mathrm{Tr}(I/4)=\tfrac12$. 반면 $\tfrac12\mathrm{Tr}(\rho_1^2)+\tfrac12\mathrm{Tr}(\rho_2^2)=1$. 둘이 다르므로 아핀이 아니다.

**16.1.4.** $\langle a|_A|\Phi^+\rangle=\tfrac1{\sqrt2}(a_0^*|0\rangle+a_1^*|1\rangle)$. 노름 제곱이 ½이므로 확률 ½로 밥의 상태는 $a_0^*|0\rangle+a_1^*|1\rangle$이다. 밥의 임의의 직교 기저 $\{|b_k\rangle\}$에 대해 앨리스가 켤레 기저 $\{|b_k^*\rangle\}$(역시 직교)로 재면 밥에게 $|b_k\rangle$가 반씩 준비된다. 따라서 어떤 직교 기저든 준비할 수 있다.

**16.1.5.** $\Delta=\hat T-\hat T'$은 에르미트이고 모든 $\rho$에서 $\mathrm{Tr}(\rho\Delta)=0$이다. $\Delta$의 고유벡터 $|v\rangle$로 $\rho=|v\rangle\langle v|$를 잡으면 고윳값이 0이다. 모든 고윳값이 0인 에르미트 행렬은 0이므로 $\hat T=\hat T'$.

**16.1.6.** $U$가 $s$와 무관하면 $\rho_B'=\sum_kp_kU\psi_k\psi_k^\dagger U^\dagger=U\rho_BU^\dagger$로 분해와 무관하다. 가지 원천을 두어도 그것이 아무것도 바꾸지 않으므로 신호가 없다. 중력이 실제로 느껴진다는 전제 (B)가 있어야 가지 의존이 관측 가능한 차이를 만든다.

**16.1.7.**
```python
import math
import numpy as np
from scipy.linalg import expm

SX = np.array([[0, 1], [1, 0]], complex)
SZ = np.array([[1, 0], [0, -1]], complex)

def haar(rng):
    z = (rng.normal(size=(2, 2)) + 1j*rng.normal(size=(2, 2)))/math.sqrt(2)
    q, r = np.linalg.qr(z)
    return q*(np.diag(r)/np.abs(np.diag(r)))

def steer(psi, u):                       # 앨리스가 u의 열로 잴 때 밥의 (확률, 상태)
    m = psi.reshape(2, 2)
    out = []
    for k in range(2):
        v = u[:, k].conj() @ m
        p = float(np.vdot(v, v).real)
        out.append((p, v/math.sqrt(p)))
    return out

def bob(dec, rule, t=0.9):
    rho_b = sum(p*np.outer(v, v.conj()) for p, v in dec)
    out = np.zeros((2, 2), complex)
    for p, v in dec:
        r = np.outer(v, v.conj())
        s = np.real(np.trace((r if rule == "branch" else rho_b) @ SZ))
        U = expm(-1j*s*SX*t)
        out += p*U @ r @ U.conj().T
    return out

rng = np.random.default_rng(3)
worst = {"branch": 0.0, "weight": 0.0}
for _ in range(200):
    psi = rng.normal(size=4) + 1j*rng.normal(size=4); psi /= np.linalg.norm(psi)
    u1, u2 = haar(rng), haar(rng)
    for rule in worst:
        d = bob(steer(psi, u1), rule) - bob(steer(psi, u2), rule)
        worst[rule] = max(worst[rule], 0.5*np.abs(np.linalg.eigvalsh(d)).sum())
print(worst)   # branch 약 0.624, weight 약 1e-16
```
확률 무게 규칙의 값은 부동소수 오차 크기다. 가지 규칙의 최댓값은 난수에 따라 조금 달라진다.

## 16.2절

**16.2.1.** $1.5822\times10^{-4}/7.0\times10^{-4}=0.2260$, $1.5822\times10^{-4}/9.5\times10^{-4}=0.1666$ rad. $\Delta\phi=0.3516+0.1666-2\times0.2260=0.0661$ rad.

**16.2.2.** $\psi_{LL}=\alpha\gamma$, $\psi_{LR}=\alpha\delta$, $\psi_{RL}=\beta\gamma$, $\psi_{RR}=\beta\delta$. $\psi_{LL}\psi_{RR}-\psi_{LR}\psi_{RL}=\alpha\gamma\beta\delta-\alpha\delta\beta\gamma=0$.

**16.2.3.** 모든 $\phi_{ij}\propto Gm^2t/\hbar$이므로 $\Delta\phi\propto m^2t$. $\Delta\phi=1$을 얻으려면 $m=10^{-14}/\sqrt{0.06609}=3.890\times10^{-14}$ kg(시간 고정), 또는 $t=2.5/0.06609=37.83$ s(질량 고정).

**16.2.4.** B의 확률 분포 $\rho_B=\mathrm{diag}(p_L,p_R)$에서 A의 위치 $i$가 느끼는 퍼텐셜은 $\sum_jp_jV(r_{ij})=\mathrm{Tr}(\rho_B\hat V_i)$, $\hat V_i=\mathrm{diag}(V(r_{iL}),V(r_{iR}))$이다. 이것은 정리 A의 $\mathrm{Tr}(\rho\hat T)$ 꼴, 곧 B의 밀도행렬에 대한 선형 범함수다.

**16.2.5.** 얽힘 0은 중력을 고전 통로로 두는 모형 일반의 예측이므로, 선형 양자 중력을 이 형태로 기각할 뿐 렌더링 이론만을 지지하지는 않는다. 다른 고전 중력 모형들 가운데 일부는 대가로 추가 결어긋남이나 확산을 예측하므로, 같은 장치에서 질량의 결맞음 유지 시간(추가 결어긋남)과 가열을 함께 재면 가를 수 있다. 렌더링 이론은 자발 붕괴가 없으므로 추가 결어긋남이 없어야 한다.

**16.2.6.**
```python
import math
from scipy.optimize import brentq

G, hbar = 6.67430e-11, 1.054571817e-34
m, t, dx = 1e-14, 2.5, 250e-6
k = G*m*m*t/hbar

def conc(d):
    dphi = k/d + k/(2*dx + d) - 2*k/(dx + d)
    return abs(math.sin(dphi/2))

for d_um in (200, 300, 400, 450, 500, 600, 800, 1000):
    print(d_um, round(conc(d_um*1e-6), 4))
print(brentq(lambda d: conc(d) - 0.1, 50e-6, 450e-6)*1e6)   # 257.1 μm
```
출력: 200 μm 0.1563, 300 μm 0.0748, 450 μm 0.0330, 1000 μm 0.0053. $C=0.1$은 $d=257.1\ \mu$m에서다. 가까울수록 얽힘이 커지지만, 실제 실험에서는 카시미르 힘 같은 비중력 상호작용도 커진다.

## 16.3절

**16.3.1.** $\cosh^2\zeta-\sinh^2\zeta=\tfrac14[(e^\zeta+e^{-\zeta})^2-(e^\zeta-e^{-\zeta})^2]=1$은 복소수에서도 성립한다. 따라서 $g(w,w)=-1$.

**16.3.2.** $0.41421/1.23\times10^{-3}=336.8$. $\gamma=1/\sqrt{1-0.17157}=1.0987$.

**16.3.3.** $H_\Lambda=56.38\times10^3/3.0857\times10^{22}=1.827\times10^{-18}$ s⁻¹. $T=\dfrac{1.0546\times10^{-34}\times1.827\times10^{-18}}{2\pi\times1.3806\times10^{-23}}=2.221\times10^{-30}$ K.

**16.3.4.** $\Lambda(a)\Lambda(b)$의 대각 성분은 $\cosh a\cosh b+\sinh a\sinh b=\cosh(a+b)$, 비대각 성분은 $\sinh a\cosh b+\cosh a\sinh b=\sinh(a+b)$. 두 덧셈 정리는 지수함수로 쓰면 복소수에서도 그대로 성립한다. 따라서 $\Lambda(a)\Lambda(b)=\Lambda(a+b)$.

**16.3.6.** $\Delta t\approx(10^4/1.22\times10^{19})\times6.3\times10^{16}=52$ s. 도착 시각이 수 초 정밀도로 알려지면 지연은 수 초 이하이므로 $E_{\rm QG}$가 $E_{\rm Pl}$의 약 10배 이상이어야 한다. LHAASO의 한계 $E_{\rm QG,1}>10E_{\rm Pl}$과 같은 차수다.

## 16.4절

**16.4.1.** $3.844\times10^5/2.998\times10^5=1.282$ s.

**16.4.2.** 경로 정보가 되돌릴 수 없게 기록되면 A의 중첩은 결어긋남으로 혼합 상태가 되고, 기록이 B의 과거 빛원뿔에 들어간 뒤로는 B의 원천이 A의 실제 위치를 따른다. 그러나 A는 이미 결맞음을 잃었으므로 어떤 이론에서도 A–B 얽힘을 증언할 수 없다. BMV 실험은 경로 기록이 없어야 성립한다.

**16.4.3.** 앨리스가 $Z$로 재서 결과 $k$를 기록하면, 즉시 조건화 규칙에서 밥의 원천은 $\langle\psi_k|\hat T|\psi_k\rangle$, 곧 밥의 조건부 상태(가지 $k$)의 기댓값이다. 이것은 가지 무게 규칙의 정의와 같다. 4.4절의 계산을 그대로 쓰면 $Z$와 $X$ 사이 대각합 거리는 ½이다.

**16.4.4.** Page–Geilker에서 검출기 기록은 저울과 같은 실험실, 곧 저울의 과거 빛원뿔 안에 있다. "평균만" 규칙은 이 기록을 무시해 원천을 가운데에 두므로 상관 0을 예측하고 실험과 어긋난다. R1은 빛원뿔 안 기록으로 조건화하므로 원천이 실제 위치를 따라 상관 1을 예측한다. 실험은 기록의 **위치**(빛원뿔 안)를 시험하지 않았으므로 R1과 충돌하지 않는다.

**16.4.5.** 어긋나지 않는다. 기록의 신호가 $c$ 이하로 도착한 뒤에 원천이 바뀌는 것은 보통의 통신이다. 무신호 원리가 금지하는 것은 빛원뿔 **밖**에서의 영향이다.

**16.4.6.** $X=\pm1$(반반), 기록 여부 $B$(확률 $p$, $X$와 독립), $S=BX$. $E[XS]=E[B]E[X^2]=p$, $\mathrm{Var}X=1$, $\mathrm{Var}S=E[B]=p$이므로 상관 $=p/\sqrt p=\sqrt p$.
```python
import numpy as np

rng = np.random.default_rng(1)
n = 200000
X = rng.choice([-1, 1], n)
for p in (0.25, 0.5, 1.0):
    B = rng.random(n) < p
    S = np.where(B, X, 0)
    print(p, round(np.corrcoef(X, S)[0, 1], 3), round(p**0.5, 3))   # 0.5, 0.707, 1.0
```

## 16.5절

**16.5.1.** $D=\tfrac12\sin1.8=0.4869$. 무작위 검산의 0.624는 벨 쌍과 $Z/X$보다 신호를 더 크게 만드는 상태와 기저 쌍이 있음을 보여 준다.

**16.5.2.** 모든 가지가 같은 $s=\mathrm{Tr}(\rho_B^2)$를 느끼므로 밥의 평균 상태는 $\sum_kp_kU(s)\psi_k\psi_k^\dagger U(s)^\dagger=U(s)\rho_BU(s)^\dagger$이다. $\rho_B$는 앨리스의 선택과 무관하므로(무신호 정리) 평균 상태도 무관하다.

**16.5.3.** $\theta=\kappa t$. $v_0=(\cos\theta,\,-i\sin\theta)$, $v_1=(i\sin\theta,\,\cos\theta)$.
$v_0v_0^\dagger=\begin{pmatrix}\cos^2\theta&i\cos\theta\sin\theta\\-i\cos\theta\sin\theta&\sin^2\theta\end{pmatrix}$, $v_1v_1^\dagger=\begin{pmatrix}\sin^2\theta&i\sin\theta\cos\theta\\-i\sin\theta\cos\theta&\cos^2\theta\end{pmatrix}$. 평균은 대각 ½, 비대각 $\pm\tfrac i2\sin2\theta$로 본문과 같다.

**16.5.4.** 무신호 시험은 가지 무게를 나머지 셋과 가른다. Page–Geilker는 평균만을 나머지 셋과 가른다. BMV는 {평균만, QG1 + R1}(0)과 {가지 무게, 선형 양자 중력}(0.0330)을 가른다. 세 시험 모두에서 QG1 + R1과 같은 결과를 내는 모형은 있을 수 있다. 중력을 고전 장으로 두고 측정 기록에 반응하게 하는 모형들이 그렇다. 이들 가운데 일부는 추가 결어긋남이나 잡음을 예측하므로, 고립된 질량의 결맞음 시간과 가열을 재서 가른다(16.2절 한계).

**16.5.5.** HJW 정리로 앨리스는 측정 선택만으로 밥에게 같은 $\rho_B$의 서로 다른 순수 상태 모음을 준비할 수 있다. 선형 동역학은 모음이 아니라 $\rho_B$에만 작용하므로 차이를 볼 수 없다. 결정론적 비선형 동역학은 순수 상태마다 따로 작용하므로 모음이 다르면 결과의 평균이 달라질 수 있고, 밥은 그 차이를 통계로 읽어 앨리스의 선택을 알게 된다. "결정론적"이 중요한 것은 확률적 붕괴처럼 잡음을 더해 평균을 선형으로 되돌리는 동역학은 이 논증을 피할 수 있기 때문이다.

**16.5.6.**
```python
import math
import numpy as np

SX = np.array([[0, 1], [1, 0]], complex)
SZ = np.array([[1, 0], [0, -1]], complex)
I2 = np.eye(2)

def U(s, t):                                        # exp(-i s σx t)
    return math.cos(s*t)*I2 - 1j*math.sin(s*t)*SX

def haar(rng):
    z = (rng.normal(size=(2, 2)) + 1j*rng.normal(size=(2, 2)))/math.sqrt(2)
    q, r = np.linalg.qr(z)
    return q*(np.diag(r)/np.abs(np.diag(r)))

def bob_branch(psi, u, t):
    m = psi.reshape(2, 2); out = np.zeros((2, 2), complex)
    for k in range(2):
        v = u[:, k].conj() @ m; p = float(np.vdot(v, v).real); v = v/math.sqrt(p)
        r = np.outer(v, v.conj()); s = np.real(np.trace(r @ SZ))
        out += p*U(s, t) @ r @ U(s, t).conj().T
    return out

rng = np.random.default_rng(0)
for t in np.linspace(0, math.pi/2, 21)[::4]:
    worst = 0.0
    for _ in range(200):
        psi = rng.normal(size=4) + 1j*rng.normal(size=4); psi /= np.linalg.norm(psi)
        d = bob_branch(psi, haar(rng), t) - bob_branch(psi, haar(rng), t)
        worst = max(worst, 0.5*np.abs(np.linalg.eigvalsh(d)).sum())
    print(round(t, 3), round(worst, 3), round(0.5*abs(math.sin(2*t)), 3))
```
출력(열: $\kappa t$, 무작위 최댓값, 벨 쌍 값)은 0.314에서 0.254 대 0.294, 0.942에서 0.620 대 0.476, 1.571에서 0.725 대 0이다. 작은 $\kappa t$에서는 표본 200개가 벨 쌍의 $Z/X$ 값에 못 미친다. $\kappa t$가 커지면 벨 쌍보다 큰 신호를 주는 상태와 기저가 있다. $\kappa t=\pi/2$에서 벨 쌍의 $Z/X$ 신호는 0이지만 다른 상태와 기저는 여전히 신호를 준다. 모든 상태에서 신호가 사라지는 것은 $\kappa t=0$, 곧 되먹임이 없을 때뿐이다.
