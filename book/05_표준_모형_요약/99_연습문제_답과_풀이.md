## 5.1절

**5.1.1.** 글루온 8, $W^{1,2,3}$ 3, $B$ 1로 12개다. 대칭 깨짐 뒤 $W^\pm$(둘)와 $Z$가 질량을 얻고, 광자와 글루온은 질량이 없다.

**5.1.2.** 한 세대 16성분(색과 약 성분을 모두 셈) × 3세대 = 48.

**5.1.3.** $d^c$는 $SU(2)$ 단일항이라 $T_3=0$, $Y=\tfrac13$이므로 $Q=\tfrac13$(반아래 쿼크의 전하).

**5.1.4.** $e_L$은 $L$의 아래 성분: $T_3=-\tfrac12$, $Y=-\tfrac12$, $Q=-1$. $e_R$은 $e^c(Y=+1)$의 켤레: $T_3=0$, $Y=-1$, $Q=-1$. 같은 전하, 다른 $T_3$과 $Y$다.

**5.1.5.** $SU(n)$의 리 대수는 대각합이 0인 $n\times n$ 반에르미트 행렬(물리 관례로는 $i$를 곱한 에르미트 행렬)이다. $n\times n$ 에르미트 행렬은 실수 $n^2$개(대각 $n$ + 비대각 복소 $n(n-1)/2$개)이고, 대각합 0 조건이 하나를 뺀다. $n^2-1$이다.

**5.1.6.**
```python
from itertools import combinations
from fractions import Fraction as Fr
names = {(1, 1): "Q", (2, 0): "u^c", (2, 2): "d^c", (3, 1): "L", (0, 2): "e^c", (0, 0): "nu^c"}
colour = {0, 1, 2}
count = {}
for n in (0, 2, 4):
    for c in combinations(range(5), n):
        S = set(c); k = len(S & colour); j = len(S) - k
        Y = Fr(j, 2) - Fr(k, 3)
        count[(k, j, Y)] = count.get((k, j, Y), 0) + 1
for (k, j, Y), m in sorted(count.items()):
    print(names[(k, j)], (k, j), Y, m)
# Q (1,1) 1/6 6, u^c (2,0) -2/3 3, d^c (2,2) 1/3 3, L (3,1) -1/2 2, e^c (0,2) 1 1, nu^c (0,0) 0 1
```

## 5.2절

**5.2.1.** 모두 단일항($T_3=0$)이므로 $Q=Y$: $u^c$ $-\tfrac23$, $d^c$ $\tfrac13$, $e^c$ $1$.

**5.2.2.** $\mathbf3$: $Q$의 두 약 성분(두 개의 셋잇단). $\bar{\mathbf3}$: $u^c$, $d^c$(두 개). 수가 같으므로 $[SU(3)]^3$이 상쇄된다.

**5.2.3.** 색 셋잇단마다 $Y$를 약 성분 수로 곱해 더한다: $Q$ $2\cdot\tfrac16=\tfrac13$, $u^c$ $-\tfrac23$, $d^c$ $\tfrac13$. 합 0.

**5.2.4.** $6(\tfrac16)^3+3(-\tfrac23)^3+3(\tfrac13)^3+2(-\tfrac12)^3+1^3=\tfrac1{36}-\tfrac89+\tfrac19-\tfrac14+1=0$.

**5.2.5.** 중력: $6y+2(-3y)+3(-4y)+3(2y)+6y=0$. $[SU(2)]^2U(1)$: $3y-3y=0$. $[SU(3)]^2U(1)$: $2y-4y+2y=0$. $[U(1)]^3$: $6y^3-54y^3-192y^3+24y^3+216y^3=0$. 모두 0이다. 전하의 비는 이상 조건으로 정해지고, 전체 척도 $y$만 남는다.

**5.2.6.**
```python
from fractions import Fraction as Fr
# (이름, 색 차원, 약 차원, Y); 색 차원 3은 셋잇단, -3은 반셋잇단
gen = [("Q", 3, 2, Fr(1, 6)), ("u^c", -3, 1, Fr(-2, 3)), ("d^c", -3, 1, Fr(1, 3)),
       ("L", 1, 2, Fr(-1, 2)), ("e^c", 1, 1, Fr(1)), ("nu^c", 1, 1, Fr(0))]
def anomalies(fs):
    grav = sum(abs(c)*w*Y for _, c, w, Y in fs)
    y3 = sum(abs(c)*w*Y**3 for _, c, w, Y in fs)
    su2 = sum(abs(c)*Y for _, c, w, Y in fs if w == 2)
    su3 = sum(w*Y for _, c, w, Y in fs if abs(c) == 3)
    su3cube = sum(w*(1 if c == 3 else -1) for _, c, w, Y in fs if abs(c) == 3)
    return grav, y3, su2, su3, su3cube
print(anomalies(gen))                                   # 모두 0
print(anomalies([f for f in gen if f[0] != "e^c"]))     # grav -1, y3 -1
```
$e^c$를 빼면 중력–$U(1)$과 $[U(1)]^3$이 $-1$이 되어 깨진다. 색·약과 섞인 이상은 $e^c$가 단일항이라 영향이 없다.

## 5.3절

**5.3.1.** $1/0.118+1.2202\ln2=8.4746+0.8458=9.3204$, $\alpha_s=0.1073$.

**5.3.2.** $8.4746+1.2202\ln(1000/91.19)=8.4746+2.9225=11.3971$, $\alpha_s=0.0877$.

**5.3.3.** $11-\tfrac23n_f<0\iff n_f>16.5$, 곧 $n_f\ge17$. 그때 점근 자유성이 사라진다.

**5.3.4.** (5.3.3)에서 $\frac1{\alpha(\mu_0)}=\frac{b_0}{2\pi}\ln\frac{\mu_0}\Lambda$다. (5.3.2)에 넣으면 $\frac1{\alpha(\mu)}=\frac{b_0}{2\pi}\big(\ln\frac{\mu_0}\Lambda+\ln\frac\mu{\mu_0}\big)=\frac{b_0}{2\pi}\ln\frac\mu\Lambda$. ∎

**5.3.5.** $L=\ln\mu$로 두면 $\hat s^2$(어림)는 $L$에 선형이라 2차 도함수가 0이다. $4\alpha_s^{4/3}=4(A+BL)^{-4/3}$의 2차 도함수는 $4\cdot\tfrac43\cdot\tfrac73B^2(A+BL)^{-10/3}>0$이다. 두 함수가 어떤 구간 전체에서 같다면 2차 도함수도 같아야 하므로 불가능하다. 직선과 순볼록 함수는 많아야 두 점에서 만난다. 실제 흐름에서는 기울기 때문에 물리 범위 안의 교차가 하나뿐이다(09장의 정리 OE).

**5.3.6.**
```python
import math
MZ, A0 = 91.1876, 0.118
def alpha_s(target):
    inv = 1/A0
    lo, hi = sorted([MZ, target]); sign = 1 if target > MZ else -1
    edges = [lo] + [x for x in (4.2, 172.6) if lo < x < hi] + [hi]
    segs = list(zip(edges[:-1], edges[1:]))
    for a, b in (segs if sign > 0 else segs[::-1]):
        nf = 4 if math.sqrt(a*b) < 4.2 else (5 if math.sqrt(a*b) < 172.6 else 6)
        inv += sign*(11 - 2*nf/3)/(2*math.pi)*math.log(b/a)
    return 1/inv
for mu in (1, 2, 4.2, 10, MZ, 172.6, 1e3, 1e6, 1e10, 1e16):
    print(f"{mu:>10.4g} GeV  {alpha_s(mu):.4f}")
```

## 5.4절

**5.4.1.** $1/g^2+1/g'^2=\sin^2\theta_W/e^2+\cos^2\theta_W/e^2=1/e^2$.

**5.4.2.** 위 쿼크 $\tfrac12/(2\cdot\tfrac23)=\tfrac38$, 아래 쿼크 $-\tfrac12/(2\cdot(-\tfrac13))=\tfrac34$.

**5.4.3.** $\sqrt{1-0.22348}=0.88120$.

**5.4.4.** $s^2=\tfrac14$: $g_L=-\tfrac14$, $g_R=\tfrac14$, 왼손 확률 $\tfrac{1/16}{1/16+1/16}=\tfrac12$. $s^2=0.23129$: $g_L^2=0.072205$, $g_R^2=0.053495$, 왼손 확률 $0.5744$.

**5.4.5.** $\tfrac38$은 한 세대 전체 상태에 대한 대각합 비로, 대통일 척도의 경계값이다. $\tfrac14$은 전하 렙톤에 대한 Z의 결합이 순수 축벡터가 되는 $\sin^2\theta_W$다. 렌더링 이론에서는 두 사실이 만난다. 색 단일항(렙톤) 영역만의 대각합 비가 $\tfrac14$이고(3.5절), 그 값이 바로 Z가 전자를 공평하게 가르는 점이다. 이 둘이 09장의 "닻"이다.

## 5.5절

**5.5.1.** $1-(80.37/91.19)^2=1-0.77677=0.2232$.

**5.5.2.** $y_t=\sqrt2\times172.57/246.22=0.9912$. top의 유카와 결합은 거의 1이다.

**5.5.3.** $g^2+g'^2=0.42463+0.12776=0.55239$, $\lambda=0.55239\times1.374713^2/8=0.1305$. $M_H=\sqrt{2\lambda}\,v=125.78$ GeV. 이 값은 트리 $M_Z=91.50$ GeV에 $F$를 곱한 것과 같다($91.50\times1.3747=125.78$). 측정 $M_Z=91.19$ GeV로 계산한 $M_ZF=125.36$과의 차이는 트리 질량과 측정 질량의 차이(고리 보정)다. 렌더링 이론은 **측정 질량의 비**를 $F$로 둔다.

**5.5.4.** 행렬 $\frac{v^2}4\begin{pmatrix}g^2&-gg'\\-gg'&g'^2\end{pmatrix}$의 대각합은 $\frac{v^2}4(g^2+g'^2)$, 행렬식은 0이므로 고윳값은 0과 $\frac{v^2}4(g^2+g'^2)$이다. 고윳값 0의 고유벡터는 $(g',g)/\sqrt{g^2+g'^2}$(광자 $A=\sin\theta_WW^3+\cos\theta_WB$), 다른 하나는 $(g,-g')/\sqrt{g^2+g'^2}$(Z)다.

**5.5.5.** $V(x)=-\mu^2x+\lambda x^2$($x=|\Phi|^2$)의 최솟값은 $x=\mu^2/2\lambda=v^2/2$, $v^2=\mu^2/\lambda$. $\Phi^0=(v+h)/\sqrt2$로 두면 $V=-\tfrac{\mu^2}2(v+h)^2+\tfrac\lambda4(v+h)^4$이고 $h^2$의 계수는 $-\tfrac{\mu^2}2+\tfrac{6\lambda v^2}4=-\tfrac{\lambda v^2}2+\tfrac{3\lambda v^2}2=\lambda v^2$이다. 질량 항 $\tfrac12M_H^2h^2$와 비교하면 $M_H^2=2\lambda v^2$. ∎

**5.5.6.**
```python
import numpy as np
g, gp, v = 0.65164, 0.35744, 246.22
M2 = (v**2/4) * np.array([[g*g, 0, 0, 0], [0, g*g, 0, 0], [0, 0, g*g, -g*gp], [0, 0, -g*gp, gp*gp]])
w, V = np.linalg.eigh(M2)
print(np.sqrt(np.clip(w, 0, None)))          # [0, 80.22, 80.22, 91.50]
photon = V[:, np.argmin(w)]
print(photon / np.linalg.norm(photon), np.array([0, 0, gp, g]) / np.hypot(g, gp))   # 같은 방향(부호 제외)
```
질량 0인 방향 $(0,0,g',g)$는 $W^3$와 $B$를 $T_3$와 $Y$의 결합 세기에 맞춰 섞은 것, 곧 $Q=T_3+Y$에 결합하는 광자다.

## 5.6절

**5.6.1.** $\begin{pmatrix}c_{12}&s_{12}&0\\-s_{12}c_{23}&c_{12}c_{23}&s_{23}\\s_{12}s_{23}&-c_{12}s_{23}&c_{23}\end{pmatrix}$.

**5.6.2.** $\theta_C=\arcsin0.225=13.0^\circ$.

**5.6.3.** 행: $\tfrac23+\tfrac13+0$, $\tfrac16+\tfrac13+\tfrac12$, $\tfrac16+\tfrac13+\tfrac12$ 모두 1. 열: $\tfrac23+\tfrac16+\tfrac16$, $\tfrac13\cdot3$, $0+\tfrac12+\tfrac12$ 모두 1.

**5.6.4.** $s_{12}c_{12}=\tfrac12\sin2\theta_{12}\le\tfrac12$, $s_{23}c_{23}\le\tfrac12$, $|\sin\delta|\le1$이다. $f(x)=\sin x\cos^2x$의 최댓값은 $f'=\cos x(\cos^2x-2\sin^2x)=0$에서 $\tan^2x=\tfrac12$, 곧 $\sin x=1/\sqrt3$, $f=\tfrac1{\sqrt3}\cdot\tfrac23=\tfrac2{3\sqrt3}$이다. 따라서 $|J|\le\tfrac12\cdot\tfrac12\cdot\tfrac2{3\sqrt3}=\tfrac1{6\sqrt3}=0.0962$. ∎

**5.6.5.** 유니터리성에서 세 복소수의 합이 0이므로, 머리와 꼬리를 이으면 닫힌 삼각형이 된다. (5.6.3)의 각은 변 사이 각이므로 내각의 합은 $\pi$다.

**5.6.6.** (5.6.1)에서

$$|U_{\mu1}|^2-|U_{\tau1}|^2=(s_{12}^2-c_{12}^2s_{13}^2)(c_{23}^2-s_{23}^2)+4s_{12}c_{12}s_{23}c_{23}s_{13}\cos\delta .$$

$s_{23}^2=\tfrac12$이면 첫 항이 0이고 둘째 항은 $2s_{12}c_{12}s_{13}\cos\delta$이므로, TM1 조건은 $\cos\delta=0$, 곧 $\delta=90^\circ$ 또는 $270^\circ$를 요구한다. $s_{23}^2\ne\tfrac12$이면 첫 항이 0이 아니어서 $\cos\delta$가 그것을 상쇄하도록 움직인다. 그래서 TM1 아래서 $\delta$는 옥탄트에 묶인다(P29).

**5.6.7.**
```python
import numpy as np
from scipy.optimize import brentq
def U(s12sq, s23sq, s13sq, d):
    s12, s23, s13 = np.sqrt([s12sq, s23sq, s13sq]); c12, c23, c13 = np.sqrt(1 - np.array([s12sq, s23sq, s13sq]))
    e = np.exp(1j*d)
    return np.array([[c12*c13, s12*c13, s13/e],
                     [-s12*c23 - c12*s23*s13*e, c12*c23 - s12*s23*s13*e, s23*c13],
                     [s12*s23 - c12*c23*s13*e, -c12*s23 - s12*c23*s13*e, c23*c13]])
a = (0.318517, 0.455551, 0.0222244)
M = U(*a, np.radians(258.76))
print(np.abs(M.conj().T @ M - np.eye(3)).max(), np.imag(M[0, 0]*M[1, 1]*np.conj(M[0, 1])*np.conj(M[1, 0])))
f = lambda d: abs(U(*a, np.radians(d))[1, 0])**2 - abs(U(*a, np.radians(d))[2, 0])**2
print(brentq(f, 181, 359))   # 258.76
```
행렬은 유니터리이고 $J=-0.0332$다. TM1 조건을 만족하는 $\delta$는 $258.76^\circ$다(반대 방향 해 $101.24^\circ$는 $[0^\circ,180^\circ]$에 있다).
