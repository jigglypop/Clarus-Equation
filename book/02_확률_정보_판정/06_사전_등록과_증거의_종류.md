# 2.6 사전 등록과 증거의 종류

> **요지.** 이론의 증거는 세 층이다. 구현이 식과 맞는다(구현), 규칙들이 서로 맞물린다(일관성), 보기 전의 예측을 자연이 확인한다(물리). 사전 등록은 셋째 층을 가능하게 하는 장치다.

## 학습 목표

1. 증거의 세 층을 구분하고 예를 들 수 있다.
2. 사전 등록 파일의 구조와 해시 잠금을 설명할 수 있다.
3. 기각 조건을 문구 그대로 적용하는 이유를 설명할 수 있다.
4. 독립 예측을 세는 규칙을 적용할 수 있다.

## 본문

### 증거의 세 층

**정의 2.6.1 (증거의 층).**

| 층 | 무엇을 보이나 | 예 | 자연에 대한 증거인가 |
|---|---|---|---|
| 구현 | 코드가 식을 올바르게 계산한다 | 테스트 통과, 두 알고리즘의 일치 | 아니다 |
| 일관성 | 이론의 규칙들이 서로 모순되지 않는다 | 렙톤 규칙의 $\alpha_s$와 E4의 $\alpha_s$가 $-0.23\sigma$로 맞음 | 아니다(필요조건) |
| 물리 | 보기 전의 예측이 관측과 맞는다 | 동결 뒤 발표된 측정이 등록값과 맞음 | 그렇다 |

일관성은 필요조건이다. 일관성이 깨지면 이론은 틀렸다. 그러나 일관성만으로는 이론이 옳다고 할 수 없다. 틀린 이론도 내부적으로 일관될 수 있기 때문이다.

**보류 자료(holdout).** 규칙을 만들 때 쓰지 않은 자료로 시험하는 것은 첫째와 셋째의 중간이다. 자료가 동결 전에 나왔더라도 규칙 선택에 쓰지 않았다면, 과적합의 위험을 어느 정도 덜어 준다. 이 책에서는 Pantheon 초신성 40구간과 H0DN 거리망이 보류 자료다. 보류 자료 확인은 예측 적중으로 세지 않는다.

### 사전 등록 파일

사전 등록 파일은 JSON이고, 다음 칸을 갖는다.

| 칸 | 내용 |
|---|---|
| `manifest_id` | 판본 이름(예: v24) |
| `supersedes_manifest_id` | 이전 판본 |
| `freeze` | 동결 날짜, 고침 정책("이 파일은 고치지 않는다") |
| `model` | 식과 규칙, 모듈 해시 |
| `predictions` | 예측 목록(번호, 관측량, 값, 규칙, 판정 실험, 기각 조건) |
| `deltas_from_…` | 이전 판본에서 바뀐 것 |
| `manifest_sha256` | 이 칸을 뺀 나머지의 정규 JSON 해시 |

**해시의 성질.** SHA-256은 임의 길이의 입력을 256 bit로 바꾸는 함수다. 입력이 한 글자만 바뀌어도 출력의 약 절반의 bit가 바뀌고, 같은 출력을 주는 다른 입력을 찾는 것은 현실적으로 불가능하다. 그래서 해시가 맞으면 파일이 바뀌지 않았다고 믿을 수 있다.

**정규 JSON.** 같은 내용도 공백이나 키 순서에 따라 문자열이 달라진다. 그래서 해시 전에 정해진 방식으로 직렬화한다(키 정렬, 구분자 `,` `:`, 한글 그대로).

### 기각 조건의 문구

기각 조건은 **등록 문구 그대로** 적용한다. 결과를 본 뒤 "이 분석은 해당하지 않는다"고 해석을 바꾸면, 어떤 예측도 죽지 않는다.

예를 들어 P17의 기각 조건은 "95% 우주론 상한이 55 meV 아래"였다. 2026년 발표된 한 분석(ΛCDM, 질량 0부터의 사전분포)이 52 meV를 주었다. 같은 논문의 다른 판본(위계 사전분포)은 92 meV를 주었다. 등록 문구는 모형과 사전분포를 지정하지 않았으므로, "하나라도 55 아래이면 충족"으로 읽고 **기각**했다. 이것이 이론에 불리한 쪽의 읽기다.

### 독립 예측

**정의 2.6.2 (독립 예측).** 두 예측이 같은 관측으로 같은 값을 판정하면, 둘을 합쳐 하나의 독립 예측으로 센다. 다른 예측의 값에서 파생된 예측도 독립으로 세지 않는다.

v24의 41개 가운데 P20(=$\alpha_s$ 행), P33(P14·P25에서 파생), P38(P20과 같은 값, 다른 기록)이 독립이 아니고, P17은 기각이다. 독립 예측은 37개다.

### 판본과 개정

잠근 파일은 고치지 않는다. 오타, 정의의 모호함, 새 자료 점검, 지위 변화는 모두 다음 판본의 `deltas`에 적는다. 예를 들어 v17은 새 예측 없이 "$\sin^2\theta_W$는 PDG의 top 떼어냄 MS-bar 값"이라는 정의만 명시한 판본이다. 떼어내지 않은 MS-bar 값을 쓰면 P36이 $+4.2\sigma$가 되므로, 이 모호함은 중요했다.

## 예제

**예제 2.6.1** 다음은 어느 층의 증거인가? (가) 레지스트리의 $\Omega_m$과 가지치기 몬테카를로의 $\Omega_m$이 같다. (나) 렙톤 질량비에서 뽑은 $\alpha_s$가 $\hat s^2$에서 뽑은 $\alpha_s$와 맞는다. (다) 2027년 JUNO 최종 $\Delta m^2_{21}$이 등록값 $7.403\times10^{-5}$와 맞는다.

*풀이.* (가) 구현: 같은 식을 두 방법으로 계산했다. (나) 일관성: 이론의 두 규칙이 맞물린다. (다) 물리: 동결 뒤의 측정이 등록값과 맞았다.

**예제 2.6.2** 한 관측이 등록값을 $2.5\sigma$ 벗어났다. 기각 조건이 "$3\sigma$ 배제"라면 판정은?

*풀이.* 기각 조건이 충족되지 않았으므로 기각이 아니다. 다만 "긴장"으로 기록하고, 다음 측정을 기다린다. 기각 조건을 결과를 본 뒤 $2\sigma$로 낮추거나 $4\sigma$로 높이지 않는다.

## 요약

- 증거에는 구현, 일관성, 물리의 세 층이 있고, 물리의 증거만 자연에 대한 증거다.
- 사전 등록 파일은 정규 JSON의 SHA-256으로 잠그고, 고치지 않는다.
- 기각 조건은 등록 문구 그대로 적용한다.
- 같은 관측으로 같은 값을 판정하는 예측은 하나로 센다.
