## 2.1절

**2.1.1.** $H=-\tfrac12\log_2\tfrac12-2\cdot\tfrac14\log_2\tfrac14=\tfrac12+2\cdot\tfrac14\cdot2=1.5$ bit.

**2.1.2.** $f=\mu^{-1}e^{-t/\mu}$이므로 $-\ln f=\ln\mu+t/\mu$다. $h=\langle-\ln f\rangle=\ln\mu+\langle t\rangle/\mu=\ln\mu+1$.

**2.1.3.** 1 bit는 결과 둘의 균등 분포의 엔트로피이므로 $\ln2=0.6931$ nat이다. 1 nat $=1/\ln2=1.4427$ bit다.

**2.1.4.** 반정규 밀도 $f(t)=\frac{2}{\sigma\sqrt{2\pi}}e^{-t^2/2\sigma^2}$($t\ge0$)의 평균은 $\sigma\sqrt{2/\pi}$다. 이것이 1이면 $\sigma^2=\pi/2$다. $-\ln f=\ln\frac{\sigma\sqrt{2\pi}}2+\frac{t^2}{2\sigma^2}$이고 $\langle t^2\rangle=\sigma^2$이므로

$$h=\ln\frac{\sigma\sqrt{2\pi}}2+\frac12=\frac12\ln\frac{\pi\sigma^2}{2}+\frac12=\frac12\ln\frac{\pi^2}4+\frac12=\ln\frac\pi2+\frac12=0.9516 .$$

**2.1.5.** $K=\ln\mu+t/\mu$이므로 $C=\mathrm{Var}(K)=\mathrm{Var}(t)/\mu^2=\mu^2/\mu^2=1$이다. $S=1+\ln\mu$이므로 $C/S=1$은 $\mu=1$일 때뿐이다. 곧 시간 단위를 시계의 평균 틱으로 잡을 때다. (미분 엔트로피는 단위에 의존한다. 17장의 화소 시계는 "평균 한 틱"을 단위로 쓴다.)

**2.1.6.** $t\sim$감마(2, 척도 ½)를 $t=u/2$, $u\sim$감마(2, 1)로 쓴다. $-\ln f=-\ln4-\ln t+2t$이고 $\langle t\rangle=1$, $\langle\ln t\rangle=\langle\ln u\rangle-\ln2=\psi(2)-\ln2=(1-\gamma)-\ln2$다. 여기서 $\langle\ln u\rangle=\int_0^\infty ue^{-u}\ln u\,du=1-\gamma$를 썼다. 따라서

$$h=-2\ln2-(1-\gamma)+\ln2+2=2-\ln2-(1-\gamma)=0.8841 .$$

**2.1.7.** (1) 구간 $[0,L]$의 균등 밀도 $u=1/L$과 임의의 $f$에 대해 $0\le D(f\|u)=\int f\ln(fL)=-h(f)+\ln L$이다. 등호는 $f=u$. (3) 평균 $m$, 분산 $\sigma^2$인 가우스 $g$에 대해 $-\int f\ln g=\tfrac12\ln(2\pi\sigma^2)+\langle(x-m)^2\rangle/2\sigma^2=\tfrac12\ln(2\pi\sigma^2)+\tfrac12$이다. 이것은 $f$가 같은 평균과 분산을 가지면 $f$에 무관하다. $0\le D(f\|g)=-h(f)+\tfrac12\ln(2\pi e\sigma^2)$이므로 $h(f)\le\tfrac12\ln(2\pi e\sigma^2)$이고 등호는 $f=g$. ∎

**2.1.8.**
```python
import numpy as np
from scipy import integrate
f = lambda t: 4*t*np.exp(-2*t)
K = lambda t: -np.log(f(t))
S = integrate.quad(lambda t: f(t)*K(t), 1e-12, 60)[0]
K2 = integrate.quad(lambda t: f(t)*K(t)**2, 1e-12, 60)[0]
print(S, K2 - S**2, np.pi**2/6 - 1)   # 0.8841 0.6449 0.6449
```
해석적으로는 $u=2t\sim$감마(2,1)에서 $K=-\ln2-\ln u+u$이므로 $C=\mathrm{Var}(u)+\mathrm{Var}(\ln u)-2\mathrm{Cov}(u,\ln u)=2+\psi'(2)-2=\psi'(2)=\pi^2/6-1$이다. 감마($k$,1)에서 $\mathrm{Cov}(u,\ln u)=k[\psi(k+1)-\psi(k)]=1$, $\psi'(2)=\pi^2/6-1$을 썼다. $C/S=0.73$이므로 지수 시계만 $C/S=1$이다.

## 2.2절

**2.2.1.** 평균 2초이므로 $\lambda=0.5$/초다. $P(T>5)=e^{-2.5}=0.0821$.

**2.2.2.** $P(T_2<T_1)=\int_0^\infty f_{T_2}(t)P(T_1>t)\,dt=\int_0^\infty\mu e^{-\mu t}e^{-\lambda t}dt=\mu\Big[\frac{-e^{-(\lambda+\mu)t}}{\lambda+\mu}\Big]_0^\infty=\frac\mu{\lambda+\mu}$.

**2.2.3.** 정리 2.2.4로 전체 빠르기는 $30\times0.1=3$이다. 1 단위 시간 안에 사건이 없을 확률은 $e^{-3}=0.0498$이다.

**2.2.4.** $P=\mu/(\lambda+\mu)$, $1-P=\lambda/(\lambda+\mu)$이므로 $P/(1-P)=\mu/\lambda$.

**2.2.5.** $G(t)=P(T>t)$는 단조 감소, $G(0)=1$, $0<G<1$($t>0$)이고 $G(s+t)=G(s)G(t)$를 만족한다. $\phi=-\ln G$로 두면 $\phi(s+t)=\phi(s)+\phi(t)$이고 $\phi$는 단조 증가다. 단조인 코시 방정식의 해는 선형뿐이므로 $\phi(t)=\lambda t$, 곧 $G(t)=e^{-\lambda t}$다. ∎

**2.2.6.** $G(s)=\sum_ke^{-\lambda}\frac{(\lambda s)^k}{k!}=e^{-\lambda}e^{\lambda s}=e^{\lambda(s-1)}$. $G'(1)=\langle N\rangle=\lambda$, $G''(1)=\langle N(N-1)\rangle=\lambda^2$이므로 $\mathrm{Var}(N)=\lambda^2+\lambda-\lambda^2=\lambda$.

**2.2.7.** $e^m-1=m+m^2/2+m^3/6+\cdots$, $m/(1-m)=m+m^2+m^3+\cdots$다. 세 규칙은 1차($X\approx m$)에서 같고 2차에서 갈린다. $m=0.3747$에서 경주 0.3747, 창 0.4546, 재귀 0.5993이다. 2차 항의 크기가 $m^2\approx0.14$이므로 자료가 쉽게 가른다.

**2.2.8.**
```python
import numpy as np
rng = np.random.default_rng(0)
n, m = 100_000, 0.374713
t_self = rng.exponential(1.0, n)
t_cap = rng.exponential(1.0/m, n)
p = np.mean(t_cap < t_self)
print(p, np.sqrt(p*(1-p)/n), m/(1+m))   # 약 0.273, 0.0014, 0.27258
```
표준 오차는 $\sqrt{p(1-p)/n}=0.0014$이므로 모의 결과는 공식과 $1\sigma$ 안에서 맞는다.

## 2.3절

**2.3.2.** 이론(73.36)이 관측(71.6)보다 크므로 위쪽 오차 $\sigma_+=3.9$를 쓴다. $(73.36-71.6)/3.9=+0.45$.

**2.3.3.** $\sqrt{(0.0081+1.1236+2.0164)/3}=\sqrt{1.0494}=1.02$.

**2.3.4.** $\langle p^4\rangle=\frac1{\sqrt{2\pi}}\int x^4e^{-x^2/2}dx$다. 부분적분으로 $\int x^3\cdot xe^{-x^2/2}dx=3\int x^2e^{-x^2/2}dx=3\sqrt{2\pi}$이므로 $\langle p^4\rangle=3$이다.

**2.3.5.** $r^TC^{-1}r=\frac{1\cdot1-0.5\cdot1\cdot(-1)\cdot2+1\cdot1}{0.75}=\frac{1+1+1}{0.75}=4$. 두 관측이 양의 상관을 가지면 같은 방향으로 어긋나기 쉽고 반대 방향으로 어긋나기 어렵다. 반대 방향 잔차는 더 놀라우므로 $\chi^2$이 크다.

**2.3.6.** $z=L^{-1}r$이라 하자. $r$의 공분산이 $C$이면 $z$의 공분산은 $L^{-1}C(L^{-1})^T=L^{-1}LL^T(L^T)^{-1}=I$다. 가우스 벡터에서 공분산이 단위행렬이면 성분은 서로 독립인 표준정규 변수다. $|z|^2=r^T(L^{-1})^TL^{-1}r=r^TC^{-1}r$이다. ∎

**2.3.7.**
```python
from scipy import stats
print(stats.chi2.sf(27.14, 39), stats.chi2.sf(35.21, 39))   # 0.924 0.643
```
두 값 모두 자유도 39에서 흔히 나올 만한 $\chi^2$이다. 규칙 사슬이 적합을 개선했지만(p값 0.64 → 0.92), 사슬 없이도 긴장은 없다. 적합이 좋아진 것과 규칙이 옳은 것은 다른 문제이므로 가설 비용(2.5절)을 함께 따진다.

## 2.4절

**2.4.1.** $1-0.99^{10}=0.0956$, $1-0.99^{100}=0.634$.

**2.4.2.** $-\log_20.27=1.89$ bit.

**2.4.3.** 창의 로그 폭은 $2\times0.001/\ln10=8.7\times10^{-4}$ 자릿수다. 11자릿수 가운데 이 폭에 들 확률은 $8.7\times10^{-4}/11=7.9\times10^{-5}$이다.

**2.4.4.** $1-(1-p)^N\approx Np-\binom N2p^2\approx Np(1-Np/2)$이므로 $Np/P_{\rm 우연}\approx1+Np/2$다. 10% 안이려면 $Np\lesssim0.2$다.

**2.4.5.** (가)에서는 식이 관측과 독립으로 정해졌으므로, 관측이 맞을 확률은 식이 틀렸다면 작다. 적중은 증거다. (나)에서는 여러 식 가운데 관측에 맞는 것을 골랐으므로, 식이 모두 틀렸어도 하나쯤은 맞는다. 적중의 증거 가치는 가족 우연 확률로 깎이고, 목격 후라면 증거로 세지 않는다.

**2.4.6.**
```python
import numpy as np
rng = np.random.default_rng(1)
lam = 0.0193
fam = lam * np.exp(-np.arange(9))
for lo in (-6.0, -4.5):
    x = 10 ** rng.uniform(lo, -3, 200_000)
    hit = np.any(np.abs(fam[None, :] - x[:, None]) <= 0.27 * x[:, None], axis=1)
    print(lo, hit.mean())    # 약 0.44, 약 0.56
```
하한을 $10^{-6}$에 두면 가족의 가장 작은 값($\lambda e^{-8}=6.5\times10^{-6}$)보다 작은 과녁이 섞여 적중률이 내려간다. 하한을 올리면 적중률이 올라간다. 과녁 범위를 결과를 본 뒤 고르면 우연 확률을 원하는 방향으로 바꿀 수 있다. 그래서 범위는 계산 전에 원리로 정한다(예: 효과가 0이 아님을 이미 안다면 $3\sigma$ 이상의 크기에서만 과녁을 뽑는다). 이 가족에서는 어느 범위로 하든 우연 적중이 흔하므로, $e$ 사다리의 적중은 증거가 되지 않는다.

```python
import math
def bits(x, sigma, decades=20):
    wide = math.log2(x * math.log(10**decades) / sigma)
    narrow = math.log2(x / sigma)
    return wide, narrow
print(bits(127.951, 0.030))               # (17.6, 12.1)
print(bits(2.0167e-17, 2.0167e-17*2.9e-4))  # (17.3, 11.8)
```

**2.6.6.**
```python
import hashlib, json
def self_hash(path):
    d = json.load(open(path, encoding="utf-8"))
    body = {k: v for k, v in d.items() if k != "manifest_sha256"}
    text = json.dumps(body, sort_keys=True, separators=(",", ":"), ensure_ascii=False)
    return hashlib.sha256(text.encode("utf-8")).hexdigest() == d["manifest_sha256"]
print(self_hash("experiments/preregistration/rendering_predictions_v24.json"))   # True
```
