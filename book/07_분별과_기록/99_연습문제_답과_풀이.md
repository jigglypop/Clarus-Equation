## 7.1절

**7.1.1.** $2^5=32$. 정확히 둘이 참인 세계는 $\binom52=10$.

**7.1.2.** $k_B\ln2=1.381\times10^{-23}\times0.6931=9.57\times10^{-24}$ J/K. 엔트로피 비용은 온도와 무관하다(열로는 $Tk_B\ln2$).

**7.1.3.** (1) $m$번째 축을 포함하는 부분집합은 나머지 $m-1$개 축의 부분집합 하나에 $m$번째 축을 더한 것이므로 $2^{m-1}$개. (2) $(2^m-1)-(2^{m-1}-1)=2^{m-1}$. ∎

**7.1.4.** GHZ 상태에서는 한 큐비트의 값이 다른 두 큐비트에 복사되어 있다. R2는 이것을 기록으로 보고, 기록된 명제에는 결맞음이 없어야 한다고 말한다. 그러나 실험은 세 큐비트 전체의 결맞음($|000\rangle\langle111|$)이 유지됨을 보여 준다. 따라서 R2를 공리로 쓰면 관측과 모순된다.

**7.1.5.** R1이 없으면 멀리 떨어진 곳의 기록이 여기의 물리(예: 중력의 원천)를 즉시 바꿀 수 있다. 그러면 기록을 만드는 선택(예: 측정 기저)으로 빛보다 빠른 신호를 보낼 수 있다(4.4절의 가지 규칙과 같은 문제). R1은 이런 신호를 막는다. 16장에서 R1은 QG1과 빛의 한계에서 강제됨을 본다.

## 7.2절

**7.2.1.** $n=4$에서 ODD는 여전히 ½이다($n\ge1$이면 늘 ½). MAJ(3개 이상)는 $\binom43+\binom44=5$개로 $\tfrac5{16}$이다. $n$이 짝수이면 "정확히 반"인 세계가 있어 MAJ와 그 여집합(소수)이 대칭이 아니다.

**7.2.2.** 첫째와 둘째가 모두 참인 세계는 $\{1,2\},\{1,2,3\}$의 2개, 확률 $\tfrac28=\tfrac14$.

**7.2.3.** $n$이 홀수이면 $|S|=n/2$인 세계가 없으므로 모든 세계는 과반 참이거나 소수 참이다. 여집합은 $|S|$를 $n-|S|$로 보내 과반과 소수를 맞바꾸는 전단사다. 두 사건의 크기가 같고 합이 전체이므로 각각 ½이다. ∎

**7.2.4.** {V, EXACT$_1$, MAJ}가 분할이라 확률의 합이 1이고, $\pi$를 곱한 합이 $\pi$라서 세 각이 삼각형의 내각이 될 수 있다. MAJ의 확률은 여집합 대칭(정리 7.2.1) 때문에 정확히 ½이므로 한 각은 $\pi/2$, 곧 직각이다. 나머지 둘($\tfrac18$, $\tfrac38$)은 세기로 정해진다.

**7.2.5.** $n=3$에서 여섯 사건과 그 여사건의 확률은 $\tfrac18$(V, A, EXACT$_0$, EXACT$_3$), $\tfrac38$(EXACT$_1$, EXACT$_2$), $\tfrac12$($M_k$, ODD, MAJ), 그리고 여사건의 $\tfrac78$, $\tfrac58$뿐이다. $\tfrac28$, $\tfrac68$은 나오지 않는다. 어휘가 모든 값을 덮는다면 어떤 계수든 사후에 "사건 하나로 읽을" 수 있어 사전이 아무것도 말하지 않는다. 덮는 값이 제한되어 있으므로, 계수가 이 값에 떨어지는지는 적어도 시험할 수 있는 성질이다. 다만 규칙들이 처음부터 이 세기로 만들어졌으므로 증거가 아니라 일관성이다.

**7.2.6.**
```python
from itertools import combinations
for n in (3, 4, 5):
    W = [set(c) for k in range(n + 1) for c in combinations(range(n), k)]
    P = lambda f: sum(1 for S in W if f(S)) / len(W)
    print(n, "V", P(lambda S: not S), "M1", P(lambda S: 0 in S), "ODD", P(lambda S: len(S) % 2),
          "EX1", P(lambda S: len(S) == 1), "MAJ", P(lambda S: len(S) > n/2))
# 3 V 0.125 M1 0.5 ODD 0.5 EX1 0.375 MAJ 0.5
# 4 V 0.0625 M1 0.5 ODD 0.5 EX1 0.25 MAJ 0.3125
# 5 V 0.03125 M1 0.5 ODD 0.5 EX1 0.15625 MAJ 0.5
```

## 7.3절

**7.3.1.** $\delta=p(1-p)$는 $p=\tfrac12$에서 최대 $\tfrac14$.

**7.3.2.** $1+2+4=7=2^3-1$은 비어 있지 않은 부분집합의 수다. 세 단계에서 "나"가 참인 세계를 모두 모으면, 빈 세계(진공 V)를 뺀 모든 세계가 한 번씩 나온다.

**7.3.3.** 여집합은 색 축 $k$개를 $3-k$개로, 약 축 $j$개를 $2-j$개로 보낸다.

| 한 세대 | $(k,j)$ | 여집합 $(3-k,2-j)$ | 전하 |
|---|---|---|---|
| $Q$ | $(1,1)$ | $(2,1)$ | $\tfrac23,-\tfrac13\to-\tfrac23,\tfrac13$ |
| $u^c$ | $(2,0)$ | $(1,2)$ | $-\tfrac23\to\tfrac23$ |
| $d^c$ | $(2,2)$ | $(1,0)$ | $\tfrac13\to-\tfrac13$ |
| $L$ | $(3,1)$ | $(0,1)$ | $0,-1\to0,1$ |
| $e^c$ | $(0,2)$ | $(3,0)$ | $1\to-1$ |
| $\nu^c$ | $(0,0)$ | $(3,2)$ | $0\to0$ |

모든 전하가 뒤집히고, 짝수 블록은 홀수 블록으로 간다.

**7.3.4.** $v=(-1,-1,2)/\sqrt6$과 TBM 열의 내적(절댓값)은 $(2,-1,-1)/\sqrt6$과 $|{-2}+1-2|/6=0.5$, $(1,1,1)/\sqrt3$과 0, $(0,-1,1)/\sqrt2$와 $|0+1+2|/\sqrt{12}=0.866$이다. 최대 겹침이 1이 아니므로 어느 열과도 같지 않다. "나 = 1세대"일 때만 대비 벡터가 TBM의 열이 된다.

**7.3.5.** 독립으로 두 번 뽑으면 (나, 아닌 나) 또는 (아닌 나, 나)가 나올 확률은 $2p(1-p)$다. 그 절반이 $p(1-p)=\delta$다.

## 7.4절

**7.4.1.** $g_L=-\tfrac14$, $g_R=\tfrac14$이라 $P_L=P_R=\tfrac12$, $\langle\gamma_5\rangle=0$.

**7.4.2.** $|\Delta|=1/(M_Z\Gamma_Z)=1/(91.1876\times2.4955)=4.39\times10^{-3}$ GeV⁻². 위상 $-90^\circ$(순허수).

**7.4.3.** 광학 정리는 산란 진폭의 앞방향 허수부가 전체 단면적(실제로 일어난 모든 과정의 확률)에 비례한다는 정리다. 확률 보존(유니터리성) $S^\dagger S=I$에서 나온다. $S=I+iT$로 쓰면 $-i(T-T^\dagger)=T^\dagger T$, 곧 $2\,\mathrm{Im}\,T=T^\dagger T\ge0$이다. 오른쪽은 실제 나간 상태로의 확률의 합이므로, 허수부는 "실제로 일어나 기록을 남긴 과정"과 이어진다. 공명의 극에서는 진폭이 순허수이므로 공명이 실제 입자로 만들어지고 붕괴한 기록만 남는다.

**7.4.4.** $(0.11792-0.1221)/0.0027=-1.55\sigma$. 오차 0.0001이면 $-0.00418/0.0001=-42\sigma$로 RS 읽기는 기각된다. 곧 FCC-ee는 이 예측을 결정적으로 가른다.

**7.4.5.** RS가 틀리고 관계가 $M_W$ 척도에서 성립한다면, 측정한 $\hat s^2$로부터 흐름을 거쳐 예측한 $\alpha_s(M_Z)$는 0.11548이 되어 세계 평균과 $-2.8\sigma$로 어긋난다(9장의 표). 또 Z 극 기록의 $\alpha_s$와도 맞지 않는다. $\alpha_s$의 정밀 측정이 척도를 가른다. 다만 9장에서 보듯, 이 표는 E4를 $M_Z$에서 찾았으므로 순환의 성격이 있다.

## 7.5절

**7.5.1.** $x=0.1x+1$에서 $x^*=1/0.9=10/9$. $g'=0.1$이므로 오차는 한 걸음마다 0.1배(부호 유지)다.

**7.5.2.** $0.0605^n=10^{-12}$에서 $n=\ln10^{-12}/\ln0.0605=9.85$, 곧 10걸음.

**7.5.3.** $e_n=x_n-x^*$로 두면 $e_{n+1}=g(x^*+e_n)-g(x^*)\approx g'(x^*)e_n$. $g'(x^*)<0$이면 $e_{n+1}$과 $e_n$의 부호가 반대다. ∎

**7.5.4.** $\delta(r)=4r^4-16r^8$, $\delta'=16r^3-128r^7$. $\lambda'(r)=\frac{3r^2}{2\pi}\big(1+\frac\delta{2\pi}\big)+\frac{r^3}{(2\pi)^2}\delta'$. $r^*=0.490352$에서 $r^2=0.24044$, $r^3=0.11790$, $r^7=0.006816$, $\delta=0.17779$, $\delta'=1.0140$이므로 $\lambda'=0.11800+0.00303=0.12103$, $g'=-\tfrac12\lambda'=-0.0605$.

**7.5.5.** $1/(1-m)=1+m+m^2+\cdots$다. 자기(1)에 붙잡힌 몫 $m$이 다시 자기가 되어 $m^2$을 붙잡고, 그것이 또 $m^3$을 붙잡는 식이다. "결합마다 새 자기가 생긴다"는 뜻이다. SS는 붙잡힌 것은 자기가 아니므로 한 번에 멈춘다고 읽고, 자료는 $1+m$(한 걸음)을 고른다($1/(1-m)$은 $M_H$에서 $+188\sigma$).

**7.5.6.**
```python
import math
import numpy as np
from scipy.optimize import brentq
def lam(r):
    s2 = 4*r**4; d = s2*(1 - s2)
    return r**3/(2*math.pi)*(1 + d/(2*math.pi))
g = lambda r: 0.5*(1 - lam(r))
rs = brentq(lambda r: r - g(r), 0.3, 0.6)
r, errs = 0.5, []
for _ in range(5):
    errs.append(r - rs); r = g(r)
print(rs, errs)            # 0.490352, [+9.65e-3, -5.96e-4, +3.60e-5, -2.18e-6, +1.32e-7]
h = 1e-7
gp = lambda r: (g(r + h) - g(r - h))/(2*h)
xs = np.linspace(1e-4, 2**-0.5, 20001)
print(max(abs(gp(x)) for x in xs), gp(rs))   # 0.0986, -0.0605
```
