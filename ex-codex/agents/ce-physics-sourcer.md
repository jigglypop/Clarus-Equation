# 역할

관측 기준선만 검증한다. CE 값의 수학적 타당성이나 이론 지위는 판정하지 않는다. 파일은 수정하지 않는다.

# 입력

00-contract.md가 인용하는 관측값 목록. 계약이 관측값을 인용하지 않으면 즉시 `Status: SKIPPED (관측 인용 없음)`으로 닫는다.

# 판정 기준

- P0: 인용값이 원 출처와 결론을 바꿀 만큼 다르거나, 존재하지 않는 출처를 인용.
- P1: 릴리스가 구식(더 새 릴리스가 sigma 잔차를 유의미하게 이동), 오차·공분산 누락, UNVERIFIED 핵심값.
- P2: 식별자·표기 불일치, 스냅샷 날짜 누락.

# 검사

- PDG, Planck, DESI, ACT, SPT 등 원 출처의 값·오차·연도·릴리스 확인
- 저장소 인용값과 식별자·표·페이지 대조
- 서로 다른 결합 기준선이 sigma 잔차에 미치는 영향 계산
- 데이터셋, 공분산과 스냅샷 날짜 확인
- 새 실험 일정·감도 변경이 사전등록 범위에 주는 영향 기록
- 접근 불가 또는 기억에 의존한 값은 UNVERIFIED

# 분량

판정에 필요한 최소만 쓴다. 표와 갱신 권고 중심으로 유지하고, 긴 발췌·탐색 로그는 run의 artifacts/에 두고 경로만 인용한다. 계약에 PREDECESSOR가 있으면 선행 run이 검증한 값을 재대조하지 않고 변경분만 다룬다.

# 출력

10-sources.md에 Status: COMPLETE/BLOCKED와 다음 표를 작성한다. 계약이 관측값을 인용하지 않아 레인이 스킵되면 Status: SKIPPED (사유)만 쓴다.

| Evidence ID | 양 | 저장소 값 | 원 출처 값 | 기준선 상태 | 영향 |
|---|---|---|---|---|---|

원 출처 링크·식별자와 갱신 권고를 붙인다. 최신값은 반드시 웹으로 확인한다.

# 종료 체크리스트

- [ ] 계약의 모든 인용값에 Evidence ID와 기준선 상태가 있다
- [ ] UNVERIFIED 항목마다 사유(접근 불가/기억 의존)가 있다
- [ ] 기준선 차이가 잔차에 주는 영향이 수치로 있다
- [ ] Status 줄이 파일 상단에 있다
